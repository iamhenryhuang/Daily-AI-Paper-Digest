### 1. Tool-Calling LLM Agents Under Realistic MCP Faults: Scale Does Not Purchase Fault Tolerance

- arXiv: [2610.32555v1](http://arxiv.org/abs/2610.32555v1)
- 發表日期：2026-10-23
- 分類：cs.SE, cs.AI
- 入選理由：+2 提及頂級機構：mit, openai; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #1 / 9/10: Introduces a novel, realistic fault-injection benchmark for LLM agents calling external tools, revealing critical brittleness not addressed by scale alone; strong empirical evidence and open code; addresses an important 

**Intro:** 本論文探討大型語言模型（LLM）代理在使用外部工具時，透過Model Context Protocol（MCP）進行工具調用時面臨的真實故障問題。現有的基準測試多假設工具能正確且及時回應，忽略了工具故障對代理性能的影響。作者提出MCP-Injector，一種可插拔且協議感知的故障注入中介軟體，能模擬真實MCP生態系統中觀察到的故障模式與持續性，並評估不同模型規模與代理框架在故障下的表現差異。

**Motivation:** 隨著LLM代理越來越依賴外部工具，工具的可用性與正確性成為系統整體可靠性的關鍵。然而，現有評測忽略了工具調用過程中可能出現的各種故障，導致代理在實際部署時可能因工具故障而性能大幅下降。理解代理在真實故障條件下的韌性，對工程實踐和產品穩定性至關重要。此外，是否透過擴大模型規模能提升故障容忍度，亦是業界關注的問題。

**Method:** 作者從1,774個公開MCP工具伺服器的GitHub倉庫中挖掘57,240個issue與pull request討論串，利用LLM分類故障模式與持續性，建立一個以真實故障分布為基礎的故障模型。MCP-Injector作為代理與工具伺服器間的中介軟體，能根據該模型注入六種故障類型（如錯誤輸出、延遲回應、無回應等）並控制故障的持續性（永久、暫時、間歇）。實驗涵蓋兩種模型規模（20B與120B）、三種代理框架（自訂計劃執行、多輪OpenAI Agents SDK、LangChain）及三種故障條件，進行1350個實驗單元的全因子分析。

**Result:** 實驗結果顯示，根據真實故障分布注入的永久性故障導致任務完成分數平均下降60%，從8.08降至3.23分。兩種模型規模在故障下的韌性無顯著差異，120B模型在故障條件下的任務完成率反而略低於20B（91.1%對95.6%），且故障暴露率較高。三種代理框架在故障響應策略上差異明顯，LangChain表現出較高的完成率與韌性，OpenAI Agents SDK較易因故障中斷，顯示框架層級的錯誤處理策略對韌性影響大於模型規模。

**Conclusion:** 本研究提出的MCP-Injector提供了一種基於真實生態系統故障分布的協議感知故障注入方法，能有效評估LLM代理在工具調用過程中的韌性。結果表明，現有能力基準測試可能掩蓋代理在實際運行中面臨的脆弱性，且擴大模型規模並不保證提升故障容忍度。代理框架的錯誤處理設計對提升系統穩定性更為關鍵。該工具及實驗方法對工程部署前的壓力測試具有實用價值，但仍需針對多伺服器協調及長期任務進行擴展。

**Research Gap:** 本論文的故障模型基於公開GitHub問題報告，存在報告偏差，可能高估永久性故障比例，對暫時性與間歇性故障的覆蓋不足。實驗僅涵蓋兩個同系列模型與三種代理框架，缺乏跨模型家族與多樣化部署環境的驗證。任務設定以單伺服器且相對簡單的工具調用為主，未涵蓋多伺服器協同與更複雜長期任務場景。故障注入雖控制持續性，但未充分探討故障對代理內部推理與重試策略的長期影響。此外，代理框架錯誤處理與工具調用頻率的交互作用未完全解耦，導致故障暴露與錯誤處理效果難以獨立評估。最後，成本、延遲與部署風險等實務面向未深入討論。

### 2. Can LLM Annotators Match Human Consistency? Benchmarking Human Agreement and Optimizing Multi-Agent with Contrastive Knowledge

- 分數：7
- arXiv: [2610.32415v1](http://arxiv.org/abs/2610.32415v1)
- 發表日期：2026-10-23
- 分類：cs.CL
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：emnlp; +2 提及程式碼可用; LLM rank #2 / 8/10: Presents a new multi-annotator benchmark reflecting real-world annotation complexity and a multi-agent framework improving alignment with human distributions; solid empirical gains and code release; advances annotation r

**Intro:** 本論文針對現有大型語言模型（LLM）自動標註系統在真實世界標註任務中面臨的挑戰進行探討。現有標註基準多半缺乏詳細的任務指引，且僅提供單一標準答案，無法反映標註者間的合理分歧。這導致單一代理或靜態多代理系統難以適應複雜且不斷演變的標註規則。為此，作者提出ANT-A基準，包含7個跨領域多模態資料集，每筆資料有5位獨立人類標註，並附有詳細指引，能評估模型標註與人類標註分布的一致性。並提出ANT-OR多代理框架，透過對比知識挖掘與迭代優化提升標註品質。

**Motivation:** 真實世界標註任務通常包含複雜且冗長的指引，且標註者間在邊界案例上可能有合理分歧，現有基準無法反映這種多樣性，限制了自動標註系統的評估與發展。此外，單一代理系統難以處理細緻且多變的判斷標準，多代理系統雖有潛力，但多數仍為靜態設計，缺乏將標註經驗結構化並持續優化的能力。這些問題阻礙了LLM標註系統在工程與產品層面的落地與可靠性提升。

**Method:** 作者建構ANT-A基準，收集7個跨領域資料集，每筆資料由5位專業標註者獨立標註，並設計詳細且經過反覆澄清的標註指引，確保標註分歧反映真實任務難度。提出ANT-OR框架，採用多代理架構，包括三個獨立標註代理與一個審核代理。核心方法為對比知識挖掘：從正負樣本對中抽取判斷維度，形成結構化決策規則，並結合質量感知的樣本檢索，將實例與規則注入提示中。透過錯誤歸因識別責任代理，針對性優化代理提示，並迭代擴充知識庫，實現多代理間的協同優化。

**Result:** 在ANT-A基準上，ANT-OR在7個資料集均優於單一代理及其他多代理基線，平均agreement@≥2準確率提升4.5個百分點，且Fleiss’ κ指標顯示其與人類標註分布的一致性接近人類標註者間的一致性。消融實驗證實判斷維度挖掘與對比三元組構造對性能提升關鍵，且質量感知檢索優於隨機或僅語義相似檢索。分析顯示ANT-OR在標註者共識較低的模糊案例中提升更明顯，且相較於強基線SPO，ANT-OR泛化能力更佳。成本分析指出ANT-OR雖增加計算開銷，但帶來顯著性能提升。

**Conclusion:** 本論文提出ANT-A多標註者基準與ANT-OR多代理優化框架，成功縮小LLM自動標註與人類標註一致性的差距。ANT-A基準結合詳細指引與多標註者標註，提供更貼近真實任務的評估環境。ANT-OR透過結構化對比知識與錯誤歸因驅動的提示優化，提升多代理系統在複雜標註任務中的表現。實驗結果證明該方法在多領域多模態任務中均有穩定優勢。限制包括基準覆蓋範圍仍有限、優化成本較高，以及對底層LLM能力依賴較大，未來可朝擴展基準多樣性與提升效率方向發展。

**Research Gap:** 本研究雖涵蓋多領域與多模態，但ANT-A基準仍未涵蓋長文本標註、開放式判斷及更專業領域工作流程，限制了對更廣泛真實場景的評估。ANT-OR的多代理結構與迭代優化雖提升性能，但帶來較高計算與成本負擔，缺乏針對效率優化的深入探討。實驗中未明確說明在極端低共識案例或標註失敗案例的表現與風險，泛化到更複雜任務的穩定性仍待驗證。此外，方法高度依賴底層LLM的推理與檢索能力，對不同模型架構或規模的適應性與可擴展性尚未充分評估。未來工作應聚焦於擴展基準多樣性、降低優化成本及強化泛化與穩定性分析。

### 3. IGG: A Benchmark for Interactive GUI Grounding under Visibility Constraints

- 分數：5
- arXiv: [2610.32536v1](http://arxiv.org/abs/2610.32536v1)
- 發表日期：2026-10-23
- 分類：cs.AI
- 入選理由：+3 提及頂級會議：emnlp; +2 提及程式碼可用; LLM rank #3 / 7/10: Proposes a novel benchmark for interactive GUI grounding under realistic visibility constraints, exposing a key bottleneck in interaction execution; strong empirical human and model studies with actionable insights and c

**Intro:** 本論文針對現有 GUI grounding 評測多半假設目標元素在靜態截圖中可見的限制，提出一個新的基準 Interactive GUI Grounding (IGG)。IGG 旨在評估代理是否能在目標可見前，透過互動使其顯示出來，然後再定位並點擊目標。此基準涵蓋 601 個任務，16 個可控 GUI 環境，並定義七種可見性限制子類型，動作空間包含滾動、移動、拖曳、等待與點擊。透過此基準，作者希望填補現有靜態 grounding 與完整導航任務中未明確分離的可見性恢復能力評估缺口。

**Motivation:** 現有 GUI grounding 研究多聚焦於靜態截圖中目標定位，忽略了現實介面中目標可能隱藏、被遮擋或需互動才能顯示的情況。這種可見性限制在實際工程與產品中普遍存在，若代理無法有效恢復目標可見性，則無法完成後續操作。IGG 透過明確分離可見性恢復與目標定位兩階段，提供一個可驗證且重現的評測環境，有助於研究者釐清模型失敗原因，並推動互動式 GUI 代理的能力提升，對於實際部署與用戶體驗優化具重要意義。

**Method:** IGG 將任務定義為四階段流程：選擇揭露目標的互動動作、在正確位置執行該動作、辨識目標元素、最後定位點擊。前兩階段合稱為可見性恢復。代理在每一步接收截圖、指令與歷史動作，從五種原子動作（SCROLL、MOVE、DRAG、WAIT、CLICK）中選擇執行。任務涵蓋三大類可見性限制：視窗範圍限制、多狀態限制與時間/操作限制，並在 16 個模擬真實應用的 deterministic GUI 環境中執行。評估以點擊是否命中目標元素 ID 為成功標準，並限制動作次數以衡量效率。作者同時設計人類實驗與多模型基線比較，並透過行為克隆與線上強化學習優化模型互動策略。

**Result:** 實驗結果顯示人類參與者在 IGG 任務中達到 94.6% 成功率，GPT-5.5 商業模型達 79.4%，而最佳開源視覺語言模型（如 Qwen3-VL、GUI-Owl-1.5）僅約 31.6%。介入實驗發現，告知模型應採取何種互動動作僅略微提升準確率（約 3%），但直接替模型執行揭露動作則大幅提升至約 82%，顯示主要瓶頸在於互動動作的選擇與執行，而非目標辨識。透過行為克隆加上基於線上回饋的強化學習，模型在可見性恢復能力上有顯著提升，且跨三種架構均有一致進步。不同子類型任務中，拖曳類動作最難學習且基線模型幾乎不使用，經訓練後才開始有效執行。

**Conclusion:** 本論文提出 IGG 基準，明確將 GUI grounding 任務拆解為可見性恢復與目標定位兩階段，填補現有評測中忽略的互動揭露能力。實驗揭示目前模型在互動執行階段存在明顯不足，且透過行為克隆與線上強化學習可有效提升此能力。IGG 不僅提供一個可重現且細緻的評測平台，也為後續研究聚焦於互動策略學習與執行提供基礎。限制方面，IGG 目前使用 deterministic 模擬環境，雖經人類評估確認具備高度真實感，但仍無法完全取代真實介面測試，且未明確討論模型在更複雜或動態環境下的泛化能力。

**Research Gap:** 本研究雖在模擬環境中提供了可見性恢復的細緻評測，但缺乏對真實動態網頁或多變介面的深入驗證，泛化性尚未充分證明。模型訓練依賴人類標註的成功軌跡，對於未見過的互動模式或複雜操作可能表現有限。實驗中動作空間雖緊湊，但對於更複雜的多步驟互動策略、錯誤恢復機制或長期規劃能力未有探討。此外，成本與延遲問題在商業模型中顯著，對實際部署仍具挑戰。消融實驗主要聚焦於動作選擇與執行，對語言理解與指令解析的影響未充分分離分析。最後，失敗案例與錯誤類型分析較為簡略，缺乏對模型失效原因的深入定量研究。

### 4. DRIVE: Fine-tuning via Data Contribution- and Diversity-aware Weighting with Prior Regularization

- 分數：5
- arXiv: [2610.32501v1](http://arxiv.org/abs/2610.32501v1)
- 發表日期：2026-10-23
- 分類：cs.LG
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #4 / 7/10: Offers a principled, theoretically grounded data weighting framework for fine-tuning balancing forgetting and adaptation, with strong empirical results and code; addresses a practical and important problem in continual l

**Intro:** 本論文聚焦於單階段微調中常見的災難性遺忘問題，尤其在無法取得原始預訓練資料的情況下更為嚴重。現有資料加權方法多偏重於新任務適應或知識保留其中一方，缺乏一套能同時兼顧兩者的統一可微分目標函數。此外，樣本多樣性與樣本特性等輔助訊號難以納入現有加權框架。為此，作者提出DRIVE，一種結合資料貢獻、多樣性與先驗正則化的加權方法，旨在平衡穩定性與可塑性，並提升微調的效率與魯棒性。

**Motivation:** 微調是深度學習中提升下游任務表現的關鍵技術，但在無法存取預訓練資料的實務場景中，災難性遺忘依然是瓶頸。現有方法多在參數空間或樣本空間進行調控，但缺乏一個能同時考量樣本對保留舊知識與學習新任務貢獻的原則性機制。且多樣性與樣本特性訊號難以以可微分方式整合，限制了端到端優化與理論分析。這對工程與產品部署造成挑戰，因為缺乏有效的樣本加權策略會導致模型性能不穩定且收斂緩慢。

**Method:** DRIVE方法核心在於將樣本貢獻分解為抗遺忘與任務適應兩部分，透過Shapley值的加法性原理實現權重分配的可調節平衡。多樣性則以基於特徵協方差行列式的可微分正則項表示，促進樣本集的代表性與覆蓋度。樣本特性則透過KL散度作為先驗分布的正則化，避免與任務貢獻混淆。整體權重透過一個統一的可微分目標函數優化，並以固定點迭代求解，結合隨機投影降低計算成本，適用於高維特徵。該方法理論上保證收斂且提升穩定性與收斂速度。

**Result:** 在多個視覺與大型語言模型微調任務中，DRIVE相較於標準微調、FLOW、DEFT-UCS等強基線展現出更佳的整體性能與更快的收斂速度。視覺任務中，DRIVE在CIFAR-10/100及Flowers102等資料集上平均提升2%以上的準確率，且有效減少災難性遺忘。語言模型微調中，DRIVE在Gemma-2-2B及Llama系列模型上提升了目標任務與通用能力的綜合表現，且統計檢定顯示改進具顯著性。消融實驗證明各組件均對性能有正向貢獻，且多樣性正則化能加速收斂並提升參數估計的穩定性。

**Conclusion:** 本論文提出的DRIVE框架成功整合了樣本貢獻的抗遺忘與適應分解、多樣性可微分正則化及先驗分布正則化，形成一個統一且可端到端優化的樣本加權方法。理論分析與實驗結果均支持其在穩定性與可塑性間取得更佳平衡，提升微調效率與魯棒性。DRIVE可作為模組整合至多種微調策略，對視覺與語言模型皆有實質效益。全文未明確說明在更大規模資料或多任務連續學習場景的表現。

**Research Gap:** 本研究雖在多種模型與資料集上驗證DRIVE效果，但仍缺乏對更大規模資料集及多任務連續學習場景的實驗，限制其泛化性評估。對於先驗分布的選擇與多樣性正則化強度的調整，全文未提供自動化或自適應策略，可能增加實務調參負擔。固定點迭代求解雖理論收斂，但在極高維度或超大批次下的計算成本與效率仍需進一步探討。此外，對失敗案例或極端樣本的行為分析不足，對工程部署風險評估有限。最後，全文未明確說明在非分類任務或其他損失函數下的適用性。

### 5. SCI-AGENT-EXAM: Benchmarking Agents on Scientific Research Tasks

- 分數：4
- arXiv: [2610.32441v1](http://arxiv.org/abs/2610.32441v1)
- 發表日期：2026-10-23
- 分類：cs.CL
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #5 / 6/10: Introduces a comprehensive, workflow-oriented scientific research benchmark with hybrid evaluation and detailed agent analysis; valuable for scientific AI agent evaluation though less methodological novelty.

**Intro:** 本論文針對大型語言模型（LLM）代理在科學研究工作流程中的能力評估問題，提出一個名為SCI-AGENT-EXAM的基準測試。現有的科學代理評估多聚焦於特定科學任務或能力，缺乏對多樣化研究活動的系統性評估。SCI-AGENT-EXAM涵蓋11個科學領域及7種研究任務類型，並要求代理同時產出可執行的程式碼與文本報告，提供更全面的能力檢測。

**Motivation:** 科學研究工作流程複雜且多樣，代理不僅需產出正確答案，還需生成可執行的分析程式與科學解釋文本。現有基準多半未同時評估這些多元交付物，且缺乏對代理執行過程中效率與穩定性的分析。為了推動科學代理在工程與產品落地的實用性，必須建立一套能全面反映代理在真實科學工作流程中表現的評估框架。

**Method:** SCI-AGENT-EXAM基於科學工作流程任務分類（SWTT），將科學任務分為文獻綜述、假設驗證、工具協調、程式碼生成、端到端分析、錯誤診斷與結果解釋七類。每個任務由領域專家設計，包含明確的科學目標、執行環境與評估標準。評估採用混合協議，結合程式化的自動驗證（針對可執行產物）與經專家校準的LLM判分（針對文本報告）。此外，透過追蹤代理執行軌跡，分析其解決方案的進展與穩定性。

**Result:** 在120個任務上評測10款先進LLM代理，GPT-6 Astra表現最佳，總分達80.9分，但僅26%的執行達到0.95以上的高成功率。不同模型在科學領域與任務類型上展現明顯差異，部分模型在文獻綜述表現較佳，另一些則在工程或材料科學領域較強。執行與報告品質不完全一致，多數代理報告表現優於程式執行結果。軌跡分析顯示高分代理較早達成高質量解決方案且回退較少。成本與效率分析指出高價模型在總成本與執行時間上仍具競爭力。

**Conclusion:** SCI-AGENT-EXAM提供一個涵蓋多科學領域與任務類型的綜合評估框架，能同時衡量代理的程式執行正確性與科學報告品質，並分析執行過程的穩定性與效率。此基準有助於推動科學代理技術向更全面、穩定且高效的方向發展，對工程實施與產品化具有指導意義。論文也強調，評估科學代理需超越單一任務結果，關注整體工作流程的表現。

**Research Gap:** 本研究主要評估通用基礎模型在標準化代理設定下的表現，尚未涵蓋具備專業領域工具、記憶管理或多階段規劃能力的專門科學代理。任務雖涵蓋多領域，但仍有限於120個任務，未涵蓋所有科學工作流程變化與複雜場景。評估中對失敗案例、泛化能力及長期迭代研究能力的分析不足。混合評估方法雖兼顧多種交付物，但對文本判分的主觀性與一致性仍有待進一步驗證。未明確說明代理在實際部署中可能面臨的成本與風險。未提供對比不同代理架構或工具整合策略的消融實驗。
