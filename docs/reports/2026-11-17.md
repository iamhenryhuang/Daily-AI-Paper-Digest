### 1. Newton-PINet: A fast physics-informed neural network with Newton linearization for meta-learning nonlinear PDEs

- 分數：7
- arXiv: [2611.20609v1](http://arxiv.org/abs/2611.20609v1)
- 發表日期：2026-11-16
- 分類：cs.LG, cs.AI, cs.CE, physics.comp-ph
- 入選理由：+2 提及頂級機構：meta, mit; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #1 / 9/10: Newton-PINet offers a novel, well-evidenced meta-learning framework for nonlinear PDEs with significant practical speed and accuracy gains, supported by strong benchmarks and public code.

**Intro:** 本論文聚焦於解決非線性偏微分方程（PDEs）在科學計算中的挑戰，特別是針對物理知識神經網絡（PINNs）在優化困難及泛化能力有限的問題。傳統數值方法計算成本高昂，且現有深度學習方法如資料驅動的運算子學習需大量標註資料，而PINNs則面臨訓練時間長與非凸優化問題。作者提出Newton-PINet，一種結合牛頓線性化與跳接層的物理知識神經網絡，旨在提升非線性PDE的元學習效率與泛化能力。

**Motivation:** 非線性PDE的求解在工程與科學模擬中極為重要，但現有PINNs在非線性問題上收斂緩慢且泛化能力不足，限制了其在實際產品與研究中的應用。資料驅動方法雖能快速預測，卻依賴大量標註數據，成本高昂且缺乏物理一致性。元學習PINNs雖可快速適應新任務，但多數仍依賴梯度優化，速度慢且不穩定。Newton-PINet透過牛頓線性化加速非線性迭代，並利用跳接層與Tikhonov正則化實現快速且穩定的輸出層更新，解決了上述瓶頸。

**Method:** Newton-PINet採用多層神經網絡結構，透過跳接層將所有隱藏層輸出串接至輸出層，提升模型非線性表達能力。輸出層權重以Tikhonov正則化的最小二乘法求解，實現無梯度快速更新。訓練分兩階段：第一階段以梯度下降元學習隱藏層權重及超參數，第二階段在推理時僅調整輸出層權重，透過牛頓線性化加速非線性最小二乘迭代，顯著提升收斂速度與穩定性。此方法等價於正則化Gauss-Newton法，具近二次收斂特性。

**Result:** 在多種非線性PDE基準測試中，Newton-PINet相較於傳統PINet及資料驅動DNN展現出更快的收斂速度與更低的測試誤差。以Burgers方程為例，Newton-PINet在6次非線性迭代下測試MSE達1.79×10^-6，遠優於PINet的1.10×10^-4。與多種神經運算子方法比較，Newton-PINet在訓練時間減少數小時至數分鐘的同時，測試誤差降低數個量級。對1D非線性反應擴散問題，Newton-PINet使用16倍少的訓練任務，測試誤差比基線低約三個量級，且推理時間顯著縮短。此外，模型在不同邊界條件與不規則幾何形狀下均展現良好泛化能力。

**Conclusion:** Newton-PINet提出一種結合牛頓線性化與跳接層的物理知識神經網絡架構，實現了非線性PDE的高效元學習與快速泛化。其優勢包括計算效率高、資料需求低及泛化準確度優異，適合於少樣本及即時模擬場景。該方法在多維度、多類型非線性PDE問題中均獲得顯著性能提升，並且推理速度遠超傳統梯度優化方法，具備實際工程與科學計算應用潛力。

**Research Gap:** 本研究主要聚焦於1D至3D空間維度的PDE，對於更高維度或多物理場耦合系統，因矩陣規模龐大及GPU記憶體限制，尚未充分驗證其效能與可擴展性。牛頓線性化雖加速收斂，但對初始猜測敏感，全文中僅提供簡單緩解策略，缺乏系統性分析。此外，時間分塊策略雖提升長時間動態預測精度，但在區塊邊界存在誤差漂移，且無法實現單次預測，限制了對混沌系統的長期模擬能力。未來需針對大規模稠密矩陣求解優化、時間整合方法改進及更複雜PDE場景的泛化能力進行深入研究。

### 2. EVIDENT: Evaluating Evidence Grounding in GUI Agents

- 分數：7
- arXiv: [2611.20488v1](http://arxiv.org/abs/2611.20488v1)
- 發表日期：2026-11-16
- 分類：cs.AI, cs.HC
- 入選理由：+2 提及頂級機構：meta; +3 提及頂級會議：acl; +2 提及程式碼可用; LLM rank #2 / 8/10: EVIDENT introduces a novel, evidence-grounded benchmark for GUI agents revealing critical evaluation gaps, with clear metrics and human-curated data, highlighting practical reliability issues.

**Intro:** 本論文針對現有GUI代理評估方法的盲點提出質疑，指出目前多以任務完成度作為成功標準，但這種表面成功可能掩蓋了代理未能基於實際觀察到的網頁證據來支持其回答的問題。作者提出EVIDENT，一個以證據為驅動的評測基準，包含220個涵蓋語義基礎、語境推理與視覺基礎的英韓雙語真實任務，並配有人工作證據元資料以明確指定必須驗證的資訊。此基準透過三種指標分別衡量任務完成、證據觀察與聲明支持，揭示了現有代理在證據基礎成功率上與表面成功率間存在顯著差距。

**Motivation:** 在實際應用中，使用者的需求往往含糊且需代理推理隱含條件，若代理僅依賴內部知識生成答案而未驗證網頁上的實際證據，可能導致錯誤或虛構資訊，影響系統的可靠性與用戶信任。現有評估多忽略代理是否真正觀察並利用了網頁證據，僅以結果是否合理為標準，無法反映代理的真實決策過程。故本研究強調不僅要評估代理是否完成任務，更要評估其是否基於可觀察的證據來支持最終回答，這對工程實踐中提升代理的透明度與可驗證性具有重要意義。

**Method:** EVIDENT基於三大任務類型設計：語義基礎、語境推理與視覺基礎，分別對應用戶意圖與網站資訊間的語義不匹配、隱含條件推理及非文字視覺線索。每個任務配有人工作成的證據元資料，明確列出代理必須觀察的證據項目。評估流程分三步：首先由判斷模型從代理的截圖中抽取可觀察證據；其次將代理最終回答的聲明與證據元資料映射至抽取證據；最後判斷這些證據是否支持最終聲明。三個指標分別為任務成功率(TSR)、證據成功率(ESR)及基於證據的成功率(GSR)，用以區分表面成功與證據支持的成功。

**Result:** 實驗涵蓋220個英韓雙語任務，評測多款商業及開源GUI代理。結果顯示商業代理在任務成功率上明顯優於開源代理，但在證據成功率與基於證據的成功率上均有大幅下降，尤其在語境推理與視覺基礎任務中差距更為顯著。評估模型與人類標註者間達到約91%的高一致性，證明自動評估的可靠性。分析指出許多表面成功的回答缺乏必要證據支持，存在虛構成功與聲明未充分基於證據的隱藏失敗，且證據基礎成功率隨任務難度增加而下降。

**Conclusion:** 本研究提出EVIDENT基準，明確區分GUI代理的表面任務完成與基於證據的回答支持，揭示現有代理在證據驗證方面的不足。結果強調未來代理設計與評估應重視證據收集與聲明驗證，提升系統的可靠性與透明度。該基準提供了多語言、多任務類型的真實場景測試，對推動GUI代理在實際應用中更嚴謹的行為評估具有價值。

**Research Gap:** 本研究限制於英韓雙語及特定網站，語言與網站差異可能影響結果泛化，且未提供跨語言或跨網站的嚴格控制比較。證據元資料由人工標註，可能未涵蓋所有有效證據路徑，存在標註偏差風險。評估依賴大型語言模型判斷，對視覺證據的抽取與解讀仍有誤差，尤其視覺基礎任務中判斷一致性較低。任務截圖基於代理執行時捕捉，無法反映網站動態變化，限制了長期重現性。最後，證據基礎成功定義較為嚴格，可能低估結合常識推理的合理答案，未充分考慮用戶滿意度或實際任務效用。未來工作可增強多元證據路徑標註、提升視覺證據抽取精度，並擴展至更多語言與動態網站環境。

### 3. MSAR: Next-Scale Autoregressive Forecasting for Time Series via Modular Multi-Scale Decoupling

- 分數：7
- arXiv: [2611.20714v1](http://arxiv.org/abs/2611.20714v1)
- 發表日期：2026-11-16
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #3 / 8/10: MSAR proposes a novel modular multi-scale autoregressive framework for time series forecasting with strong empirical improvements and broad applicability, backed by extensive experiments and code.

**Intro:** 時間序列預測在金融、能源、醫療和交通等多個關鍵領域具有重要應用價值。現有深度學習模型多採用單一時間尺度的建模，忽略了時間序列中存在的多尺度異質性，導致模型難以有效捕捉不同時間解析度下的特徵，進而影響預測準確度。過去多尺度方法多集中於輸入端的多尺度混合，卻未能解決輸入與輸出尺度不一致的問題。本文提出的MSAR框架，旨在通過模組化的多尺度自回歸方法，實現輸入與輸出在多尺度上的對齊與分離建模，提升預測性能。

**Motivation:** 單尺度預測模型無法充分捕捉時間序列中跨尺度的異質性模式，導致模型泛化能力不足。現有多尺度方法雖然在輸入端引入多尺度信息，但最終預測仍停留在單一細粒度尺度，造成輸入與輸出尺度不匹配，增加學習難度並降低預測效果。多解析度解碼器雖嘗試生成多尺度中間結果，但缺乏對每個尺度的明確監督，無法充分利用多尺度信息。基於此，MSAR提出了嚴格的尺度對齊和逐層自回歸預測策略，解決多尺度輸入輸出不一致的問題，並通過模組化設計支持多種骨幹模型，方便工程和產品部署。

**Method:** MSAR將時間序列分解為多個尺度，對每個尺度獨立建模，並通過自回歸方式從粗尺度逐步細化到細尺度預測。每個尺度的預測模組接收該尺度的輸入及來自粗尺度的預測作為上下文，進行缺失值插補式的細化預測。訓練採用兩階段策略，先用教師強制學習以穩定收斂，再切換到推理一致的輸入以減少暴露偏差，並對所有尺度的預測結果進行全窗口監督。該框架模組化且與骨幹模型無關，可靈活集成CNN、MLP、Transformer等多種架構。

**Result:** 在多個公開數據集（如ECL、ETT、Exchange、Traffic、Weather等）及五種主流骨幹模型（SimpleTM、DUET、iTransformer、PatchTST、DLinear）上，MSAR均顯著提升了預測準確度，尤其在具有強週期性和長預測時段的數據集上效果更為明顯。實驗中，MSAR在保持或降低推理延遲的同時，提升了模型的泛化能力和穩定性。消融實驗證明多尺度、尺度對齊及尺度自回歸三者的協同作用是性能提升的關鍵。敏感度分析顯示MSAR對尺度間隔和層數選擇具有較強魯棒性。訓練時間較基線模型增加約1.67倍，但帶來更穩定的收斂和更低的推理延遲。

**Conclusion:** 本文提出的MSAR框架通過嚴格的多尺度輸入輸出對齊和逐層自回歸預測，有效解決了傳統時間序列預測中尺度不匹配和長期依賴捕捉不足的問題。其模組化設計支持多種骨幹模型，便於工程集成與部署。實驗結果證明MSAR在多數數據集和模型上均帶來穩定的性能提升，特別是在長期預測和強週期數據上表現突出。該方法為多尺度時間序列預測提供了新的思路，推動了多尺度建模的理論與實踐發展。

**Research Gap:** 雖然MSAR在多數場景下表現良好，但仍存在幾點不足。首先，粗尺度預測誤差可能會傳遞至細尺度，雖有細化機制緩解但未完全消除，全文未明確說明如何系統性控制誤差累積。其次，訓練過程中兩階段策略增加了訓練時間和複雜度，對於實時或資源受限場景可能不夠友好。第三，實驗主要集中於點估計性能，缺乏對模型不確定性、隨機性及失敗案例的深入分析。第四，對於多變量時間序列中跨通道依賴的處理仍依賴骨幹模型，MSAR本身未提供專門機制。最後，雖有敏感度分析，但對於不同尺度選擇和層數配置的理論指導不足，實際應用中仍需大量調參。未來工作可考慮引入殘差校正、結構化噪聲處理及多尺度預訓練等以提升穩健性和泛化能力。

### 4. AdMem: Expectation-Grounded Procedural Memory for Long-Horizon Task-Solving Agents

- 分數：5
- arXiv: [2611.20605v1](http://arxiv.org/abs/2611.20605v1)
- 發表日期：2026-11-16
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mila, mit; +3 提及頂級會議：neurips; LLM rank #4 / 7/10: AdMem addresses a fundamental problem in long-horizon task-solving agents with a novel procedural memory design, showing statistically significant gains and interpretable memory management.

**Intro:** 本文探討長期任務解決代理中跨任務記憶的有效管理問題。現有方法中，簡單累積跨任務經驗反而可能降低代理表現，甚至不如無記憶的基線。作者指出缺乏對每個行動的信用分配以及記憶條目的生命週期管理是主要原因。為此，提出AdMem方法，結合行動前的期望承諾與後續評價，並對記憶條目進行效用估計與動態管理。實驗涵蓋多個不同類型的任務域，展示了AdMem在跨任務結構存在時的優勢。

**Motivation:** 在實際工程與產品部署中，代理需要在多任務長期運行中有效利用過去經驗，但無限制累積記憶會導致無用或錯誤資訊干擾決策，降低性能。現有工作多聚焦於如何存儲更多資訊，卻忽略了如何判斷哪些經驗值得保留。AdMem的動機是解決跨任務記憶中信用分配不明確及無生命週期管理導致的性能退化問題，從而提升代理在長期、多樣化任務中的穩定性與效率。

**Method:** AdMem架構包含三個並行模組：行動者（actor）、評價者（critic）與長期記憶庫。行動者在執行每個動作前，需明確承諾該動作預期達成的結果；評價者則在觀察結果後，根據期望與實際結果的比較，給予該動作二元獎勵並生成反思文本。長期記憶庫保存語義、情節與程序性三類條目，並為程序性條目維護一個基於noisy-OR模型的效用分數，該分數用於檢索排序、條目合併與淘汰。短期記憶則以子目標堆疊形式組織，限制上下文大小並劃分評價範圍。此設計使得記憶條目能動態更新價值，避免無限制增長與無效干擾。

**Result:** 在八個AgentBoard域共707個任務上，AdMem解決了441個任務，顯著優於無記憶的ReAct（388個）及工作流誘導記憶AWM（312個）。AdMem在六個域中完成率超過ReAct，且所有域中平均進度均為最高。AWM在七個域表現不及ReAct，顯示未管理的跨任務記憶可能有害。消融實驗表明，程序性長期記憶單獨使用效果不佳，需結合短期規劃與上下文管理方能發揮效用。成本方面，AdMem約為基線的兩倍時間與三倍LLM調用，屬於性能與成本的權衡。

**Conclusion:** 本文明確指出跨任務記憶若無有效信用分配與生命週期管理，會損害代理性能。AdMem通過期望導向的逐動作評價與基於效用的記憶管理策略，實現了跨任務知識的有效保留與利用。其可讀文本記憶結構利於故障診斷與審計，但同時也帶來安全風險。實驗證明該方法在存在可轉移結構的任務域中顯著提升性能，且結合短期規劃是關鍵。限制包括僅單次種子實驗、部分域任務數量有限及未細分各機制貢獻，未進行對抗性評估。

**Research Gap:** 本文未對多個隨機種子進行充分實驗，導致結果穩定性尚不明確。消融分析未能細分期望導向獎勵、效用更新、條目合併與淘汰等子機制的獨立貢獻，缺乏更細緻的機制驗證。實驗域雖多樣，但部分域任務數量較少，且在WebShop與ScienceWorld等轉移結構薄弱域中AdMem未顯著優於基線，顯示泛化能力有限。成本較高，且全文未明確說明在實際部署中如何平衡性能與資源消耗。此外，記憶文本的可讀性雖利於審計，但也使系統易受間接提示注入攻擊，缺乏對抗性防禦評估與實驗。

**Intro:** 本論文探討大型語言模型（LLMs）在部署後遭受有害微調的安全風險，指出即使模型在發布時已經安全對齊，少量有害數據仍能快速改變模型行為，造成濫用。現有的模型免疫方法多透過增加損失函數的條件數來減緩有害優化，但此方法計算成本高且理論上條件數大並非充分條件。作者提出理論與方法上的改進，強調除了條件數外，損失函數在釋放參數附近的平坦區域（plateau）也對阻止有害微調至關重要。

**Motivation:** 從工程與產品角度看，隨著FTaaS和開放權重模型的普及，模型在發布後可被用戶或攻擊者微調，安全風險顯著增加。現有免疫方法因計算複雜且理論假設過於嚴苛，難以在大規模模型中實用。作者希望提出一種既理論嚴謹又計算可行的免疫框架，能有效提升模型對有害微調的抵抗力，同時保持模型的正常效用與可訓練性，促進安全對齊技術在實際部署中的落地。

**Method:** 作者基於優化理論，證明有害微調收斂速度受條件數與梯度大小共同影響，提出同時最大化條件數與促進有害損失平坦區域的免疫目標。提出BECON算法，利用高效的Gauss-Newton近似估計Hessian矩陣的極值奇異值，並透過梯度擾動促進平坦區域。該方法避免直接計算Hessian，僅需額外兩次反向傳播，適用於大型模型。整體優化目標結合對齊損失、平坦區域損失與條件數調節項，並在多種應用場景中實施。

**Result:** 在FTaaS場景下，BECON在多個模型與數據集上均顯著降低有害分數（Harmful Score），同時保持或提升下游任務的微調準確率，展現良好的安全與效用平衡。於開放權重場景，BECON對抗不同學習率與訓練輪數的有害微調攻擊表現出較強的免疫效果，雖然在極端攻擊下仍有性能下降，但整體優於現有防禦方法。於強制遺忘（unlearning）任務中，結合BECON的模型對抗知識恢復攻擊展現更高的遺忘效果。消融實驗證實條件數調節與平坦區域促進兩者結合效果最佳。

**Conclusion:** 本論文提出一種理論與實踐兼具的模型免疫框架，突破傳統僅依賴條件數的限制，強調平坦區域的重要性，並設計出適用於大型語言模型的高效算法BECON。實驗涵蓋多種部署場景，證明該方法能有效減緩有害微調，提升模型安全性，同時維持良好的效用與可訓練性。此工作為開放權重模型的安全防護提供了重要技術支持，促進安全對齊技術在實際環境中的應用。

**Research Gap:** 論文中免疫效果依賴於有害數據分布與攻擊策略與訓練時使用的代理數據相似，對於分布外或更激進的攻擊防護能力尚未充分驗證。實驗多以LoRA微調為主，對全參數微調的防禦效果及計算成本影響未完全展開。理論分析基於確定性全批梯度下降，未涵蓋隨機梯度下降的情況，限制了理論與實際訓練的對應。免疫過程仍存在效用下降的權衡，如何在更廣泛任務中保持效用同時提升安全仍需深入研究。此外，對失敗案例、泛化能力及部署風險的探討較少，未來工作可聚焦於提升免疫方法的普適性與穩健性。
