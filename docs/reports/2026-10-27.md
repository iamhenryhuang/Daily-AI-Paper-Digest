**Intro:** 化學反應資料在合成化學文獻中多以複雜的圖表形式呈現，如Screen Tables和Substrate Scopes，這些圖表包含豐富但結構化困難的資訊。自動化從這些圖表中提取結構化反應資料對於推動AI在化學領域的應用至關重要。現有資料集多聚焦於文字或簡單圖表，缺乏對這類複雜圖表的全面評估。本文提出RxnExBench，作為首個涵蓋Screen Tables與Substrate Scopes的多模態基準，包含完整的反應層級結構化標註與難度分級，旨在評估視覺語言模型在化學反應抽取任務上的能力。

**Motivation:** 合成化學文獻中大量重要反應資訊以圖表形式存在，這些圖表結構複雜且包含跨模態推理需求，傳統文字抽取方法無法有效處理。現有視覺語言模型雖在科學文檔理解上有進展，但尚未系統性評估其在這類化學圖表的結構化反應抽取表現。缺乏高品質、細粒度且涵蓋多種難度層級的資料集，限制了模型的研發與應用。RxnExBench旨在填補此空白，提供一個可用於工程與研究落地的標準化評測平台。

**Method:** RxnExBench建立於8個高影響力化學期刊，收集並標註266幅Screen Tables與Substrate Scopes圖表，包含3,565個反應與2,361個分子結構。設計一套包含15種反應角色與26個核心欄位的統一結構化反應模式，支持下游AI化學任務。提出三層次難度分類，從局部閱讀到全局整合再到R-group空間推理，反映不同推理複雜度。標註流程分為反應模板標註、模板實例化與分子結構標註三階段，並採用40位化學專家多輪交叉驗證。評測涵蓋9種先進視覺語言模型，並引入Oracle-MolRec協議，透過提供完美分子識別結果，分離分子識別與高階推理的影響。

**Result:** 實驗結果顯示，所有模型在完整結構化反應抽取任務中表現均有限，最高F1分數約23%（Criterion 1），在更嚴格條件下（Criterion 3）下降至不足9%。難度層級越高，模型表現越差，尤其在複雜多反應行（CLS）圖表中反應數量識別嚴重不足。錯誤分析指出分子結構識別錯誤佔主導，但條件欄位抽取與版面推理亦為主要瓶頸。Oracle-MolRec實驗證明即使分子識別完美，模型在多模態整合與化學推理方面仍有顯著不足，最高F1提升但仍低於20%。

**Conclusion:** 本文提出RxnExBench，為化學反應結構化抽取任務提供首個涵蓋Screen Tables與Substrate Scopes的多模態基準，並設計細粒度反應層級結構與難度分級。實驗揭示當前視覺語言模型在分子識別、條件抽取與跨區域推理方面仍存在顯著挑戰。Oracle-MolRec協議進一步證明高階推理能力是主要瓶頸。此基準有助於推動AI-for-Chemistry領域中多模態理解與資料集建構的研究與應用。限制在於目前資料集主要涵蓋英語有機合成文獻，且評估標準較嚴格，未涵蓋更廣泛化學子領域與語言。

### 2. Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution

- 分數：5
- arXiv: [2610.32285](https://arxiv.org/abs/2610.32285)
- 發表日期：2026-10-26
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; LLM rank #2 / 8/10: Presents TraceTrial-Bench, a novel benchmark focusing on AI agent harness reliability and failure attribution, with extensive evaluation and a reproducible framework addressing an underexplored but important aspect of LL

**Intro:** 本論文聚焦於大型語言模型（LLM）代理系統中的代理 harness，指出現有評測多集中於模型能力與整體任務表現，卻忽略了代理 harness 本身的可靠性評估。代理 harness 負責連接模型與外部工具、環境，管理上下文、執行流程與安全機制，其穩定性直接影響代理系統的行為與結果。為此，作者提出 TraceTrial-Bench，一個涵蓋七大可靠性組件的 benchmark，透過 95 個專家設計的機制導向任務，分別評估代理表現與 harness 可靠性，並支援失敗歸因分析。該工作旨在為代理系統的 harness 提供可審計、可重現的比較與診斷基礎。

**Motivation:** 代理系統的效能不僅取決於底層模型，還依賴於代理 harness 的設計與執行。現有評測多以任務成功率為指標，無法揭示 harness 在上下文管理、工具調用、生命週期控制等方面的可靠性問題。任務成功可能掩蓋 harness 的失誤，反之亦然，這對工程與產品部署帶來風險。因而需要一套能分離模型決策與 harness 行為的評估框架，幫助從業者理解並改進 harness 的可靠性，提升整體系統穩定性與可解釋性。

**Method:** TraceTrial-Bench 採用七大可靠性維度（上下文、執行、治理、生命週期、可觀察性、工具、驗證）組織評估標準，設計 95 個專家級任務，結合可執行或狀態基準作為真實標準。核心方法包含：1) Trajectory Tracing 模組，收集並標準化代理執行軌跡，保留原生 harness 行為；2) Multi-source Evidence Acquisition 模組，從代理上下文、harness 記錄與執行環境中抽取證據，支持語義判斷；3) 雙層評估框架，分別對代理任務表現與 harness 可靠性進行評分；4) Failure Attribution 模組，利用預先定義的機制鏈條，將 harness 失敗與代理失敗進行關聯，支援運行層級的失敗歸因。評測涵蓋四種 harness、九種模型與 95 個任務，共 3420 次執行。

**Result:** 實驗結果顯示，代理任務成功率約為 39.5%，而 harness 可靠性宏觀平均分數約為 68.3%，兩者存在明顯差異。不同 harness 在任務成功率與 harness 可靠性排名不一致，例如 Claude Code 在任務成功率最高，但 OpenClaw 在 harness 可靠性得分最高。31.1% 的執行在至少一項 harness 標準失敗的情況下仍達成任務成功，顯示任務結果無法完全反映 harness 可靠性。不同可靠性維度表現差異顯著，執行與生命週期維度較低，而驗證與可觀察性較高。失敗歸因分析發現，約半數同時失敗的執行存在可激活的失敗機制鏈，支持機制導向的失敗診斷。資源消耗方面，平均每次執行成本在 0.4 至 0.6 美元間。

**Conclusion:** TraceTrial-Bench 提供了一套針對代理 harness 的機制導向評測框架，能分離代理模型與 harness 行為，揭示任務成功率無法反映的 harness 可靠性問題。透過 95 個專家設計任務與多源證據收集，該 benchmark 支援可審計、可重現的比較與失敗歸因，對代理系統的工程與研究落地具有實用價值。限制在於任務覆蓋不均、每組合僅選擇一次執行，且缺乏對部署場景的泛化驗證。未來可用於指導 harness 演進與自我改進策略，促進代理系統的穩定性提升。

**Research Gap:** 本研究雖涵蓋多種 harness 與模型，但每個任務-模型- harness 組合僅執行一次，缺乏重複性驗證，無法評估結果穩定性與隨機性影響。任務設計偏重特定機制，覆蓋面仍有限，部分可靠性維度任務數量較少，可能影響評估全面性。實驗環境與配置存在變異，限制對 harness 設計因果影響的嚴格推斷。失敗歸因依賴人工審核，缺乏自動化精確度評估。成本與部署風險分析不足，未明確探討 harness 在實際產品環境中的運行效率與安全性。泛化能力與在更複雜或動態場景中的表現尚未驗證，未提供失敗案例分析以指導改進方向。

- 發表日期：2026-10-26
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #3 / 8/10: PaperFormalizer offers a credible, practical pipeline for author-in-the-loop formal verification of research papers in Lean, addressing robustness in mathematical proofs with a clear methodology and available code.

**Intro:** 許多理論性論文包含複雜且冗長的數學證明，常因細節疏漏導致證明不完整或假設不明確。即使經過多次校對，這些小缺口仍可能存在，影響研究的嚴謹性。Lean 證明助理能確保每一步證明皆嚴格符合定義與先前結果，避免遺漏。PaperFormalizer 是一個基於 Lean 的自動化流程，協助作者將論文轉換成 Lean 驗證版本，找出並修補證明中的缺口。此工具結合作者判斷，確保形式化過程符合作者原意。

**Motivation:** 手動將論文形式化需要作者同時精通領域知識與 Lean，耗時且門檻高。現有自動形式化系統無法解決自然語言模糊性及修正錯誤時多種可能修補方案的選擇問題。作者的意圖是判斷正確形式化與修補方案的關鍵，因此需要作者參與。PaperFormalizer 透過人機互動，讓作者在關鍵決策點介入，提升形式化的準確度與實用性，降低形式化門檻，促進數學證明的嚴謹性與研究成果的可重用性。

**Method:** PaperFormalizer 包含兩大階段：自然語言審查與自動形式化。首先將 LaTeX 原始碼轉換成依賴圖，節點為論文中的定義、假設、引理、定理等陳述。接著由審查代理檢查每個節點的忠實度、模糊性與正確性，並在不確定時向作者詢問，提出修補建議供作者接受或拒絕。通過審查後，系統自動將陳述形式化為 Lean 程式碼，並嘗試證明。整個流程中作者可透過網頁介面做出決策，最終輸出包含標註修訂的論文版本、修訂報告與對應的 Lean 程式碼。作者可將驗證結果納入個人工具包，並選擇是否公開分享。

**Result:** 作者使用 PaperFormalizer 形式化三篇自身論文，發現多數結果存在需修正的錯誤。以案例論文為例，7 個主要結果中有 5 個需修正，系統提出的修補方案均保留主要結論。形式化後的 Lean 程式碼超過 2.6 萬行，涵蓋基礎庫、領域庫與個人工具包。系統能揭露論文中隱含假設與錯誤，並協助作者明確化模糊陳述。公開分享的驗證論文可供後續研究者重用，降低重複形式化成本。全文明確說明實驗設定、基準與指標，並展示系統在實際論文上的應用成效。

**Conclusion:** PaperFormalizer 提供一套實用的作者參與式自動形式化流程，降低了形式化研究論文的門檻，提升數學證明的嚴謹性與透明度。透過作者決策介入，避免形式化誤解與不當修補，並促進形式化結果的重用與共享。此系統有助於將形式化驗證納入論文撰寫流程，推動數學基礎研究的可靠性與可持續發展。全文未明確說明系統在其他領域或更大規模論文上的適用性與效能。

**Research Gap:** 本文雖展示系統在三篇論文上的應用，但缺乏對不同領域、不同規模論文的廣泛驗證，泛化能力尚未充分評估。系統依賴作者大量參與，對於缺乏 Lean 背景或時間有限的作者，實際使用門檻仍較高。修補建議多為局部調整，對於根本性錯誤或複雜推理錯誤的處理策略未詳述。系統對於自然語言理解的準確度及錯誤判斷的容錯性未有深入分析。成本與部署風險、失敗案例及用戶體驗細節亦未充分揭露，限制了對其工程與產品落地的全面評估。

### 4. MPQ: A Message-Passing View of Post-Training Quantization

- 分數：4
- arXiv: [2610.32127](https://arxiv.org/abs/2610.32127)
- 發表日期：2026-10-26
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: MPQ proposes a novel message-passing approach to post-training quantization improving over strong baselines on large language models, with credible evidence and open-source implementation.

**Intro:** 本論文聚焦於後訓練量化（PTQ）技術，該技術能在不需重新訓練的情況下，將大型語言模型的權重壓縮為低位元表示，對於在資源有限的設備上部署大型模型至關重要。現有的PTQ求解器如GPTQ、LDLQ及區塊座標下降方法，通常在處理權重區塊時會立即做出硬性決策，忽略了鄰近區塊間的相互影響，導致可能錯失更佳的量化方案。作者提出一種新的觀點，將行級PTQ視為對離散碼本的後驗推斷，並以此為基礎設計新的求解策略。

**Motivation:** 現有硬決策求解器在低位元量化時表現受限，因為在碼本空間中多個碼字可能產生相近的局部誤差，且區塊間存在強耦合，早期硬性決策可能導致全局次優解。隨著預處理和碼本設計的進步，求解器本身成為瓶頸。若能在求解過程中保留軟性後驗分布，並讓區塊間的分布相互影響，將有助於找到更佳的量化配置，提升模型在低位元量化下的性能。

**Method:** 作者提出Message-Passing Quantization（MPQ），將PTQ問題建模為帶有高斯似然的離散碼本後驗推斷。MPQ包含兩階段：第一階段利用向量近似訊息傳遞（V AMP）在有限溫度下計算區塊後驗分布，保留多個可能碼字的軟性資訊；第二階段將軟分布投影為硬決策初始化，並透過精確的區塊座標下降進行局部優化。此方法在秩空間中運算，結合了訊息傳遞的全局不確定性探索與局部精修，提升量化結果的全局品質。

**Result:** 在多個大型語言模型家族（Llama、Qwen、Mistral）上，MPQ在2位元格點碼本及3、4位元標量碼本量化任務中，均優於強硬決策基線（如GPTQ+CD、LDLQ+CD、QuantEase、OJBKQ），在WikiText-2和C4資料集上的困惑度及多項零射任務的準確率均有提升。尤其在2位元極限量化下，MPQ展現明顯優勢。求解時間方面，MPQ在2位元格點碼本下速度接近LDLQ且優於OJBKQ，具備實際部署潛力。消融實驗顯示V AMP階段有效降低後續座標下降的修正需求，理論分析則說明預處理對訊息傳遞精度的正面影響。

**Conclusion:** 本論文提出的MPQ方法從求解器角度創新地將PTQ視為有限溫度的後驗推斷問題，成功克服了傳統硬決策求解器在低位元量化中的限制。MPQ通過保留軟性後驗分布並結合局部精修，提升了量化模型的性能，尤其在2位元量化場景中效果顯著。該方法理論與實驗均支持其有效性，且已公開程式碼，對工程與產品部署具有實際價值。然MPQ仍需在求解時間與記憶體消耗間取得平衡，並依賴預處理技術以達最佳效果。

**Research Gap:** 本論文雖在多模型與多位元設定下驗證MPQ優勢，但全文未明確說明在更大規模模型或不同架構（如Transformer變體）上的泛化能力。求解器在極低位元（如1位元）或非均勻量化場景下的表現尚未探討。實驗中主要使用固定校準資料集，對於不同校準資料分布或動態量化情境的適應性未充分驗證。此外，MPQ的計算成本仍高於最簡單硬決策方法，部署於資源極度受限環境的可行性與成本效益分析不足。最後，對於失敗案例或量化後模型在下游任務中可能出現的性能退化缺乏深入分析。

**Intro:** 本論文探討如何讓長期部署的語言模型代理在有限上下文視窗內，從不斷累積的互動經驗中持續學習與適應。過去經驗的記憶有助於提供背景資訊，但代理仍需推理如何利用這些記憶解決新任務。技能則提供可重用的程序，但可能缺乏任務特定的事實。作者提出MEMCRYST框架，透過雙向學習記憶與技能，並保持語言模型參數凍結，實現上下文的持續適應。此方法在多個領域與任務中展現優越表現，並公開程式碼以利工程實踐與後續研究。

**Motivation:** 長期運行的LLM代理面臨任務解決需依賴過去經驗的挑戰，但上下文視窗限制使得直接利用全部歷史不切實際。記憶與技能各有優缺點，單獨使用難以兼顧事實細節與程序重用。且記憶與技能的選擇會影響代理行為，進而影響未來學習經驗。如何協調記憶與技能的學習與應用，並根據任務結果調整檢索策略，是提升長期適應能力的關鍵。這對工程與產品而言，可提升代理在多變環境下的持續效能與可靠性。

**Method:** MEMCRYST維護三類外部狀態：情節記憶、類型化事實與技能目錄。情節記憶保存任務證據與診斷，支持技能的創建與修訂；技能則為條件化程序文本，指導代理行為。代理在每次任務中檢索相關記憶與技能組成上下文，並執行行動。任務結果用於兩階段更新：一是根據結果調整記憶與技能的檢索影響力，二是將新互動寫入記憶並定期進行技能整合與修訂。此過程實現記憶與技能的雙向學習循環，且語言模型參數保持凍結。

**Result:** 在十個跨領域任務設定中，MEMCRYST在七項中領先，整體成功率達52.26%，較最佳基線SimpleMem提升約20個百分點。ALFWorld任務中，結合記憶與技能的策略成功率為63.17%，優於僅用記憶的59.83%與僅用技能的50.50%。跨模型架構與規模均展現一致提升。消融實驗顯示技能修訂與結果回饋機制均帶來正向影響。共享跨域狀態在多領域交錯任務中提升整體表現。凍結狀態下，相關記憶與技能的選擇優於隨機，且技能上下文輸入令牌數較少，提升效率。

**Conclusion:** 本研究提出的MEMCRYST框架有效結合記憶與技能的雙向學習，實現凍結語言模型的長期上下文適應。透過分離內容更新與檢索影響力調整，系統能持續從經驗中提煉可重用程序並優化檢索策略。實驗結果證明此方法在多種任務與模型上均有顯著效益，尤其在對話記憶與多域交錯場景中表現突出。此架構對工程實踐具參考價值，能提升持續部署代理的適應性與效率。

**Research Gap:** 本論文未明確評估結果回饋機制對錯誤反饋的魯棒性，且將任務結果均等分配給所有檢索記錄，無法辨識個別記錄的因果貢獻。技能審核依賴語言模型，無法保證程序正確性。跨域共享狀態雖提升表現，但未驗證技能在未見領域的泛化能力。實驗中缺乏對失敗案例與成本效益的深入分析，且對部署時的資源消耗與延遲影響未充分討論。未見對比其他先進聯合記憶技能學習方法的全面消融，限制了對方法優劣的全面理解。
