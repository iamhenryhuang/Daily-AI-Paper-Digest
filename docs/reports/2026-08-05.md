### 1. SWE-Touch: Benchmarking Coding Agents When Users Touch the Code

- 分數：7
- arXiv: [2608.02499v1](http://arxiv.org/abs/2608.02499v1)
- 發表日期：2026-08-03
- 分類：cs.SE, cs.AI, cs.CL
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #1 / 9/10: Introduces a novel, realistic benchmark (SWE-Touch) for coding agents in shared workspaces with user edits, revealing key limitations in current agents' adaptive behavior and state awareness, supported by thorough evalua

**Intro:** 本論文針對現實軟體開發中，使用者與程式碼代理人共用工作空間且使用者會直接修改程式碼的情境，提出一個新的評測框架SWE-Touch。現有的程式碼代理人評測多半假設代理人獨立作業或僅透過訊息與使用者互動，忽略了使用者直接修改程式碼的情況。SWE-Touch透過注入經過驗證的任務衝突性修改（Counter-Edits），來測試代理人對共享工作空間中程式碼變更的理解與回應能力。此框架在多個長短期任務資料集上評估九種主流模型，揭示了代理人在面對使用者直接修改時的性能下降與行為特徵。

**Motivation:** 軟體開發實務中，使用者與代理人常在同一程式碼庫中協作，使用者會直接修改程式碼，這會影響代理人的後續行動。現有評測多忽略此種互動，導致代理人在真實場景中可能無法有效處理程式碼狀態的變化。為了提升代理人在實際產品與工程環境中的適用性，必須評估並強化其對共享工作空間中使用者修改的感知與調適能力。SWE-Touch正是為了填補此評測缺口，提供一個可控且可重複的測試環境，幫助研究者與工程師理解代理人在動態協作環境中的表現與限制。

**Method:** SWE-Touch首先從多個代理人修復軌跡中挖掘任務關鍵程式碼區域，接著由獨立的User Patch Generator產生局部且合理的衝突性使用者修改（Counter-Edit），這些修改經過驗證確保不會自行解決任務且無法與參考修復合併通過測試。評測過程中，當代理人讀取或修改到相關程式碼區域時，系統會注入該使用者修改及對應的上下文訊息，迫使代理人面對共享工作空間的變化並繼續修復任務。此方法在SWE-bench Verified、SWE-Bench Pro及DeepSWE等資料集上進行，並比較多種模型在有無使用者修改介入下的解決率、資源使用與行為差異。

**Result:** 實驗結果顯示，注入Counter-Edit會使九個模型在SWE-bench Verified上的平均解決率下降7.7個百分點，且模型排名也因此顯著變動。頂尖模型Claude Opus 4.8與GPT 5.5在介入後仍維持較高穩定性，其他模型則有較大性能衰退。長期任務資料集SWE-Bench Pro與DeepSWE也觀察到類似下降趨勢，但受影響的模型有所不同。消融實驗指出，僅訊息介入影響有限，真正造成性能下降的是程式碼的衝突性修改。行為分析發現63.3%的失敗案例是代理人保留了使用者的衝突修改，且不同模型在是否挑戰使用者修改、修正正確性及驗證行為上有明顯差異，顯示代理人缺乏充分的狀態感知與動態調整能力。

**Conclusion:** 本論文提出的SWE-Touch框架填補了現有程式碼代理人評測中忽略使用者直接修改程式碼的缺口，提供了一個可控且可重複的測試環境來評估代理人在共享工作空間中對衝突性修改的反應能力。實驗結果揭示即使是性能優異的代理人，在面對動態變化的程式碼庫時仍存在顯著性能下降，且不同模型失敗原因多元。此研究強調未來代理人優化不僅需提升自主解決率，更應強化對工作空間變化的偵測、衝突調和與行為驗證能力，以符合真實軟體開發的協作需求。

**Research Gap:** 本研究採用受控且區域觸發的衝突性修改，雖有助於行為比較與結果解釋，但無法涵蓋真實使用者多樣且動態的修改行為，缺乏對更複雜互動模式的評估。全文未明確說明代理人如何在多輪動態互動中持續調整策略，亦未充分探討不同修改頻率與類型對模型表現的長期影響。此外，實驗中多數模型在驗證階段表現不足，未能有效利用測試回饋完成修復，顯示代理人在測試驅動開發流程中的適應性仍有限。成本與部署風險方面，增加互動步驟與資源消耗未必帶來性能提升，需進一步研究效率與穩定性的平衡。最後，泛化能力與失敗案例分析雖有初步呈現，但缺乏針對不同程式語言、專案規模及真實開發場景的廣泛驗證。

### 2. Cooperative Coevolution for Resource-Constrained Agentic LLM Post-Training

- 分數：7
- arXiv: [2608.02391v1](http://arxiv.org/abs/2608.02391v1)
- 發表日期：2026-08-03
- 分類：cs.AI, cs.LG
- 入選理由：+2 提及頂級機構：meta, mit; +3 提及頂級會議：aaai; +2 提及程式碼可用; LLM rank #2 / 8/10: Proposes CoPES, a resource-efficient evolutionary post-training method for LLM agents with strong empirical results and open-source code, addressing practical constraints in agent training with credible evidence.

**Intro:** 本論文聚焦於大型語言模型（LLM）代理的後訓練，特別是在資源受限的環境下，如何有效進行全參數優化。傳統基於梯度的強化學習方法在處理長多輪軌跡時，因反向傳播需要大量GPU記憶體而面臨瓶頸。演化策略（ES）提供了無需反向傳播的記憶體節省優勢，但其高GPU小時需求導致訓練時間過長，尤其在GPU數量有限的情況下。為解決此問題，作者提出一種合作共演化方法Cooperative Parameter-subspace Evolution Strategy（CoPES），將參數空間分解為低維子空間，並協同搜索以提升優化效率。

**Motivation:** 在實際工程與產品部署中，LLM代理常需處理長且複雜的多輪交互，導致基於梯度的後訓練在記憶體消耗上難以擴展。雖然ES避免了反向傳播，降低了記憶體需求，但其龐大的計算成本在有限GPU資源下無法有效利用並行加速，造成訓練時間過長。這使得在資源受限的環境中，如何兼顧記憶體效率與訓練速度成為關鍵挑戰。CoPES透過子空間分解與獎勵標準化，旨在提升ES的優化效率，降低訓練時間，從而促進LLM代理後訓練的實際落地。

**Method:** CoPES基於合作共演化框架，將模型參數隨機分割成多個互斥的子空間，每個子空間獨立進行高斯擾動並評估對應的獎勵。為保持與全參數擾動相當的尺度，子空間擾動幅度根據子空間維度調整。所有子空間的獎勵在更新前進行聯合標準化，確保不同子空間更新方向的獎勵尺度一致，最後將各子空間的更新合成為全參數更新。此方法保留了ES無需反向傳播的記憶體優勢，同時提升了固定GPU小時預算下的優化效率。實現細節包括使用隨機種子重播擾動、分塊處理參數及備份權重以確保評估穩定性。

**Result:** 在數學任務的五個基準測試中，CoPES在與全參數GRPO相同GPU小時預算下，恢復了92%的GRPO驗證準確度提升，優於標準ES的67%。CoPES在所有pass@k指標上均超越標準ES及LoRA基GRPO，且理論GPU記憶體需求不到全參數GRPO的八分之一。硬體可行性測試顯示，CoPES可在單張24GB GPU上訓練，而GRPO需多張48GB GPU。在多跳問答任務中，CoPES同樣優於標準ES並接近GRPO表現。消融實驗證明適中子空間數量與聯合獎勵標準化對性能提升關鍵，且擾動尺度調整非性能提升唯一原因。

**Conclusion:** 本論文提出CoPES，一種結合參數子空間分解與聯合獎勵標準化的合作共演化演化策略，顯著提升了資源受限環境下LLM代理後訓練的優化效率。實驗結果證明CoPES在保持ES記憶體優勢的同時，能在固定GPU小時預算內超越標準ES並接近甚至超越部分梯度基方法。此方法對於有限GPU資源的實際部署具有重要意義。限制在於目前僅針對Qwen3.5-4B模型及兩類任務進行驗證，且子空間劃分為隨機等分，未考慮參數間相依性。

**Research Gap:** 全文未明確說明CoPES在更大規模模型或其他類型代理任務上的泛化能力，且子空間劃分策略僅為隨機等分，未探討基於參數相依性或結構的自適應劃分，可能影響優化效果。實驗中GPU小時估算基於推斷，缺乏實際長時間訓練的壁鐘時間對比。消融分析未涵蓋不同擾動數量與子空間大小的更細粒度調整，對於不同硬體配置下的效率與性能權衡也未充分討論。此外，未展示失敗案例或在極端資源限制下的穩定性，這對工程部署風險評估至關重要。未提供對比其他無梯度優化方法的實驗，限制了方法優勢的全面評估。

### 3. Real-Time Detection and Repair of LLM Agent Failures

- 分數：4
- arXiv: [2608.02464v1](http://arxiv.org/abs/2608.02464v1)
- 發表日期：2026-08-03
- 分類：cs.AI, cs.LG, cs.SE
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #3 / 8/10: Presents a lightweight, effective failure detection and repair system for LLM agents with strong empirical validation, practical efficiency, and open-source release, addressing a critical reliability challenge.

**Intro:** 大型語言模型代理在執行過程中常見失敗，如無限迴圈、工具錯誤連鎖、目標偏移、虛構結果或靜默吸收錯誤內容。傳統解決方案是用第二個大型模型逐步判斷，但成本遠高於代理本身。本文探討是否能僅利用可觀察的步驟遙測數據，以微秒級成本且只用健康運行資料訓練的監控器，實現即時失敗偵測。研究涵蓋多模型、多框架及商業API，並結合統計監控與確定性驗證方法，嘗試在不依賴第二模型的情況下提升失敗偵測與修復效率。

**Motivation:** 在工程與產品層面，代理失敗會導致任務失敗、資源浪費及用戶體驗下降。現有逐步審核方法成本過高，難以大規模部署。若能用輕量級、無需額外標註且只基於健康運行資料的監控器，快速偵測失敗並及時修復，將大幅降低運行成本並提升系統穩定性。這對於實際部署多工具、多模型的複雜代理系統尤為重要，因為它能在不中斷服務的情況下及早發現並糾正錯誤。

**Method:** 核心方法是利用一類回聲狀態網路（ESN）集成與CUSUM累積統計，對步驟輸出語義嵌入、標記不確定性及行動元數據進行異常偵測。監控器只在健康運行資料上訓練，無需失敗標籤，且計算成本約200微秒每步。為彌補內容腐敗盲點，加入內容基礎遙測通道與確定性驗證層，後者透過重算工具結果總和及檢查必須呼叫覆蓋率，無需閾值或校準。偵測到失敗後，系統會回滾至最後一次事實收集步驟並重新執行，實現即時修復。

**Result:** 在2823個真實代理執行集上，ESN集成在5%誤報率下達成71%失敗偵測率，AUROC達0.872，且在後續步數較多時優於無記憶基線。監控器需針對部署重新校準，跨模型家族轉移性有限。確定性驗證層在無誤報下捕獲60%失敗，結合覆蓋檢查可達96%，且在不同模型與語料上表現穩定。修復實驗顯示，回滾並重新執行可將任務成功率從52%提升至73%，平均每次多一個模型呼叫。監控器與驗證層互補，分別對不同失敗類型有效。對有機失敗（非注入）偵測能力有限，尤其是虛構類型需確定性驗證輔助。

**Conclusion:** 本文提出一套結合輕量級統計監控與確定性驗證的即時代理失敗偵測與修復系統，能在微秒級成本下有效捕捉多種失敗類型，並透過回滾重跑提升任務成功率。系統不依賴第二大型模型逐步審核，適合實際部署場景。確定性驗證補足了統計監控的內容盲點，兩者協同提升整體可靠性。限制包括監控器需針對部署校準、對慢速目標漂移及部分內容腐敗偵測能力不足，以及有機虛構失敗樣本不足無法充分驗證。整體而言，該方法為大型代理系統的實時監控與修復提供了可行且高效的技術路徑。

**Research Gap:** 本研究監控器需在每個部署環境重新收集健康資料進行校準，缺乏跨部署的泛化能力，限制了實際大規模應用的靈活性。對慢速目標漂移類失敗偵測效果有限，且對內容腐敗的偵測依賴結構化工具結果，對非結構化或隱藏錯誤無能為力。有機虛構失敗樣本數量極少，導致該類失敗偵測能力未充分驗證，且統計監控無法覆蓋此類，需依賴確定性驗證。修復策略雖有效，但對某些失敗類型（如工具錯誤連鎖、無限迴圈）修復效果有限，且回滾重跑增加額外計算成本。全文未明確說明在更大規模、多樣化任務及實際生產環境中系統的穩定性與成本效益。

### 4. CoWAM: Coordination Contracts for Selective Policy Intervention with WAMs

- 分數：5
- arXiv: [2608.02578v1](http://arxiv.org/abs/2608.02578v1)
- 發表日期：2026-08-03
- 分類：cs.RO, cs.AI, cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #4 / 7/10: Introduces CoWAM, a principled coordination contract framework for safe selective policy intervention in bimanual robot tasks, showing significant improvements with clear methodology and evaluation.

**Intro:** 本論文針對雙手機器人操作中，如何利用世界行動模型（WAMs）所預測的未來行動結果，來判斷是否應該介入並改變原本政策建議的動作。雙手操作涉及多種協調問題，如同步性、角色分配及碰撞避免，僅憑未來行動的合理性不足以決定是否替換動作。作者提出CoWAM，一種選擇性介入層，透過協調契約來明確定義這些協調義務，並結合事件條件驗證與校準的介入門檻，來保守地決定是否介入。此方法在多個模擬雙手任務中展現出提升協調有效性與任務成功率的能力。

**Motivation:** 雙手機器人操作因涉及兩個手臂的動作同步與角色分配，容易產生協調失誤，導致任務失敗。現有WAMs雖能預測未來狀態，但無法直接判斷何時應該改變原政策動作以避免失誤。若任意替換動作，可能引入不必要的風險。工程與產品層面上，如何在不改變原政策生成器的前提下，安全且有效地介入動作選擇，是提升雙手機器人穩定性與任務成功率的關鍵。CoWAM透過明確的協調契約與事件條件驗證，提供一套可驗證且保守的介入機制，對實際部署具有重要意義。

**Method:** CoWAM核心在於定義三類協調契約：同步性、角色相容性及碰撞收斂，這些契約以事件為基礎，結合類型化的可接受性檢查與事件條件的學習驗證器。系統接收一組由凍結的WAM生成的候選動作及其預測未來，並在不改變候選池的前提下，根據契約規則與校準門檻決定是否保留原動作、替換為其他候選動作或放棄介入。驗證器估計事件滿足度、風險、效用、機會值與信心，並透過保守的界限與多重門檻組合，確保介入決策的安全性與有效性。所有決策均在獲得結果標籤前完成，實現結果盲評估。

**Result:** 在八個RoboTwin2.0模擬雙手任務中，CoWAM在150個介入機會中成功選擇協調有效動作達93.3%，較僅用契約的76.7%提升16.7個百分點，且假陽性與有害介入率分別低於3%與1%。自然閉環測試中，CoWAM將任務成功率提升至62.9%，較最強選擇性基線提升9.6個百分點。跨不同WAM生成器與候選池規模的測試顯示，CoWAM能穩定提升成功率且維持低誤介入。消融實驗證明事件條件驗證與校準門檻對性能提升關鍵，且保留原動作的策略有效降低誤介入。整體結果支持CoWAM作為保守且有效的雙手協調介入機制。

**Conclusion:** 本論文提出CoWAM，透過明確的協調契約與事件條件驗證，實現基於WAM預測未來的保守選擇性政策介入。方法在多任務、多事件類型及多生成器環境中均展現出提升協調有效性與任務成功率的能力，同時維持低誤介入率。CoWAM分離了候選生成與介入決策，提供一種可重用且可驗證的介面，對雙手機器人控制系統的工程實踐具有指導價值。消融與跨生成器測試進一步強化了方法的穩健性與泛化能力。

**Research Gap:** 全文未明確說明CoWAM在真實機器人硬體上的部署與實驗，模擬環境與真實世界的差異可能影響方法效能。候選池依賴凍結的WAM生成，若生成質量不足，介入效果受限，且未探討生成器改進對整體系統的影響。事件條件驗證器需大量標註數據訓練，對標註成本與泛化能力的影響未充分討論。此外，介入門檻的校準依賴驗證集，對不同任務或環境的自適應能力尚不明確。最後，對失敗案例與介入失誤的深入分析較少，缺乏對方法潛在風險與限制的全面評估。

### 5. UEmbed: Unified Sparse and Dense Multimodal Embeddings

- 分數：5
- arXiv: [2608.02583v1](http://arxiv.org/abs/2608.02583v1)
- 發表日期：2026-08-03
- 分類：cs.CV, cs.AI, cs.CL, cs.IR
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; LLM rank #5 / 7/10: Proposes UEmbed, a unified decoder-only model producing both sparse and dense multimodal embeddings in one pass, demonstrating strong performance and practical utility across tasks with public release.

**Intro:** 本論文聚焦於資訊檢索中稀疏檢索的限制，特別是現有學習稀疏檢索（LSR）方法多依賴雙向編碼器架構，且在多模態場景中仍需輔助跨模態模組。作者提出UEmbed，一種基於解碼器的多模態嵌入模型，能在單次因果前向傳播中同時產生稀疏詞彙和密集向量表示。此模型通過附加多個可學習特殊標記並將詞彙表分割成多個子集，克服了因果模型在稀疏表示上的瓶頸。UEmbed在多個公開數據集上訓練並釋出多種規模版本，展現了在多模態檢索任務上的競爭力。

**Motivation:** 傳統稀疏檢索方法如BM25雖具效率與解釋性，但無法捕捉語義相似性。學習稀疏檢索雖提升語義表達，但受限於雙向編碼器架構，難以利用解碼器模型的優勢，且多模態擴展依賴額外模組，增加系統複雜度與部署成本。解決這些限制對於提升多模態檢索系統的效率、擴展性及實際應用價值至關重要。UEmbed旨在統一稀疏與密集表示，並原生支持多模態輸入，簡化架構並提升檢索性能與部署便利性。

**Method:** UEmbed基於解碼器架構，於輸入序列末尾附加N個可學習特殊標記，並將詞彙表透過k-means語義聚類分割成N個不相交子集。每個特殊標記的隱藏狀態負責預測其子集內詞彙的稀疏權重，最終將所有子集稀疏向量串接成完整稀疏表示。密集向量則取自EOS標記的隱藏狀態。模型以結合密集與稀疏InfoNCE損失及FLOPS正則化共同訓練，促進稀疏性與表徵質量。訓練數據涵蓋多模態公開數據集，並利用教師模型挖掘困難負樣本以提升訓練效果。

**Result:** 在MMEB-v2多模態基準上，UEmbed-9B版本的密集與稀疏模式分別達到71.8與71.0分，稀疏檢索性能接近密集檢索，且優於其他公開數據訓練的多模態模型如RzenEmbed。BEIR文本檢索評測中，UEmbed同樣展現與強力密集及稀疏基線相當的表現。實驗還顯示，結合稀疏與密集模式的混合打分可進一步提升檢索效果。部署方面，UEmbed兼容高吞吐量的因果模型服務架構及倒排索引，並在代理式檢索場景中降低工具調用成本，展現實用價值。

**Conclusion:** UEmbed成功提出一種基於解碼器的統一多模態嵌入模型，原生支持稀疏與密集檢索，克服了傳統LSR對雙向編碼器的依賴及多模態擴展的複雜性。實驗證明其在多模態及文本檢索任務中均達到競爭性表現，並具備良好的部署效率與實際應用潛力。該方法為多模態檢索系統提供了一種新範式，將稀疏檢索從獨立模組轉變為多模態大模型的自然產物。

**Research Gap:** 本研究的限制包括：首先，訓練數據主要為英語與中文，導致模型在多語言支持上表現有限，未充分驗證跨語言泛化能力。其次，模型偶爾生成非標準詞彙或異常子詞，顯示詞彙穩定性不足，可能影響生產環境的穩定性，需進一步詞彙剪枝或後處理。第三，稀疏與密集表示在視頻類任務中性能差距較大，可能因視頻時空信息密度高，平坦稀疏向量表徵能力受限。最後，全文未明確說明模型在更大規模或更複雜多模態場景下的泛化性與失敗案例，且缺少對模型推理成本與部署風險的深入分析。
