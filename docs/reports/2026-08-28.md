### 1. PACE: A Unified Condense-and-Extract Paradigm for Fast VLM Inference

- 分數：7
- arXiv: [2608.27206v1](http://arxiv.org/abs/2608.27206v1)
- 發表日期：2026-08-27
- 分類：cs.CV, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：emnlp; +2 提及程式碼可用; LLM rank #1 / 9/10: Proposes a novel, training-free framework (PACE) that significantly accelerates vision-language model inference by adaptively condensing visual tokens while preserving performance, supported by strong empirical evidence 

**Intro:** 本論文針對視覺語言模型（VLM）在高解析度輸入下推理成本急劇增加的問題，提出一種統一的壓縮與抽取框架PACE。現有視覺token剪枝方法多僅在視覺編碼器後階段操作，無法優化視覺編碼本身的高延遲，且在嚴格token預算下難以同時保留全局視覺上下文與細節，導致性能下降。PACE透過在編碼前自適應壓縮像素和編碼後融合視覺與語言注意力的動態雙注意力抽取，實現高效且性能保留良好的推理加速。論文以Qwen2.5-VL-7B為主體進行實驗，展示在僅保留10%視覺token的情況下，仍能保留93.8%的性能並達成3.1倍的首字生成時間加速。

**Motivation:** 隨著VLM處理高解析度影像或長影片，視覺token數量大幅增加，導致視覺編碼器與LLM預填充階段成為推理瓶頸。現有方法多只在編碼後剪枝，無法降低視覺編碼器的計算負擔，且在嚴格token限制下，剪枝往往犧牲細節與全局結構，影響細節敏感任務表現。為解決此雙重瓶頸，必須在編碼前先壓縮冗餘像素，同時在編碼後精選關鍵token，兼顧全局與細節，提升推理效率與準確度。

**Method:** PACE包含兩階段：Condense階段的Adaptive Pixel Compressor（APC）利用ViT第一層的淺層特徵預覽，計算全局資訊密度與局部細節對比，動態調整輸入影像解析度，減少視覺編碼器的像素輸入量，保留全局佈局與重要細節。Extract階段的Dynamic Dual-Attention Extractor（DDAE）融合ViT自注意力與LLM跨模態注意力，根據兩者的信心權重動態加權，選擇語義相關且細節豐富的視覺token，確保關鍵資訊不被遺失。此框架無需額外訓練，且可與其他剪枝方法結合。

**Result:** 在Qwen2.5-VL-7B上，PACE在固定解析度設定下，於10%視覺token預算維持93.8%整體性能，較VisionZip與FastV分別提升約12.7與13.9個百分點，尤其在細節敏感的OCRBench與DocVQA任務中表現優異。效率方面，PACE將視覺編碼器延遲從約149ms降至49ms，LLM預填充延遲從217ms降至33ms，整體首字生成時間加速3.1倍。跨模型測試於InternVL3.5-4B亦展現穩定提升。動態解析度調整與雙注意力融合均顯著優於靜態解析度與單一注意力源方法。

**Conclusion:** PACE提出一種無需訓練的統一壓縮與抽取推理框架，有效解決高解析度VLM推理中視覺編碼器與LLM預填充的雙重瓶頸。透過APC動態調整輸入解析度與DDAE融合多模態注意力，PACE在大幅降低視覺token數量的同時，保留了全局佈局與細節，實現顯著的性能與效率提升。此方法兼容多種剪枝策略，具備良好擴展性與實用價值。

**Research Gap:** PACE的APC在固定格點VLM架構中無法降低視覺編碼器成本，且預覽階段的計算開銷與不同架構、解析度的適配性尚未充分驗證。APC為一次性、查詢無關的壓縮，可能遺失微小、低對比度或細節豐富的視覺元素，且一旦縮放導致資訊模糊，DDAE無法補救。全文未明確說明在極端細節敏感任務中失敗案例與泛化能力，且缺乏對不同硬體環境下推理加速穩定性的深入分析。此外，DDAE抽取層深度與融合權重的調整對性能與延遲的平衡仍需更細緻探討，實際部署中可能面臨的成本與風險亦未充分評估。

### 2. TTPO: Test-Time Policy Optimization

- 分數：5
- arXiv: [2608.27448v1](http://arxiv.org/abs/2608.27448v1)
- 發表日期：2026-08-27
- 分類：cs.CL
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #2 / 8/10: Introduces TTPO, a novel test-time training method that robustly improves large language model reasoning without ground-truth labels, demonstrating strong empirical gains and cross-task generalization.

**Intro:** 本論文聚焦於大型語言模型在數學推理任務中的測試時訓練（Test-Time Training, TTT）問題。現有方法如強化學習與在策略自我蒸餾（OPSD）依賴真實標籤，無法直接應用於無標籤的測試時訓練場景。作者提出利用多數投票產生的偽標籤作為替代，但指出偽標籤錯誤率高，直接使用會導致模型誤導。基於觀察到偽標籤錯誤時不同策略的錯誤影響不對稱，提出一種新的不對稱目標函數來提升訓練穩定性與效果。

**Motivation:** 在無標籤的測試時訓練中，偽標籤錯誤率高達約85%，直接用偽標籤進行蒸餾會將錯誤信號傳播至所有生成的token，造成嚴重誤導。然而，與偽標籤不一致的生成結果中約79%確實是錯誤的，對這些生成結果施加懲罰仍是合理的。基於此，作者設計一個不對稱的訓練目標，對與偽標籤一致的生成結果進行蒸餾，對不一致的生成結果則採用強化學習懲罰，藉此降低偽標籤錯誤帶來的負面影響，提升模型在無標籤環境下的推理能力。

**Method:** 提出的Test-Time Policy Optimization (TTPO)方法，將生成的多條軌跡根據答案是否與多數投票偽標籤一致分為正樣本與負樣本。對正樣本使用基於答案條件的在策略自我蒸餾（OPSD）進行密集的token層級指導，並採用token權重機制降低已收斂位置的梯度影響。對負樣本則使用分組強化學習（Grouped RL, GRPO）施加懲罰，並透過token遮罩機制只懲罰模型自信的錯誤token。整體目標函數結合兩者並以權重平衡，實現對偽標籤錯誤的魯棒性與有效利用正負樣本信號。

**Result:** 在五個競賽級數學推理基準（AIME 2025/2026、HMMT 2025/2026、BRUMO 2025）上，TTPO在無標籤測試時訓練設定下，對Qwen3-1.7B模型的平均準確率從38.0%提升至45.2%，超越了現有的TTRL和OPSD-TTT基線。TTPO在有標籤訓練設定下，也能匹敵甚至超越依賴真實標籤的OPSD方法。消融實驗證明token層級選擇機制對性能提升有顯著貢獻。跨基準訓練測試顯示TTPO具備良好的跨任務泛化能力。訓練過程中模型的自我演化使得偽標籤質量隨模型提升而改善，進一步推動性能提升。

**Conclusion:** TTPO成功將在策略自我蒸餾引入無標籤的測試時訓練場景，通過不對稱目標函數結合蒸餾與強化學習，實現對偽標籤錯誤的魯棒性。該方法在多個競賽級基準上達到或超越有標籤監督的性能，並展現出良好的跨任務泛化與自我演化能力。TTPO為無標籤環境下提升大型語言模型推理能力提供了有效方案，對工程實踐中無法獲得標籤的場景具有重要參考價值。

**Research Gap:** 本論文雖展示TTPO在多個基準上的優異表現，但全文未明確說明在更廣泛任務類型或非數學推理場景下的適用性與泛化能力。此外，偽標籤生成依賴多條軌跡的多數投票，對計算資源需求較高，部署成本與效率未充分討論。消融實驗主要集中於token層級選擇，對於不同超參數設定、偽標籤錯誤率變化的敏感性分析不足。模型在極端偽標籤錯誤或低資源環境下的穩定性與失敗案例亦未詳述。最後，TTPO結合強化學習與蒸餾的訓練流程較為複雜，實際工程部署時的調參難度與潛在風險仍需進一步評估。

### 3. WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution

- 分數：5
- arXiv: [2608.27454v1](http://arxiv.org/abs/2608.27454v1)
- 發表日期：2026-08-27
- 分類：cs.AI, cs.CL
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; LLM rank #3 / 7/10: Presents WikiSkill, a credible framework for evolving agent skills via persistent knowledge accumulation, showing consistent improvements and effective skill transfer with thorough ablations.

**Intro:** 本論文探討如何讓AI代理從執行經驗中持續累積並組織知識，以促進技能的演化與提升。現有方法多半將技能演化的資訊分散於優化歷史中，缺乏系統化的知識保存與重用機制。WikiSkill提出一個三層架構，將原始執行軌跡、持續累積的知識庫（wiki）與可執行技能分離，並透過持續整合經驗到wiki中，支持技能的迭代更新。此架構旨在提升技能的可重用性與跨模型的轉移能力。

**Motivation:** AI代理在處理複雜任務時需要專門的程序性知識，手動編寫技能成本高且難以預測所需知識。自動從代理經驗中發現並演化技能能使代理逐步適應，但現有方法未能有效保存與組織這些經驗，導致知識重複學習且難以累積。WikiSkill透過持久化知識庫解決此問題，讓技能演化能基於系統化且持續更新的知識，提升技能品質與演化效率，對工程和產品實現具有實際意義。

**Method:** WikiSkill架構包含三層：Raw Layer保存不可變的執行軌跡，Wiki Layer持續累積結構化的知識模式與演化日誌，Skills Layer則包含可執行的技能模組。演化迴圈包括四個步驟：推理代理執行任務並生成軌跡，Wiki Maintainer分析軌跡並更新wiki，Skill Proposer根據wiki與軌跡提出技能更新，最後透過驗證集評估並決定是否接受更新。wiki層持續累積知識且不回滾，確保長期知識保存與利用。

**Result:** 在五個多樣化基準與五種模型上，WikiSkill均優於現有技能演化方法及無技能基線，平均提升幅度達3.3至12個百分點不等。技能演化效果隨模型規模增大而提升，且小模型搭配技能可超越大模型無技能表現。跨模型技能轉移實驗顯示，技能能有效跨模型與模型家族轉移，且有時轉移技能優於自我演化技能。消融實驗證實持久化wiki對技能演化成效至關重要。案例分析展示wiki如何累積錯誤模式並指導技能細化。

**Conclusion:** WikiSkill提出一種結合持久化知識庫與技能演化的框架，有效提升技能品質與跨模型轉移能力。實驗結果證明其在多種任務與模型上的穩定優勢，並揭示技能演化與模型擴展的互補性。持續累積與組織經驗是提升技能演化的關鍵。限制包括未涵蓋技能檢索機制、嚴格的驗證門檻可能排除潛在有益更新、缺乏wiki自動修剪機制，以及未涵蓋極長時間跨度任務。未來可探索更靈活的技能接受標準及長期知識管理。

**Research Gap:** 本研究未評估技能檢索與觸發機制，隨技能數量增加，檢索效率與準確度將成為瓶頸。嚴格的驗證門檻排除中性或潛在長期有益的技能更新，可能限制技能多樣性與創新。wiki層無自動修剪機制，長期演化可能導致知識庫膨脹與冗餘。實驗場景未涵蓋極長時間或多階段任務，對於持續在線調整技能的能力尚未驗證。此外，跨模型轉移中存在負向轉移案例，顯示技能泛化與適應性仍需加強。全文未明確說明技能演化在真實部署環境的計算成本與風險。

### 4. CLAP: Cross-Embodiment Video World Models are Zero-Shot Physical Simulators

- 分數：4
- arXiv: [2608.27406v1](http://arxiv.org/abs/2608.27406v1)
- 發表日期：2026-08-27
- 分類：cs.RO, cs.AI, cs.CV
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: CLAP enables cross-embodiment video world modeling with zero-shot physical simulation, addressing a key limitation in robotics video models and demonstrating strong performance with open-source code.

**Intro:** 現有的動作條件影片模型多半侷限於單一機器人形態，無法利用多樣化的影片資料學習通用的物理規律。CLAP提出一種跨形態的動作條件影片生成框架，能在包含人類與機器人代理的多元網路規模影片上訓練。此方法基於物理定律普遍適用於不同執行者的洞察，試圖突破不同機器人動作表示差異與缺乏標註的挑戰。全文明確指出CLAP能在多種機器人形態與動作條件空間中達成高品質的影片模擬，並開放原始碼與模型。

**Motivation:** 動作條件影片模型在機器人學與視覺領域中被視為學習物理先驗與未來預測的關鍵工具，但現有模型多限於單一機器人形態，限制了資料規模與多樣性。跨形態學習面臨動作空間差異大與人類影片缺乏動作標註的問題。CLAP的動機在於利用跨形態資料擴大訓練規模，學習更通用的物理先驗，進而提升影片模擬的準確度與泛化能力，並促進機器人策略的零樣本遷移與少量樣本微調。

**Method:** CLAP核心在於統一多樣化的動作空間，採用三種動作表示：末端執行器姿態、自然語言指令與潛在動作表示。透過課程式學習，先利用潛在動作從無標註影片中學習物理先驗，再以末端執行器動作微調以實現零樣本部署。模型架構基於影片擴散模型，結合歷史條件與多視角預測以提升時空一致性。針對不同形態，CLAP提供少量樣本微調策略，保留跨形態先驗以快速適應目標機器人。此方法兼顧資料擴展性與部署可行性。

**Result:** CLAP在多個機器人資料集（如DROID、Bridge及OXE-Mix）上與單一形態基線比較，展現相當甚至超越的預測準確度。末端執行器動作在精細動態預測上優於語言動作，潛在動作則因能利用無標註資料而提升跨形態表現。相較於相對動作，絕對動作在末端執行器條件下表現更佳。CLAP在零樣本條件下於多任務機器人操作中提升策略成功率，並能透過少量樣本微調快速適應新形態，超越現有單形態模型。實驗涵蓋多視角、多任務及多形態，並提供定量指標如PSNR、SSIM、LPIPS、FVD等支持。

**Conclusion:** CLAP提出一套跨形態動作條件影片模型訓練框架，成功融合多種動作表示與課程式學習策略，實現高保真度的跨形態物理模擬與零樣本機器人任務泛化。此方法不僅挑戰了單形態模型的既有優勢，也建立了少量樣本微調的有效訓練新範式。限制包括模型仍可能產生幻覺現象，且訓練主要基於單臂機器人與人類影片，尚未充分涵蓋雙臂與人形機器人。未來可朝向幻覺偵測、資料多樣性擴充與模型效率優化發展。

**Research Gap:** 全文未明確說明CLAP在極端動作複雜度或高自由度機器人上的泛化能力與失敗案例，缺乏對模型幻覺現象的定量分析與緩解策略。訓練資料主要涵蓋單臂機器人與人類影片，對雙臂及人形機器人資料的利用仍有限，可能影響多形態泛化。課程式學習與動作空間轉換的計算成本與實際部署效率未充分討論。缺少對不同動作表示在真實機器人控制中延遲與穩定性的評估。消融實驗對各動作表示組合的貢獻分析尚不完整，且未明確說明在多任務場景下的長期穩定性。

### 5. Beyond Parallel Blindness: Information Floors and Model Gaps in Block Drafting

- 分數：5
- arXiv: [2608.27339v1](http://arxiv.org/abs/2608.27339v1)
- 發表日期：2026-08-27
- 分類：cs.LG, cs.CL, cs.IT
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #5 / 6/10: Provides a rigorous information-theoretic analysis of block drafting in language models, separating inherent limitations from model gaps with clear empirical validation.

**Intro:** 本論文探討區塊式草稿生成（block drafting）中，因為同時生成多個token而產生的資訊限制問題。區塊草稿器在尚未確定前面token的情況下，必須同時提出多個token，導致拒絕率包含兩種損失來源：缺少區塊內路徑資訊與模型對可觀察資訊的建模不完善。作者提出資訊下限（information floor）與模型差距（model gap）的概念，將拒絕率分解為這兩部分，並透過多個模型與任務實驗進行量化分析。

**Motivation:** 區塊式草稿生成能大幅提升生成速度，但其效能受限於資訊可用性與模型能力。現有方法無法僅透過接受長度判斷拒絕率的成因，無法明確區分因資訊缺失與模型不足造成的拒絕。這對工程與產品部署有重要意義，因為理解拒絕率來源能指導改進方向，是增加接受率與加速生成的關鍵。作者希望透過分解拒絕率，明確界定資訊限制與模型能力的影響，為後續優化提供理論基礎。

**Method:** 作者定義在不同條件資訊下的接受率下限，稱為資訊下限，表示在相同資訊限制下理論上可達到的最低拒絕率。模型差距則是實際拒絕率超過資訊下限的部分。透過目標模型的自由採樣軌跡，估計不同條件（如無條件、條件於前一token）下的資訊下限，並與實際草稿器拒絕率比較。此方法涵蓋多個模型（Qwen3系列、Gemma、DeepSeek API）與多領域任務，並利用條件互信息驗證資訊局部性。

**Result:** 實驗發現：一、全平行草稿器的資訊下限在最後位置達到約0.286，意味最高接受率約71%，顯示平行盲點造成顯著限制。二、條件於前一已實現token可移除86%至100%的資訊下限，證實資訊缺失主要來自於缺少前一token資訊，且此局部性由互信息分析支持。三、現有草稿器拒絕率遠高於資訊下限，模型差距佔DFlash拒絕率43%至64%，DSpark在oracle條件下模型差距更高達85%至92%。此外，服務時風險因存活路徑偏好而降低，模型差距與資訊下限的分解在多模型與規模下均成立。

**Conclusion:** 本論文提出資訊下限與模型差距的分解框架，有效區分區塊草稿生成中拒絕率的兩大來源。結果顯示，缺少前一token資訊是主要的資訊限制，但現有草稿器在利用可得資訊方面仍有大量改進空間。此分析對工程師與研究者理解草稿器性能瓶頸、設計更有效的條件機制及提升模型能力具有指導意義。限制在於估計依賴目標模型自由採樣，且未明確探討更長條件歷史或不同架構的潛力。

**Research Gap:** 論文未充分驗證模型差距是否可透過架構改進或訓練策略有效縮小，缺乏對不同草稿器架構（如更深層次條件或非馬可夫模型）在資訊下限與模型差距上的比較。實驗場景主要集中於特定模型與任務，泛化性與在實際部署中面對多樣化輸入的表現尚未明確說明。對於模型差距的成本、計算負擔及部署風險亦未深入討論。此外，消融實驗與失敗案例分析不足，無法全面評估提出方法在極端或複雜情況下的穩健性。
