### 1. Pro-t-VAE: Closed-Form Student's t Mixtures for Robust Prototype Discovery

- 分數：7
- arXiv: [2610.14894v1](http://arxiv.org/abs/2610.14894v1)
- 發表日期：2026-10-10
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #1 / 9/10: Presents a novel, mathematically rigorous Student's t mixture VAE with closed-form ELBO for robust prototype discovery, validated on challenging neuroimaging tasks with clinical relevance; strong novelty, practical impac

**Intro:** 本論文聚焦於無監督影像原型發現，提出一種基於重尾Student's t混合先驗的深度生成框架。現有方法多依賴高斯先驗或計算成本高昂的擴散模型，前者對噪聲敏感，後者則缺乏明確的潛在結構與解析優化。作者利用貝葉斯尺度混合形式，將Student's t分布轉化為高斯-伽瑪層次結構，實現了首個完全閉式的增強ELBO目標，兼具統計魯棒性與數學可解性。此方法在標準視覺基準與神經影像臨床任務中展現優異性能，特別是在腦MRI中能恢復解剖學一致的原型，對臨床噪聲下的罕見亞型保持辨識力。

**Motivation:** 在無監督視覺表徵學習中，將大量影像壓縮為少數原型有助於資料模式總結與解釋，但現有方法多為剛性模板或高斯混合，對異常值敏感且無法適應拓撲差異。擴散模型雖能提供強先驗，卻因迭代採樣與不可解的似然限制了擴展性與解釋性。因此，亟需一種既能保留明確潛在結構又具備重尾魯棒性的生成模型，特別是在臨床影像中，能有效處理噪聲與異常，提升原型的穩定性與可用性。

**Method:** 核心方法是將Student's t分布表示為高斯分布與伽瑪分布的尺度混合，將潛在變數精度視為隱藏變數，並與群集標籤共同推斷。此結構使得ELBO可透過高斯-伽瑪共軛關係完全解析求解，避免了傳統t分布變分推斷中無法解析的KL散度問題。模型學習每個群集的自由度參數，實現對不同噪聲水平的自適應重權重，對離群點自動降權。整體架構基於ResNet編碼器-解碼器，並以變分深度嵌入(VaDE)為基礎，將高斯混合先驗替換為閉式Student's t混合先驗。

**Result:** 在MNIST與Fashion-MNIST兩個標準資料集上，模型在不同強度的Cauchy噪聲下均優於六個代表性基線，包括VaDE、Contra-VaDE及多種t-VaDE變體，原型分配準確率(ACC)、ARI與NMI均顯著提升，且訓練時間僅略增。模型在腦MRI資料集上，面對九種真實臨床噪聲類型，展現最高的Silhouette分數與穩定的Davies-Bouldin指標，且無群集崩潰現象。原型影像清晰，解剖結構明確，且能反映病理變化區域的不確定性，顯示臨床應用潛力。

**Conclusion:** 本論文提出的Pro-t-VAE框架成功結合了重尾分布的魯棒性與變分推斷的解析性，實現了無監督影像原型發現的高效且穩定學習。方法在自然影像與臨床腦MRI中均展現優異的原型質量與表示分離度，且具備自適應降權離群點的能力。該框架為深度生成模型與經典魯棒估計建立了理論連結，對臨床影像分析特別有價值。限制在於目前假設每個群集為單一橢圓形組件，且原型數量需預先設定，未涵蓋非參數模型與多組件擴展。

**Research Gap:** 論文未明確探討模型在更複雜群集結構（如多組件或非橢圓形分布）下的適用性，且原型數量固定，缺乏自動模型選擇機制。實驗主要集中於固定架構的ResNet編碼器-解碼器，對其他網路架構的泛化性未驗證。雖然展示了對噪聲的魯棒性，但對極端異常值或不同類型噪聲的失敗案例未充分分析。此外，模型在大規模資料集或多模態影像上的效能與計算成本仍需評估。最後，臨床應用中對模型不確定性的定量評估與解釋尚待加強。

### 2. Exact Phase-Type Point Processes for Certified Measurement and Prediction of Event Streams

**Intro:** 本論文聚焦於時間點過程在金融市場事件流的測量與預測兩大應用。傳統方法在測量市場反應速度與內生性時，常面臨非凸優化與模型不確定性問題；而在預測方面，神經時間點過程多依賴蒙地卡羅估計補償器，導致似然估計存在誤差。作者提出利用相位型（phase-type）分布的狀態空間結構，實現測量與預測的精確似然計算，並提供全局最優解的證明與響應函數的封閉形式。此方法同時兼顧模型解釋性與計算效率，對金融事件流建模具有實務價值。

**Motivation:** 市場事件流的動態包含外生新聞衝擊與內生交易回應，準確分離兩者對理解價格發現機制與風險管理至關重要。現有測量方法多為非凸優化，缺乏全局最優證明，且對回聲效應的捕捉不足。預測模型則多依賴近似方法，難以保證似然精確性。工程與產品層面，精確且可證明優化結果的模型能提升風控與交易策略的穩健性，且封閉形式計算利於實時部署與解釋。故本研究旨在填補測量與預測中精確似然與模型可證明性的缺口。

**Method:** 作者提出多尺度相位型Hawkes過程（MSX）作為測量模型，將所有參數線性化，使得對數似然函數為凸函數，並利用加速EM與障壁牛頓法求解全局最優解，附帶Fenchel對偶間隙證明優化距離。透過Markov嵌入，響應函數包含外生衝擊及其回聲，封閉形式表示且穩定性由分支矩陣譜半徑控制。預測模型EPT-X結合神經網絡GRU編碼器與相位型狀態空間，加入歷史依賴的Erlang混合更新通道，保持強度與補償器的封閉形式，並可從MSX的認證解初始化。訓練採用平行掃描加速狀態更新，提升計算效率。

**Result:** 在合成數據中，MSX在多種核函數結構下均優於傳統指數與多指數核估計方法，且對分支矩陣估計與因果圖恢復表現優異。EPT-X在五個公開時間點過程基準（包括Amazon、Retweet、Taxi、Taobao、StackOverflow）中，測試似然優於或持平於現有最佳模型，並在五檔LOBSTER限價單數據集上顯著超越多種神經基線。實驗揭示EasyTPP實現中對短間隔事件的截斷影響評分結果。應用於六個市場約670次宏觀經濟發布，MSX模型通過內建安慰劑測試，揭示CPI、非農就業、PPI及FOMC聲明的直接反應約一秒內吸收，但市場回聲將反應時間拉長至數分鐘級別。

**Conclusion:** 本論文提出的相位型狀態空間方法實現了金融市場事件流的精確測量與預測，兼具模型可解釋性與計算效率。MSX模型提供全局最優解的證明與響應函數封閉形式，EPT-X則結合神經網絡靈活性與精確似然，實驗中展現優越性能。應用結果強調市場回聲對吸收速度的顯著影響，並驗證了安慰劑測試的重要性。此方法對金融風控、交易策略及市場監管均具實務意義。限制包括部分宏觀指標預期為統計預測、數據集時間跨度有限及部分基線模型訓練條件受限。

**Research Gap:** 本研究雖提供全局最優證明與封閉形式響應，但對非線性或非相位型核函數的泛化能力未充分驗證。EPT-X雖結合神經網絡，仍依賴相位型狀態空間，對極端事件或異常模式的魯棒性未明。實驗中部分基線模型因硬體限制使用較小批次，可能影響比較公平性。宏觀經濟數據預測依賴統計預測，存在預期偏差風險。安慰劑測試雖有助驗證，但對更多市場與資產類別的適用性尚未展開。未見對模型部署成本、實時性及失敗案例的深入討論。未明確說明在高頻極端波動期間模型表現及穩定性。

### 3. SEEK: Agentic Knowledge Graph Retrieval for Secure Code Generation

- 分數：4
- arXiv: [2610.14968v1](http://arxiv.org/abs/2610.14968v1)
- 發表日期：2026-10-10
- 分類：cs.CR, cs.LG
- 入選理由：+2 提及頂級機構：mila, mit; +2 提及程式碼可用; LLM rank #3 / 7/10: Proposes SEEK, an agentic graph retrieval framework for secure code generation with strong empirical results on out-of-distribution benchmarks, demonstrating generalizability and practical security improvements.

**Intro:** 本論文探討大型語言模型（LLMs）在生成程式碼時，雖能滿足功能需求，卻常因缺乏明確安全要求而產生可被利用的安全漏洞。現有方法多依賴平面相似度檢索獨立安全知識，難以從功能需求推斷相關漏洞空間，且無法有效應對缺乏直接匹配的漏洞知識。為此，作者提出SEEK，一種基於CWE分類結構的安全知識圖譜，結合真實CVE漏洞修復實例，並透過代理人規劃與選擇機制，實現針對性且具泛化能力的安全知識檢索，提升安全程式碼生成效果。

**Motivation:** LLMs生成的程式碼雖功能正確，但可能隱含嚴重安全風險，尤其當開發者未明確指定安全需求時。現有方法如CodeGuarder與RESCUE雖引入外部安全知識，但多依賴功能相似度檢索，無法有效映射功能到潛在漏洞，且無法利用漏洞間的結構關係來彌補知識稀疏問題。此缺口使得安全知識檢索效率低且泛化能力不足，限制了安全程式碼生成的實際應用價值。

**Method:** SEEK構建一個以CWE分類為骨架的安全知識圖譜，將經過LLM輔助策展的CVE漏洞修復實例附加於對應CWE節點。線上推理階段，Planner Agent根據開發者功能性查詢預測可能的CWE漏洞，並以此進行Graph Scoping，限制檢索範圍至相關CWE子節點，減少無關知識干擾。接著進行多面向相似度排序，最後由Selection Agent驗證預測與檢索結果，必要時反饋Planner重新規劃。通過將驗證後的安全知識注入生成提示，提升生成程式碼的安全性與功能正確性。

**Result:** 在CodeGuard+與CyberSecEval兩大安全程式碼生成基準上，SEEK在五種開源LLM上均顯著提升安全相關指標。以Gemma4-31B為例，SecurePass@1由64.68%提升至77.45%，超越先前最佳方法7.75個百分點，且保持功能正確率高達89.57%。在13種無直接漏洞修復實例的CWE類型上，SEEK仍達85.2% SecurePass@1，展現優異泛化能力。CyberSecEval上，SEEK以79.45% ICD通過率略勝CodeGuarder，尤其在C與C++語言表現突出。整體推理延遲約20至32秒，具備實務可行性。

**Conclusion:** SEEK透過結合CWE結構化知識圖譜與代理人驅動的檢索策略，有效解決功能查詢與安全漏洞映射的挑戰，並利用漏洞間關聯提升檢索精準度與泛化能力。實驗證明其在多種LLM與多語言環境下均能顯著提升安全程式碼生成性能，且保持功能正確性。此方法不需修改模型參數，適合現有LLM部署環境，對推動安全AI輔助軟體開發具實際價值。

**Research Gap:** 本論文未明確說明SEEK在更大規模或多樣化漏洞資料集上的表現與擴展性，且對於代理人規劃與選擇階段的錯誤率及其對最終生成影響缺乏深入分析。實驗主要集中於C、C++與Python，對其他語言支持及跨語言泛化能力仍待驗證。雖然推理延遲在可接受範圍，但未探討在資源受限環境下的部署成本與優化策略。此外，對於複雜多漏洞交互情境及惡意輸入誘導的安全防護能力未有評估，限制了對真實世界安全威脅的全面應對。未來可加強對失敗案例的分析與多輪代理人互動的效果評估。

### 4. SkillHorizon: Constructing Long-Horizon Agent Tasks through Skill Composition

- 分數：4
- arXiv: [2610.14966v1](http://arxiv.org/abs/2610.14966v1)
- 發表日期：2026-10-10
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: SkillHorizon benchmark enables systematic study of long-horizon agent tasks with verifiable outcomes and realistic business workflows; provides valuable testbed and insights into scaling agent capabilities.

**Intro:** 本論文針對長期任務中，後續活動依賴於先前輸出及共享狀態變更的挑戰，提出SkillHorizon基準。該基準透過技能組合，在七個商業環境中構建長期任務，並以可執行的任務和可驗證的結果為目標。作者設計了域特定規則，將可重用技能程序轉化為具體商業活動，並透過輸入輸出依賴、共享資源及狀態更新連結這些活動。此基準旨在擴展任務需求與依賴，同時保持任務可執行性與結果可驗證性。

**Motivation:** 現有長期任務評估多半缺乏對任務規模與依賴關係同步擴展的系統性方法，難以深入理解代理在任務規模增長時的表現。商業工作流程中，任務間的依賴與狀態變更使得持續進展與結果驗證變得複雜。SkillHorizon透過技能組合與依賴結構，提供一個可調整工作量與協調需求的測試平台，有助於研究代理在實際工程與產品場景中如何管理長期任務的挑戰。

**Method:** SkillHorizon基於七個商業環境，利用域特定生成器將可重用技能程序轉為具體商業模組，並以有向無環圖形式連結模組，形成依賴結構。每個模組定義輸入需求、輸出與狀態效應及完成條件。任務透過擴展模組數量與依賴關係，增加工作量與協調複雜度。環境提供公共工具與程序化評估器，並以參考執行驗證任務可行性與工作量。評估涵蓋五種語言模型，任務工作量從64K至1M token不等，衡量局部目標完成率與整體任務成功率。

**Result:** 實驗結果顯示，隨著工作量擴大，五種模型的局部目標完成率從90.4%降至46.8%，任務成功率亦明顯下降。部分模型在大規模任務中仍能保持較高表現，但整體趨勢為完成工作未能跟上需求增長。分析發現，許多失敗案例中代理未完成大部分局部目標，卻仍有大量工具調用配額未用盡。此外，成功執行的腳本輸出有時未通過下游商業檢查，顯示局部成功不保證全局交付。不同環境與模型間表現差異顯著，且長期恢復能力隨工作量增加而下降。

**Conclusion:** SkillHorizon提供一個可配置且可擴展的長期任務基準，通過技能組合與依賴結構模擬真實商業工作流程，支持對代理持續進展、依賴協調與完整交付能力的評估。實驗揭示了代理在面對大規模任務時的挑戰，包括進展不足、局部成功與全局失敗的差距，以及恢復能力下降。該基準有助於推動長期任務代理的研究與工程落地，並促進對上下文管理與技能運用策略的深入理解。

**Research Gap:** 全文未明確說明代理在更複雜或非商業場景的泛化能力，且缺乏對失敗案例中具體失效原因的深入分析。實驗中工具調用配額未用盡但任務未完成，顯示策略或規劃層面仍有不足，未提供針對此問題的改進方案。依賴結構與狀態更新的設計雖具代表性，但對於更動態或不確定環境的適應性未被探討。消融實驗與不同技能組合策略的比較不足，無法明確評估各組件對整體表現的貢獻。此外，部署成本與實際商業系統整合風險未被討論。

### 5. Can You Trust Your Preference Models? Stackelberg Games for Alignment

- 分數：3
- arXiv: [2610.15008v1](http://arxiv.org/abs/2610.15008v1)
- 發表日期：2026-10-10
- 分類：cs.AI, cs.GT
- 入選理由：+3 提及頂級會議：acl; LLM rank #5 / 6/10: Formulates preference model alignment as a Stackelberg game with theoretical guarantees and a novel algorithm; credible methodology with promising experimental validation on synthetic data.

**Intro:** 本論文探討語言模型對人類偏好進行對齊時，偏好評估器的不完美性及其被優化策略利用的問題。偏好模型通常基於有限的人類標註資料訓練，可能在未見過的輸入上產生錯誤，導致模型行為偏離真實人類偏好。為了提升偏好模型的可靠性，作者提出一種方法主動尋找評估器可能出錯的比較樣本，作為額外監督的候選。此問題在工程與產品層面關鍵，因為偏好模型的錯誤可能導致下游應用中模型行為不符合預期，甚至產生安全風險。

**Motivation:** 現有的偏好模型因訓練資料有限且靜態，容易被優化策略利用其弱點，造成所謂的獎勵駭客行為。這種現象在大型語言模型的對齊過程中尤為嚴重，因為模型可能優化評估指標而非真實偏好。為了有效識別並修正這些錯誤，作者提出利用偏好模型集成間的分歧作為不確定性代理，並通過博弈論框架主動生成高分歧的比較樣本，從而指導有限的人類監督資源聚焦於模型弱點。

**Method:** 作者將尋找高分歧比較的過程建模為一個零和Stackelberg遊戲，包含一個先行者（Leader）和一個跟隨者（Follower）。Leader生成一個回應，Follower觀察該回應後生成另一個回應以最大化偏好模型集成的分歧。Leader則試圖生成能最小化此分歧的回應。理論上證明了遊戲均衡的存在性與唯一性，並提出Stackelberg Mirror Descent–Ascent (SMIDA)算法，該算法在有限狀態下具備線性收斂性。為應對大型語言模型，進一步設計了基於神經網路的DEEP-SMIDA策略梯度版本，並在合成oracle環境中進行實驗驗證。

**Result:** 實驗使用基於UltraFeedback資料集的合成oracle標註，訓練五個偏好模型組成集成。結果顯示，偏好模型集成的分歧與預測錯誤率呈正相關，分歧越大錯誤率越高。訓練後的Leader-Follower策略在未見提示上生成的比較樣本中，分歧顯著高於基線策略，且高分歧樣本中錯誤率提升約2倍以上。此外，訓練的Leader在偏好對比中表現競爭力，且訓練的Follower在指令遵循任務上優於固定Leader的Follower，顯示雙方交互訓練有助於生成更具挑戰性的樣本。

**Conclusion:** 本研究提出一種基於Stackelberg遊戲的框架，用於主動尋找並暴露偏好模型錯誤的比較樣本，為偏好模型的增強監督提供候選。理論與算法貢獻包括均衡存在性與唯一性證明，以及具收斂保證的SMIDA算法。實驗結果支持利用集成分歧作為錯誤代理的有效性，並展示了該方法在合成環境中提升錯誤樣本生成率的能力。限制在於實驗規模較小，使用合成oracle評估，尚未驗證在更大模型及真實人類標註上的效果，未來工作需結合反覆標註與模型更新驗證實用性。

**Research Gap:** 本論文雖提出理論嚴謹的Stackelberg遊戲框架及算法，但實驗僅限於小規模模型與合成oracle環境，缺乏在大型前沿語言模型及真實人類偏好標註上的驗證。對於生成的高分歧樣本是否能有效提升偏好模型的整體魯棒性與下游對齊效果，全文未明確說明。此外，對於算法在計算成本、訓練穩定性及部署風險的分析不足，尤其是神經策略梯度版本的超參數敏感性與收斂行為仍需深入探討。缺乏對失敗案例、泛化能力及多樣化任務場景的評估，限制了方法的實際工程應用指導價值。
