### 1. IDEAgent: Agentic Quality-Diversity Search for Research Idea Generation

- 分數：7
- arXiv: [2607.22375v1](http://arxiv.org/abs/2607.22375v1)
- 發表日期：2026-07-24
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #1 / 9/10: Introduces a novel multi-agent Quality-Diversity framework for research idea generation with strong empirical gains across diverse CS domains and open-sourced code, showing clear novelty and practical usefulness.

**Intro:** 本論文針對AI輔助科學研究中最基礎的構思階段提出改進，指出現有大型語言模型（LLMs）在生成研究想法時，往往只優化品質或多樣性其中一項，導致生成的想法彼此過於相似或品質不佳。作者主張應將研究構思視為品質與多樣性並重的搜尋問題，並提出IDEAgent框架以管理想法的演化過程，透過多目標評估驅動品質提升，並利用記憶機制與歷史比較維持多樣性。此議題對於AI在科研自動化與輔助工具的工程與產品落地具有重要意義，因為能提升生成想法的實用性與探索價值。

**Motivation:** 現有LLM基礎的構思系統多半獨立優化品質或多樣性，缺乏系統性地同時兼顧兩者，導致生成想法集中在狹窄的設計空間或產生大量瑣碎且不嚴謹的想法，降低了科研探索的效率與深度。真實的科研過程中，研究者會持續修正與精煉想法以提升品質，同時保持想法間的多樣性以探索不同方向。作者認為AI系統應模擬此過程，透過多代理人協同管理想法世系，並引入結合品質與多樣性的評估指標，提升生成想法的實用價值與多樣性，促進科研自動化的落地應用。

**Method:** IDEAgent為一多代理人框架，將研究構思視為品質-多樣性（Quality-Diversity, QD）搜尋問題。系統中包含生成代理（Ideator）、摘要代理（Stenographer）、多維度評估代理（品質評估、嚴謹性評估、與多樣性評估）及批判代理（Critic）等。生成的想法會被結構化為五元組摘要，方便比較與評估。系統維護四個記憶庫：活躍想法、修復隊列、歷史想法與拒絕想法，透過與這些記憶庫的比較確保多樣性。對於未達標準但接近門檻的想法，系統會進行修復與精煉，提升品質。最終以Yield指標評估生成想法集合的品質與多樣性，該指標計算在品質門檻下最大互異子集大小。

**Result:** 作者在涵蓋32個計算機科學主題的實驗中，將IDEAgent與多種基線方法比較，結果顯示IDEAgent在Yield指標上比最佳基線高出3.89倍，且在更多主題上達成非零Yield。具體來說，IDEAgent在非顯而易見性、嚴謹性與機制清晰度三大品質指標均優於基線，且透過修復與精煉子程序顯著提升想法品質。多樣性方面，雖然NOVA基線在多樣性指標上略勝一籌，但其整體Yield仍不及IDEAgent。內外部評審者對品質提升的一致性驗證了系統的有效性。實驗也揭示輕量級序列記憶足以維持多樣性，避免生成過程中品質低劣想法的負面影響。

**Conclusion:** 本研究提出將科學構思視為品質與多樣性並重的搜尋問題，並設計IDEAgent框架以多代理人協同管理想法演化，結合多維度評估與修復精煉機制，有效提升生成想法的品質與多樣性。實驗結果證明該方法在多個主題與品質門檻下均優於現有基線，展現出在AI輔助科研構思領域的潛力。該框架及評估指標Yield為未來AI驅動科研構思提供了新的視角與工具，並已開源促進後續研究。

**Research Gap:** 本論文主要依賴大型語言模型作為生成與評估代理，且評估多為模型內部或其他LLM判斷，缺乏人類專家實際驗證生成想法的真實可行性與創新性。修復與精煉機制受限於計算資源，僅允許有限次數，未探討更多迭代對品質提升的影響。實驗中使用的背景資料與主題範圍雖涵蓋多領域，但仍有限，泛化能力尚未充分驗證。系統對於生成想法的實際科研價值、可實施性及與現有文獻重複性的檢測未明確說明。此外，使用專有模型限制了方法的可重現性與普適性。未來可考慮引入人類專家評審、擴展多樣性維度、增加修復精煉次數，以及評估在更廣泛科研場景中的應用效果。

### 2. Skill Self-Play: Pushing the Frontier of LLM Capability with Co-Evolving Skills

- 分數：5
- arXiv: [2607.22529v1](http://arxiv.org/abs/2607.22529v1)
- 發表日期：2026-07-24
- 分類：cs.CL
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #2 / 8/10: Proposes a novel co-evolutionary Skill Self-Play framework balancing task diversity and verification reliability for LLM training, with robust empirical validation and open code.

**Intro:** 本論文探討大型語言模型（LLM）自我演化過程中，任務多樣性與驗證可靠性之間的根本矛盾。現有方法要麼依賴環境綁定的精確反饋但限制任務範圍，要麼採用開放式自生成擴展任務空間但缺乏有效驗證，導致訓練迴路受誤導獎勵污染。作者提出以「技能」作為中介，將技能視為可重用的模組化程序知識單元，兼顧深度執行與動態路由，實現任務多樣性與高保真驗證的平衡。論文提出Skill Self-Play（Skill-SP）框架，通過提議者、解決者與技能控制器的協同演化，推動LLM能力邊界的持續擴展。

**Motivation:** LLM自我演化的核心挑戰在於如何在保持任務多樣性的同時確保生成任務的結構與邏輯有效性。環境綁定方法雖提供精確驗證，但限制模型學習於狹窄領域，無法推廣至開放任務。反之，無指導的任務生成雖擴大覆蓋範圍，卻因缺乏主動結構引導，導致生成任務質量下降，甚至陷入模式崩潰。從工程與產品角度看，這種矛盾直接影響模型的穩定性與泛化能力，限制了自我演化技術在實際應用中的落地與擴展。Skill-SP旨在透過技能模組化管理，實現結構化且可驗證的任務生成，提升訓練效率與模型性能。

**Method:** Skill-SP框架包含三大核心組件：提議者（Proposer）負責根據動態抽樣的技能生成挑戰任務；解決者（Solver）嘗試解決這些任務以推動能力邊界；技能控制器（Controller）根據執行反饋持續更新與擴展技能庫。任務以技能為條件生成，技能定義包含路由元數據、程序規則、示例、驗證器及使用統計。生成任務經過嚴格的結構與邏輯驗證，包括格式合規、合約有效性及解決者回應一致性。訓練過程中，提議者與解決者通過強化學習協同優化，技能庫則根據失敗案例進行精煉、淘汰過時技能並從探索中誘導新技能，形成持續演化的閉環。

**Result:** 實驗涵蓋工具調用（API-Bank與BFCL）及邏輯推理（ZebraLogic）兩大任務類型，評估五種不同規模與架構的LLM骨幹。結果顯示Skill-SP在所有骨幹模型上均帶來穩定且顯著的性能提升，工具調用任務中提升幅度最高達42.9個百分點，邏輯推理任務中最高提升12.0個百分點。與無指導自我對弈（Unguided SP）相比，Skill-SP不僅提升更大且更穩定，後者在複雜任務上甚至無法有效啟動訓練迴路。消融實驗證明動態技能路由、技能庫持續演化及提議者與解決者的協同更新均為性能提升的關鍵因素。數據循環診斷顯示Skill-SP生成的任務更接近模型學習前沿且涵蓋更廣泛的結構多樣性。

**Conclusion:** 本論文提出的Skill Self-Play框架有效解決了LLM自我演化中任務多樣性與驗證可靠性之間的矛盾，通過動態演化的技能庫作為結構化任務生成與驗證的接口，實現了高保真且多樣化的自我訓練課程。實驗結果證明該方法能顯著提升多種LLM骨幹在工具調用與邏輯推理任務上的性能，並成功推動模型能力邊界。該框架為LLM自主演化提供了可持續且開放的訓練途徑，具有重要的工程與研究價值。

**Research Gap:** 全文未明確說明Skill-SP在更大規模模型或多模態任務中的適用性與效能，缺乏跨領域泛化的實驗驗證。技能庫的自動誘導與精煉機制雖有描述，但對於技能質量控制與避免過度專化的細節不足，可能影響長期演化的穩定性。消融實驗主要集中於提議者與解決者的協同更新，對技能控制器內部策略的影響分析有限。成本與部署風險方面，全文未討論該框架在實際系統中計算資源消耗與延遲的影響。此外，對於失敗案例或技能演化失效的情況缺乏深入探討，限制了對方法魯棒性的全面評估。

### 3. PinEqualizer: Full Funnel Content Exploration and Debiasing System at Pinterest

- 分數：3
- arXiv: [2607.22518v1](http://arxiv.org/abs/2607.22518v1)
- 發表日期：2026-07-24
- 分類：cs.IR, cs.LG
- 入選理由：+3 提及頂級會議：kdd; LLM rank #3 / 7/10: Industry-scale deployed system addressing content cold-start with measurable long-term impact and scalable evaluation, demonstrating practical value in real-world recommender/search systems.

**Intro:** 本論文針對產業規模的搜尋與推薦系統中內容冷啟動問題提出解決方案。Pinterest作為一個擁有數億用戶及數百億內容的視覺發現引擎，面臨新內容因曝光不足而難以獲得用戶關注的挑戰。傳統方法多依賴內容基礎匹配及圖結構，但隨著內容不斷增加，冷啟動問題日益嚴重，導致既有內容獲得過多優勢，影響內容生態健康。作者提出一套涵蓋整個多階段推薦漏斗的系統，並在Pinterest實際部署兩年，取得顯著成效。

**Motivation:** 冷啟動問題會造成新內容難以被推薦，進而影響用戶體驗與平台內容多樣性。現有系統偏向既有內容，導致新內容曝光不足，形成富者越富效應。解決此問題不僅能提升用戶參與度，也能促進內容生態健康，增加內容提供者多樣性。Pinterest的三大產品面(Homefeed、Related Pins、Search)佔平台92%曝光，亟需一套能跨多產品面且能減少偏差的探索系統。現有實驗設計難以快速驗證長期影響，需建立可擴展且快速的測量框架。

**Method:** 系統涵蓋從語料選擇、檢索、到最終排序的完整多階段漏斗。語料選擇階段利用Thompson Sampling結合機器學習模型預測內容參與率，動態挑選高潛力新內容進行探索。特徵工程方面，加入內容專屬嵌入(如PinCLIP)、語義ID及特徵補齊，並對歷史參與特徵進行dropout以減少模型偏差。檢索階段建立專門的新內容索引，並調整圖隨機游走權重以提升新內容召回。排序階段透過內容類型校準、正則化損失及數據增強減少新舊內容預測偏差，並引入基於即時曝光的UCB探索策略及Neural Linear UCB提升探索效率。整體系統配合三層測量框架：長期新內容holdout、內容畢業指標及短期用戶分群實驗指標，確保快速且準確評估效果。

**Result:** 系統自2024年起逐步部署，2025年相較2024年用戶成功會話數在北美及國際市場分別提升24%及49%，購物會話提升更顯著，北美達63%。新內容畢業語料庫規模增長41%，三大產品面下未充分探索內容的參與量分別提升13%至37%。內容提供者成功數量年增99%，顯示生態多樣性提升。組件層面實驗顯示，探索語料庫及排序特徵改進對未充分探索內容參與提升最為顯著，UCB探索策略中Neural Linear UCB優於簡單啟發式，但後者因簡單易用仍被部分場景採用。全漏斗瓶頸分析指導優先順序，先解決語料及檢索瓶頸，再聚焦排序階段。

**Conclusion:** 本論文提出一套涵蓋全漏斗的內容探索與去偏系統，成功應用於Pinterest大規模生產環境，顯著提升新內容曝光與用戶參與，並促進內容生態健康。系統創新點包括全漏斗設計、內容去偏策略及可擴展測量框架，具備跨產品面通用性。未來工作將持續優化關鍵組件，並引入長期創作者價值等更複雜目標。整體而言，該系統為產業界解決冷啟動問題提供了實務參考與技術路徑。

**Research Gap:** 論文未明確說明系統在不同語言或文化背景內容上的泛化能力，且實驗主要集中於Pinterest平台，跨平台適用性尚待驗證。雖有提及多產品面，但各面細節調整與相互影響未充分展開，缺乏更細緻的消融實驗。UCB探索策略雖有比較，但對成本與部署風險的分析不足。對於失敗案例或探索失效情況未有討論，缺乏對極端情況的魯棒性驗證。測量框架雖快速，但短期指標與長期效果的關聯性仍有待更嚴謹的統計驗證。最後，系統對於新興內容類型（如短影片、直播等）適應性未明確說明。

### 4. Reflector: Arrangement-Aware Harmonic Retrieval for Sample-Based Composition

- 分數：5
- arXiv: [2607.22413v1](http://arxiv.org/abs/2607.22413v1)
- 發表日期：2026-07-24
- 分類：cs.SD, cs.IR, cs.LG
- 入選理由：+3 提及頂級會議：acl; +2 提及程式碼可用; LLM rank #4 / 7/10: Presents a well-motivated, system-level contribution for harmonic retrieval in music composition with a novel embedding approach, open source code, and detailed analysis.

**Intro:** 本論文探討音樂創作中樣本檢索工具的限制，特別是當編曲進展且和聲背景隨之變化時，從固定參考樣本查詢的效果逐漸降低。作者提出Reflector，一個互動式音頻工作站，能追蹤作曲家時間軸上累積的和聲組合，並隨著編曲發展動態調整檢索結果。系統核心為一個手工設計的間隔類別權重表（interval-class oracle），用以評分音高類別內容的相容性，並透過訓練於合成音頻的編碼器將該規則近似於128維嵌入空間，實現快速相容性評分。Reflector能分析多軌時間線上的同時發聲區域，計算加權重心，並根據整體和聲身份進行檢索，支持跨會話的結構性和聲關係導航。

**Motivation:** 在音樂創作過程中，作曲家經常需要從大量樣本中尋找和聲相容的素材，但隨著編曲進展，和聲上下文不斷變化，固定樣本查詢無法反映當前的和聲狀態。現有系統多半基於單一樣本或混音作為查詢，缺乏對多軌編曲中動態和聲關係的建模。Reflector旨在解決此問題，提供一個能隨編曲演變即時更新檢索條件的系統，對工程和產品而言，這意味著能更靈活地支持作曲家在創作過程中探索和聲搭配，提升創作效率與靈感觸發。

**Method:** Reflector核心為一個12×12的間隔類別權重表，評分兩個音高類別內容在同時發聲時的和聲相容性。系統將音頻轉換為CQT chroma特徵，並以合成音頻生成的標籤資料訓練一個雙塔式編碼器，將上下文與候選樣本映射至128維嵌入空間，點積代表相容性分數。訓練分兩階段：第一階段以合成音高類別軌跡監督學習相容性與轉調分布，第二階段以InfoNCE對音頻衍生的chroma進行微調，強化嵌入空間的幾何結構。系統在索引階段將樣本分割為3秒重疊窗口，計算嵌入並加權平均形成檔案向量。檢索時，先以點積排序候選樣本，再進行12種轉調評分以捕捉最佳匹配。編曲過程中，系統透過掃描線分析同時發聲區域，計算加權重心形成動態會話向量，並投影至3D空間以視覺化跨會話和聲關係。

**Result:** 系統在631個多樣化樣本庫上進行評估，發現直接以間隔類別權重表進行檢索會集中於少數普遍相容的樣本，導致檢索覆蓋率低。反觀學習後的嵌入空間能保留規則的配對判斷，且覆蓋整個樣本庫，避免了退化解。嵌入空間與傳統和聲相似度指標呈現負相關，反映出相似性與相容性是不同的檢索問題。系統能隨著編曲中和聲中心的轉移動態調整檢索結果，實驗中展示了和聲三全音轉折點前後檢索結果的顯著變化。多次會話分析顯示，隨著素材累積，檢索建議與初始樣本的重疊度下降，且會話向量的分散度增加，反映系統能捕捉編曲的和聲演變。

**Conclusion:** Reflector展示了基於固定和聲規則與合成音頻訓練的編碼器，能實現即時反映編曲演變的和聲相容性檢索。系統提供從單樣本到整體會話的統一嵌入空間，使作曲家能在多層次上探索和聲關係並視覺化其創作軌跡。實驗揭示直接規則檢索的退化問題及嵌入空間的多樣性控制效果，並區分了相似性與相容性兩種檢索視角。Reflector作為免費本地應用，且訓練流程開源，對音樂AI從業者提供了可驗證且可擴展的系統架構。

**Research Gap:** 本研究主要侷限於西方調性和聲體系，間隔類別權重表及合成訓練資料未涵蓋非西方或非傳統和聲結構，泛化能力尚未驗證。系統僅考慮音高類別相容性，未整合音色、節奏、動態等其他音樂維度，對實際創作中多維度判斷的支持有限。實驗集中於單一631樣本庫，缺乏跨庫或更大規模資料的測試，且未呈現失敗案例或用戶主觀評價。消融實驗與多種基線比較不足，尤其在多軌動態檢索的實際效益與計算成本方面未充分說明。最後，系統對多鍵調轉換的自動化處理及多樣性控制策略仍待深入探討。

### 5. TRaM-VSR: Importance-Aware Token Routing and Merging for One-Step Diffusion Video Super-Resolution

- 分數：4
- arXiv: [2607.22231v1](http://arxiv.org/abs/2607.22231v1)
- 發表日期：2026-07-24
- 分類：cs.CV, cs.AI
- 入選理由：+2 提及頂級機構：mila; +2 提及程式碼可用; LLM rank #5 / 6/10: Addresses computational efficiency in diffusion-based video super-resolution with a novel token routing and merging method, supported by extensive experiments and code release.

**Intro:** 影片超解析（VSR）旨在從低解析度影片恢復高解析度，同時保持時間一致性。近年來，基於擴散模型的Diffusion Transformer（DiT）在視覺品質上取得顯著進展，但其計算成本因處理大量時空token而呈二次方增長，導致實際應用困難。現有提升效率的方法多採用均勻token壓縮，易造成細節不可逆損失及時間閃爍，尤其在單步擴散模型中更為明顯。本文提出TRaM-VSR，透過重要性感知的token路由與合併策略，針對影片內容與網路層級先驗進行自適應token分配，兼顧效率與品質。

**Motivation:** 單步擴散VSR雖大幅降低推理延遲，但缺乏多步迭代修正，容易累積生成錯誤，導致時間不穩定與細節流失。均勻token壓縮忽略動態物體與結構邊界的重要性，無法有效分配有限的計算資源，造成時間一致性差與畫質下降。為解決此問題，需設計能根據語義與動態資訊判斷token重要性的機制，並結合網路深度特性，動態調整token處理策略，以提升單步擴散VSR的實用性與穩定性。

**Method:** TRaM-VSR包含三大核心模組：離線風險導向的路由區間規劃、重要性感知的token路由，以及雙流路由合併與身份恢復。首先，透過分析基線模型各層局部更新幅度與最終輸出擾動，離線選擇低風險的路由區間。接著，結合語義文本相似度與時間曲率指標，計算token重要性分數，選擇保留動態物體與結構邊界相關token。於路由區間內，重要token進入高保真本地流，非重要token則合併為緊湊全局流，最後在路由出口以身份恢復機制還原完整token，避免細節不可逆損失。此設計兼顧計算效率與重建品質。

**Result:** 在多個合成與真實世界VSR基準（如UDM10、SPMCS、YouHQ40、RealVSR等）上，TRaM-VSR在保持或提升LPIPS、DISTS等感知指標的同時，維持競爭力的PSNR與SSIM，並顯著降低時間閃爍（E*warp指標）。與多種先進方法比較，TRaM-VSR展現更佳的品質與效率平衡。消融實驗證明雙流架構與語義-時間融合重要性評分對性能提升關鍵。視覺結果顯示本方法能有效保留細節與結構，減少過度平滑與時間不連續現象。

**Conclusion:** 本文提出的TRaM-VSR框架透過重要性感知的token路由與合併策略，成功解決單步擴散VSR中計算成本高與時間不穩定的問題。結合語義與動態資訊的token選擇，配合網路深度的離線路由規劃，實現高效且高品質的影片超解析。實驗結果證實其在多種資料集上均達到或超越現有最佳方法，且具備良好的時間一致性，對實際VSR產品與研究落地具重要參考價值。

**Research Gap:** 本文雖有效提升單步擴散VSR效率與穩定性，但仍存在幾項限制。首先，對於快速局部運動、細微重複紋理及陰影等複雜場景，仍可能出現輕微震動與細節損失。其次，整體加速效果受限於VAE解碼成本與實作細節，端到端速度提升有限。第三，路由區間依賴離線校準，對新架構或不同退化模型適應性不足，缺乏動態調整機制。此外，缺少對失敗案例、泛化能力及部署成本的深入分析。未來可探討更強的時間先驗與自適應路由策略以提升泛化與穩定性。全文未明確說明對多樣化真實場景的全面驗證。
