### 1. Beyond Marginal Validity: Finite-Sample Guarantees for Localized Conformal Prediction

- 分數：5
- arXiv: [2608.06206v1](http://arxiv.org/abs/2608.06206v1)
- 發表日期：2026-08-06
- 分類：stat.ML, cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #1 / 9/10: Provides novel finite-sample theoretical guarantees for localized conformal prediction, addressing a key gap with rigorous analysis and practical insights on bias-variance tradeoffs, improving reliability of uncertainty 

**Intro:** 本論文聚焦於保證局部化共形預測（Localized Conformal Prediction, RLCP）在有限樣本下的條件覆蓋率與效率。傳統共形預測提供邊際有效性，但無法保證條件有效性，且條件有效性在有限樣本下無法無分布假設達成。RLCP透過在測試點附近進行校準，試圖縮小邊際與條件有效性間的差距。作者針對RLCP的實際預測集合，提出有限樣本下的高概率界，統一控制條件覆蓋誤差與相對於理想oracle集合的長度誤差。論文同時分析固定分數與學習分數的情況，並以嚴格的數學假設與實驗驗證理論結果。

**Motivation:** 在實務中，邊際有效性的保證可能掩蓋特定區域的嚴重誤校準，對於需要精細局部預測的應用場景（如醫療、金融風險評估）尤為重要。現有理論多聚焦於平均性質，缺乏對實際局部化預測集合的有限樣本保證，尤其是同時考慮條件有效性與效率的分析。工程與產品層面，理解RLCP在有限樣本下的行為，有助於合理選擇帶寬與校準樣本大小，平衡偏差與方差，提升預測集合的實用性與可靠性。

**Method:** 核心方法是基於隨機局部化共形預測，透過引入輔助局部中心，對校準與測試樣本賦予基於核函數的權重，形成加權共形分布。作者在固定分數設定下，假設條件分數分布函數具備Hölder連續性，並在設計密度與核函數滿足標準條件下，證明了條件覆蓋誤差與長度誤差的高概率界限，界限分解為帶寬偏差項與校準誤差項。對於學習分數，假設存在一個樞軸分數（pivotal score）使得條件分數分布的分位數不依賴於協變量，進一步將誤差分解為校準誤差與分數估計誤差，並證明估計誤差線性影響局部保證。

**Result:** 理論結果包括：1) 對固定分數，給出在實際輔助中心選擇下，對局部鄰域內所有點同時成立的條件覆蓋與長度誤差界，達到經典非參數收斂率n^{-β/(2β+d)}，其中β為Hölder指數，d為協變量維度。2) 對學習分數，在樞軸條件下，消除局部化偏差，誤差由校準與估計兩部分組成，且估計誤差以高概率均勻界控制。3) 透過合成數據實驗驗證理論速率，展示帶寬選擇的偏差-方差權衡，並分析估計誤差對性能的影響。4) 提供多種分數函數實例（殘差分數、CQR分數、分布分數）及其假設驗證。

**Conclusion:** 本論文在有限樣本條件下，首次對RLCP的實際預測集合提供了同時控制條件覆蓋與效率的理論保證，並明確揭示帶寬與校準樣本大小的權衡關係。對於學習分數，提出了樞軸性假設，將估計誤差與校準誤差分離，為實務中結合學習模型與局部共形校準提供理論依據。論文的理論與實驗結果對工程師與研究者在設計與部署局部共形預測系統時具有指導意義。限制在於理論依賴較強的平滑性與密度條件，且實驗主要在合成數據上，真實世界的泛化性與計算成本尚未充分探討。

**Research Gap:** 本論文的理論分析依賴於Hölder連續性、局部密度下界及核函數支持等較嚴格假設，對於高維或非平滑場景的適用性未明確說明。學習分數的樞軸性假設雖然理論上消除偏差，但在實際複雜模型中是否成立及其影響尚未充分驗證。實驗部分主要集中於一維合成數據，缺乏多維及真實數據的廣泛測試，且未深入探討帶寬選擇的自適應策略與計算效率。此外，對於失敗案例、模型錯誤估計對局部保證的影響，以及在非交換性或分布漂移條件下的魯棒性分析仍有不足。未來工作可聚焦於放寬假設、擴展至更複雜數據結構及實際部署挑戰。

### 2. Depth-Guided Video Object Counting in Crowded Scenes

- 分數：4
- arXiv: [2608.06236v1](http://arxiv.org/abs/2608.06236v1)
- 發表日期：2026-08-06
- 分類：cs.CV, cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #2 / 8/10: Introduces a novel depth-guided approach for video object counting in crowded scenes with strong empirical gains and released dataset/code, offering practical value and clear methodological novelty.

**Intro:** 本論文聚焦於擁擠場景下的視頻目標計數任務，目標是根據文本或視覺提示準確計數目標類別的所有實例。現有方法多依賴RGB影像，面對遮擋嚴重且目標外觀相似的場景，辨識能力有限。作者提出利用深度資訊輔助，提升空間理解與遮擋辨識能力，並針對跨幀重複計數問題設計去重框架。此外，釋出包含深度資訊的多類別RGB-D視頻計數資料集，促進後續研究。

**Motivation:** 在實際應用如貨架盤點和倉庫檢查中，準確的視頻計數對自動化管理至關重要。擁擠且遮擋嚴重的場景中，僅依賴RGB特徵難以區分緊密排列且外觀相似的目標，且跨幀的視角變化和短期遮擋使得目標匹配更具挑戰。深度資訊提供三維空間的前後關係和距離約束，有助於解決遮擋和外觀混淆問題，但如何有效融合深度與RGB特徵仍是關鍵挑戰。

**Method:** 提出Depth-Guided Detector (DG-Det)，利用多尺度RGB-D交叉注意力融合深度與RGB特徵，並引入深度親和偏置以抑制空間上深度差異大的區域間錯誤關聯，同時設計遮擋感知預測頭以估計目標遮擋概率。跨幀階段，採用深度引導的目標追蹤與去重策略，結合位置、深度和外觀特徵計算匹配成本，並透過遮擋自適應時間投票機制動態調整軌跡有效性判斷，提升遮擋目標的追蹤穩定性。訓練時結合分類、邊界框回歸與遮擋預測損失，並釋出同步RGB-D視頻計數資料集以驗證方法。

**Result:** 在新釋出的RGBD-VideoCount資料集上，方法相較於多個基線（包括CountVID及多種RGB和RGB-D追蹤方法）在MAE指標上最高減少62.01%，RMSE也有穩定提升。消融實驗證明多尺度交叉注意力融合、深度親和偏置及遮擋頭均對性能有顯著貢獻。深度品質影響顯著，真實深度優於偽深度。方法對結構性深度退化（如模糊、缺失）具較好魯棒性，但對隨機噪聲較敏感。遮擋自適應時間投票機制相比固定閾值策略，能更有效平衡去重與遮擋恢復。

**Conclusion:** 本研究首次將深度資訊系統性引入擁擠場景下的視頻目標計數，通過深度引導的多尺度特徵融合與遮擋感知設計，顯著提升了目標定位與跨幀去重的準確性。釋出的RGB-D視頻計數資料集為該領域提供了新的評測基準。方法在多種基線和設定下均展現優越性能，證明深度輔助對於解決遮擋與外觀相似目標計數問題的有效性。

**Research Gap:** 全文未明確說明方法在更大規模、多樣化場景（如戶外或動態背景）下的泛化能力及實時性能，對深度感測器噪聲的容忍度雖有初步分析，但缺乏系統性評估與應對策略。跨類別混淆、極端遮擋或快速運動場景下的失敗案例未充分展示。去重策略依賴遮擋概率預測，若遮擋估計不準確可能影響結果穩定性。消融實驗中對融合模塊的設計選擇缺乏更多比較，且對計算成本與部署風險未有詳細討論。未涉及多目標同時計數時的互動影響及擴展性分析。

### 3. EnvACE: Internalizing Environment Dynamics via World Rehearsal for Agentic Reinforcement Learning

- 分數：4
- arXiv: [2608.06197v1](http://arxiv.org/abs/2608.06197v1)
- 發表日期：2026-08-06
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #3 / 8/10: Proposes EnvACE, a new agentic RL method internalizing environment dynamics via world rehearsal, showing strong empirical performance and enabling scalable training without external simulators.

**Intro:** 本論文針對大型語言模型代理在長期工具使用任務中，訓練過程依賴昂貴且難以驗證的真實或合成環境互動，提出一種新方法EnvACE。該方法透過world rehearsal機制，讓代理在訓練時不再依賴外部環境，而是由同一策略交替扮演行動者與環境角色，自行生成環境反饋。此設計使策略能內化環境動態，提升決策能力。論文在多個工具使用基準上驗證EnvACE，展現其優於現有環境擴展方法的性能。

**Motivation:** 現有大型語言模型代理訓練依賴外部環境或模擬器提供環境反饋，這些環境構建成本高且難以保證準確性，限制了訓練規模與泛化能力。模擬器雖較靈活，但回饋可能不一致且仍需真實環境監督。作者認為代理策略應同時具備行動與環境建模能力，將環境反饋生成內化於策略中，能減少對外部環境依賴，提升訓練效率與決策質量，對工程與產品落地有實際意義。

**Method:** EnvACE方法將策略分為兩個角色：行動者負責產生工具呼叫，環境角色則根據行動生成對應的環境反饋，兩者交替進行形成完整軌跡。策略參數共享並端到端優化，使用角色分別計算的基線進行Group Relative Policy Optimization (GRPO)強化學習。訓練完成後，策略可在測試時進行多次私有rehearsal，模擬多種行動結果以優化最終執行決策，無需額外外部環境互動。

**Result:** 在BFCL-v4、τ2-Bench、VitaBench及FinMCP-Bench等多個基準上，EnvACE均超越多個強力環境擴展基線，包括EnvScaler、AWM及ScaleEnv等。8B模型版本在整體評分上比次佳方法高出約1%。FinMCP-Bench中，EnvACE在TF1指標達46.78%，工具精確率最高。消融實驗顯示共享策略參數的world rehearsal優於分開策略，且在不同模型規模均有效。測試時的私有rehearsal能在有限預算下提升執行表現，證明內化環境模型的實用性。

**Conclusion:** EnvACE提出一種將環境動態內化於單一策略的agentic RL框架，透過world rehearsal機制，策略同時學習行動與環境反饋生成，提升了工具使用任務的泛化與效率。實驗證明該方法在多種基準與模型規模下均優於現有環境擴展方法，並能在測試階段透過私有rehearsal進一步提升性能。此方法為擴展大型語言模型代理訓練提供了新思路，減少對昂貴外部環境的依賴。

**Research Gap:** 論文僅在最高8B模型規模下驗證，尚未探討更大規模模型的適用性與效益。實驗主要聚焦於工具互動任務，對於其他類型的agentic任務或更複雜環境的泛化能力未充分驗證。world rehearsal在長期訓練穩定性、計算成本及實際部署風險方面的分析不足。消融實驗雖有，但對比其他環境建模方法的多樣性與失敗案例缺乏深入討論。測試時rehearsal預算與策略選擇對性能影響的機制仍未完全明確。

### 4. DASH: Divergence-Adaptive Supervision Horizons for On-Policy Self-Distillation of Reasoning Models

- 分數：4
- arXiv: [2608.06243v1](http://arxiv.org/abs/2608.06243v1)
- 發表日期：2026-08-06
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: Presents DASH, an improved on-policy self-distillation method that adaptively weights supervision based on temporal divergence, validated on multiple benchmarks with code available.

**Intro:** 本論文聚焦於強化學習中利用可驗證獎勵（RLVR）提升大型語言模型推理能力的問題。RLVR通常依賴稀疏且序列層級的回饋信號，導致難以有效分配時間上的信用。為緩解此問題，現有方法如on-policy self-distillation（OPSD）透過在學生生成的前綴上查詢教師模型，提供密集的token層級分布式監督，但仍未充分利用序列中時間結構的資訊。作者指出，標準OPSD對於不同時間點的局部差異給予相同權重，忽略了差異隨時間演變的上下文。論文提出一種新的方法DASH，旨在根據局部差異與序列平均差異的關係，自適應調整監督權重，進而改善時間上的信用分配。實驗在三個數學推理基準和三種模型規模上進行，顯示DASH在所有設定均優於標準OPSD。此方法重用OPSD已計算的教師與學生分布，無需額外前向運算，具備實用性。

**Motivation:** 在長序列推理任務中，RLVR面臨稀疏且粗糙的序列層級獎勵，難以有效指導模型每個token的決策。OPSD透過教師模型提供密集的token層級監督，緩解了稀疏性，但其均一的權重分配忽略了時間序列中差異的演變，無法根據不同時間點的上下文調整監督強度。這種忽視時間結構的做法限制了模型在長期推理中對錯誤的精細調整與改進。從工程與產品角度看，提升時間上的信用分配能增加訓練效率與推理準確度，尤其對需要長步驟推理的應用場景如數學解題與程式碼生成尤為重要。

**Method:** DASH方法核心在於利用局部distillation信號與序列平均值的差距，透過一個自適應的傳播門控機制（propagation gate）調節監督權重。具體而言，DASH先計算每個token的局部KL散度，將其與序列平均值比較後映射為門控係數，然後以反向多步聚合的方式累積權重，形成依序列上下文條件調整的監督強度。此過程使得監督權重不再均一，而是根據差異隨時間的演變動態調整，強化對錯誤累積或修正階段的監督。該方法不需額外的教師或學生模型前向計算，僅利用OPSD已計算的分布資訊，保持訓練效率。

**Result:** 實驗使用Qwen3系列模型（1.7B、4B、8B參數）與OpenThoughts-Math-30K數學推理資料集，評估於AIME 2024、AIME 2025及HMMT 2025三個基準。結果顯示，DASH在所有模型規模與基準上均優於標準OPSD，平均提升約1.4至3.2個百分點。與其他先進方法如EOPD、AVSD、PW-OPSD比較，DASH在多數情況下取得最高平均正確率。消融實驗證明，DASH的自適應門控機制是性能提升的主要來源，固定權重的多步聚合或反向門控映射均無法達到同等效果。參數敏感度分析指出，適中門控敏感度與使用forward KL作為distillation divergence效果最佳。詞彙壓縮實驗顯示保留top-100詞彙可維持大部分性能，過度壓縮則明顯退步。

**Conclusion:** 本論文提出DASH，一種基於序列相對差異自適應調整token層級監督權重的方法，解決了標準OPSD忽略時間結構的問題。DASH通過動態門控與反向多步聚合，有效利用局部差異的時間演變，提升了長序列推理任務中模型的學習效果。實驗結果在多個數學推理基準和模型規模上均顯示穩定提升，且無需額外計算資源，具備實際應用潛力。此方法為強化學習與自蒸餾領域提供了新的監督分配視角，有助於改進長期推理與時間信用分配問題。

**Research Gap:** 雖然DASH在數學推理基準上展現優異表現，但全文未明確說明其在其他類型推理任務或自然語言生成任務中的泛化能力。此外，實驗主要集中於Qwen3系列模型，缺乏對不同架構或更大規模模型的驗證。DASH依賴forward KL作為distillation divergence，對其他距離度量的適用性與穩定性仍需更深入探討。消融分析雖揭示門控機制重要性，但對於不同超參數設定下的訓練穩定性與收斂速度缺乏充分報告。最後，論文未提供DASH在實際部署中可能面臨的計算成本與延遲影響評估，對工程落地的風險與限制說明不足。
