### 1. TokEval: A Tokenizer Evaluation Suite

- 分數：7
- arXiv: [2608.18062v1](http://arxiv.org/abs/2608.18062v1)
- 發表日期：2026-08-18
- 分類：cs.CL, cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：colm; +2 提及程式碼可用; LLM rank #1 / 9/10: Introduces TokEval, a novel tokenizer evaluation framework with strong empirical validation linking intrinsic tokenizer metrics to downstream model performance, addressing a fundamental yet underexplored aspect of langua

**Intro:** 本論文針對語言模型中分詞器(tokenizer)的設計與評估問題提出了TokEval評估框架。分詞器是現代語言模型不可或缺的組件，但其設計往往被忽略，且現有的內在評估指標如壓縮率等過於狹隘，無法充分反映分詞器對下游任務性能的影響。作者透過設計多元且具語言學及結構意義的指標，並進行嚴謹的控制實驗，探討分詞器特性與模型能力間的關聯性。

**Motivation:** 分詞器設計直接影響模型的效能與訓練成本，但目前多數分詞器選擇依賴簡單啟發式指標，缺乏系統化評估方法。由於訓練完整模型以評估分詞器代價高昂，且現有內在指標與下游表現關聯不明，迫切需要一套能捕捉語言及結構特性的豐富指標體系，並透過控制變因的實驗驗證其預測能力，協助工程師與研究者更有效率地選擇與優化分詞器。

**Method:** 作者提出TokEval，一個開源的分詞器內在評估套件，涵蓋文本、數學、程式碼及多語言公平性指標。核心方法包括多種資訊理論指標（如Rényi效率、n-gram熵）、語言學對齊指標（如MorphScore）、結構完整性檢查（如UTF-8邊界完整性、數字分割一致性、AST邊界對齊）等。實驗中，作者訓練46種不同配置的分詞器，控制模型架構與訓練資料，僅變動分詞器設計，並評估模型在bits-per-byte及多項語言、數學、程式碼任務上的表現，進行混合效應迴歸分析以量化指標與下游能力的關聯。

**Result:** 實驗結果顯示，資訊理論指標與語言模型的bits-per-byte（BPB）表現高度相關（Spearman ρ最高達0.80），可作為編碼效率的可靠篩選指標。結構敏感指標如數字邊界F1與AST邊界對齊則顯著預測數學推理與程式碼生成任務的準確率。不同語言間的基線差異使得跨語言聚合分析可能掩蓋真實關係，需以語言為單位分析。壓縮率等傳統指標無法穩定預測任務準確度。基於內在指標的模型性能預測可用於篩選不適合的分詞器，但無法精確排序相近候選者。

**Conclusion:** 本論文提出的TokEval框架提供了多元且具針對性的分詞器內在評估指標，並透過嚴謹控制實驗驗證其與下游性能的關聯性。資訊理論指標適合用於快速篩選編碼效率，結構性指標則能預測特定任務表現。此方法可減少昂貴的預訓練掃描，促進分詞器設計的系統化與標準化。限制包括僅使用單一模型架構與中等規模模型，未涵蓋長上下文推理或開放式生成等能力，且實驗中分詞器配置空間仍有限，未充分驗證泛化性與失敗案例。

**Research Gap:** 本研究主要在1.27B參數的nanochat架構上進行，尚未驗證更大規模或不同架構模型中分詞器指標的適用性。實驗中分詞器設計軸向有限，未涵蓋所有可能的正規化、預分詞策略及語言組合，可能限制結論的普適性。評估任務雖涵蓋語言、數學與程式碼，但未包含長文本推理、指令跟隨或生成質量等重要能力。內在指標對任務準確度的預測力有限，且對相近分詞器排序能力不足，仍需結合下游訓練驗證。多語言公平性指標涵蓋語言有限，未能反映模型跨語言能力差異。未明確說明指標計算對不同語料庫及語言分布的敏感度及其對結果的影響。

- 發表日期：2026-08-18
- 分類：cs.CV
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：eccv; +2 提及程式碼可用; LLM rank #2 / 8/10: Proposes a novel memory tree guided key frame selection method for efficient 3D question answering, demonstrating significant performance gains and practical efficiency improvements with code available, validated on stro

**Intro:** 3D 問答在場景理解與實體環境中扮演關鍵角色，尤其對於機器人導航、家居服務與擴增實境等應用至關重要。然而，現有視覺語言模型在處理高幀率3D掃描影片時，面臨計算與記憶體資源限制，導致效率與準確度受限。傳統方法多依賴視覺搜尋來挑選關鍵影格，但此方法在每次查詢時都需遍歷大量影片影格，效率低下且難以即時回應。本文提出一種基於記憶樹結構的關鍵影格查詢方法，旨在提升3D問答的效率與準確性。

**Motivation:** 現有視覺搜尋方法雖能減少輸入影格數量，但每次查詢仍需對整段影片進行搜尋，導致計算成本隨影片長度線性增加，且無法有效處理多輪查詢。此外，視覺搜尋依賴物件偵測，若偵測失敗則無法找到相關影格，降低系統穩健性。為解決這些問題，作者設計一種可重用且即時建構的3D場景表示MemTree3D，結合大型語言模型推理，能在不重複視覺搜尋的情況下，快速定位與查詢相關影格，提升實務應用中即時互動的可行性。

**Method:** 本文提出MemTree3D，一種三層結構的3D場景表示，包括位置節點、物件節點與偵測節點。利用相機6自由度姿態資訊，將影片切分為多個空間位置節點，並在每個節點中追蹤物件軌跡。該結構可於影片錄製時即時建構，並以JSON格式序列化供大型語言模型推理。語言模型根據問題與MemTree3D推理出時間與空間線索，指導關鍵影格選擇，避免對整段影片進行昂貴的視覺搜尋。最後，選出的關鍵影格輸入視覺語言模型進行最終問答。

**Result:** 在OpenEQA、ScanQA與SQA3D三大3D問答基準上，MemTree3D方法顯著提升問答準確率。以GPT-4o為視覺語言模型時，在OpenEQA上LLM-Match指標提升17.4%，且相較於傳統視覺搜尋方法，關鍵影格檢索速度提升約69%。此外，該方法在多輪查詢場景中展現更低延遲，且在物件偵測失敗時仍能維持較高準確度，顯示系統具備較佳的穩健性。實驗亦證明MemTree3D可與多種開源及專有模型搭配使用，具備良好泛化能力。

**Conclusion:** 本文提出的MemTree3D結合大型語言模型推理，成功解決了3D問答中視覺搜尋效率低與偵測失敗問題。該方法透過即時建構的輕量級3D場景樹結構，實現高效且準確的關鍵影格選擇，適合資源受限的實體環境應用。實驗結果證明其在多個基準上均優於現有方法，並具備良好的多輪查詢效率與錯誤容忍度。此方法為3D問答系統在真實場景中落地提供了可行的技術路徑。

**Research Gap:** 本文雖展現優異效能，但仍存在幾項不足。首先，MemTree3D依賴6-DoF相機姿態資訊，對於無法準確獲取此資訊的場景適用性未明。其次，對於極端視覺偵測失敗或物件遮擋嚴重的情況，系統的恢復能力與泛化性尚未充分驗證。第三，實驗主要聚焦於室內場景，對於戶外或動態環境的適應性未探討。此外，關鍵影格選擇的權重參數未經細緻調優，可能影響不同場景下的表現穩定性。最後，全文未明確說明系統在大規模長影片或多用戶同時查詢時的資源消耗與部署風險，這對實際產品化仍具挑戰。

### 3. Debate Training Reduces Reward Hacking in RLAIF

- 分數：5
- arXiv: [2608.17776v1](http://arxiv.org/abs/2608.17776v1)
- 發表日期：2026-08-18
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #3 / 7/10: Presents a credible and well-evidenced approach to reduce reward hacking in reinforcement learning from AI feedback via debate training, with thorough experiments on verifiable tasks and nuanced analysis of multi-agent t

**Intro:** 本文探討在強化學習從AI反饋（RLAIF）中，如何減少獎勵駭客行為。獎勵駭客是指策略利用AI評審系統的系統性錯誤，導致任務表現下降的問題，尤其在評審模型能力弱於策略模型時更為嚴重。作者以數學推理任務為實驗場景，利用可驗證的最終答案正確性來衡量獎勵駭客現象，並比較單玩家RLAIF基線與雙玩家辯論訓練的效果。研究中使用較強的Gemini 2.5 Flash模型作為策略，較弱的Gemini 2.5 Flash Lite作為凍結評審模型，模擬現實中較弱模型監督更強模型的情境。

**Motivation:** 在RLAIF中，隨著訓練進行，策略可能學會利用評審模型的缺陷來獲取更高獎勵，導致模型行為偏離預期，這對於日益強大的AI系統監督是一大挑戰。傳統方法如線上更新獎勵模型或約束優化難以隨模型能力提升而有效防止獎勵駭客。辯論訓練透過生成者與批評者的對抗，讓評審模型能接收到更多反駁信息，有望提升評審判斷的穩健性，進而減少獎勵駭客行為，對於工程和產品中需要長期穩定性能的AI系統尤為重要。

**Method:** 作者設計一種雙玩家零和辯論遊戲，策略模型同時扮演生成者（Alice）和批評者（Bob）兩個角色，生成者提出解答，批評者提出批評，最後由凍結的較弱LLM評審判定勝負。訓練過程中，Alice和Bob共享權重，透過多代理強化學習自我對弈進行優化。實驗中比較單玩家RLAIF基線（僅Alice生成解答）與雙玩家辯論（Alice生成解答，Bob批評）及三回合辯論（增加Alice反駁回合）。評審基於多次獨立投票給予獎勵，並對批評和反駁回合設置字數限制以避免評審被冗長輸出操控。

**Result:** 實驗結果顯示，雙玩家辯論訓練能有效抑制獎勵駭客，維持評審判斷的Matthews相關係數穩定，並保持較高的最終答案正確率，較單玩家基線提升約2個百分點，回復約45%的性能差距。當評審模型能力進一步降低時，增加辯論回合數能補償評審弱勢，提升穩定性。辯論訓練亦能克服明確的誤導性提示，促使策略回歸正確解答。相比使用可驗證獎勵，使用LLM評審的訓練在訓練與驗證獎勵間的差距較小，顯示較佳的泛化能力。嘗試用真實標籤訓練批評者說服評審的實驗進展緩慢，暗示說服評審認同真相較指出錯誤更具挑戰。

**Conclusion:** 本文首次展示多代理強化學習辯論訓練能在RLAIF中減少獎勵駭客，維持評審判斷穩定並提升策略最終答案正確率，對於無法直接獲得真實標籤的任務尤具實用價值。辯論訓練通過對抗性自我對弈，促使策略避免利用評審漏洞，提升訓練穩定性和性能。然辯論遊戲需透過字數限制等機制平衡，避免批評者過度操控評審，否則可能導致新的駭客行為。該方法在數學推理任務中取得積極成果，為可擴展監督提供了有希望的技術路徑。

**Research Gap:** 本研究限於數學推理任務，該任務具備可驗證的客觀標準，未涵蓋主觀或模糊任務，這些場景中辯論訓練效果尚不明確。策略與評審模型架構相似，與人類監督超強AI的情境存在差異，未充分模擬未來監督挑戰。辯論訓練中批評者說服評審的能力有限，且字數限制雖防止駭客行為，但限制了批評表達的深度與細膩度，可能影響評審判斷質量。訓練動態與獎勵駭客產生機制尚未完全理解，缺乏對失敗案例和泛化能力的深入分析。此外，辯論訓練增加計算與實現複雜度，對實際部署成本與風險評估不足。未來需探索更靈活的遊戲平衡機制及擴展至更廣泛任務類型。

**Intro:** 本論文探討大型語言模型（LLM）代理在跨結構化工作流程與多會話操作時，長期記憶中證據可達性的問題。現有記憶檢索多依賴語義相似度，雖能有效回溯主題相關記憶，但常忽略語義距離較遠的早期經驗、計畫或動機，導致重要背景資訊無法被檢索。作者提出CABLE，一種補充式先行記憶連結與擴展機制，旨在擴展主檢索器的語義覆蓋範圍，提升跨記憶與跨會話的證據檢索能力。

**Motivation:** 在實際工程與產品中，LLM代理需處理長期且跨多階段的對話或任務，單純保留歷史記憶並不足以保證後續查詢能找到所有相關證據。現有記憶圖多以語義重疊為連結依據，容易與主檢索器重複檢索結果，浪費有限的上下文容量。為提升檢索效率與效果，必須優先建立能補充主檢索器、且稀疏且具推理價值的連結，避免冗餘並擴展檢索範圍，這對於多會話、開放領域及偏好導向問題尤為重要。

**Method:** CABLE在記憶寫入階段，針對每個新記憶生成多個先行導向查詢，分別檢索主檢索器的直接語義鄰居與先行候選記憶，並將兩者重疊部分剔除，剩餘候選經由LLM驗證其是否提供有用的先行背景或動機，通過者即建立有向先行連結，形成稀疏的記憶圖。檢索階段，CABLE從主檢索器返回的種子記憶出發，沿著先行連結擴展一跳，並透過相似度與新穎性過濾選擇補充記憶，無需額外LLM調用，確保擴展結果具補充性且不冗餘。

**Result:** 作者在兩個長期記憶對話基準LoCoMo與MA-LongMemEval上，將CABLE整合至三種不同記憶系統（A-MEM、SimpleMem、Mem0g），並使用多種LLM骨幹（Qwen3.5-27B、DeepSeek-chat、GPT-4o-mini）進行評估。結果顯示CABLE在所有系統與模型設定下均提升平均LLM評分，最大提升達6個百分點。尤其在開放領域、多會話及偏好導向問題類別中效果顯著。消融實驗證明重疊剔除與LLM驗證均為關鍵組件。質性分析展示CABLE能連結語義距離較遠但推理相關的記憶，補足主檢索器不足。

**Conclusion:** 本研究提出CABLE作為一種補充主檢索器的記憶連結與擴展機制，有效提升長期記憶中證據的可達性。實驗跨多基準、多記憶系統與多模型，均證明其穩定提升檢索與問答表現。CABLE強調稀疏且具推理價值的先行連結，避免冗餘擴展，並且檢索階段無需額外模型調用，具備實用性與擴展性。此方法對於需要跨多階段、跨會話整合資訊的LLM應用具重要參考價值。

**Research Gap:** 全文未明確說明CABLE在極大規模記憶庫或更複雜多代理系統中的效能與擴展性，尤其在記憶圖規模增長時的維護成本與檢索延遲未充分探討。驗證階段依賴LLM判斷先行連結的合理性，可能受限於驗證模型的準確性與偏差，缺乏對錯誤連結對系統整體影響的分析。實驗中上下文容量固定，未評估在不同上下文限制下CABLE的表現變化。此外，對於時間序列嚴格依賴的任務（如時間推理）表現下降，顯示方法在特定任務類型的適用性有限，未提供針對此類問題的改進策略。最後，消融實驗雖有，但對比其他先進連結生成或檢索擴展方法的全面比較不足，限制了對方法優劣的深入理解。

### 5. aDSL: Agentic 3D Creation via Joint Agent-Program Design

- 分數：5
- arXiv: [2608.17975v1](http://arxiv.org/abs/2608.17975v1)
- 發表日期：2026-08-18
- 分類：cs.GR, cs.CV
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #5 / 7/10: Co-designs a domain-specific language and multi-agent system to improve robustness and controllability in 3D content creation via LLMs, demonstrating clear practical benefits and enabling downstream applications with ope

**Intro:** 3D內容創建是電腦圖形學中的基礎問題，支撐遊戲、電影製作及具身AI等多種應用。現有基於大型語言模型(LLMs)的3D程式生成方法常因低層數值參數不穩定，導致生成結果與用戶意圖不符且難以迭代修正。本文提出一種結合代理中心領域專用語言(aDSL)與多角色代理系統的訓練免費框架，旨在提升3D程式生成的穩健性與可控性。該系統通過語義結構與空間推理橋接高層意圖與低層幾何，並利用生成-執行-評價循環進行程式合成與修正。

**Motivation:** 現有3D程式生成多依賴低層次的數值座標，對LLM的語義推理能力支持不足，導致生成的幾何結構易出錯且難以修正。純粹提升語言表達能力無法解決數值不精確帶來的幾何錯誤。為此，需要設計一種更貼合LLM推理特性的程式語言，並配合專門的代理系統進行分工合作，實現結構化、可驗證且易於修正的3D內容生成流程，從而提升生成結果的準確性和用戶意圖的忠實度。

**Method:** 本文設計了aDSL，一種強調表達力、組合性與空間推理的3D程式語言，支持參數化幾何基元、布林運算、層次組合及空間約束操作。aDSL以Python嵌入形式實現，方便重用與驗證。基於aDSL，系統包含四個角色代理：Planner負責將用戶輸入分解為結構化規範與空間約束；Coder根據規範生成程式；Executor執行程式並產生幾何與渲染；Critic結合視覺與程式層面檢查結果，反饋給Coder進行迭代修正。整體流程採用Plan-Execute-Critic循環，支持多輪自我修正與用戶交互。

**Result:** 在文本到形狀及圖像到形狀生成任務中，aDSL系統在CLIP、VQA及FID等指標上均優於多個先進基於程式碼生成的基線方法，且執行成功率達100%。用戶研究顯示，生成結果在語義對齊與幾何質量上均獲得顯著偏好。消融實驗證明空間推理操作與迭代修正環節均對性能提升關鍵。系統還支持關節物體生成、局部程式編輯、高保真細節生成及場景組合等下游應用，展示了良好的靈活性與可擴展性。

**Conclusion:** 本文提出的aDSL及其多代理系統通過結合結構化程式語言與迭代生成-驗證-修正流程，有效提升了基於LLM的3D內容創建的穩健性、可控性與可編輯性。該方法不依賴訓練數據，能處理多種輸入條件並支持複雜的結構與運動定義。限制包括DSL表達能力對極複雜幾何及材質效果的支持有限，評價主要依賴2D渲染存在視角歧義，以及依賴專有LLM限制了普及性。未來工作可聚焦於提升DSL豐富度、加強3D層面驗證及開源模型的能力遷移。

**Research Gap:** 本文雖展示了aDSL與多代理系統的優勢，但仍存在幾點不足。首先，DSL的幾何基元及布林運算對極其複雜或高細節的模型支持有限，限制了生成多樣性與真實感。其次，Critic主要依賴2D多視角渲染進行驗證，可能因視角遮擋導致錯誤判斷，缺乏直接3D幾何驗證機制。第三，系統依賴強大的專有LLM完成長程空間推理與修正，未明確說明在開源或較小模型上的適用性與性能。最後，消融實驗中缺乏對不同代理角色間協同策略的深入分析，且未充分探討在更大規模場景或多樣化物件類別下的泛化能力與失敗案例。這些限制提示未來需加強DSL表達力、完善3D驗證方法及降低對專有模型的依賴。
