### 1. Where Natural Language Ends in Agents: Executable Skill Composition with MetaSkill

- 分數：7
- arXiv: [2610.24723v1](http://arxiv.org/abs/2610.24723v1)
- 發表日期：2026-10-17
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：meta; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #1 / 9/10: MetaSkill proposes a novel hybrid representation for executable skill composition in agents, supported by rigorous empirical evaluation with multiple LLMs and artifact tasks, with clear practical value and code availabil

**Intro:** 本論文探討在多技能代理系統中，如何有效地組合開放式任務知識。傳統以自然語言描述的技能組合缺乏明確的執行順序與輸出交接機制，導致多技能協作時容易出錯。作者提出MetaSkill，一種混合表示法，將技能包完整保留並在技能邊界引入可執行的依賴關係與前置文本綁定，透過有向無環圖（DAG）運行時管理調度與資料流。此方法旨在保持技能內部的語言靈活性，同時實現跨技能的明確協調與可審計執行。論文基於20個多技能任務及兩種大型語言模型進行實驗，並與自然語言程序、提示圖及AgentSkillOS等系統比較，展示MetaSkill在產物質量與執行合規性上的優勢。

**Motivation:** 多技能代理系統在實際應用中面臨跨技能調度與資料交接的挑戰，若僅依賴自然語言描述，模型需自行推斷執行順序與輸入輸出關係，易導致錯誤與不一致。現有工作多將控制流程與狀態封裝為可執行語言，但往往要求技能內部重寫或限制靈活性。MetaSkill提出在技能調用邊界選擇性形式化，將持久且可機器檢查的協調關係抽象出來，既保留技能本身的語言自由度，也提供明確且可執行的跨技能協調機制，對工程實踐中提升系統穩定性與可維護性具重要意義。

**Method:** MetaSkill將每個技能調用視為一個節點，包含完整的技能包與本地自然語言指令，並在節點間建立依賴關係與前置文本綁定，形成一個有向無環圖。運行時系統先驗證圖的結構正確性（無重複節點、無循環等），再根據依賴關係調度節點執行，並將前置節點輸出文本渲染為下游節點的輸入參數。技能內部仍由模型根據本地指令自由生成結果，跨技能的執行順序與資料流由MetaSkill運行時嚴格管理。此設計使得跨技能協調成為可檢查且可審計的操作，而不影響技能內部的語言推理與決策。

**Result:** 在20個多技能任務上，使用GLM-5.2與DeepSeek-V4-Flash兩種大型語言模型，MetaSkill相較於自然語言程序（NL-SOP）與提示圖（Prompt Graph）在人工盲評產物質量上均有優勢，DeepSeek-V4-Flash下對Prompt Graph的偏好估計達0.658且95%置信區間排除平價。與AgentSkillOS在相同技能包條件下比較，MetaSkill也呈現較佳偏好（0.542）。與其他代理系統（OpenSquilla、OpenClaw、Hermes Agent）比較，MetaSkill在OpenClaw下偏好估計達0.625且排除平價。GLM-5.2執行追蹤顯示所有節點均成功執行且無違反宣告的依賴關係，證明MetaSkill運行時能有效維護執行順序與資料綁定。

**Conclusion:** MetaSkill透過在技能調用邊界引入可執行的依賴與文本綁定，實現了跨技能協調的明確性與可審計性，同時保留技能內部的語言靈活性。實驗結果表明，MetaSkill在多技能任務中能提升產物質量並確保執行合規，對於構建穩健且可擴展的多技能代理系統具有實用價值。該方法為技能組合提供了一種平衡語言自由度與結構化協調的設計思路，對工程與產品落地均具參考意義。

**Research Gap:** 本研究聚焦於技能組合的執行階段，未涵蓋技能檢索與選擇過程，未評估在大規模或動態技能庫中MetaSkill的適用性與效能。產物質量評估僅依賴單一固定評審，且受限於輸入資料與視覺證據的呈現，可能影響偏好判斷的泛化性。實驗中使用的任務與技能數量有限，尚未充分驗證方法在更複雜或異質場景下的穩健性。此外，全文未明確說明MetaSkill在面對技能失敗、異常處理或資源限制時的表現與成本，這些均為實際部署時需進一步探討的問題。

### 2. VisR-RAG-Fin: Benchmarking Multimodal RAG over Visually Rich Financial Documents

- 分類：cs.IR
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：sigir; +2 提及程式碼可用; LLM rank #2 / 8/10: VisR-RAG-Fin offers a comprehensive benchmark and systematic analysis for multimodal retrieval-augmented generation on visually rich financial documents, addressing a practical and underexplored challenge with code and s

**Intro:** 本論文聚焦於企業文件中視覺豐富的金融報告，這類文件結合了密集文字、表格、圖表和複雜版面，對於 Retrieval-Augmented Generation (RAG) 系統在檢索和生成階段帶來挑戰。現有多數評測偏重純文字，忽略了視覺與版面結構資訊，導致無法充分反映真實工業場景中 RAG 系統的效能。為此，作者提出 VisR-RAG-Fin，一個保留原始版面與視覺內容的金融文件多模態 RAG 基準，並系統性分析檢索與生成模組在不同配置下的表現。

**Motivation:** 金融文件的視覺結構複雜，傳統文字檢索無法有效捕捉表格、圖表等視覺元素，影響檢索準確度與答案生成品質。多模態檢索與視覺語言模型的進展提供了可能，但缺乏針對視覺豐富企業文件的端到端 RAG 系統評測與設計指引。此研究旨在填補此空白，提供一套可重複使用的基準建構流程與實證分析，幫助從業者理解不同檢索與生成策略對系統整體效能的影響，促進多模態 RAG 在工業應用中的落地。

**Method:** 作者設計一套七階段的基準建構流程，包括文件收集、過濾、頁面抽樣、QA 生成與人工審核、查詢重寫及難負樣本挖掘。文件來源涵蓋九家歐洲大型銀行公開金融報告，保證資料多樣性與代表性。QA 生成採用 GPT-4o 等視覺語言模型，強調問題須依據視覺元素並具推理性。人工審核確保問題與答案的正確性與合理性，並透過 GPT-5 進行查詢重寫以符合 RAG 使用場景。檢索實驗涵蓋文字、單向向量與多向量多模態模型，生成實驗則評估多種開源與閉源視覺語言模型，並以 GPT-5.2 作為答案正確性評判者。

**Result:** 實驗結果顯示，多向量多模態檢索器在頁面檢索任務中表現最佳，顯著優於文字檢索器，尤其在表格與視覺證據類問題上提升明顯。難負樣本挖掘增加檢索難度但不改變模型排名。生成階段，閉源模型 GPT-5.2 在提供 oracle 頁面時達近八成正確率，但在實際檢索上下文中正確率大幅下降近 40 個百分點，反映檢索噪聲為主要瓶頸。影像上下文（image-only）與混合上下文（hybrid）均明顯優於純文字上下文，且在簡單與困難問題上均有提升，顯示視覺資訊對答案生成至關重要。

**Conclusion:** 本研究提出 VisR-RAG-Fin 基準與建構流程，為多模態 RAG 在視覺豐富金融文件上的評測提供了實用工具與深入分析。結果強調多向量多模態檢索與視覺上下文對提升系統效能的重要性，並揭示檢索階段的準確性對最終生成結果影響甚鉅。此工作為工業界設計與評估多模態 RAG 系統提供了具體指引，尤其適用於複雜企業文件的問答應用。

**Research Gap:** 本論文雖提供全面的基準與分析，但仍存在幾項不足。首先，生成實驗僅使用部分查詢子集，可能限制結果的全面性。其次，全文未明確說明模型在不同語言或非歐洲金融文件上的泛化能力，限制跨域應用。第三，對於檢索與生成錯誤的細緻分析不足，未揭示失敗案例與具體原因。第四，雖有硬負樣本挖掘，但缺乏對檢索效率與計算成本的討論，對實際部署風險評估有限。最後，缺少對多模態融合策略的消融實驗，無法明確判斷視覺與文字資訊融合的最佳方式。未來研究可針對這些方面進行深入探討。

### 3. Uncovering Semantic Hierarchies in Text-Attributed Graphs via Variational EM-based LLM-GNN Synergy

- 分數：5
- arXiv: [2610.24624v1](http://arxiv.org/abs/2610.24624v1)
- 發表日期：2026-10-17
- 分類：cs.LG
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #3 / 7/10: SHiFT introduces a credible and theoretically grounded LLM-GNN synergy for uncovering semantic hierarchies in text-attributed graphs, with strong empirical results and code release.

**Intro:** 本文探討文本屬性圖（Text-Attributed Graphs, TAGs）中固有的語義層級結構，指出現有方法多在平面語義空間中學習節點表示，忽略了真實資料中存在的粗細粒度層級。TAGs廣泛存在於學術文獻、電商和社交媒體等領域，這些資料天然呈現層級語義結構，對於提升圖表示學習的語義豐富度和可解釋性具有重要意義。作者提出一種結合大型語言模型（LLM）與圖神經網絡（GNN）的變分期望最大化（Variational EM）框架，旨在同時挖掘並利用TAG中的語義層級結構。

**Motivation:** 現有TAG表示學習方法多聚焦於捕捉圖的拓撲結構，卻缺乏對節點文本語義層級的建模，導致學習到的嵌入缺乏層級語義解釋。雖有超曲面嵌入等方法嘗試引入層級結構，但其結果多為隱式的幾何座標，缺乏明確的語義概念，且優化複雜。LLM具備豐富的語義推理能力，能生成可讀的語義分類，但無法直接感知圖結構；GNN則擅長結構聚類但缺乏語義命名能力。如何有效結合兩者優勢，挖掘TAG中隱含的語義層級，並降低LLM推理成本，是工程與研究落地的關鍵挑戰。

**Method:** 提出SHiFT框架，採用EM迭代策略。E步驟中，利用GNN生成的節點嵌入進行過度聚類，從每個微群中抽取代表性文本，透過LLM作為專家分類師生成語義樹狀結構，並透過輕量的Mapping & Diagnosis策略，僅在檢測到語義異常時局部更新層級結構以節省推理成本。M步驟中，固定語義層級結構，優化GNN編碼器，使節點嵌入在三個層面與層級結構對齊：分群一致性（Taxonomy Partition Alignment）、層級骨架幾何一致性（Taxonomy Skeleton Alignment）及語義概念對齊（Taxonomy Concept Alignment）。理論上，SHiFT可視為一種廣義的變分EM算法，保證迭代收斂。

**Result:** 在五個多領域大型TAG數據集上，SHiFT在節點分類任務中平均準確率達81.4%，超越多個經典GNN、超曲面嵌入及最新LLM+GNN混合方法，尤其在大規模數據集ArXiv上提升明顯。節點聚類任務中，SHiFT在NMI與ARI指標上均優於對比方法，顯示其能更好地解耦語義結構。語義層級結構的內在一致性通過NPMI指標和人工評估得到驗證，後者評估了概念可讀性、一致性及層級合理性，SHiFT均優於純文本基線。利用誘導層級路徑作為特徵增強，能顯著提升結構無感知模型（MLP）及結構感知模型（GCN）的分類性能。消融實驗證實EM迭代及三種對齊目標均對性能有顯著貢獻。

**Conclusion:** 本文提出的SHiFT框架成功結合LLM的語義推理與GNN的結構學習能力，通過變分EM方法挖掘並利用TAG中的語義層級結構。該方法不僅提升了下游任務性能，還生成了高質量且可解釋的語義分類樹，對工程實踐中提升TAG表示的語義豐富度和可解釋性具有重要價值。理論分析支持其收斂性與合理性，實驗結果全面展示了其優越性與穩健性。

**Research Gap:** 本文雖在多數公開數據集上驗證了SHiFT的有效性，但對於更大規模或異構圖結構的泛化能力尚未充分探討。LLM推理成本雖經Mapping & Diagnosis策略優化，但在極大規模實際應用中仍可能成為瓶頸，全文未明確說明具體成本與延遲。誘導的語義層級結構主要基於靜態文本與圖拓撲，對動態變化或多模態信息的適應性未涉及。消融實驗未包含更多不同LLM或GNN架構的比較，對模型架構敏感性分析有限。此外，失敗案例、錯誤分類或語義層級錯誤的具體分析缺乏，限制了對模型穩健性和風險的全面評估。

### 4. CorrCLIPv2: Harnessing Unlabeled Images for Open-Vocabulary Semantic Segmentation

- 分數：4
- arXiv: [2610.24757v1](http://arxiv.org/abs/2610.24757v1)
- 發表日期：2026-10-17
- 分類：cs.CV
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: CorrCLIPv2 advances open-vocabulary semantic segmentation by leveraging unlabeled images and multi-CLIP ensembles, achieving state-of-the-art results surpassing fully supervised methods, with extensive experiments and co

**Intro:** 本論文聚焦於開放詞彙語義分割（Open-Vocabulary Semantic Segmentation, OVSS），該任務旨在不受限於固定類別集，對影像中的像素進行分類。現有基於CLIP的模型雖具備強大的零樣本識別能力，但在細粒度分割上受限於不同類別間的patch互動噪聲，導致性能下降。作者提出一個無需訓練的物件中心框架CorrCLIPv2，從patch相關性、特徵表示及輸出正則化三方面進行改進，並進一步引入跨影像物件檢索機制以減少語境偏差。該方法在多個標準資料集上達成新的最佳表現，甚至超越部分全監督方法。

**Motivation:** CLIP模型的對比學習目標偏重全局資訊，導致局部patch間表徵過於相似，降低了局部區域的辨識能力。現有方法多透過調整最後ViT層的注意力機制來提升分割，但未明確區分有害的跨類別相關性。作者的分析發現跨類別patch相關性主要是噪聲，反而損害分割效果，因此有必要明確限制patch間的互動範圍。此外，CLIP早期層的全局交互使物件表徵易受背景干擾，單一影像難以修正語義漂移，故引入跨影像檢索以聚合多樣語境下的物件特徵，提升穩定性與準確度。

**Method:** CorrCLIPv2基於CLIP的ViT視覺編碼器，核心在最後一層重構patch間相關性。首先，利用無類別遮罩生成器產生物件區域遮罩，限制patch間互動僅在同一物件內（Scope Reconstruction），以減少跨類別干擾。接著，採用自監督學習的視覺基礎模型（VFM）特徵重建相似度矩陣（Value Reconstruction），軟化遮罩不準確帶來的影響。再透過雙分支特徵精煉（Feature Refinement）結合空間細節與語義資訊，最後以遮罩內多數投票統一預測（Map Correction）提升空間一致性。進階版本引入跨影像物件檢索，建構基於VFM特徵的離線記憶庫，檢索語義一致的支持物件特徵，並融合多CLIP模型特徵（Decoupled Multi-CLIP Ensemble）以增強泛化與穩定性。

**Result:** 作者在十個標準資料集及包含22個多領域資料集的MESS基準上進行評測。實驗顯示，基礎CorrCLIP已優於多數訓練自由方法，且CorrCLIPv2透過跨影像檢索與多模型融合，平均mIoU提升至51.0%，超越包括ReME等依賴語言先驗的記憶庫方法，並在大語彙量資料集如ADE20K-847上有顯著提升。與全監督方法比較，CorrCLIPv2在多數跨域資料集表現更佳，證明其優越的泛化能力。消融實驗驗證各模組對性能的貢獻，且不同VFM、遮罩生成器及記憶庫資料集均影響最終表現。計算成本方面，CorrCLIPv2在保持高效推理的同時，透過輕量版本兼顧速度與準確度。

**Conclusion:** 本研究揭示CLIP中跨類別patch相關性為分割性能瓶頸，提出無需訓練的物件中心框架CorrCLIPv2，有效重構相關性、精煉特徵並統一輸出，顯著提升CLIP的分割能力。跨影像檢索機制利用大量未標註影像構建語義一致支持集，減少語境偏差並提升穩定性。多模型融合策略在不增加推理負擔下進一步強化性能。實驗結果證明該方法在多個標準及跨域資料集達成最先進表現，展現良好的擴展性與泛化能力。整體而言，該框架為開放詞彙語義分割提供了一個可行且高效的基礎。

**Research Gap:** 儘管CorrCLIPv2在多項評測中表現優異，仍存在若干限制。首先，對於語義干擾的抑制依賴於遮罩生成器的品質，當遮罩不準確時仍可能影響結果，且遮罩解析度與CLIP特徵解析度不匹配帶來量化誤差。其次，跨影像檢索依賴於記憶庫中樣本的多樣性與覆蓋度，對於特定專業領域或稀有類別的支持不足會導致性能下降。此外，全文未明確說明在極大規模記憶庫下的檢索效率與存儲成本，以及在實際部署中對硬體資源的需求。最後，模型對於開放詞彙中大量無關類別的語義干擾仍較敏感，缺乏有效的圖像級類別預篩選機制，未來可針對此方向進行深入研究以進一步提升實用性。

### 5. What RL Brings to Reasoning: A Few Decisions the Base Model Would Not Make

- 分數：4
- arXiv: [2610.24663v1](http://arxiv.org/abs/2610.24663v1)
- 發表日期：2026-10-17
- 分類：cs.CL, cs.LG
- 入選理由：+2 提及頂級機構：mila, mit; +2 提及程式碼可用; LLM rank #5 / 6/10: This paper provides insightful analysis on what reinforcement learning adds to reasoning models, with detailed interventions and strong empirical evidence, plus code availability.

**Intro:** 本論文探討強化學習（RL）在提升數學推理能力中，對基礎語言模型帶來的具體貢獻。雖然RL訓練確實顯著提升模型在數學問題上的表現，但其改進的本質與機制尚不明確。作者透過在生成過程中對基礎模型進行多種干預，量化RL模型相較基礎模型的性能提升中，哪些部分可被回收。研究以Qwen3-4B-Base及其RL訓練版本為主要對象，並在AIME及MATH-500等數學競賽題庫上進行評估。

**Motivation:** 理解RL帶來的提升對工程與產品落地至關重要，因為這關係到是否必須完整部署RL模型或可透過部分策略提升基礎模型性能。若RL主要透過少數關鍵決策改變生成結果，則可設計混合解碼策略以兼顧準確度與多樣性，降低部署成本。此外，釐清RL是否教會模型新能力或僅是更有效利用既有能力，有助於後續研究聚焦於模型能力本質與強化學習策略的改進。

**Method:** 作者設計一系列生成時干預實驗，包括：1) 利用power sampling（MCMC）嘗試透過銳化基礎模型分布回收RL提升；2) 在兩模型貪婪解碼結果不一致的位置，僅替換為RL模型的token（約4%位置），觀察性能恢復程度；3) 強制基礎模型以RL模型常用的開頭詞“Alright”開始生成，評估開頭詞貢獻；4) 針對後續token替換，嘗試以固定規則插入反思詞如“Wait”，檢驗是否能複製RL提升；5) 評估稀疏替換策略在保持基礎模型多樣性的同時，能否維持RL模型的準確度提升。實驗主要在120道AIME問題及MATH-500上進行，並比較多個模型對。

**Result:** 實驗結果顯示，power sampling在8,192 token輸出限制下，無法超越基礎模型的貪婪解碼，且無法回收RL的性能提升。稀疏替換策略（rl-replace）在約4%不同token位置替換為RL模型選擇，回收了90.5%的pass@1提升，且在三組模型對及MATH-500上均有類似表現。強制開頭詞“Alright”可回收約35%的提升，但後續token替換仍貢獻額外5.2個百分點。固定規則插入反思詞如“Wait”未能複製此效果。稀疏替換保持較高多樣性，且在大樣本數（k=256）下，解題率達67.5%，顯著高於RL模型（61.4%）及基於回應層級混合策略（61.45%）。

**Conclusion:** 本研究證明RL提升數學推理性能主要來自少數關鍵token決策的改變，尤其是開頭詞與後續選擇的結合。稀疏替換策略能有效回收RL提升，且兼顧生成多樣性與大樣本覆蓋率，對工程實踐有指導意義。固定規則插入反思詞無法複製RL效果，暗示RL可能學會何時適當使用反思行為，而非單純增加反思詞頻率。此研究提供了分析RL增益的通用干預框架，並揭示了基礎模型與RL模型間行為差異的細節。

**Research Gap:** 論文未明確說明稀疏替換策略在實際部署中的計算成本與延遲影響，因為每步解碼需同時查詢兩模型。固定規則插入反思詞的失敗未進一步探討是否可透過學習式或基於不確定度的選擇策略改善。實驗主要聚焦於數學推理競賽題，對其他推理任務或多模態場景的泛化性尚未驗證。對於RL是否創造全新推理路徑仍無定論，因為稀疏替換為混合生成策略，無法完全反映模型內部能力。消融實驗中對開頭詞與後續token替換的交互作用未完全拆解，限制對各部分貢獻的精確理解。
