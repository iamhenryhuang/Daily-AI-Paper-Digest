### 1. Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents

- 分數：7
- arXiv: [2611.14320v1](http://arxiv.org/abs/2611.14320v1)
- 發表日期：2026-11-10
- 分類：cs.AI, cs.MA
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; +2 提及程式碼可用; LLM rank #1 / 9/10: Introduces a novel evidence-linked memory system (WikiTrace) that addresses a clear limitation in LLM agents' memory degradation with strong empirical validation across multiple benchmarks and publicly available code.

**Intro:** 本論文探討大型語言模型（LLM）代理在使用外部記憶時，可能出現的記憶引起的性能退化問題。這種退化通常是因為代理依賴了錯誤或誤用的經驗教訓，導致在本可解決的任務上失敗。作者提出一種名為WikiTrace的證據鏈接記憶系統，讓代理能夠在執行新任務時，根據原始執行軌跡檢查和修正記憶中的教訓。此方法旨在提升代理的經驗重用效率，同時降低記憶引起的退化風險。

**Motivation:** 現有記憶方法多從成功或失敗的任務軌跡中萃取教訓，但這些教訓通常缺乏對原始軌跡的連結，代理無法驗證教訓的正確性。這導致代理在新任務中可能誤用錯誤教訓，造成性能下降。為了提升記憶的可靠性與可驗證性，必須讓代理能夠回溯並檢查教訓的來源，確保教訓適用於當前任務。WikiTrace正是基於此需求，設計出多層次鏈接記憶結構，支持代理在決策時動態訪問原始證據。

**Method:** WikiTrace將記憶組織為三層結構：最上層為簡潔的教訓（insights），中間為對軌跡成功或失敗原因的總結（compilations），底層為完整的原始軌跡（raw trajectories）。每個教訓都鏈接回其來源軌跡和總結，保持來源透明。代理在執行新任務時，會先從所有教訓開始，當教訓缺乏足夠細節、與其他教訓衝突或來自失敗軌跡時，代理會沿著鏈接深入查閱原始軌跡，利用終端工具檢索必要資訊，並根據證據修正或補充教訓後再行動。此流程使代理能動態評估和調整記憶內容，降低錯誤教訓的負面影響。

**Result:** 作者在五個多任務代理基準測試中驗證WikiTrace，涵蓋模擬文字世界與工具使用環境。實驗中，WikiTrace在八個測試套件中均取得最高平均準確率（約90.2%），較無記憶基線提升約10.7個百分點，並優於只給予教訓但無原始軌跡的Insights Only方法3.2個百分點。WikiTrace同時顯著降低記憶引起的性能退化（Regression由6.5%降至4.5%），並在較難任務中更頻繁地訪問原始證據，提升決策質量。多模型測試也顯示其泛化能力。分析指出，WikiTrace能有效識別並修正錯誤或不適用的教訓，提升記憶重用的可靠性。

**Conclusion:** 本論文提出的WikiTrace系統通過將教訓與其原始執行軌跡鏈接，讓LLM代理能夠在任務執行時動態檢查和修正記憶內容，有效減少記憶引起的性能退化。實驗結果證明此方法在多種環境下均優於現有記憶方法，提升了經驗重用的穩健性與效能。WikiTrace強調記憶不僅應保存教訓，還應保留足夠的證據以供代理重新評估，對實際部署具有重要意義。限制在於記憶建構依賴二元成功失敗標籤，導致部分教訓可能不準確，且記憶規模增大時，全文放入提示的策略將面臨挑戰，需未來研究解決檢索問題。

**Research Gap:** 本研究雖然有效降低了記憶引起的退化，但仍依賴於二元成功失敗標籤來生成教訓和總結，缺乏更細粒度的失敗原因標註，可能導致部分教訓誤導代理。WikiTrace未明確說明如何處理大規模記憶無法全部放入提示的情況，缺乏針對記憶檢索與篩選的機制設計。此外，實驗主要集中於特定模擬環境和工具使用場景，泛化至更複雜或真實世界任務的效果尚未驗證。消融實驗中對不同記憶組成部分的貢獻分析有限，且未充分探討系統在資源消耗與延遲上的實際部署成本與風險。最後，失敗案例與錯誤修正失敗的情境分析不足，限制了對系統魯棒性的全面理解。

### 2. DnNP: Denoising Input Uncertainty in Neural Processes

- 分數：7
- arXiv: [2611.14424v1](http://arxiv.org/abs/2611.14424v1)
- 發表日期：2026-11-10
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：meta; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #2 / 8/10: Presents a principled extension to Neural Processes that explicitly models input noise, with strong theoretical grounding and significant practical improvements on real-world datasets, supported by code.

**Intro:** Neural Processes (NPs) 是一類靈活的元學習模型，能在多種應用中提供不確定性量化。然而，標準的 NP 框架假設輸入資料無噪聲，這在實際場景中往往不成立，因為感測器噪聲或測量誤差普遍存在。這種假設與現實資料的差異會嚴重影響預測品質與不確定性估計的準確性。本文提出 Denoising Neural Processes (DnNP)，透過變分推論明確建模輸入不確定性，提升模型對噪聲輸入的魯棒性。

**Motivation:** 在工程與產品應用中，感測器資料常含有測量誤差，若模型忽略輸入噪聲，會導致預測偏差與不確定性錯估，影響決策品質。現有 NP 變體多未考慮輸入噪聲，且處理標籤噪聲的研究有限。Gaussian Processes 雖有相關研究，但計算成本高且難以擴展。因此，開發能同時進行去噪與元學習的 NP 模型，對於提升實務中模型的穩健性與可靠性具重要意義。

**Method:** DnNP 將噪聲自由的輸入視為潛在變數，並假設觀測輸入為該潛在輸入加上已知協方差的高斯噪聲。模型結合一個去噪網路與 NP 的編碼器-解碼器架構，透過變分推論同時學習去噪與函數預測。訓練目標為最大化包含預測重建、測量一致性與正則化項的 ELBO。推論時，先從去噪後的輸入分布抽樣，再進行標籤預測。此方法可直接套用於多種 NP 變體，並在理論上證明能達到貝葉斯最優預測器。

**Result:** 實驗涵蓋合成一維高斯過程回歸、MNIST 圖像補全及兩個真實世界空間插值資料集（PM2.5 空氣品質與 NOAA 氣壓資料）。DnNP 在所有場景中均優於或持平於標準 NP，尤其在真實空氣品質資料上，RMSE 最多降低 30%，NLL 降低 73%。在合成資料中，DnNP 對不同噪聲水準均展現穩健性，且對輸入噪聲估計的誤差容忍度高。MNIST 實驗中，DnNP 在中低噪聲下恢復接近無噪聲基準的性能，且形狀重建更準確。空間插值任務中，DnNP 對含噪聲的氣象感測器資料表現出更佳的預測與不確定性校準。

**Conclusion:** 本文提出的 DnNP 模型有效解決了 NP 框架中忽略輸入噪聲的問題，透過變分去噪機制提升了對噪聲輸入的預測準確度與不確定性估計。理論證明其模型類別包含貝葉斯最優預測器，且避免了傳統 NP 固有的不可消除誤差。實驗結果在合成與多個真實資料集上均證實其優勢，特別適合感測器資料含噪聲的工程應用場景。限制在於需事先知道或估計輸入噪聲協方差，且目前尚未處理輸入噪聲間的相關性。

**Research Gap:** 本文雖提供理論保證與多場景實驗，但仍存在幾點不足。首先，輸入噪聲協方差需事先設定或估計，對噪聲模型的依賴可能限制泛化能力，且對噪聲估計誤差的影響僅在合成資料中有限探討。其次，去噪器獨立處理每個輸入點，未考慮輸入噪聲間可能的相關結構，限制了在複雜感測網路中應用。第三，實驗中缺乏對模型在極端噪聲或異常輸入下的失效分析。最後，模型的計算成本與部署風險未明確評估，尤其在大規模感測器網路中實時推論的可行性尚不清楚。

### 3. Causal Concept Explanations for Deep Neural Models

- 分數：5
- arXiv: [2611.14407v1](http://arxiv.org/abs/2611.14407v1)
- 發表日期：2026-11-10
- 分類：cs.LG, cs.AI
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #3 / 7/10: Proposes a novel causal framework for concept explanations in neural models with rigorous evaluation and code, advancing interpretability beyond correlational methods.

**Intro:** 本論文聚焦於深度神經網路中基於概念的解釋方法，強調現有解釋多為相關性而非因果性，可能導致誤導。作者提出一種新方法CCW-Net，利用經濟學、醫學等領域的介入式中介分析作為訓練目標，使概念解釋與模型輸出之間的因果關係得以對齊。該方法不僅提供因果解釋的訓練架構，也提出評估工具量化每個概念對模型輸出的因果貢獻。實驗涵蓋飛機控制、駕駛與影像分類等多個領域，展示了因果解釋的可行性與優勢。

**Motivation:** 在安全關鍵的自主系統中，如航空、駕駛與醫療影像，模型的可解釋性是必須的，但現有的概念解釋多為相關性，無法保證概念對輸出的因果影響，可能導致錯誤判斷與風險。工程與產品層面，若解釋不能反映真實因果關係，將影響故障排查、驗證與認證流程，阻礙模型的安全部署。研究上，缺乏將因果中介分析融入訓練的深度模型方法，且缺少細粒度的因果貢獻評估工具，限制了因果解釋的實用性與可信度。

**Method:** CCW-Net架構包含一個凍結的預訓練骨幹網路、一個將骨幹輸出映射為多維向量概念表示的編碼器，以及一個基於注意力機制的頭部，用於生成模型輸出。核心創新在於將介入式多中介中介分析作為訓練目標，強制概念表示滿足必要性、充分性與獨立性三大因果對齊條件。必要性確保不活躍概念不影響輸出，充分性保證活躍概念能重建輸出，獨立性則要求各概念貢獻線性可加。為生成反事實概念表示，使用每個概念的可逆流模型作為中介模型。訓練分階段進行，先預熱骨幹與概念分類，再擬合中介模型，最後加入因果對齊損失優化整體模型。

**Result:** 在飛機控制、CarRacing駕駛模擬與CUB-200鳥類影像分類三個任務上，CCW-Net均展示出較高的因果效應路徑分配給活躍概念的比例，飛機控制任務中活躍概念攜帶約94.5%的效果，遠超過無因果對齊損失的88.1%及先前方法約50%。CarRacing任務中活躍概念攜帶約89.8%的效果，優於無對齊損失的87.5%及先前方法約33%。CUB-200中，CCW-Net架構本身即能將91.3%的效果歸因於活躍概念，明顯優於傳統概念瓶頸模型的41.6%。此外，消融實驗顯示因果對齊損失與向量化概念表示均有助於提升因果忠實度，且在標註稀疏或本體不完全時仍具一定魯棒性。

**Conclusion:** 本論文提出CCW-Net，首次將多中介介入式中介分析作為深度網路訓練目標，實現概念解釋與模型輸出之間的因果對齊。該方法不僅提升了解釋的因果忠實度，也提供了可量化的評估工具，推動概念解釋從相關性走向因果性。實驗結果表明，CCW-Net在多個安全關鍵任務中均能有效路由輸出效應至活躍概念，提升解釋的可信度。限制方面，因果效應的估計依賴於中介模型的準確性與本體設計，且全文未明確說明在更複雜場景或大規模數據下的計算成本與部署風險，未涵蓋輸入到輸出全流程的因果關係，僅聚焦於概念到輸出的因果影響。

**Research Gap:** 本研究假設概念本體完整且標註準確，然而實際應用中本體不完全或標註噪聲會影響因果對齊效果，相關實驗雖有初步探討但缺乏深入分析。中介模型依賴可逆流模型生成反事實概念表示，全文未明確說明該模型在高維或複雜概念空間的泛化能力與計算負擔。因果對齊損失的權重調整與訓練穩定性細節有限，可能影響實際工程部署。評估方法基於觀察性資料與匹配策略，對於因果假設的驗證與違反情況未充分討論。此外，全文未涵蓋失敗案例或在多任務、多模態場景下的適用性，限制了方法的通用性判斷。

### 4. Emergent Biological Capabilities in a Foundation Model for Molecular Interactions

- 分數：3
- arXiv: [2611.14504v1](http://arxiv.org/abs/2611.14504v1)
- 發表日期：2026-11-10
- 分類：cs.LG, q-bio.BM
- 入選理由：+3 提及頂級會議：neurips; LLM rank #4 / 7/10: Demonstrates emergent biological capabilities in a large-scale foundation model for molecular interactions with strong zero-shot generalization and prospective wet-lab validation, indicating high research impact.

**Intro:** 本論文提出Bonbon，一個基於Transformer架構的分子互動基礎模型，專注於蛋白質與配體序列的配對數據。該模型在約3.2兆個配對序列標記上進行自監督學習，無需結構座標或任務特定標籤。Bonbon展示了三種層級的零樣本突現能力：功能層級的作用機制預測、殘基層級的結合位點定位及正交/變構位點區分，以及鍵層級的共價與非共價結合識別。這些能力均能泛化至分布外的複合物，且在多個蛋白家族的實驗驗證中展現出高命中率。

**Motivation:** 目前分子互動模型多為任務專用且依賴結構資訊，缺乏能從序列資料中無監督學習多層次互動特性的基礎模型。傳統結構預測模型雖能預測三維結構，但無法直接推斷功能結果或結合模式，且泛化能力有限。Bonbon旨在填補此研究空白，通過大規模序列數據訓練，實現多層次生物學能力的自發獲得，為藥物發現提供快速且多功能的計算工具，縮短設計-合成-測試週期。

**Method:** Bonbon採用Transformer架構，具備長達65,536標記的上下文窗口，適應蛋白質與配體多對多的互動關係。訓練資料來自專有篩選數據集，包含實驗與合成生成的配對序列，經過嚴格質量過濾與冗餘刪除。模型在六種規模（42M至1.6B參數）下進行訓練，保持1:2,000的參數與標記比例以應對數據稀疏性。評估包括預訓練損失及三項零樣本能力指標，均使用不含調整的固定表示進行，確保能力突現與模型規模直接相關。

**Result:** 在1.6B參數規模下，Bonbon的三項能力均出現明顯跳躍，功能層級作用機制預測達81.1%宏精度，能在同一受體中區分激動劑與拮抗劑達85.5%平衡準確率。結合位點定位在多個蛋白家族中F1分數約0.38，優於多數基線且無需結構資訊。正交/變構位點區分AUROC達0.834，且在同一蛋白質內區分能力達0.821。共價鍵識別AUROC達0.838，且能在無電親核基團分子中區分共價與非共價結合。Bonbon在多個標準資料集上達到或超越現有最佳性能，且推理速度比共摺疊方法快約五個數量級。實驗室前瞻性驗證涵蓋九個疾病目標，61.5%劑量反應命中率，包含多個結構新穎的抑制劑，且對分布外目標具泛化能力。

**Conclusion:** Bonbon成功展示了從蛋白質與配體序列中無監督學習分子互動的多層次生物學能力，這些能力不依賴結構座標或任務特定標籤，且在多種評估中均展現出優異性能與泛化性。其高效推理速度及實驗驗證結果表明，Bonbon可作為藥物發現中的基礎計算平台，支持機制導向的分子設計與多目標選擇性優化。該模型的數據密集型訓練策略與規模突現現象也為基礎模型的設計提供了新見解。

**Research Gap:** 本研究雖展示多項突現能力，但仍存在限制。首先，能力解析僅達粗粒度，缺乏更細緻的三維結構或動態交互信息提取。其次，所有結果均基於凍結表示，未探討微調對性能提升的潛力。訓練與評估均依賴特定配對序列數據，對於更稀疏或異質數據的泛化能力尚未充分驗證。缺乏對模型在不同訓練隨機種子下的穩定性分析，且未公開訓練數據與權重限制了社群復現與擴展。最後，模型對於結合後的構象變化、解離動力學等關鍵藥物設計屬性尚未涵蓋，未來需補充這些方面以提升實際應用價值。

### 5. Pyrite: Building and Benchmarking Protein-Ligand Pose Ranking Agents

- 分數：3
- arXiv: [2611.14511v1](http://arxiv.org/abs/2611.14511v1)
- 發表日期：2026-11-10
- 分類：cs.LG, q-bio.QM
- 入選理由：+3 提及頂級會議：neurips; LLM rank #5 / 7/10: Introduces Contrastive Discovery, a novel framework for scientific discovery agents that improves hypothesis evaluation by considering competing explanations, validated across multiple domains with strong empirical evide

**Intro:** 蛋白質-配體結合姿態的準確預測是小分子藥物發現中的核心問題。現有的共摺疊模型能生成多樣的候選姿態，但如何有效排序這些候選仍具挑戰性。本文提出Pyrite，一個包含1500對蛋白質-配體姿態的配對排序基準，並發現專家化學家在此任務上的表現接近隨機，顯示現有化學信號難以解讀。為此，作者設計了PyriteRep結構化表示，並基於大型語言模型（LLM）開發兩種排序代理，分別是直接文本推理的PyriteReasoner和生成可執行特徵代碼的PyriteFeaturizer。這些方法在基準上超越專家表現，展示了LLM在結合計算化學工具輸出方面的潛力。

**Motivation:** 蛋白質-配體姿態排序在藥物設計中至關重要，因為錯誤排序會浪費後續實驗資源並降低對模型的信任。傳統物理基礎分數如MM-GBSA在高質量共摺疊姿態中表現不佳甚至反相關，專家化學家也難以準確判斷。隨著LLM在科學推理領域的進步，探索其是否能超越人類專家並有效整合多種化學訊息，對工程和產品開發具有實際意義。Pyrite基準提供了一個嚴格且多樣的測試平台，促進開發更可靠的自動姿態排序系統。

**Method:** 本文核心方法包括三部分：首先，PyriteRep是一種結構化數據格式，包含分子幾何、蛋白質-配體相互作用及物理化學特徵，提升LLM對姿態信息的理解。其次，PyriteReasoner利用LLM直接對姿態對進行文本推理，評估其相對合理性，並測試多種輸入組合及模型大小。第三，PyriteFeaturizer則利用LLM生成Python代碼，從PyriteRep中自動發掘並構造特徵，這些特徵用於訓練邏輯回歸模型，並可結合LLM子調用以提取蛋白質及姿態特定特徵。此外，作者採用Group Relative Policy Optimization（GRPO）強化學習方法，提升開源模型的性能，縮小與閉源前沿模型的差距。

**Result:** 實驗結果顯示，專家化學家在Pyrite基準上的準確率約42%-57%，接近或低於隨機水平。單一物理分數如MM-GBSA表現反相關且準確率低。PyriteReasoner在提供完整PyriteRep特徵時，最高達67%準確率，顯著優於專家。PyriteFeaturizer通過LLM生成的特徵結合邏輯回歸，最高達74%準確率，超越所有基線方法。GRPO強化學習顯著提升開源模型表現，尤其對PyriteFeaturizer效果明顯。實驗還發現，去除3D坐標不影響PyriteReasoner性能，且LLM子調用有助於特徵發掘。整體而言，LLM輔助的特徵工程優於直接文本推理，且簡單統計模型在結構化特徵上已具競爭力。

**Conclusion:** 本文提出的Pyrite基準揭示了蛋白質-配體姿態排序的高難度，尤其在高質量共摺疊姿態中，傳統物理分數和專家判斷均表現有限。通過PyriteRep結構化表示和兩種基於LLM的排序代理，展示了語言模型在整合多源化學信息和自動特徵發掘上的優勢。強化學習進一步提升了開源模型的能力，縮小與閉源模型的差距。這些成果對藥物發現中的自動化姿態排序具有實際應用價值，並為未來結合AI與計算化學工具的研究提供了方法基礎。

**Research Gap:** 本文仍存在多項不足。首先，訓練數據僅限於pre-AF3結構，可能存在分布偏移，影響模型泛化至post-AF3數據。其次，Pyrite基準僅涵蓋特定共摺疊模型生成的姿態，尚未驗證方法對其他生成模型或採樣策略的適用性。第三，雖然展示了配對排序能力提升，但未明確說明該能力是否能直接轉化為整體姿態排序或下游藥物設計流程中的效益。此外，強化學習訓練的穩定性和計算成本未充分討論，對實際部署可能構成挑戰。最後，缺乏對失敗案例和模型解釋性的深入分析，限制了對模型決策機制的理解與信任建立。
