### 1. KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards

- 分數：5
- arXiv: [2610.02206v1](http://arxiv.org/abs/2610.02206v1)

**Intro:** 隨著大型語言模型（LLMs）在資安工作流程中的應用日益增加，這些模型被期望能將分析師的意圖轉換為具體的工具指令。然而，現有的評估多集中於知識層面或端到端代理任務，缺乏對LLMs生成可執行指令能力的直接測試。資安操作高度依賴嚴格的命令列介面（CLI），任何細微的語法錯誤或參數錯置都可能導致指令無法執行，因此準確生成指令對實務應用至關重要。本文提出KaliBench，一個針對Kali Linux環境下自然語言轉CLI指令的細粒度基準測試與資料集，涵蓋多種工具與安全階段，旨在填補此評估缺口。

**Motivation:** 資安工具的CLI指令通常結構嚴謹且錯誤容忍度低，這使得LLMs在生成指令時面臨挑戰。現有評估方法無法精確衡量模型在真實資安工具指令生成上的表現，導致難以判斷模型在實務部署中的可靠性。透過建立一個涵蓋廣泛工具與多階段安全任務的細粒度基準，能夠更精確地評估模型在指令選擇與參數構造上的能力，進而推動更有效的模型訓練與優化，提升資安自動化的實用價值。

**Method:** KaliBench包含8,504組查詢與指令對，涵蓋1,642種工具、23個能力維度及5個安全階段。資料集透過嚴謹的手稿導向流程建構，並採用確定性正規化與別名感知評估，確保工具選擇與參數構造的精確與可重現性。為驗證語義正確性與實際可執行性，設計多階段驗證流程，結合LLM驗證、沙盒終端執行及人類審核。基於此細粒度且確定性的信號，KaliBench進一步支持無需執行時環境即可驗證的獎勵機制，用於模型訓練優化。

**Result:** 在三種評估模式及24種通用與資安專用開放權重模型配置下，無任何開放權重模型在無限制設定中超過42%的精確指令正確率，顯示在缺乏明確工具提示時，準確生成CLI指令仍具挑戰。透過KaliBench提供的監督微調與基於可驗證獎勵的強化學習，對一個8B參數模型進行訓練後，性能顯著提升，達到與一個685B參數MoE模型相當的表現，證明該基準與訓練策略對提升模型實務應用能力具有效果。

**Conclusion:** 本文提出的KaliBench為資安領域中自然語言到CLI指令轉換提供了一個細粒度且可驗證的基準，填補了現有評估在實務指令生成能力上的不足。多階段驗證流程與無需執行時環境的獎勵機制，為模型訓練提供了精確且可重複的信號。實驗結果顯示，利用KaliBench進行的微調與強化學習能顯著提升模型在資安工具指令生成的準確度，對推動資安自動化具實際意義。全文未明確說明在不同資安場景下的泛化能力與部署成本。

**Research Gap:** 本文雖提供了廣泛工具與多階段的基準，但全文未明確說明資料集在真實世界多變資安環境中的覆蓋度與泛化性，缺乏對模型在不同攻防場景或異常指令情況下的穩健性測試。此外，對於多階段驗證流程中人類審核的成本與可擴展性未有詳細討論，可能影響實際部署。實驗中未見對比其他現有CLI指令生成方法的消融分析，無法全面評估KaliBench訓練策略的相對優勢。最後，模型在資安工具指令生成的失敗案例與錯誤類型分析較少，限制了對改進方向的深入理解。

**Intro:** 本論文提出 Argo-Bench，一個針對企業級數據科學與分析工作流程的評估框架。現有的 text-to-SQL 基準多半只評估查詢生成，且多基於公開資料集，無法反映真實企業資料倉庫的複雜性與多表關聯。Argo-Bench 模擬一個真實規模的紐約市食品外送平台，包含 235 張表格與 75 億筆資料，並以 Oracle E-Business Suite 的 ERP 架構為藍本，提供 210 個跨領域的數據任務，涵蓋詐欺偵測、財務規劃、成長分析等。該框架不僅要求生成 SQL 查詢，更要求代理人根據資料採取行動，並以模擬器的潛在狀態評分行動結果。

**Motivation:** 企業級數據分析工作流程複雜，涉及多表資料整合、統計分析與決策執行，現有基準無法全面評估代理人在此環境下的能力。公開資料集多為單表或簡化結構，且答案標準常有錯誤，無法真實反映企業場景。企業資料倉庫因敏感性無法公開，且多為多模組、多表結構，需代理人具備探索與理解資料組織的能力。Argo-Bench 透過模擬真實世界經濟與詐欺行為，並以行動結果評分，彌補現有基準的不足，對工程與產品落地有高度參考價值。

**Method:** Argo-Bench 以公開資料、產業文獻及監管申報為基礎，模擬 2024 年紐約市食品外送平台，包含 8100 萬訂單與 340 萬活躍用戶。模擬結果投影至 Oracle EBS 12.2 格式的 ERP 資料倉庫，包含 235 張表與 75 億筆資料。代理人只能存取資料倉庫，無法直接取得模擬器潛在狀態，需透過 SQL 與 Python 等工具重建事實並採取行動。任務涵蓋詐欺封鎖、預算分配、薪資調整等，代理人透過 Python sandbox 提交行動，評分器根據模擬器潛在狀態評估行動後果。框架公開資料倉庫與任務，但模擬器與評分器未公開以防止作弊。

**Result:** 評估 14 款前沿及開源模型，最高分為 Claude Opus 5.5，僅有 34.8% 任務達到 95 分以上，平均分數為 59.5。GPT-6 Astra 在預測任務表現最佳。多數失敗案例因讀取錯誤紀錄、優化錯誤目標或計算錯誤量度。部分模型在預測任務中表現過度自信，80% 預測區間僅包含真實值 44.8%。實驗在 Google Kubernetes Engine 上執行，代理人受限於沙箱環境與資源限制。結果顯示現有模型尚無法全面掌握企業級複雜資料環境與決策流程。

**Conclusion:** Argo-Bench 提供一個真實規模且多面向的企業資料代理人評估平台，突破傳統只評估查詢生成的限制，強調代理人對資料理解、探索與行動的能力。公開的資料倉庫與任務促進社群研究與比較。實驗結果顯示現有模型在企業級任務仍有顯著不足，尤其在正確理解業務邏輯與優化決策目標方面。該框架有助於推動代理人技術向更貼近實務的方向發展。

**Research Gap:** 本論文模擬單一城市的食品外送平台，缺乏多業務、多貨幣、多年度的複雜場景，限制了泛化能力。僅支援 Oracle EBS 格式，未涵蓋其他主流 ERP 系統如 SAP S/4HANA。模擬器假設與校準基於公開統計，可能無法完全反映真實企業資料的異常與雜訊。評估僅基於單一模擬世界，缺乏跨世界或跨種子測試以驗證穩健性。部分任務對提示敏感，且消融實驗與模型間比較有限。成本與部署風險未充分討論，代理人在真實企業環境的實際運行表現仍待驗證。

### 3. Wasserstein Gradient Flows and Forward-Only Diffusion Are Not Enough for Multimodal Sampling

- 分數：5
- arXiv: [2610.02081v1](http://arxiv.org/abs/2610.02081v1)
- 發表日期：2026-10-01
- 分類：stat.ML, cs.LG, math-ph, math.DS, math.PR, math.SP
- 入選理由：+2 提及頂級機構：meta, mit; +3 提及頂級會議：neurips; LLM rank #3 / 8/10: This paper provides a rigorous theoretical and empirical critique of popular Wasserstein gradient flow and diffusion samplers, revealing fundamental limitations for multimodal sampling and motivating new directions.

**Intro:** 本論文探討基於Wasserstein梯度流（WGF）與前向擴散過程（FODP）的取樣方法在多模態分布取樣上的限制。這些方法雖然理論上保證指數級快速收斂，但作者指出這種保證在實際多模態情境中可能誤導。透過Jordan-Kinderlehrer-Otto（JKO）方案與Otto微積分，論文證明WGF與FODP在邊際分布演化上等價，因而共享慢混合與亞穩態現象。此研究將統計物理中經典的頻譜分析與平均首次通過時間（MFPT）分析工具引入現代取樣方法，揭示其在多模態分布下的本質瓶頸。

**Motivation:** 多模態分布在高維度機器學習與統計推斷中普遍存在，然而傳統MCMC與新興WGF、FODP方法在此類問題中常面臨混合速度緩慢的挑戰。雖然WGF與FODP方法理論上有指數收斂保證，但實務中仍觀察到取樣效率低下。理解這些方法的結構性限制對於工程師與研究者設計更有效的多模態取樣演算法至關重要，尤其是在需要快速且準確生成樣本的應用場景中。

**Method:** 論文首先利用JKO方案與Otto微積分，嚴謹證明WGF與FODP在邊際分布演化上的等價性，兩者皆遵循相同的Fokker-Planck方程。接著，作者採用頻譜分析，透過Fokker-Planck算子的特徵值與特徵函數展開，定量評估混合時間與頻譜間隙大小的關係。並利用MFPT分析，計算從一個模態到另一模態的平均首次通過時間，進一步估計整體混合時間。實驗設計以一維及多維雙峰高斯混合分布為測試案例，並探討常用的對數線性退火策略對混合時間的影響。

**Result:** 實驗結果顯示，當模態間距離增加時，頻譜分析與MFPT分析均預測混合時間呈指數級增長，且兩者結果高度一致。直接模擬FODP與WGF基方法（如SVGD與VWGF）亦觀察到類似的性能急劇下降現象，且在多維空間中此現象依然存在。對數線性退火策略雖能稍微降低相鄰中間分布間的障礙，但無法根本改變整體混合時間的指數擴展趨勢。此結果表明，純粹依賴局部梯度驅動的動態在多模態取樣中存在結構性瓶頸。

**Conclusion:** 本研究明確指出，WGF與FODP基於局部梯度信息的取樣方法，在多模態分布取樣時面臨根本性限制，混合時間可能隨模態間距離指數增長。此限制非實作細節所致，而是方法本身的結構性問題。作者建議未來多模態取樣應引入非局部機制，如重採樣、路徑空間優化等，以突破局部動態的瓶頸。此論文提供了理論與實驗的嚴謹分析，對AI從業者理解與設計多模態取樣演算法具有重要參考價值。

**Research Gap:** 論文雖以一維及部分多維雙峰高斯混合為測試案例，驗證了理論分析，但未充分探討更高維度、更多模態或非高斯分布下的泛化性與實務效能。實驗中對退火策略的探討限於對數線性進度，缺乏對其他退火路徑或非局部策略的系統性比較。此外，對於實際取樣過程中估計分數函數、數值離散誤差及有限粒子效應的影響未深入分析。最後，雖提出非局部機制的重要性，但未提供具體設計原則或理論框架，限制了對未來方法開發的直接指引。

### 4. Trust the Direction, Search the Step: Zero-and-First-Order Methods for LLM Fine-Tuning

**Intro:** 在大型神經網路優化中，步長選擇是一個核心挑戰。步長過小會導致收斂速度緩慢，而步長過大則可能使優化過程不穩定。本文提出一種結合零階與一階優化方法的框架，旨在有效解決步長調整問題。該框架利用一階優化器決定方向，並在該方向上進行零階評估以選擇合適的步長。此方法在保持計算成本低的同時，提升了步長選擇的靈活性與準確性。

**Motivation:** 現有一階優化方法通常使用固定或預設的步長，這在大規模模型微調時容易導致收斂效率低或不穩定。全線搜索雖能找到較優步長，但計算成本高昂，不適合大規模應用。因此，如何在保證計算效率的前提下，動態且準確地選擇步長，是提升模型訓練效率與穩定性的關鍵。本文提出的ZFO框架正是針對此問題，試圖在工程實踐中提供一種輕量且有效的步長調整方案。

**Method:** ZFO框架核心在於將方向選擇與步長選擇解耦。首先，利用可信賴的一階優化器（如梯度下降）確定更新方向。接著，在該方向的一維子空間內，通過兩次額外的目標函數評估，利用有限差分估計曲率，構建局部目標函數模型。最後，在一個有界的搜索區間內，根據該局部模型選擇一個曲率感知的步長。此過程避免了全線搜索的高昂成本，同時保證步長選擇的適應性和理論收斂性。

**Result:** 全文明確指出，ZFO在多種語言模型和數據集上進行評估，與固定步長的一階優化基線相比，ZFO在優化效率和最終性能上均有提升。實驗中使用了共享樣本評估以獲得可靠的曲率估計，並證明所選步長接近局部最優。具體指標和數據細節全文未明確說明，但整體結果顯示ZFO能根據不同目標函數調整局部模型和步長大小，提升了優化過程的穩定性和效果。

**Conclusion:** 本文提出的ZFO框架為大型神經網路微調中的步長選擇問題提供了一種輕量且理論有保障的解決方案。通過結合一階方向選擇與零階步長評估，實現了計算成本與優化性能的良好平衡。該方法在多個語言模型和數據集上展現出優於固定步長基線的效果，並公開了程式碼以促進實際應用和後續研究。然而，全文未明確說明具體實驗細節與指標，限制了對結果的深入評估。

**Research Gap:** 本文雖提供理論保證與多場景評估，但全文未詳細說明實驗設置、基線比較細節及指標數據，缺乏充分的消融實驗來驗證各組件的貢獻。此外，對於不同模型規模、任務類型及數據分布的泛化能力未有深入探討。步長選擇過程中額外函數評估的計算成本與實際部署風險也未明確量化。最後，對失敗案例或不適用場景的分析不足，限制了該方法在工業應用中的風險評估與調整策略制定。

### 5. SoftServe: A Scalable Quasi-Newton Method for Deep Learning

- 分數：5
- arXiv: [2610.02182v1](http://arxiv.org/abs/2610.02182v1)
- 發表日期：2026-10-01
- 分類：cs.LG, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #5 / 7/10: SoftServe introduces a scalable quasi-Newton method overcoming key obstacles in deep learning optimization with credible evidence on ill-conditioned tasks and large models, showing practical impact.

**Intro:** 準牛頓法（Quasi-Newton methods）在大規模無約束凸優化中長期被視為有效方法，但在深度學習中應用受限，主要原因是深度模型的非凸性質及龐大參數量。這些限制使得傳統準牛頓法難以直接應用於深度神經網絡的訓練。本文提出SoftServe，一種專為深度學習設計的可擴展準牛頓法家族，旨在克服這些挑戰。SoftServe不依賴線搜尋或臨時曲率修正，並能處理負曲率情況，提升了準牛頓法在非凸問題上的適用性。

**Motivation:** 深度學習模型通常面臨嚴重的病態條件與非凸優化問題，現有優化器如Adam雖然廣泛使用，但在某些任務中仍可能收斂緩慢或效果有限。準牛頓法理論上能提供更精確的曲率估計，有助於加速收斂，但傳統方法無法有效處理深度模型的規模與非凸性。SoftServe的動機在於設計一種既能保持正定曲率估計，又能在大規模深度模型中高效運行的準牛頓法，從而提升優化效率與模型性能。

**Method:** SoftServe基於Berglund等人（2025）提出的變分目標函數，推導出正定曲率估計，即使在負曲率存在時也能保持正定性。方法包含對角與Kronecker分解兩種變體，這些變體在結構上保證曲率矩陣正定，並能擴展至巨量參數的神經網絡。為了避免昂貴的矩陣分解，SoftServe採用穩定的耦合Newton-Schulz迭代，將矩陣運算轉換為GPU友好的矩陣乘法，提升計算效率與可擴展性。

**Result:** SoftServe在多種嚴重病態問題上表現優異，包括循環神經網絡、深度自編碼器、物理信息神經網絡及一個擁有1.36億參數的物理信息擴散模型。實驗中，SoftServe常常達到比Adam、Muon及SOAP等基準方法更低的損失值。全文未明確說明具體實驗設置、數據集細節及指標數值，但強調其在大規模及非凸優化場景的優勢。

**Conclusion:** 本文提出的SoftServe為深度學習優化提供了一種可擴展且理論上有保障的準牛頓法解決方案，能有效處理非凸性與大規模參數問題。其利用變分目標推導正定曲率估計及GPU友好的矩陣運算，提升了準牛頓法在深度學習中的實用性。儘管實驗結果顯示優於多種基準方法，但全文未提供完整的實驗細節與泛化能力分析，限制了對其普適性的評估。

**Research Gap:** 全文未明確說明SoftServe在不同深度學習任務與資料集上的廣泛測試，缺乏對泛化能力與穩定性的深入分析。實驗細節如超參數設定、訓練時間與資源消耗未充分披露，難以評估其實際部署成本。缺少對失敗案例或性能退化情況的討論，亦未與更多現代優化器進行系統性比較。此外，SoftServe的Kronecker分解變體在極大規模模型中的計算與記憶體負擔未被充分探討，這些均是未來需補足的關鍵環節。
