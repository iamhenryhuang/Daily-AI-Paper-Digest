### 1. Improving 5G AI-RAN MCS Selection by Predicting Retransmissions

- 分數：4
- arXiv: [2609.09324](https://arxiv.org/abs/2609.09324)
- 發表日期：2026-09-11
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：nvidia, openai; +2 提及程式碼可用; LLM rank #1 / 9/10: Presents a novel, practically validated predictive framework (NOSTRAdAMUS) for 5G link adaptation with strong real-world OTA evaluation, significant performance gains, and robust generalization across scenarios.

**Intro:** 5G NR中的連結調適（Link Adaptation, LA）主要依賴於通道品質指標和HARQ反饋，這些資訊在通道快速變化時容易過時且含有噪聲，導致調適反應滯後。現有實務多採用簡單且穩健的演算法，雖然保證了性能的可預測性，但往往犧牲了頻譜效率。本文提出NOSTRAdAMUS，一種可疊加於現有LA演算法之上的預測框架，透過預測下一個無線幀是否會發生重傳，主動修正調適決策。此方法不需替換或重新設計原有LA策略，具有實務部署的潛力。

**Motivation:** 現有LA方法因為反應式設計，無法即時應對快速變化的無線通道，導致調適過於保守或過於激進，降低頻譜利用率並增加重傳次數。尤其在TDD系統中，HARQ與CQI反饋延遲更嚴重。雖然已有研究嘗試透過重設LA策略或預測通道狀態來改善，但缺乏一種能直接疊加於現有LA演算法且不需改動其內部機制的通用解決方案。NOSTRAdAMUS正是為解決此問題而設計，能提升現有LA性能且易於工程實現。

**Method:** NOSTRAdAMUS將現有LA策略視為黑盒，利用最近HARQ歷史資料作為特徵，透過機器學習模型預測下一個無線幀是否會發生重傳。核心為一個二元分類問題，輸出為重傳發生的機率。根據預測結果及置信度，系統對原LA選擇的MCS進行上下調整。模型訓練使用OTA收集的真實數據，並在X5G測試平台上部署為dApp，支持低延遲推理（約5.5微秒），可即時介入調整。實驗涵蓋多種3GPP通道模型、SISO/MIMO配置及不同移動速度，驗證其泛化能力。

**Result:** 在OTA及硬體在環測試中，NOSTRAdAMUS在不需重新訓練的情況下，成功提升兩種先進LA策略（OLLA與SALAD）的性能。具體表現為平均goodput提升最高達71.5%，重傳次數減少最高達71.8%。在靜態及移動場景下均展現穩定增益，且在多種3GPP TDL與CDL通道模型中均有顯著改善。模型的高置信度介入正確率達94.2%，推理延遲低，適合實時調度環境。OTA實驗也證實其在真實無線環境中的有效性。

**Conclusion:** 本文提出的NOSTRAdAMUS為一種輕量且可疊加於現有LA策略的預測框架，利用短期HARQ歷史成功預測重傳，主動調整MCS選擇，顯著提升5G AI-RAN的頻譜效率與降低重傳。其設計兼顧實務部署需求，並在多種通道與移動場景中展現良好泛化能力。限制在於目前僅驗證單用戶場景，且未涵蓋上行鏈路LA，未來可擴展至多用戶環境及其他LA策略，並深入探討在更複雜網路條件下的表現。

**Research Gap:** 本文雖展示NOSTRAdAMUS在多種通道與移動條件下的泛化能力，但實驗主要集中於單用戶場景，缺乏多用戶競爭與干擾環境下的驗證。模型僅基於HARQ歷史，未考慮其他可能影響LA決策的通道特徵或上下文資訊。對於模型在極端通道變化或非典型場景的魯棒性未充分探討。成本與部署風險方面，雖推理延遲低，但未明確評估整體系統資源消耗與實際商用網路整合挑戰。此外，對於失敗案例、模型誤判對系統性能的影響及補救機制未有深入分析。全文未明確說明多用戶及上行鏈路的適用性與擴展性。

### 2. The Menu Is an Execution Prior: State-Path Tool Menus for Online Agents

- 分數：4
- arXiv: [2609.09395](https://arxiv.org/abs/2609.09395)
- 發表日期：2026-09-11
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #2 / 8/10: Introduces a clear novel concept (State-Path Tool Menu) improving multi-step tool use in language model agents with strong empirical gains and open code, addressing a practical challenge in agent execution.

**Intro:** 本論文探討語言模型代理在面對龐大工具庫時，如何有效選擇並排序工具以完成多步驟任務。現有方法多以工具與請求的相關性排序，但此策略常忽略完成任務所需的前置工具，導致執行失敗。作者提出工具選單（tool menu）概念，將工具庫中一小部分有序工具作為代理可用的介面，並強調選單應包含完整可執行路徑。此問題在實務中尤為重要，因為工具庫規模龐大，且多步任務需依賴多個工具的正確執行順序。研究聚焦於如何在不改變代理本身及其呼叫預算的前提下，提升任務成功率。

**Motivation:** 多步驟任務需要代理依序呼叫多個工具，且後續工具的輸入依賴前置工具的輸出。現有以相關性排序的工具選單，常將最終動作工具排在前面，卻忽略了必要的橋接工具，導致工具無法執行。這種缺乏完整路徑的選單限制了代理的執行能力。實務上，若工具選單能預先呈現完整且有序的工具路徑，代理能更有效率且成功率更高地完成任務，對於工程部署與產品穩定性有直接影響。

**Method:** 作者提出State-Path Tool Menu方法，將工具選單視為一個執行先驗，學習從初始可見狀態到目標結果的完整工具路徑。方法包含三個主要組件：編碼器利用工具的輸入輸出欄位及訓練路徑資訊，生成具狀態相容性與路徑關係的工具表示；檢索器根據這些表示選出涵蓋入口、橋接、目標及終端角色的32個工具，確保路徑完整；重排序器則將選出的工具依生產者先於消費者的順序排列，形成可執行的前綴序列。整個流程在執行前完成，代理執行環境與呼叫預算不變。

**Result:** 在ToolBench基準上，State-Path方法將任務成功率從0.737提升至0.898，顯著優於多種檢索、重排序、生成及路由基線。該方法在32工具限制下，覆蓋的完整工具鏈比官方128工具清單還多，且成功率提升在不同代理模型容量與執行器家族中均持續存在。消融實驗顯示，工具覆蓋與排序兩者皆對成功率提升有貢獻，且隨著任務所需橋接工具數量增加，State-Path的優勢更明顯。跨工具庫與評估器測試也證實方法的泛化能力。

**Conclusion:** 本論文提出的State-Path Tool Menu方法，透過學習完整且有序的工具路徑，顯著提升了多步驟任務中語言模型代理的成功率。該方法不需改變代理本身或增加呼叫預算，即可改善工具選單的覆蓋與排序，並在多個基準與執行環境中驗證其有效性。限制在於目前僅固定選單於執行前，未涵蓋執行中動態更新，且依賴工具輸入輸出欄位及訓練路徑的豐富度。未來可探索在線更新及對稀疏或新工具庫的適應。

**Research Gap:** 本研究未明確說明在工具輸入輸出欄位不足或訓練路徑稀疏的情況下，方法的效能與穩定性如何，這在新興或未充分標註的工具庫中可能成為瓶頸。選單構建固定於執行前，缺乏對執行過程中狀態變化的動態調整能力，限制了對突發狀況的應對。實驗中雖有跨庫與跨執行器測試，但對於極端長鏈路或極大工具庫的擴展性與計算成本仍未充分探討。此外，消融分析主要聚焦於覆蓋與排序，對於不同類型任務的適用性及失敗案例分析較少，實務部署時的安全性與風險管理也僅作簡要提及。

### 3. LexAgentHallu: A Hierarchical Benchmark for Profiling Hallucinations in Legal Agents

- 分數：4
- arXiv: [2609.09754](https://arxiv.org/abs/2609.09754)
- 發表日期：2026-09-11
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #3 / 8/10: Provides a novel, detailed benchmark for legal agent hallucinations with expert annotations and fine-grained metrics, revealing new insights into failure modes beyond outcome-level evaluation.

**Intro:** 隨著大型語言模型被廣泛應用於法律領域的工具輔助代理，出現了代理層級的幻覺問題，即工具調用錯誤與推理錯誤連鎖導致虛構判決和錯誤引用權威。現有法律基準多聚焦於單輪問答且僅用結果層級指標評估，缺乏對多步驟代理過程中幻覺發生程度與類型的細緻診斷。本文提出LexAgentHallu，一個專為法律代理幻覺設計的分層基準，能評估法律代理在多步推理軌跡中錯誤的發生頻率與類型，彌補現有基準的不足。

**Motivation:** 法律代理系統在多步推理與工具調用過程中，幻覺不僅來自法律知識錯誤，也可能源自代理過程中的計劃偏差、工具誤用或記憶錯亂。現有評估方法無法區分這些錯誤來源，也無法定位錯誤發生的具體步驟，限制了對法律代理系統可靠性的深入理解與改進。為了提升法律代理的可用性與可信度，亟需一個能細緻剖析代理幻覺的多層次評估框架。

**Method:** LexAgentHallu通過四階段專家介入流程構建，涵蓋3414個實例，分布於17個法律類別與6種任務類型。核心方法包括雙層幻覺分類法，分別捕捉法律實質錯誤與代理過程錯誤，共含7個中層類別與27個細分類別。每個實例配備基於分類法的細粒度評估指標，並利用LLM作為評判者，對代理軌跡中每一步的錯誤進行判定與定位。此方法不僅評估最終答案，也分析推理過程中的錯誤分布與類型。

**Result:** 在18個專有及開源法律代理模型上進行評測，結果顯示所有系統均存在高頻率幻覺，最佳模型仍有近九成推理軌跡包含幻覺。不同代理框架在幻覺類型分布上表現差異明顯，ReAct框架在抑制實質性錯誤方面表現較佳，而LawThinker在降低程序性錯誤上更優。模型規模與幻覺率呈負相關，較大模型普遍幻覺較少。實驗還揭示了「正確答案錯誤理由」現象，即即使答案正確，推理過程中仍大量存在幻覺。幻覺類別呈現聚集而非分散，反映錯誤機制的結構性特徵。

**Conclusion:** LexAgentHallu首次提供一個針對法律代理多步推理幻覺的分層診斷基準，通過雙層分類法與細粒度指標，實現對法律代理幻覺的精確定位與量化。實驗結果證明該基準能揭示傳統結果層級評估無法觀察的錯誤模式，為法律代理系統的可靠性提升提供了重要工具。該基準有助於推動法律代理設計向軌跡感知評估轉變，促進更可信的法律AI應用。

**Research Gap:** 本研究基準僅涵蓋中國法律體系，所有數據與標註均基於中文及中國法規，限制了跨司法管轄區的適用性與泛化能力。法律系統差異可能導致其他司法管轄區出現不同的幻覺類型與錯誤模式，全文未明確說明如何擴展至普通法或混合法系。實驗僅評估單一模型代理，未涵蓋多代理系統或角色分工場景，這些複雜系統可能有不同的幻覺特徵與挑戰。此外，隨著模型能力演進，幻覺模式可能變化，基準需持續更新以保持有效性。最後，全文未明確說明評估過程中對成本、部署風險及失敗案例的分析，這些對實際工程落地亦具重要意義。

### 4. AgentAudit: An Open, Extensible Framework for Full-Lifecycle Trust Evaluation of AI Agents

- 分數：2
- arXiv: [2609.09875](https://arxiv.org/abs/2609.09875)
- 發表日期：2026-09-11
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mila, mit, openai; LLM rank #4 / 7/10: Proposes a comprehensive, extensible framework (AgentAudit) for full-lifecycle trust evaluation of AI agents with multi-dimensional failure attribution, evaluated on multiple large models, highlighting trustworthiness be

**Intro:** 現有的 AI 代理評估框架多半只聚焦於單一面向，如任務完成度或安全性，無法全面覆蓋代理的整個執行流程。隨著大型語言模型（LLM）成為具備規劃、工具使用、記憶與推理能力的完整代理，單純評估最終結果已不足以揭示潛在失敗原因。AgentAudit 提出一套完整的執行軌跡審核框架，涵蓋指令完整性、規劃、記憶、工具選擇與調用、工具正確性、對齊、安全性與執行完整性等十個維度，並結合行為分類與失敗歸因，精確定位失敗來源。此框架不干涉代理內部實現，能兼容多種 LLM 代理架構。

**Motivation:** 隨著 AI 代理系統複雜度提升，失敗可能發生於規劃錯誤、工具調用失誤、記憶污染或安全攻擊等多個環節。現有評估多只關注最終任務成功與否，無法揭示具體失敗階段，導致難以針對性改進。AgentAudit 透過完整執行軌跡分析，提供多維度分數與失敗歸因，幫助開發者精準診斷問題，提升代理系統的可靠性與安全性，對工程與產品落地具實際價值。

**Method:** AgentAudit 採用三層架構：執行層負責代理與環境互動，軌跡層記錄完整執行過程，評估層獨立分析軌跡。評估模組包含十個獨立子模組，分別評估指令完整性、規劃、記憶、工具選擇、工具調用、工具正確性、對齊、工具忠實度、安全性與執行完整性。每個模組產生 0-100 分數與信心值。行為分類將代理行為分為安全正確、危險服從、安全無能與部分成功，失敗歸因則定位具體失敗環節。最終以加權合成的綜合信任分數（CTS）呈現整體表現。評估完全基於執行軌跡，不干擾代理運行，兼容多種代理架構與環境。

**Result:** 作者使用 AgentAudit 評估五款大型語言模型（OpenAI GPT-5、Claude Sonnet 5、Sarvam 105B、Llama 3.3 70B、Gemini 2.5 Flash），涵蓋九個任務與六種環境，包含能力與對抗性攻擊場景。Claude Sonnet 5 與 GPT-5 分別以 95.1 與 80.6 分領先，Sarvam、Llama 與 Gemini 分數明顯較低。行為分類揭示相似任務完成度下，模型在安全性表現差異顯著，部分模型會危險服從惡意指令，這是傳統通過/失敗評估無法察覺的。實驗使用單一 LLM 評判模型，並指出此為限制。結果顯示 AgentAudit 能有效區分能力與安全性問題，提供細緻診斷。

**Conclusion:** AgentAudit 提供一套全面且可擴展的 AI 代理信任評估框架，突破現有僅評估單一面向的限制。透過完整執行軌跡分析與多維度評分，結合行為分類與失敗歸因，能精確定位代理失敗階段並揭示安全風險。實驗驗證其在多模型、多任務上的有效性，顯示相似任務成功率下模型信任度差異明顯。該框架對工程實踐與產品部署具重要參考價值，尤其在安全性與可靠性保障方面。限制包括依賴完整執行軌跡、部分評估依賴 LLM 判斷模型、未涵蓋多代理協作場景，未來可擴展至實時監控與動態任務生成。

**Research Gap:** 本文尚未充分驗證多次重複實驗的穩定性，僅以單次評估結果呈現，可能受偶然因素影響。評估過程依賴單一 LLM 評判模型，存在偏見與能力限制風險，未提供多模型交叉驗證。框架假設可取得完整執行軌跡，對部分商業封閉系統適用性有限。安全評估雖涵蓋多種攻擊類型，但未明確展示對新興攻擊手法的適應能力。未涵蓋多代理系統與動態交互場景，限制了對複雜協作任務的評估。成本與運行效率未詳細討論，實際部署風險與資源需求仍待評估。未提供失敗案例分析細節，缺乏對失敗原因的深入探討。

### 5. Multi-Agent Agentic Graph Learning via Structural Signatures

**Intro:** 本文聚焦於文本屬性圖（TAG）上的圖推理任務，該任務結合結構資訊與語義資訊，傳統GNN方法在不同節點需不同鄰域上下文時表現有限。近年來，基於大型語言模型（LLM）的Agentic Graph Learning（AGL）方法透過智能代理動態採樣圖證據以支持推理，但現有方法多依賴單一共享推理策略，難以適應圖中異質的結構與語義模式。本文提出一種多代理協作框架MAAGL，旨在提升圖推理的靈活性與效率。

**Motivation:** 現有AGL方法將圖結構口語化為文本，導致推理過程對鄰居節點順序敏感，破壞圖的排列不變性，且多跳鄰域擴展使上下文迅速膨脹，增加推理成本並影響結構證據的有效利用。共享推理策略無法針對不同圖區域的異質性進行專門化學習。多代理協作在語言推理任務中已證明有效，但直接應用於圖推理面臨結構證據交換困難及成本問題。這些挑戰促使作者設計MAAGL以解決上述問題。

**Method:** MAAGL首先將圖劃分為多個社群，為每個社群分配獨立代理，使代理能專注於區域特定的結構與語義特徵。代理分別維護私有記憶與推理策略。結構證據以固定維度且排列不變的結構簽名表示，包含節點度數、PageRank、聚類係數、跨社群比例等統計指標，動態更新標籤熵與多數標籤比例。語義證據則根據與目標節點的語義相似度篩選前k個節點文本。代理根據歷史推理軌跡估計信心，信心不足時觸發多代理辯論式協作，通過多輪交換推理結果達成共識。代理還從歷史軌跡中學習結構條件與推理策略的經驗，並經跨代理驗證後共享。

**Conclusion:** 本文提出的MAAGL框架通過多代理專區域專門化與結構簽名表示，有效解決了現有AGL方法在圖推理中面臨的排列不變性破壞與上下文膨脹問題。多代理辯論式協作與經驗學習進一步提升推理準確率與泛化能力。實驗結果證明MAAGL在多數場景下優於現有方法，且具備較高的推理效率。限制在於結構簽名維度由人工指定，未自動適應任務特性，未明確說明在更大規模圖或其他圖任務的適用性。
