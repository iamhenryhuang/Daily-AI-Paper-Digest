### 1. DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training

- 分數：7
- arXiv: [2609.04094v1](http://arxiv.org/abs/2609.04094v1)
- 發表日期：2026-09-03
- 分類：cs.AI, cs.LG, cs.SE
- 入選理由：+2 提及頂級機構：ibm; +3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #1 / 9/10: Proposes a novel, mathematically principled method (DRACO) for fine-grained credit assignment in long-horizon RL without verifiable rewards, with strong empirical gains and open-source code, addressing a key challenge in

**Intro:** 本論文探討在缺乏可驗證終端成功信號的長期任務中，如何利用多準則評分標準（rubrics）作為強化學習的獎勵信號。長期任務中，單一的軌跡級別標量獎勵難以有效分配給多步驟決策，且許多實際應用無法取得真實成功標準。作者提出DRACO方法，動態生成每條軌跡的評分標準，並將軌跡級別評分根據評分標準中指示的步驟分配給各步驟，以解決結果盲目（outcome-blind）強化學習中的信用分配問題。

**Motivation:** 在長期代理任務中，缺乏程式化的成功驗證器使得訓練信號難以獲得，且單一軌跡獎勵無法精細反映每步驟的貢獻，導致學習效率低下。現有方法多依賴終端驗證信號或昂貴的逐步評分，限制了在無驗證器場景的應用。DRACO旨在提供一種不依賴真實成功信號，且能動態調整評分標準並精細分配信用的方案，對工程和產品落地具有重要意義，尤其是在無法設計明確驗證器的複雜任務中。

**Method:** DRACO包含兩大核心組件：首先，根據任務指令及多條軌跡動態生成評分標準，這些標準互斥且涵蓋所有可能失敗情況，並透過判斷模型（judge）對每條軌跡進行評分，產生軌跡級別的獎勵。其次，根據判斷模型對每個評分標準所指涉的具體步驟，將軌跡整體優勢值（advantage）以封閉形式重新分配給各步驟，形成細粒度的步驟優勢，並用於GRPO強化學習更新。此方法不需訓練額外的歸因模型，且保證總推力守恆與符號一致。

**Result:** 在AppWorld基準上，DRACO較未訓練模型提升15.9點任務完成率（TGC），並超越使用稀疏真實獎勵的GRPO 5.3點。零射轉移至τ-bench銀行客服基準亦提升5.3點成功率，優於真實獎勵訓練及其他rubric基方法。消融實驗顯示動態評分標準與步驟信用分配兩者結合效果最佳。使用自我判斷模型替代前沿判斷模型可大幅降低評分成本，且仍達到或超越真實獎勵基準。訓練過程中，DRACO使代理在更短步驟內完成任務，且提升成功率與一致性。

**Conclusion:** 本論文提出DRACO方法，成功解決了無真實成功信號的長期任務中信用分配的挑戰。動態生成的軌跡特定評分標準結合封閉形式的步驟信用重分配，提升了強化學習效率與性能，並在多個基準上證明其有效性與泛化能力。此方法不依賴訓練歸因模型，降低了系統複雜度與成本，對實際工程部署具吸引力。限制在於無法獨立驗證評分標準與信用分配的正確性，且訓練過程中評分標準的變異性未被充分量化。

**Research Gap:** 本研究未明確驗證評分標準是否真實反映任務目標，缺乏人類標註者對判斷模型一致性與準確性的評估，可能導致系統學習到偏誤或錯誤的獎勵信號。此外，步驟信用分配雖提升性能，但未展示其是否精確指向真正關鍵步驟，存在信用錯置風險。動態評分標準依賴於樣本群體，可能導致訓練過程中獎勵信號波動，未有系統性分析其對訓練穩定性的影響。最後，全文未明確說明在更大規模或更複雜任務中的泛化能力及部署成本，這些均為未來改進方向。

### 2. Compile by Training: Turning Natural-Language Specifications into Local Neural Functions

- 發表日期：2026-09-03
- 分類：cs.CL, cs.AI, cs.LG
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +3 提及頂級會議：emnlp; LLM rank #2 / 8/10: Introduces a novel compile-by-training approach turning natural language specs into reusable neural functions, with strong semantic accuracy and practical deployments, supported by credible experiments and a public demo.

**Intro:** 許多重複性的文字處理功能雖然容易用自然語言描述，但難以用規則實現。直接呼叫大型遠端模型雖然可行，卻會帶來高延遲、成本及對外部服務的依賴。本文提出一種名為 compile by training 的方法，將自然語言規格轉換成可重用的本地神經函數，藉此降低執行時成本與依賴。該方法利用教師模型在編譯階段生成任務特定的訓練資料，並訓練一個小型適配器來專門化共享的解釋器。編譯完成後，函數可離線執行，不再需要教師模型支援，方便版本管理與組合使用。

**Motivation:** 在工程與產品層面，許多文字處理任務介於難以用規則實現與頻繁呼叫大型模型之間，既不適合寫死規則，也不適合每次都呼叫遠端大模型。這導致延遲高、成本大且依賴外部服務，影響系統穩定性與用戶體驗。將自然語言規格編譯成本地神經函數，能在編譯時花費較多時間換取執行時的高效與低成本，對於需要頻繁執行的任務尤其重要。此外，這種方法使得大型模型成為工具建造者而非執行時依賴，提升系統可控性與可維護性。

**Method:** 核心方法分兩階段：首先由教師模型根據自然語言規格合成大量輸入輸出對作為訓練資料；其次利用這些資料對共享的凍結語言模型解釋器進行 LoRA 適配器的微調，專門化該解釋器以實現指定功能。系統以 Program-as-Weights (PAW) 框架為基礎，先用快速的攤銷編譯器產生初始適配器參數，再進行進一步優化。編譯過程中，教師資料合成與訓練重疊進行以縮短等待時間。最終產出包含適配器、提示模板與元資料的可重用程序，能離線本地執行且支持版本管理與組合。

**Result:** 在 FuzzyBench-Hard 基準上，該方法在 PAW 快速編譯器無法產生完全匹配的任務中達到 83.6% 的語義準確率，較快速編譯器的 22.4% 有明顯提升。編譯時間約為 50 秒，較快速編譯器的 3.5 秒長，但仍可接受且支援互動式使用。教師模型組合與訓練資料規模對準確率有正向影響。系統已部署於公開服務，並展示多站點網站助手、語言控制的 3D 虛擬人偶及英語與 Claudish 雙向翻譯等應用，證明可組合多個編譯函數並與傳統程式碼協同工作。

**Conclusion:** 本文提出的 compile by training 方法有效將自然語言規格轉換為本地可重用的神經函數，解決了頻繁呼叫大型模型的成本與延遲問題。該方法在準確率上明顯優於快速攤銷編譯器，且編譯時間仍在可接受範圍內，適合互動式應用。實際部署案例展示了其在多任務組合與結構化執行上的可行性。限制在於合成監督可能繼承教師模型錯誤，且對於需要嚴格正確性的應用仍需額外驗證。系統尚缺乏系統性用戶研究以評估實際使用效果。

**Research Gap:** 本文雖展示了編譯準確率提升與互動式編譯可行性，但缺乏對合成監督錯誤影響的深入分析與緩解策略。實驗主要集中於特定基準與任務，泛化能力與跨領域適用性尚未充分驗證。系統對於大規模多任務同時編譯的資源消耗與調度效率未詳細探討。缺少對失敗案例的分析與對比其他微調或蒸餾方法的消融實驗。此外，部署成本、模型大小與延遲間的權衡、以及在低資源環境下的適用性也未明確說明。全文未明確說明用戶體驗與長期維護的挑戰。

### 3. ESPO: Error-Structured Prompt Optimization via Diagnose, Diversify, and Stabilize

- 分數：5
- arXiv: [2609.04197v1](http://arxiv.org/abs/2609.04197v1)
- 發表日期：2026-09-03
- 分類：cs.CL, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：emnlp; LLM rank #3 / 7/10: Addresses prompt bloat in evolutionary prompt optimization with a well-motivated, multi-phase method (ESPO) that improves accuracy and efficiency across multiple benchmarks and models, supported by theoretical bounds and

**Intro:** 本論文針對現有進化式提示優化器如GEPA存在的提示膨脹問題進行研究，該問題導致提示長度大幅增加但準確度無明顯提升。作者指出這主要源於三大缺陷：錯誤觀察不完整、搜尋多樣性不足及選擇不穩定。為此，提出ESPO框架，將提示優化分解為三階段：錯誤診斷、候選生成及穩定性選擇，旨在提升優化效率與結果品質。

**Motivation:** 隨著大型語言模型應用日益複雜，手動調整提示成本高且效率低，故自動化提示優化成為關鍵技術。然而現有方法如GEPA在優化過程中容易累積冗餘規則，導致提示過長且推理延遲增加，甚至影響泛化能力。從工程與產品角度，提示過長不僅增加推理成本，也降低系統部署效率，因此需要更有效且穩健的提示優化策略。

**Method:** ESPO框架包含三個核心階段：第一階段為錯誤診斷，利用大型語言模型一次性聚類所有訓練錯誤，形成3至7個結構化錯誤模式；第二階段為多策略候選生成，採用四種互補策略（診斷修正、合併精簡、消融過度觸發規則及事實注入）生成多樣化候選提示，並透過交叉融合與精細調整控制候選數量；第三階段為引入引導式bootstrap穩定性選擇，通過多次重抽樣驗證集評估候選，選出在不同樣本子集上表現穩定且泛化能力強的提示，並偏好較短提示以避免過擬合。

**Result:** 在七個公開NLP基準（包含分類、多跳推理、數學問題及隱私保護生成）上，ESPO相較於GEPA平均提升3.76個百分點準確率（74.67%對70.91%），且生成的提示長度減少47%（平均1004字元對1878字元），推理延遲亦降低。跨模型測試涵蓋四種不同學生模型，ESPO均取得最佳平均準確率，尤其在Qwen3 GSM8K數學任務中，準確率從15.00%大幅提升至91.40%。消融實驗證實三階段設計均有貢獻，且多樣性策略若無穩定性選擇反而降低性能。

**Conclusion:** 本論文提出的ESPO框架有效解決了進化式提示優化中錯誤觀察不全、多樣性不足及選擇不穩定的問題，實驗結果顯示其在多種任務與模型上均優於現有方法GEPA，且能生成更短且推理更快的提示。理論上，ESPO的三階段設計對應於泛化誤差的不同組成部分，並透過引導式bootstrap選擇提升選擇穩定性。限制方面，ESPO仍需較高計算成本，且診斷階段依賴單一反思模型，對錯誤模式複雜度的覆蓋仍有限。

**Research Gap:** 本研究未充分探討多反思模型混合使用對診斷與候選生成的影響，且理論假設中策略獨立性與驗證集噪聲分布的前提在實務中難以完全成立，可能影響泛化保證的嚴謹性。診斷階段對錯誤模式的聚類依賴大型語言模型，對於錯誤模式數量眾多或分布式變化的場景可能不足以全面覆蓋。此外，實驗集中於單輪提示優化，未涵蓋多輪互動、長上下文或代碼生成等複雜應用，限制了方法的普適性與實際部署風險評估。最後，成本與計算資源需求較高，對資源有限的工程環境可能造成挑戰。

### 4. CORE: Improving Compositional Reasoning in MLLM Embedding via Reranker Distillation

- 分數：5
- arXiv: [2609.04083v1](http://arxiv.org/abs/2609.04083v1)
- 發表日期：2026-09-03
- 分類：cs.CV, cs.AI, cs.CL, cs.IR
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; LLM rank #4 / 7/10: Presents a novel distillation method (CORE) to improve compositional reasoning in MLLM embeddings via reranker supervision, showing significant benchmark improvements and thorough evaluation of objectives.

**Intro:** 多模態大型語言模型（MLLM）在嵌入式檢索中仍面臨組合推理的挑戰，尤其難以區分具有相同概念但屬性-物件綁定不同的場景。現有的嵌入模型無法有效捕捉這些細粒度的組合結構，導致檢索結果不精確。該論文提出一種將跨注意力重排序器（reranker）的組合判斷能力蒸餾到嵌入模型中的方法，旨在提升嵌入模型的組合推理能力。

**Motivation:** 現有的組合推理問題主要來自於嵌入模型無法保留細粒度的屬性-物件綁定信息，而同一模型作為重排序器時能夠正確區分，顯示了模型本身具備潛力但嵌入空間表達不足。此外，傳統對比學習將所有負樣本視為同等錯誤，忽略了組合相似度的分層結構，限制了模型學習細緻排序的能力。這對工程和產品落地意味著，若能提升組合推理能力，將顯著改善多條件檢索和細粒度匹配的準確性。

**Method:** 提出CORE框架，首先通過一個結構化的數據合成管道，從真實圖像生成包含五個組合匹配層級的候選列表，這五級分別代表從完全匹配到完全不匹配的不同組合相似度。接著，利用Rank-KL的列表式蒸餾損失，將重排序器對候選列表的細粒度排序知識轉移到嵌入模型中。該方法與對比學習和CoSENT等目標函數在相同數據和調參預算下進行比較，證明Rank-KL能更有效利用多層級監督信號。

**Result:** 在三個組合推理基準（COLA、SUGARCREPE++、NEGBENCH）上，CORE-RERANKER-8B達到82.7%的總平均分，超越先前最佳重排序器Jina-Reranker 10.7個百分點。CORE-EMBED-8B在所有評估的嵌入模型中表現最佳，總平均達0.666，較基線VL-EMB-8B提升5.7個百分點。該改進在MCMR多條件檢索基準上也有遷移效果，且在COCO和Flickr30K等通用檢索任務中保持性能不降。Rank-KL優於對比學習和CoSENT，能更好地捕捉組合結構的分層排序。

**Conclusion:** CORE框架通過結構化數據合成和Rank-KL列表蒸餾，有效將重排序器的細粒度組合推理能力注入嵌入模型，提升了多模態檢索中組合推理的精度。該方法在多個組合推理基準和多條件檢索任務中均展現出優越性能，且不損害通用檢索能力。這對實際應用中需要細粒度多條件匹配的系統具有重要意義，提供了一種可行的組合推理能力提升路徑。

**Research Gap:** 論文中嵌入模型的組合推理提升幅度相對有限，表明蒸餾過程未能完全轉移重排序器的能力。評估主要基於與訓練數據合成管道相同的分布，缺乏獨立且多樣化的外部驗證，限制了泛化性的判斷。COLA基準上的提升較小，且重排序器在該任務上也表現有限，顯示該類細粒度屬性-物件綁定仍具挑戰性。實驗中對不同基礎模型和蒸餾溫度等超參數的敏感性分析不足，且未充分探討蒸餾對模型推理成本和部署風險的影響。未明確說明失敗案例或在更複雜場景下的表現，限制了對方法穩健性的全面評估。

### 5. Rethinking On-Policy Distillation of Large Language Models II: One Training Example

- 分數：5
- arXiv: [2609.04172v1](http://arxiv.org/abs/2609.04172v1)
- 發表日期：2026-09-03
- 分類：cs.AI, cs.CL

**Intro:** 本論文探討On-Policy Distillation（OPD）在大型語言模型後訓練中的數據需求，特別聚焦於極端數據限制下的訓練行為。OPD結合學生模型自產生的rollouts與教師模型提供的密集token級監督，過去研究多集中於算法層面，缺乏對訓練數據角色的深入理解。作者以單一訓練查詢為實驗設定，發現即使只用一個查詢，OPD仍能持續數百步優化並恢復大部分全數據訓練的效益，跨任務領域與模型家族均有效。此現象促使重新思考OPD的數據與算法效率問題。

**Motivation:** 在工程與產品實務中，理解OPD對訓練數據的依賴性關乎訓練成本與數據收集策略優化。若少量數據即可達成接近全數據訓練的效果，將大幅降低標註與數據準備負擔。另一方面，若算法吸收監督信號的速率為瓶頸，則優化訓練步數與更新策略更為關鍵。現有研究多忽略數據與算法的交互，本論文透過極端的單一查詢設定，拆解數據覆蓋與算法吸收兩大因素，對後訓練流程設計與資源配置具有實務指導意義。
