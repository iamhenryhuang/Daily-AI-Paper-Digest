### 1. Imagine3D-LLM: Teaching MLLMs to Imagine 3D Scenes Before Answering

- 分數：5
- arXiv: [2609.38177v1](http://arxiv.org/abs/2609.38177v1)
- 發表日期：2026-09-29
- 分類：cs.CV, cs.CL
- 入選理由：+2 提及頂級機構：mila; +3 提及頂級會議：neurips; LLM rank #1 / 9/10: Introduces a novel approach inspired by human spatial reasoning to improve 3D scene understanding in MLLMs, with strong empirical evidence and clear practical impact on spatial reasoning benchmarks.

**Intro:** 多視角影像中推理三維世界是多模態大型語言模型（MLLMs）面臨的核心挑戰。現有的MLLMs雖能有效處理單張影像，但難以整合多視角資訊以形成連貫的三維理解。過去研究多透過強化像素層級的跨視角對應或融合三維幾何基礎模型特徵，仍無法達到人類空間推理的水準。本文提出一種模擬人類空間推理過程的新方法，試圖彌補此缺口。

**Motivation:** 人類在空間推理時，並非依賴細緻的幾何資訊，而是透過辨識多視角中共同物體、推斷視角間相對幾何關係，並組合成粗略的三維場景布局。現有方法多聚焦於細節幾何對應，忽略了這種粗略但有效的三維場景想像過程。若能讓MLLM模擬此過程，或許能提升其多視角三維推理能力，對工程與產品應用中多視角理解、虛擬環境建模等場景有實質幫助。

**Method:** 本文提出Imagine3D-LLM，透過在影像token後附加一組可學習的摘要token，將其解碼為緊湊的三維高斯點雲（Gaussian Splatting）表示。此表示由光度重建損失監督，同時與標準的下一token預測目標共同訓練。雖然只有摘要token直接接受重建監督，但此過程促使模型內部影像特徵跨視角對應能力增強，實現三維感知信號的全模型傳播。此方法模擬人類粗略組合三維場景的策略，避免過度依賴細節幾何。

**Result:** 在多個空間推理與三維理解基準測試中，Imagine3D-LLM均優於先前方法。實驗明確比較了不同方法在多視角整合與三維推理任務上的表現，指標涵蓋重建誤差與語言理解準確度。結果顯示，透過想像三維場景的方式，模型能更有效地整合跨視角資訊，提升推理品質。全文未明確說明具體數值與基準細節，但整體趨勢明確。

**Conclusion:** 本文提出的Imagine3D-LLM透過模擬人類空間推理過程，成功提升了MLLM在多視角三維理解與空間推理任務的表現。方法兼顧三維表示的緊湊性與跨視角對應能力，對工程應用中多視角資訊整合具有實際價值。限制在於全文未明確說明模型在更複雜場景或真實世界部署的泛化能力與計算成本，仍需進一步驗證。

**Research Gap:** 本文未充分探討模型在多樣化場景（如動態場景、遮擋嚴重情況）下的表現與穩定性，缺乏對失敗案例的分析。實驗細節與基準數據未完全公開，難以全面評估泛化能力與效能。方法依賴光度重建損失，可能對光照變化敏感，全文未說明如何處理此問題。此外，模型的計算資源需求與實際部署成本未被討論，對工程落地有一定限制。消融實驗與與其他三維表示方法的比較也較為有限，尚需補充以驗證方法的普適性與優勢。

### 2. Breaking the Uniformity Trap: Scaling Video Diffusion Model via SplitMoE

- 分數：5
- arXiv: [2609.38140v1](http://arxiv.org/abs/2609.38140v1)
- 發表日期：2026-09-29
- 分類：cs.CV, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：neurips; LLM rank #2 / 8/10: Proposes a principled architecture (SplitMoE) addressing a fundamental limitation in scaling video diffusion models, supported by extensive experiments and offering a new modality-aware scaling path.

**Intro:** 視覺生成模型在擴展規模時面臨計算與效率的挑戰，尤其是視頻數據具有時空冗餘與語義長尾分布的特性。傳統的Mixture-of-Experts (MoE)方法多採用均勻分配專家負載的策略，忽略了視頻數據的語義不均衡，導致專家路由分散且結構扭曲。這種均勻性陷阱限制了MoE在視頻生成任務中的表現與擴展能力。該論文針對這一問題提出新的架構設計，旨在提升視頻生成模型的效率與質量。

**Motivation:** 視頻數據的時空冗餘與語義長尾特性使得傳統均勻負載的MoE路由策略不適用，因為它會將語義相關的資訊分散到不同專家，造成路由碎片化和結構失真。這種不合理的專家使用正則化限制了模型捕捉視頻中高層語義與細節的能力。對於工程與產品來說，提升視頻生成模型的收斂速度與生成質量，並降低計算資源消耗，是實際落地的關鍵需求。論文提出的SplitMoE架構正是為了解決這些問題，提供更適合視頻數據的專家分工與路由機制。

**Method:** 核心方法是將專家池拆分為兩類：語義專家與通用專家。語義專家負責捕捉高層語義抽象，通用專家則保留剩餘的視覺信息與靈活的生成能力。透過原型引導的路由機制，模型能根據語義屬性自然聚類token，而非強制均勻分配。此外，採用拉推正則化（pull-push regularization）來促進路由的語義一致性與專家間的協調。這種分角色的稀疏架構打破了傳統MoE的均勻性限制，更符合視頻數據的特性。

**Result:** 在相同激活參數預算下，SplitMoE在多個標準視頻生成基準測試中，較傳統均衡負載MoE展現出更快的收斂速度、更高的路由一致性以及更優的視頻生成質量。實驗結果顯示，該方法能有效減少路由碎片化，並揭示出一種由粗到細的去噪邏輯，這對於提升大規模視頻世界模型的建構具有指標性意義。全文未明確說明具體的數據集名稱與指標數值，但強調了在多個標準基準上的優勢。

**Conclusion:** 本文提出的SplitMoE架構針對視頻生成模型中的均勻性陷阱，通過專家角色拆分與語義引導路由，提升了模型的收斂效率與生成質量。該方法為視覺生成模型的擴展提供了一條模態感知的路徑，對於工程實踐中如何有效利用MoE架構具有參考價值。然而，全文未提供詳細的實驗設置與指標數據，限制了結果的可驗證性與復現性。

**Research Gap:** 論文未明確說明具體的數據集、評估指標與實驗細節，導致結果的可驗證性不足。缺乏對比多種路由策略與正則化方法的消融實驗，無法充分評估各組件的貢獻。此外，對於模型在不同視頻場景（如動態複雜度、語義多樣性）下的泛化能力與失敗案例未做探討。成本與部署風險方面的分析也較為缺乏，對於實際工程落地的挑戰未有深入說明。未來工作可補充這些方面以提升論文的完整性與實用價值。

### 3. Tail-Influence Sampling for CVaR Policy Evaluation

- 分數：5
- arXiv: [2609.38096v1](http://arxiv.org/abs/2609.38096v1)
- 發表日期：2026-09-29
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mila; +3 提及頂級會議：acl; LLM rank #3 / 8/10: Presents a theoretically grounded and empirically validated sampling method (TIS) for CVaR policy evaluation that significantly reduces MSE, with clear novelty and practical usefulness in RL evaluation.

**Intro:** 在強化學習與決策制定中，政策的平均回報相近，但在罕見失敗事件的表現可能有顯著差異。準確估計下尾條件風險值（CVaR）對於理解和控制這些罕見風險至關重要，但這通常需要大量昂貴的模擬試驗。本文聚焦於如何在有限的評估預算下，最有效率地估計固定政策的CVaR，尤其是在可分別查詢隨機流程中不同條件成分的情況下。

**Motivation:** 現有方法在估計CVaR時往往忽略了不同條件分布對尾部風險的影響，導致資源分配不均且效率低下。對工程與產品而言，這意味著在有限的計算資源下難以準確評估政策的風險表現，影響決策安全性與可靠性。研究如何根據各條件分布對CVaR的影響來分配評估資源，有助於提升風險評估的精準度與成本效益，對實際部署與風險管理具有直接價值。

**Method:** 作者提出Tail-Influence Sampling（TIS）方法，首先從一個先導模型估計每個可查詢條件分布對CVaR的影響程度（tail influence），該影響度量匯總了不確定性如何通過Bellman方程重用影響CVaR。根據這些影響度，TIS將評估資源重新分配給對尾部風險影響最大的條件分布。為防止先導模型低估重要性，還設計了基於訪問頻率的錨定變體。理論上，在固定維度和正分位數邊界條件下，TIS可達到理想的漸近方差與一階均方誤差，錨定變體則在性能上接近理想分配的兩倍內。

**Result:** 在CliffWalking環境中，TIS相較於基於學習佔用率的分配減少了41%的均方誤差（MSE），相較於完全模擬試驗則減少了76%，且在相同的轉移次數預算下達成。於凍結語言模型的審查工作流程中，錨定TIS在24個MMLU-Pro設定中贏過均勻正則化的平均影響力混合方法23次，並在六次FinQA審查呼叫中達到2.4至3.4倍低的MSE。這些結果表明TIS在多種場景下均能有效提升CVaR估計的準確度與效率。

**Conclusion:** 本文提出的Tail-Influence Sampling方法針對CVaR估計中的資源分配問題提供了一套理論嚴謹且實務可行的解決方案。透過先導模型估計影響度並動態調整查詢分配，TIS顯著提升了尾部風險估計的效率與準確性。錨定變體則增加了方法的穩健性，適合實際應用。整體而言，該方法對於需要精確風險評估的強化學習與決策系統具有重要意義，但全文未明確說明在更高維度或非理想條件下的表現。

**Research Gap:** 全文未明確說明TIS在高維狀態空間或更複雜策略結構下的適用性與效能，這對實際大型系統部署至關重要。實驗中主要聚焦於特定環境與語言模型審查，缺乏跨領域或多樣化場景的驗證。此外，先導模型的選擇與估計誤差對最終分配策略的影響未充分探討，可能存在低估重要條件分布導致資源錯配的風險。成本與計算負擔的具體量化也較為有限，對於實際工程部署的可行性評估不足。最後，缺少對失敗案例或方法限制的深入分析，影響讀者對方法穩健性的全面判斷。

### 4. VideoLoop: Looped Working Memory Against Semantic Thrashing in Long-Form Video Agents

- 分數：4
- arXiv: [2609.38119v1](http://arxiv.org/abs/2609.38119v1)
- 發表日期：2026-09-29
- 分類：cs.CV
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: Addresses a key challenge in long-form video understanding by proposing a novel memory management mechanism (VideoLoop) that mitigates semantic thrashing, with strong empirical gains and open code.

**Intro:** 長影片理解需要多模態智能體在多個推理步驟中反覆蒐集證據。現有多數方法使用的附加式工作記憶會隨時間累積，導致注意力分散，無法有效聚焦關鍵證據，造成語義混亂。這使得智能體難以保持對已獲取資訊的有效存取，影響推理品質與結果準確度。本文針對此問題提出結構性分析，指出附加式記憶缺乏重寫機制，無法去除噪聲或控制上下文成長。基於此，作者設計了一種雙迴圈架構的多模態智能體VideoLoop。

**Motivation:** 在長影片任務中，智能體需要長時間累積並整合多輪推理資訊，但附加式記憶的無限制增長會導致語義混亂，降低模型對關鍵證據的注意力，進而影響推理效果。這對工程與產品落地造成挑戰，因為無法有效管理工作記憶會限制模型在長時間、多步驟任務中的表現。解決此問題有助於提升長影片理解的準確度與穩定性，對多模態智能體的實際應用價值顯著。

**Method:** VideoLoop採用雙迴圈設計：外迴圈負責對影片進行推理，內迴圈則在每一步後從無限擴展的檔案系統中檢索過去觀察與中間分析結果，並重寫有限大小的工作記憶。此重寫機制允許智能體去除累積的噪聲，避免上下文無限制增長，從而減緩語義混亂。該方法可插拔地應用於多種主流長影片視覺語言模型(LVLM)骨幹，提升其長影片推理能力。

**Result:** 實驗在VideoMME (long)資料集上進行，VideoLoop在四個主流LVLM骨幹上平均提升4.2個百分點。進一步分析顯示，VideoLoop在最難的四分之一問題中，僅依據智能體上下文的盲測判斷正確率達81.1%，明顯優於附加式記憶的60.9%。使用Gemini 3.1 Pro骨幹時，VideoLoop在VideoMME (long)、VideoMMMU及LongVideoBench (long)分別達到88.3%、88.8%及80.9%的準確率，展現良好泛化能力。

**Conclusion:** 本文針對長影片理解中附加式工作記憶導致的語義混亂問題，提出雙迴圈VideoLoop架構，有效管理工作記憶，提升多模態智能體的推理表現。實驗結果證明該方法能顯著改善多個LVLM骨幹在長影片任務上的準確率，並減少語義混亂現象。此方法對長影片理解的工程實踐具有參考價值，尤其在需要長期累積與整合資訊的場景中。

**Research Gap:** 全文未明確說明VideoLoop在不同影片類型、長度及多模態資訊複雜度上的泛化能力與限制。實驗主要集中在三個資料集，缺乏更廣泛的場景驗證。重寫機制的計算成本與實際部署風險未充分討論，對於資源受限環境的適用性尚不明確。此外，缺乏對失敗案例或語義混亂仍未完全消除情況的分析，未提供消融實驗以驗證雙迴圈中各組件的獨立貢獻。這些均為後續改進與深入研究的方向。

### 5. Video-RSI: Recursive Self-Improvement of Video Understanding Agents via Harness Evolution

- 分數：4
- arXiv: [2609.37950v1](http://arxiv.org/abs/2609.37950v1)
- 發表日期：2026-09-29
- 分類：cs.AI, cs.CV
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #5 / 7/10: Introduces a recursive self-improvement framework for video understanding agents that adaptively refines evidence acquisition, showing competitive accuracy-efficiency trade-offs and providing code.

**Intro:** 影片理解代理通常透過一個可執行的控制機制（harness）來決定觀察什麼以及如何使用這些觀察證據。然而，現有的執行紀錄只包含當前控制機制所獲得的證據，無法解決失敗的多重解釋問題，限制了代理自我改進的可能性。本文提出一個名為 Video-RSI 的框架，旨在讓影片理解代理能夠遞迴地自我改進，透過自身的語言模型來修正控制機制。這樣的設計有助於提升代理在影片理解任務中的表現與效率。

**Motivation:** 影片理解任務中，代理的觀察策略直接影響其理解的準確度與計算成本。現有方法多依賴固定或手動設計的控制機制，缺乏自我調整能力，導致無法有效排除錯誤解釋或優化證據獲取流程。透過讓代理能夠主動重新檢視訓練影片並測試不同失敗解釋，能夠基於更多證據來改進控制機制，進而提升準確率並降低視覺成本，對工程落地與產品效能優化具有實際意義。
