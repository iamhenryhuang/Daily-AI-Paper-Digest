**Intro:** 本文聚焦於Vision-Language-Action (VLA)模型在語言條件下的機器人操作任務。現有資料集與基準多半只評估任務完成度，缺乏對模型在空間推理與長期規劃能力的深入診斷。為此，作者提出RoboSPA，一個大規模的機器人操作資料集與基準，專門用來評估VLA模型的具體空間推理與程序規劃能力。此資料集涵蓋多種任務類別與難度，並收集大量操作軌跡，提供更細緻的評估指標。這對於推動更可靠且具泛化能力的機器人系統研發具有重要意義。

**Motivation:** 現有VLA模型雖在簡單場景與短期任務中表現良好，但在面對複雜空間關係與長期程序規劃時仍顯不足。現有資料集多以任務成功率為主，無法揭示模型在細節推理與執行層面的瓶頸。工程與產品層面，這限制了VLA模型在真實複雜環境中應用的可靠性與穩定性。RoboSPA的設計旨在填補此缺口，幫助研究者與工程師更精確地診斷與改進模型的核心能力，促進技術落地與商業化。

**Method:** RoboSPA資料集包含10個任務類別與56個基礎任務，每個任務設計五個難度等級，總計280個變體，涵蓋細粒度空間推理與長期程序規劃兩大維度。資料集收錄超過52萬條操作軌跡，涵蓋多種機器人形態與多樣場景。評估指標不僅包含傳統的二元成功率，還引入多種診斷性指標，用以衡量模型在空間關係理解、低層次精確執行及記憶密集型規劃的表現。實驗中使用多個代表性VLA模型進行測試，對比不同難度與任務類型的挑戰。

**Result:** 實驗結果顯示，現有VLA模型在處理複雜空間關係時表現不佳，尤其在精確的低層次操作執行與長期記憶規劃方面存在明顯不足。隨著任務難度提升，模型成功率顯著下降，反映出其在程序複雜度與空間模糊性增加時的推理能力有限。這些發現驗證了RoboSPA作為診斷基準的價值，能有效揭示模型在多維度能力上的短板，為後續改進提供具體方向。

**Conclusion:** 本文提出的RoboSPA資料集與基準為VLA模型提供了一個更全面且細緻的評估平台，特別針對空間推理與長期程序規劃能力。實驗證明目前模型在這些關鍵能力上仍有顯著不足，強調了未來研究需聚焦於提升模型的精確執行與記憶管理能力。RoboSPA的公開資料與代碼有助於推動該領域的技術進步與實際應用。全文未明確說明模型在真實機器人系統中的部署成本與效能表現。

### 2. Beyond Stationarity in Time Series: Discovering Causal Structures and Latent Regimes via Markov Blankets

- 分數：5
- arXiv: [2609.05150v1](http://arxiv.org/abs/2609.05150v1)
- 發表日期：2026-09-04
- 分類：cs.LG, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：kdd; LLM rank #2 / 8/10: Presents a novel causal discovery algorithm for non-stationary time series with theoretical guarantees and strong empirical validation, addressing regime shifts in dynamic systems with credible methodology.

**Intro:** 時間序列資料在許多實際應用中常包含多個潛在的因果結構變化階段，傳統因果發現方法多假設因果結構在整個序列中保持不變，這在動態系統中往往不成立。本文提出一種新穎的因果發現演算法RCBNB-MB，專門針對非平穩時間序列中潛在的因果結構變化進行辨識。該方法透過辨識潛在的因果階段（regimes），在每個階段內假設因果結構穩定，進而進行因果圖的發現。此方法利用Markov blanket而非直接父節點來提升因果發現的魯棒性與預測能力。全文提供理論保證並在模擬與真實IT監控資料上驗證效果。

**Motivation:** 在實務中，許多時間序列資料因系統狀態變化而呈現多個不同的因果結構，若忽略這些變化，會導致因果推論錯誤，影響後續決策與預測。現有方法多假設因果結構不變，無法有效捕捉因果關係隨時間的變動。針對這點，RCBNB-MB透過辨識並分割潛在因果階段，能更精確地反映真實系統的動態因果結構，對於工程上監控異常偵測、系統維護及動態決策支援等場景具實質意義。

**Method:** RCBNB-MB採用一種迭代策略，先將時間序列分割成多個潛在的因果階段，每個階段內假設因果結構穩定。接著在每個階段中利用Markov blanket進行因果圖的發現，這比直接尋找父節點更能保留預測資訊並減少錯誤傳播。演算法結合約束式與噪聲基礎的因果發現方法，並提供理論證明其在合理假設下能正確恢復階段轉換點及對應因果圖。全文未明確說明具體分割演算法細節及參數設定。

**Result:** 作者在模擬資料中以已知真實因果結構與階段變化作為基準，與多個基線方法比較，結果顯示RCBNB-MB在準確偵測階段變化點及恢復因果圖結構上均有明顯優勢。於真實IT監控資料實驗中，考慮階段變化的模型能更有效捕捉系統異常與因果關係，提升監控精度。全文未提供詳細的指標數值與基線方法名稱，僅能根據摘要判斷整體表現優於現有方法。

**Conclusion:** 本文提出的RCBNB-MB為非平穩時間序列因果發現提供了一個理論與實務兼具的框架，能同時辨識潛在因果階段及其內部因果結構，對動態系統分析與監控有實際應用價值。方法利用Markov blanket提升因果發現的穩健性，並在模擬及真實資料中展現優越性能。限制在於全文未明確說明演算法細節與參數調整，且實驗範圍主要集中於IT監控，泛化性尚待進一步驗證。

**Research Gap:** 全文未明確說明潛在階段分割的具體演算法流程與參數選擇，缺乏對不同分割策略的消融分析。實驗中基線方法與評估指標細節不足，難以全面評估相對優勢。資料集主要為模擬與IT監控，缺乏多樣化應用場景驗證，對於更複雜或高維時間序列的適用性未探討。理論保證基於合理假設，實務中假設違反的影響未說明。成本與部署風險、演算法運算效率等工程面細節亦未涉及。

### 3. Don't Drop Dropout: Optimizing Layer Sparsity for Efficient LLM Training and Inference

- 分數：5
- arXiv: [2609.05275v1](http://arxiv.org/abs/2609.05275v1)
- 發表日期：2026-09-04
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mila, mit; +3 提及頂級會議：icml; LLM rank #3 / 8/10: Comprehensive large-scale study showing layer dropout's benefits for efficient LLM training and inference with extensive experiments and practical speedup gains, offering actionable best practices.

**Intro:** Layer dropout（又稱 stochastic depth）曾被證明能加速訓練、提升準確度，並增強語言與視覺 Transformer 模型對零射層剪枝的魯棒性。然而，隨著模型與資料集規模擴大，layer dropout 在大型語言模型（LLM）預訓練中逐漸消失。過去部分研究指出 dropout 可能降低準確度，但缺乏完整量化與緩解策略。本文針對 layer dropout 在 LLM 預訓練中的應用進行系統性研究，試圖恢復其在現代大型模型訓練中的價值。

**Motivation:** 大型語言模型訓練成本高昂，尋求有效降低計算資源與時間的技術十分重要。layer dropout 具備潛在加速訓練與推理的優勢，但因過去報告的準確度下降問題而被忽略。若能找到最佳的 layer dropout 配置與超參數，將有助於提升訓練效率並帶來推理階段的優化，對工程實務與產品部署均具實際意義。

**Method:** 本文提出針對 layer dropout 的最佳層分布、時間排程與優化器超參數設定，透過超過2400次訓練實驗，涵蓋從2.7億到82億參數模型及高達1600億字元的資料集，系統性評估其對訓練與推理效能的影響。訓練過程在 Cerebras CS-3 系統上執行，並探討 layer dropout 在訓練 FLOPs 相同條件下的損失表現，以及推理階段利用早期退出、中間層跳過與自我推測解碼等技術的加速效果。

**Result:** 實驗結果顯示，經過優化的 layer dropout 配置能在相同訓練 FLOPs 下達成更低的訓練損失，或在固定訓練步數下節省最多25%的 FLOPs 且保持相似或更佳的驗證損失。推理階段透過 layer dropout 支持的早期退出與跳層策略，最高可實現1.5倍速度提升，且準確度損失極小。這些發現跨越多種模型規模與資料集，證明方法在大規模訓練場景下的穩健性。

**Conclusion:** 本文重新肯定了 layer dropout 在大型語言模型訓練與推理中的價值，提出了具體的最佳實踐與超參數調整策略，實驗證明其能有效降低訓練成本並提升推理效率。此研究對於希望在有限資源下提升 LLM 性能的工程師與研究者具有參考價值。然而，全文未明確說明在不同模型架構或更極端規模下的泛化能力，且對於 dropout 對模型穩定性與長期訓練影響的深入分析有限。

**Research Gap:** 本文雖涵蓋多種模型與資料規模，但缺乏對不同 Transformer 架構（如 decoder-only 與 encoder-decoder）間 layer dropout 效果的比較。實驗主要集中於 Cerebras CS-3 硬體，對於其他硬體平台的適用性與效能影響未充分探討。推理加速策略的準確度損失評估較為粗略，缺少對失敗案例或極端條件下的穩定性分析。此外，全文未明確說明 layer dropout 對模型泛化能力與下游任務表現的影響，這對實際產品部署與多任務應用至關重要。最後，成本節省與加速效果的實際部署風險與工程複雜度亦未充分評估。

### 4. CABAL: Multi-Agent Simulacra for Tracing the Effects of Collusive Bidding in Peer Review

- 分數：5
- arXiv: [2609.05227v1](http://arxiv.org/abs/2609.05227v1)
- 發表日期：2026-09-04
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：aaai; LLM rank #4 / 7/10: Develops a multi-agent simulation framework to study collusive bidding in peer review with realistic LLM-driven agents and controlled experiments, providing novel insights into a critical integrity issue.

**Intro:** 本論文關注學術會議審稿過程中，評審者可能透過協同投標（collusive bidding）來獲取互惠分配優勢的問題。過去研究多將投標、評審分配與審稿操控視為獨立階段，缺乏對協同投標整個生命週期影響的全面分析。現實中協同意圖通常不可觀察，且缺乏同一會議的反事實資料，使得真實場景分析更為困難。為此，作者提出一套模擬框架以彌補此研究空白。

**Motivation:** 協同投標可能嚴重影響審稿公平性與學術評價的公正性，對會議品質與學術生態造成威脅。現有方法無法同時考量投標策略與分配機制的互動，且缺乏可控環境來驗證協同投標的實際效果。從工程與產品角度，理解協同投標的全流程影響，有助於設計更有效的檢測與防範機制，提升審稿系統的透明度與可信度。

**Method:** 作者提出CABAL，一個端到端多代理模擬框架，利用大型語言模型驅動的評審代理，分別配置誠實或協同投標策略，並在固定的會議環境中模擬審稿流程。核心方法包括一種基於評審與論文相似度的親和力引導協同投標策略，透過構建協同圈並選擇目標論文，實現專業一致性而非隨機攻擊。此方法使得模擬更貼近真實情境，並能量化協同投標對分配與評分的影響。

**Result:** 實驗結果顯示，協同投標策略使目標論文被分配的機率增加超過兩倍，且協同評審對目標論文的評分平均比誠實評審高約兩分。整體會議層面的影響則相對有限。此外，針對投標階段的檢測器評估發現，現有方法難以有效區分協同投標與正常的親和力關係，僅在特定高強度投標視角下能精確但覆蓋率低地識別部分協同行為。

**Conclusion:** 本論文提出的CABAL框架為研究協同投標提供了一個可控且可驗證的模擬環境，揭示了協同投標對審稿分配與評分的具體影響，並評估了現有檢測方法的局限性。此研究對學術會議審稿系統設計與防範策略制定具有實務參考價值，但全文未明確說明在更大規模或多樣化會議環境下的適用性與效能。

**Research Gap:** 全文未明確說明模擬框架在不同會議規模、領域多樣性及評審行為複雜度下的泛化能力。實驗中協同策略與誠實策略的設定細節不足，缺乏對多種協同攻擊模式的比較與消融分析。檢測方法評估僅限於固定三元組與高強度投標視角，未涵蓋其他可能的檢測技術或結合多階段資訊的效果。成本與部署風險未討論，實際應用於真實審稿系統的挑戰與限制尚不清楚。整體而言，該研究雖提供重要模擬工具，但仍需更全面的實驗與方法驗證以支持實務落地。

### 5. First Things First: Teaching LLM-Based Agents to Prioritize Must-Haves before Nice-to-Haves

- 分數：5
- arXiv: [2609.05224v1](http://arxiv.org/abs/2609.05224v1)
- 發表日期：2026-09-04
- 分類：cs.CV
- 入選理由：+3 提及頂級會議：emnlp; +2 提及程式碼可用; LLM rank #5 / 7/10: Introduces a novel KST-based framework to evaluate LLMs' knowledge structure in math reasoning, revealing fundamental structural deficiencies invisible to accuracy metrics, with implications for future model design.

**Intro:** 多模態大型語言模型（MLLMs）在自動化代理任務上展現出強大潛力，但在處理用戶複雜且結構化的需求時，仍存在明顯不足。這類需求通常包含必須滿足的條件（must-have）與可選優先條件（nice-to-have），如何正確區分並優先處理這些需求是實務應用中的挑戰。本文針對三種需求場景進行探討，包括唯一解決方案、多解決方案排序以及無解決方案時的拒絕回答。研究基於真實服務場景設計了3,649個問題，涵蓋電商、訂票及地圖叫車等領域。實驗發現現有頂尖MLLM在這些場景中表現不佳，常常誤解需求或產生無效解答。

**Motivation:** 在工程與產品層面，代理系統若無法正確區分並優先處理必須條件，將導致用戶體驗大幅下降，甚至產生錯誤決策。現有模型在多優先級需求推理上缺乏有效機制，限制了其在複雜任務中的實用性與可靠性。提升模型對多層次需求的理解與推理能力，對於實際部署自動化服務代理、提升任務成功率及降低錯誤風險具有重要意義。本文提出的方法旨在填補此一關鍵空白，促進MLLM在真實應用場景中的落地與擴展。

**Method:** 本文提出First Things First Reinforcement Learning（FTF-rl）方法，透過強化學習明確優化模型對多優先級用戶需求的推理能力。核心流程包括先識別並嚴格滿足必須條件，再根據可選條件進行排序與優化。此方法強調分層處理需求，避免模型忽略或違反必須條件。訓練過程中，利用設計的獎勵機制引導模型學習正確的優先級判斷與決策策略。該方法不僅針對多模態任務設計，也在邏輯與數學推理任務中驗證其泛化能力。
