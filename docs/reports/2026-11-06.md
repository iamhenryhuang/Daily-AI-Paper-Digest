### 1. Towards Foundation Decision Models: Drex

- 分數：5
- arXiv: [2611.07854v1](http://arxiv.org/abs/2611.07854v1)
- 發表日期：2026-11-05
- 分類：cs.CL
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #1 / 9/10: Presents a novel family of open-source decision models addressing key production issues of LLMs with strong empirical evidence and state-of-the-art results, balancing novelty, practical usefulness, and credible evaluatio

**Intro:** 本論文聚焦於決策模型（decision models），這類模型在給定問題及選項集合時，直接輸出選項的機率分布，避免了傳統自回歸生成模型在生產環境中面臨的不一致性、解析輸出困難及延遲成本等問題。作者提出Drex系列四款開源決策模型，涵蓋不同規模與架構，並特別介紹27B參數的Drex Max，該模型結合多模態輸入與非因果注意力機制，旨在提升決策準確度與穩定性。全文詳細探討模型架構、訓練流程與多項評估指標，並與現有決策模型及大型聊天模型進行比較。

**Motivation:** 自回歸大型語言模型雖然在多任務上達到高準確度，但在實際產品部署中存在輸出不穩定、需額外解析及高延遲等挑戰，限制其應用。決策模型透過直接輸出選項機率分布，能有效降低推理成本與延遲，並提升輸出一致性。對AI從業者而言，開發高效且可校準的決策模型，有助於在多樣化任務中快速且穩定地做出判斷，尤其適合需要即時回應且選項動態變化的場景，如客服、推薦系統及多模態決策應用。

**Method:** Drex系列包含四款模型，三款採用pointer架構，將上下文編碼一次並共享於多問題，透過query-key機制計算選項分數，支援多達255個選項且無自回歸解碼。Drex Max則採用27B參數的dense多模態模型，移除部分層的因果遮罩，對每個問題重新編碼上下文，並以readout head輸出選項機率，支援圖像輸入。訓練流程分三階段：監督微調（SFT）結合一致性正則化以提升選項排序穩定性；調整回饋強化學習（RLAF）利用教師模型分布與驗證標籤調整目標分布，提升準確度與校準；最後對Drex Max進行視覺調整微調以整合圖像資訊。模型輸出經溫度調整以優化校準效果。

**Result:** 在Decision Index 0.4.1公開子集上，Drex Max達到67.52分，超越其他Drex模型及Jev 1.14.0，且在私有測試集及新領域測試中優勢更明顯。Decision Bench v4中，Drex Max在提供圖像輸入時整體準確率達94.0%，與GPT-6 Sol及d3-turbo相當，僅略低於Claude Opus 5.5，且推理延遲顯著低於大型聊天模型。校準評估顯示Drex Max在部署溫度下稍微過度自信，經任務特定溫度調整後校準誤差顯著降低。選項排序敏感度測試中，Drex Max在隨機排列選項時僅有4.3%決策結果改變，且改變多集中於低信心決策。訓練階段分析指出RLAF顯著提升準確度與校準，一致性正則化降低選項排序敏感度。多模態能力使Drex Max在圖像相關任務表現大幅優於文字描述版本。

**Conclusion:** 本研究成功開發一套高效且開源的決策模型家族，特別是Drex Max，在多項公開及私有決策基準中展現領先性能，且推理速度快、輸出穩定且具校準能力。透過結合監督微調、一致性正則化及調整回饋強化學習，模型在準確度與穩定性間取得良好平衡。多模態設計使其能處理圖像與文本混合輸入，擴展應用範圍。限制方面，Drex Max在閉卷知識任務上仍落後於頂尖聊天模型，且選項排序敏感度及校準在特定領域與選項數量上仍有提升空間。未來需進一步拆解架構與訓練因素對性能的貢獻，並探索融合推理鏈與工具調用以縮小與聊天模型的知識差距。

**Research Gap:** 本論文雖展示Drex Max在多項決策任務的優異表現，但仍存在幾項不足。首先，模型在閉卷知識密集型任務上表現明顯落後於大型聊天模型，且未實驗結合推理鏈或工具調用的可能性。其次，選項排序敏感度測試樣本有限且排除結構化選項，尚需更大規模與多樣化的測試以驗證穩定性。再者，Drex Max結合多種架構與訓練策略，缺乏嚴謹的消融實驗以明確量化各組件貢獻。此外，校準效果在不同領域及選項數量間差異顯著，單一溫度調整不足以普遍適用，需針對特定應用場景進行調整。最後，推理成本與部署風險在長上下文及多問題場景下仍需評估，尤其Drex Max無法共享上下文編碼，可能限制大規模應用。

### 2. The Intrusion Pathway: How Non-Evidential Context Degrades Language Model Performance

- 分數：5
- arXiv: [2611.07778v1](http://arxiv.org/abs/2611.07778v1)
- 發表日期：2026-11-05
- 分類：cs.AI
- 入選理由：+3 提及頂級會議：acl; +2 提及程式碼可用; LLM rank #2 / 8/10: Provides a mechanistic explanation for LLM performance degradation due to non-evidential context with detailed analysis and actionable interventions, supported by code and strong empirical validation.

**Intro:** 本論文探討語言模型在輸入提示中包含非證據性上下文（irrelevant context）時，準確度下降的現象。這類上下文指的是與查詢無關的陳述或隨機分布外的詞彙，既不提供競爭答案，也無語義重疊。此問題在檢索增強、工具使用及長上下文應用中普遍存在，但其內在機制尚未被充分理解。作者提出了名為「Intrusion Pathway」的機制，揭示非證據性上下文如何通過多層感知機（MLP）和注意力頭影響模型的最終預測。研究聚焦於定位造成干擾的注意力頭，並提出可行的干預方法以減少此類干擾。

**Motivation:** 在實際工程與產品部署中，語言模型常需處理來自多源的混合上下文，其中包含大量無關或噪聲信息。這些非證據性上下文會降低模型對正確答案的支持，影響模型的可靠性與用戶體驗。理解這種干擾的機制，有助於設計更健壯的模型架構與推理流程，避免因無關信息導致性能下降。尤其在檢索增強生成、工具調用及多輪對話等場景，能有效區分有用與無用上下文，對提升系統穩定性與準確性至關重要。

**Method:** 作者首先將上下文劃分為五類：golden、counterfactual、related、irrelevant及random，並以多個7B規模的開放權重模型進行分析。通過對MLP層的主題與非主題詞彙表示豐富度的測量，發現非證據性上下文並未消除主題信息，但仍會干擾最終預測。接著，研究發現部分注意力頭（稱為intrusion heads）在讀取非證據性上下文時，會增加對干擾詞的寫入，同時減弱對正確答案的支持。作者設計了針對這些頭的注意力遮罩策略，阻斷它們對無關上下文的讀取，從而減少干擾。此外，提出了oracle級別的殘差替換方法，利用匹配的乾淨前向傳播結果修正最後一個token的殘差表示，達到更高的性能恢復。

**Result:** 在四個下游任務（包括GSM-DC、GSM-IC、HotpotQA及PubMedQA）中，固定遮罩約10個intrusion heads（約佔模型注意力頭的1%）可恢復約57%的因非證據性上下文引起的準確率下降。oracle殘差替換方法則平均恢復達97.6%，顯示干擾主要集中於這些局部計算狀態。實驗涵蓋多種模型與不同類型的干擾上下文，證明intrusion heads在任務間具有一定的穩定性與可遷移性。遮罩策略在保留有用上下文信息的同時，有效降低了無關信息的負面影響。

**Conclusion:** 本研究首次系統性揭示了非證據性上下文如何通過特定注意力頭干擾語言模型的答案支持，並提出了基於機制理解的針對性干預方法。該方法不需重新訓練模型，且在多任務、多模型上均展現良好效果，對提升檢索增強及長上下文應用的模型穩健性具有實際意義。限制方面，研究主要針對7B規模的解碼器模型，尚未驗證更大模型、混合專家架構或多模態系統的適用性。oracle方法雖效果顯著，但需匹配乾淨前向傳播，實際部署受限。未來需探索更高效的干預策略及更廣泛的應用場景。

**Research Gap:** 論文雖定位了intrusion heads並提出遮罩干預，但未充分探討該方法在更大規模模型、encoder-decoder架構或多模態模型中的泛化能力。實驗主要集中於英語及特定任務，缺乏多語言、多輪對話、代碼生成及更複雜數學推理場景的驗證。遮罩策略雖保留部分有用上下文，但未提供理論保證，且對遮罩頭數的選擇及其對性能的權衡缺乏深入分析。oracle殘差替換雖為性能上限提供參考，但實際部署成本高且不可行。全文未明確說明在對抗性或惡意輸入下的表現及失敗案例，這對安全性評估尤為重要。未來工作應補充這些方面的實證與理論支持。

### 3. Static Recovery Is Not Dynamic Stability: Dynamics-Aware Benchmarking of Protein Motif Scaffolding

- 分數：5
- arXiv: [2611.07723v1](http://arxiv.org/abs/2611.07723v1)
- 發表日期：2026-11-05
- 分類：cs.LG, q-bio.BM
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #3 / 8/10: Introduces a comprehensive benchmark and molecular dynamics evaluation framework for protein motif scaffolding, revealing important limitations of static benchmarks and advancing methodological rigor.

**Intro:** 蛋白質基序支架設計是生成模型能否在功能性重要殘基周圍構建可折疊蛋白質支架的關鍵任務。現有的基準多依賴靜態結構評估，忽略了蛋白質功能往往依賴於構象集合和動態轉換的事實。本文提出了BILBY框架，包含系統性擴展的BILBY-PRO基準和基於分子動力學的BILBY-MD評估，旨在同時考察靜態結構恢復與動態穩定性，從而更全面評估蛋白質基序支架生成模型的性能。

**Motivation:** 現有基準使用小規模手工挑選的基序集和靜態重折疊標準，無法反映蛋白質在生理條件下的動態行為，可能導致靜態成功不代表動態穩定。此問題對於催化和結合位點等功能性基序尤為重要。且小規模基準限制了對模型性能的全面評估。為此，作者提出更大規模且系統性衍生的基準集BILBY-PRO，並引入基於全原子分子動力學的BILBY-MD框架，補充靜態評估的不足。

**Method:** BILBY-PRO基準從PROSITE資料庫中系統性篩選結構保守的功能性基序，涵蓋220個案例，涵蓋多種構象狀態。六種先進的生成模型（包括RFDiffusion、Proteina、ESM3等）在此基準上進行靜態評估，使用MotifBench標準的重折疊與新穎性指標。BILBY-MD則採用顯式溶劑全原子分子動力學模擬，對靜態成功的設計進行200納秒模擬，並與實驗參考結構的1微秒模擬比較，評估基序和支架的RMSD漂移、接觸保持及基序二面角自由能面相似性，從多層面驗證動態穩定性。

**Result:** 靜態評估顯示RFDiffusion和Proteina在目標覆蓋率上表現較好，ESM3則在成功目標上產生更多獨特解。分子動力學評估中，55個靜態成功案例中僅31個（56.4%）通過動態支持標準，且只有8個（14.5%）通過所有檢查。結果表明靜態重折疊成功主要反映局部基序恢復，但不保證整體支架的動態穩定。緊湊且自包含的基序較易維持動態穩定，而界面或依賴上下文的基序則較易失穩。不同模型在局部接觸保持和支架穩定性上表現不一，揭示靜態與動態評估的互補性。

**Conclusion:** 本文提出的BILBY框架通過擴展基準規模和引入動態評估，揭示了蛋白質基序支架生成模型在靜態結構恢復與動態穩定性上的差異。靜態評估適合大規模篩選，動態評估則為設計提供必要的物理驗證。三個評估軸（目標覆蓋率、獨特解產出、動態穩定性）應被視為互補指標，避免將性能簡化為單一分數。此工作強調動態穩定性在功能性蛋白質設計中的重要性，並提供可用的基準和工具促進後續研究。

**Research Gap:** 本文的動態評估基於200納秒模擬，可能無法捕捉更慢的結構不穩定性，且參考結構模擬時間較長，存在比較不對稱。靜態成功的判定依賴ProteinMPNN+ESMFold管線，該管線可能存在預測偏差，未能完全獨立驗證設計的物理合理性。BILBY-PRO基準受限於PROSITE的序列模式，偏向連續或近連續基序，對多段不連續功能位點覆蓋有限。生成模型的預訓練數據未完全公開，可能與基準存在重疊，影響泛化評估。缺乏對失敗案例的深入分析及成本和部署風險評估，限制了對實際應用場景的指導價值。未明確探討如何將動態評估整合入設計流程以提升效率。

### 4. Axis-LoRA: Probing and Adapting Embedding Models for Personal-Memory Retrieval

- 分數：5
- arXiv: [2611.07820v1](http://arxiv.org/abs/2611.07820v1)
- 發表日期：2026-11-05
- 分類：cs.CL, cs.AI
- 入選理由：+3 提及頂級會議：emnlp; +2 提及程式碼可用; LLM rank #4 / 7/10: Proposes a novel adapter method (Axis-LoRA) to improve personal-memory retrieval by disentangling key axes in embeddings, with clear empirical gains and open code, addressing a practical problem.

**Intro:** 隨著大型語言模型越來越多被用於回答使用者個人經驗相關的問題，個人記憶檢索需要能夠區分時間、地點、人物和事件這四個軸向。然而，目前的個人記憶檢索流程多依賴凍結的密集嵌入模型，這些模型無法有效捕捉這四個軸的資訊。本文針對這個問題提出了新的觀察與方法，並在多個個人記憶檢索基準上進行評估。

**Motivation:** 個人記憶檢索與一般開放領域檢索不同，因為記憶本身自然帶有時間、空間、人物和事件等分類軸。現有的嵌入模型主要優化主題和內容重疊，導致對這些軸向屬性的辨識能力不足。這會使得檢索系統無法根據軸向訊息正確排序相關記憶，影響下游個人化問答的品質。本文透過分析發現軸向訊息在模型內部的注意力頭中有特定分布，啟發了針對軸向的模型內部調整方法。

**Method:** 本文提出Axis-LoRA，一種在凍結嵌入模型內部插入四個針對時間、空間、人物、事件軸的LoRA分支的適配器架構。每個軸有獨立的LoRA分支，並透過一個基於查詢的稀疏門控機制決定各軸的加權比例。訓練時使用合成的軸向反事實三元組資料集AxisCF，並結合對一般檢索能力的知識蒸餾正則化，確保模型在非軸向文本上的穩定性。LoRA只調整模型最後20%層的注意力投影參數，參數量小且訓練高效。

**Result:** 在三個標準個人記憶檢索基準LongMemEval、ATM-Bench和LoCoMo上，Axis-LoRA在三種不同架構的嵌入模型（MiniLM-L6-v2、bge-base-en-v1.5、Qwen3-Embedding-0.6B）均帶來平均1.28至1.56個百分點的R@10提升。尤其在ATM-Bench的多證據Hard分割上，提升達2.4至3.8個百分點。此外，Axis-LoRA在通用檢索任務MTEB BEIR-6子集上保持了基本檢索性能，顯示不會損害模型的通用能力。消融實驗證明軸向反事實資料、知識蒸餾錨定和稀疏門控均為關鍵組件。

**Conclusion:** 本文揭示了現有凍結密集嵌入模型對個人記憶四大軸向訊息的軸向不對稱弱暴露問題，並定位訊息存在於模型內部特定注意力頭。基於此，提出Axis-LoRA透過四個軸向LoRA分支和查詢門控，有效提升個人記憶檢索性能。該方法輕量且資料需求低，適用於多種嵌入模型。限制包括軸向定義依賴於特定標註架構，合成資料未涵蓋隱含軸向訊息，且方法尚未驗證於用戶個人化快速適配場景。

**Research Gap:** 本文的軸向反事實資料集主要針對明確標註的軸向值進行編輯，對隱含或模糊的軸向訊息（如相對時間表達、多重實體糾纏事件）覆蓋不足，可能限制方法泛化。Axis-LoRA的門控與LoRA結構較為簡單，尚未探索更複雜的混合專家路由或內部軸向監督信號。實驗中主要聚焦於三個基準和三種模型，缺乏更大規模或多語言、多模態場景的驗證。方法雖輕量，但部署成本與實時查詢效率未明確討論。最後，對於單用戶快速個人化適配的能力與挑戰，全文未明確說明，仍需後續研究補充。

**Motivation:** 隱藏內部結構對於物理模擬、機器人操作及無損檢測等應用至關重要，但現有3D重建多聚焦於可見表面，無法捕捉內部空洞。碰撞動態提供了間接訊息，但密度基方法因無法有效利用空洞區域的梯度，常陷入錯誤局部最小值。為提升工程與產品中對物體內部結構的理解與預測能力，亟需一種能有效推理並優化隱藏結構假設的框架。

**Method:** 作者提出一個兩階段架構：第一階段為全局假設優化，定義結構假設空間，包含空洞形狀、位置、大小與方向等參數，透過無梯度的前向材料點方法(MPM)模擬評估假設與觀察的匹配度，使用粗到細的枚舉策略尋找最佳假設。第二階段為局部拉格朗日粒子優化，利用可微分MPM模擬，對選定假設進行粒子位置的細節調整，並加入排斥與體積保持正則化以維持結構合理性。此方法避免了密度基局部更新的模糊性，將結構推理與幾何細化分離。
