### 1. Module-Aware Optimization for Graph Neural Networks

- 分數：7
- arXiv: [2611.08379v1](http://arxiv.org/abs/2611.08379v1)
- 發表日期：2026-11-05
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #1 / 9/10: Introduces a novel graph-aware optimizer (GraphMuon) with strong theoretical grounding and significant empirical speedups on large-scale benchmarks, supported by code release.

**Intro:** 本論文探討圖神經網絡（GNN）中優化器設計的問題，指出現有優化器如AdamW和Muon未充分考慮圖結構對權重矩陣更新的影響。GNN的權重矩陣作用於經過圖傳播的特徵表示，其更新效果受圖結構調控，導致傳統基於參數空間的更新尺度無法準確反映對層輸出的實際影響。為此，作者提出GraphMuon，一種結合圖結構信息的矩陣感知優化器，旨在更合理地度量和調整更新步長。此問題對於提升GNN訓練效率和穩定性具有重要意義。

**Motivation:** GNN的權重矩陣更新不僅受參數本身形狀影響，更受圖傳播特徵的協方差結構影響，導致相同參數空間尺度的更新在表示空間中可能被放大或衰減。現有優化器如AdamW採用坐標軸獨立的更新，Muon雖考慮矩陣結構但忽略圖傳播特徵的幾何，無法避免圖誘導的更新放大問題。這種不匹配會影響優化效率與收斂速度，尤其在大規模圖數據和多樣GNN架構中更為明顯。解決此問題有助於提升GNN在工程和產品中的訓練速度與性能穩定性。

**Method:** GraphMuon基於Muon優化器，將更新方向和步長調整為圖感知形式。首先，定義圖誘導的特徵協方差矩陣Cg，利用其特徵分解構造一種圖度量，並在該度量下對動量更新進行極分解正交化，稱為圖感知正交化。其次，根據更新在圖傳播特徵空間中引起的實際擾動大小，對步長進行歸一化，確保更新在表示空間的影響被嚴格控制。理論證明GraphMuon能有效抑制Muon中存在的圖誘導更新放大現象，並且圖感知正交化是Muon極分解的自然推廣。實驗中，GraphMuon在多種GNN架構和任務上均顯示出優越的收斂速度和競爭力的預測性能。

**Result:** 作者在15組不同資料集與GNN架構配置上進行評估，涵蓋節點分類、歸納式圖分類及圖回歸任務。GraphMuon在13組配置中以較AdamW更快達到固定驗證損失目標，壁鐘時間加速幅度介於1.32倍至2.42倍。與Muon和其他基線比較，GraphMuon在控制表示層擾動和優化效率方面均有顯著提升。消融實驗顯示圖感知正交化與步長歸一化兩者均對性能提升有貢獻。理論分析與實驗結果一致，證實GraphMuon能有效調節圖誘導的更新幾何，提升GNN訓練效率。

**Conclusion:** 本論文提出GraphMuon，針對GNN特有的圖傳播特徵結構，設計了一種圖感知的矩陣優化器，通過圖誘導的協方差度量調整更新方向與步長，克服了傳統優化器在表示空間更新放大問題上的不足。實驗結果證明GraphMuon在多種大型圖數據集和GNN架構下均能加速收斂且保持或提升預測性能。限制方面，GraphMuon在小型圖或圖協方差矩陣不穩定時效果有限，因為協方差估計不準確可能導致優化效果下降。未來可考慮根據協方差的有效秩或穩定性動態調節圖感知強度，以適應不同圖規模和特性。

**Research Gap:** 論文未充分探討GraphMuon在極小型圖或高噪聲圖數據上的表現，該場景下協方差矩陣估計不穩定可能影響優化效果。實驗中雖涵蓋多種任務與架構，但對於異構圖或更複雜圖結構的適用性未明確說明。消融分析主要集中在兩個核心組件，對比其他先進圖優化方法如自然梯度的深入比較不足。成本與部署風險方面，GraphMuon涉及特徵協方差的特徵分解，對大規模高維圖可能帶來計算負擔，全文未詳細評估實際部署的效率與資源需求。此外，泛化能力及失敗案例分析較少，缺乏對不同圖結構變化下優化穩定性的系統性研究。

### 2. DART: Domain-Agnostic Residual Transfer for Generalist Anomaly Detection

- 分數：7
- arXiv: [2611.08271v1](http://arxiv.org/abs/2611.08271v1)
- 發表日期：2026-11-05
- 分類：cs.CV, cs.AI, cs.LG
- 入選理由：+2 提及頂級機構：meta, mit; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #2 / 8/10: Proposes a novel residual disentanglement framework (DART) for generalist anomaly detection with clear improvements on multiple datasets and strong methodological credibility.

**Intro:** 本論文聚焦於Generalist Anomaly Detection（GAD），即在未見過的領域中，利用少量參考樣本來偵測異常。現有方法多依賴正常與異常參考樣本的殘差特徵，但這些殘差往往混合了異常訊息與領域特定的外觀因素，如材質、幾何形狀及拍攝條件，導致跨領域轉移效果不佳。作者提出DART框架，旨在分離殘差中的異常相關成分與領域特定成分，以提升跨領域異常偵測的泛化能力。

**Motivation:** 異常偵測在工業檢測、醫療診斷及安全監控等場景中極為重要，但傳統方法需針對每個領域訓練獨立模型，面對新類別或標註不足時不具彈性。GAD試圖解決此問題，但殘差特徵的領域糾纏限制了模型在未見領域的表現。若殘差中包含過多領域特定訊息，將導致偵測誤報或漏報，尤其在領域差異大時更為明顯，因此如何有效分離異常與領域訊息成為關鍵挑戰。

**Method:** DART包含兩大核心組件：一是Residual Disentanglement Module（RDM），透過多頭自注意力的異常編碼器與輕量域編碼器，將殘差分解為異常相關成分與域特定成分，並利用重建損失確保資訊完整性，同時透過對抗訓練抑制域資訊；二是Cross-Domain Meta-Training（CDMT），在訓練時以跨域樣本組合形成任務，使模型學習忽略域特定訊息，強化異常成分的泛化能力。此框架可作為插件，插入於現有GAD方法的殘差計算與偵測頭之間，無需改動主體架構。

**Result:** 實驗涵蓋MVTec AD、VisA及BraTS三大資料集，並在多種基線方法（NAGL、InCTRL、ResAD）上測試。結果顯示DART在影像層級AUROC指標上持續優於基線，尤其在領域差異較大（如工業到醫療轉移）及低樣本設定下提升更為顯著，最高提升達13.28%。像素層級定位性能亦維持或略有提升，證明分離殘差不犧牲定位能力。消融實驗確認所有損失項及CDMT策略均為性能提升關鍵，且在殘差空間進行分離優於直接在特徵空間操作。

**Conclusion:** 本論文提出DART，有效解決了normal-abnormal guided GAD中殘差域糾纏的瓶頸，提升跨域異常偵測性能。其架構通用且易於整合於現有方法，實驗證明在多種資料集和基線上均有穩定增益，且增益隨領域差異擴大而加劇。限制方面，DART假設測試時至少有一張異常參考影像，對於零樣本部署尚不適用，且目前僅驗證於影像資料，未涵蓋視訊或時間序列異常偵測。

**Research Gap:** 論文未明確探討DART在完全無異常參考的零樣本場景下的適用性，這限制了其在部分實際應用的泛用性。實驗中跨域訓練僅涵蓋有限的工業與醫療影像資料，尚缺乏更廣泛領域（如自然影像、視訊或多模態資料）的驗證。此外，雖有提及推理時額外計算負擔較小，但未詳細分析在資源受限環境或實時系統中的部署成本與效能。消融實驗雖充分，但對於不同基線方法的超參數敏感度及穩定性探討不足。最後，失敗案例與泛化失效情況未被充分揭示，對工程實務中風險評估仍有不足。

### 3. NPCBench: A Clinical Apprenticeship Benchmark for Multimodal Care-Pathway Reasoning in Nasopharyngeal Carcinoma

- 分數：6
- arXiv: [2611.08369v1](http://arxiv.org/abs/2611.08369v1)
- 發表日期：2026-11-05
- 分類：cs.AI
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +3 提及頂級會議：neurips; LLM rank #3 / 8/10: Presents a comprehensive, clinically relevant benchmark (NPCBench) for multimodal care-pathway reasoning with detailed evaluation revealing important gaps in current models.

**Intro:** 目前醫療領域的評測多集中於孤立的事實性問題、單一影像任務或靜態病例，這些方法無法充分評估模型是否能整合多專科知識與多模態證據，並追蹤患者在整個治療過程中的狀態變化。鼻咽癌（NPC）作為一種需結合病理、MRI及血液指標等多模態資料，並依據臨床指南進行分期與治療的疾病，提供了評估臨床決策連貫性與多階段推理的理想場景。本文提出NPCBench，一個模擬臨床專科醫師培訓過程的多模態臨床實習評測基準，涵蓋從指南知識、病例規劃、縱向回顧到完整治療路徑及開放式諮詢的多層次評估。此基準包含4777個組件與諮詢題目，以及100名患者的CarePath隊列，涵蓋417個診斷與治療任務，並以患者層級的決策正確性作為評價標準。

**Motivation:** 現有醫療AI評測多聚焦於靜態答題，無法反映臨床專家如何結合多模態影像、病理資料與臨床指南，並隨著患者狀態變化調整決策。臨床實習強調從基礎知識到縱向決策修正的能力培養，缺乏此類評測限制了模型在真實醫療場景的應用與信任建立。NPCBench旨在填補此空白，通過多階段、跨模態的評測框架，檢驗模型是否能在整個治療過程中保持證據依據與決策一致性，對工程與產品開發具有重要指導意義，尤其是在腫瘤學等需長期追蹤與多次決策的領域。

**Method:** NPCBench設計為六個漸進能力層級（L1至L6）及一個開放式諮詢評估（O1），涵蓋指南記憶、原子級指南應用、多模態證據基礎、病例規劃、縱向決策修正及完整CarePath評估。資料來源包括CSCO與NCCN指南、多序列MRI、病理切片及真實患者電子病歷。每個層級的題目均由專科醫師審核，確保臨床有效性與證據充分。評測採用患者層級的嚴格正確性指標，要求診斷與治療決策在同一患者中均正確，並透過多模型對比、控制實驗及醫師校準的評分機制，深入分析模型在證據解讀與決策一致性上的表現。

**Result:** 評估涵蓋30個醫療及通用模型，21個多模態模型完成影像相關任務。結果顯示，雖然部分模型在指南記憶與原子應用層級達到超過90%的準確率，但在病例規劃層級準確率下降至約72%。影像分期任務中，最高T期與N期準確率分別約為43.5%與42.8%，但基於完整解剖結構的證據依據正確率不足5%，顯示模型常以不完整的視覺證據做出分期判斷。縱向決策修正中，最高模型Turn準確率達87.9%，但患者層級全程正確率顯著下降。CarePath評估中，最高Care決策正確率近90%，但嚴格患者層級成功率僅23%。諮詢任務中，最高模型仍有約15%的回答觸發重大錯誤標準，且自動評分與醫師判斷存在敏感度與特異度不平衡。整體結果揭示局部任務表現優異不代表整體臨床決策一致且正確。

**Conclusion:** NPCBench成功建立了一個涵蓋多模態證據整合與縱向臨床決策的評測框架，推動醫療AI評估從靜態答題轉向臨床實習式的流程評估。研究發現模型在證據依據與決策一致性方面仍存在顯著挑戰，尤其是在影像分期的解剖依據與患者全程決策正確性上。此基準為腫瘤學領域的AI模型開發與臨床落地提供了更嚴謹的測試平台，有助於推動更安全且符合臨床需求的醫療AI系統。限制包括資料主要來自單一中心，部分CarePath病例採用模型選擇的病理標籤，且評分對類別不平衡與病例長度敏感，未來需多中心、全模態匹配及前瞻性研究驗證。

**Research Gap:** 本文雖涵蓋多模態與縱向決策，但資料主要來自單一中心，可能限制模型泛化能力。CarePath中75例病理標籤為模型指定，可能引入偏差。評分指標對類別不平衡與決策數量敏感，影響結果穩定性。縱向決策修正雖有評估，但對錯誤來源與模型內部推理過程缺乏深入分析。諮詢評分依賴自動評分器與有限醫師校準，存在敏感度與特異度不均衡，可能影響安全性判斷。全文未明確說明模型在不同臨床子場景的失敗案例與部署成本，缺乏對實際臨床應用風險的全面評估。未來研究應擴展多中心資料、多模態同步收集，並加強模型解釋性與安全性評估。

### 4. GINGER: Spicing Up Graph-Based Vector Search

- 分數：4
- arXiv: [2611.08306v1](http://arxiv.org/abs/2611.08306v1)
- 發表日期：2026-11-05
- 分類：cs.IR, cs.DC
- 入選理由：+2 提及頂級機構：google, mit; +2 提及程式碼可用; LLM rank #4 / 7/10: State-of-the-art graph-based vector search library (GINGER) with novel compression techniques and significant speed and memory improvements, backed by strong engineering and code.

**Intro:** 本文提出了Ginger，一個由Google開發的開源C++圖形近似最近鄰搜索（ANNS）庫，專注於提升大規模高維嵌入資料集上的查詢速度與記憶體效率。隨著深度學習推動ANNS需求增加，尤其在高維度與大規模資料上，現有圖索引面臨記憶體頻寬、索引大小與建構時間的瓶頸。Ginger基於先前PiPNN圖構建與TurboQuant向量量化技術，並引入Nested TurboQuant（NTQ）兩層量化器，實現低精度導航與高精度重排序的單一編碼，顯著降低記憶體使用。本文同時提出AdaptiveGap無損壓縮編碼，壓縮圖結構大小，並在多個公開資料集上展示Ginger在查詢吞吐量、索引建構時間與記憶體佔用上的優勢。

**Motivation:** 現有圖形ANNS方法在高維度資料上雖有良好召回率，但查詢時記憶體頻寬限制、索引大小與建構時間仍是實務應用的主要瓶頸。尤其在工業場景中，如何在保持高召回的同時提升查詢速度與降低記憶體成本，是推動產品落地的關鍵。Ginger旨在解決這些問題，通過創新量化方法與圖壓縮技術，減少記憶體流量並加速查詢，同時縮短索引建構時間，提升整體系統效能與可擴展性，對於需要大規模向量檢索的工業與研究應用具有重要意義。

**Method:** 核心方法包含三大創新：首先，Nested TurboQuant（NTQ）將4位元TurboQuant碼作為導航碼，並在每個區間內細分2^k個子區間，形成(4+k)位元的碼，兼顧導航速度與重排序精度，且記憶體使用量降低約2.6倍。其次，設計了高效的SIMD向量化4位元碼評分內核，並利用PCA降維與TurboSlice預篩選減少查詢時的記憶體流量。最後，提出AdaptiveGap圖壓縮編碼，結合圖重排序（使用平衡多層次圖分割）將鄰居ID重新編號以減少差距，並以子位元寬度編碼鄰居差距，實現2.1倍以上的圖結構壓縮而不影響查詢速度。整體架構以PiPNN快速圖構建為基礎，並整合上述技術提升索引效能。

**Result:** 在14個公開資料集（涵蓋低維至高維，最大達10億向量）上，Ginger在95%召回率下平均查詢吞吐量較最快競爭者提升1.8倍，高維資料集提升達2.0倍，最大提升2.7倍。記憶體佔用方面，低維資料集因圖壓縮技術，Ginger索引大小平均比最緊湊競爭者小約54%，高維資料集因NTQ量化，索引大小約為原始向量的43%。索引建構時間方面，Ginger以PiPNN建構方式在11個資料集上最快，平均比競爭者快1.4倍，最大達4.9倍。消融實驗顯示，4位元TurboQuant導航碼帶來最大速度提升，PCA降維與TurboSlice預篩選亦有顯著加速效果。NTQ在12位元時重排序精度接近浮點數，優於其他量化方案。AdaptiveGap結合圖重排序在壓縮率與查詢速度間取得良好平衡。

**Conclusion:** Ginger展示了圖形基近似最近鄰搜索在查詢速度、記憶體效率與索引建構時間上的顯著提升，證明透過量化與圖壓縮的協同設計可突破現有瓶頸。NTQ兩層量化碼有效整合導航與重排序需求，AdaptiveGap壓縮技術則大幅減少圖結構記憶體佔用。PiPNN快速建構方法補足整體系統的實務可用性。Ginger的模組化設計與SIMD優化使其易於整合至多種檢索系統，對工業與研究界均具實用價值。全文未明確說明在極端低資源環境或非歐氏距離下的表現，且對於動態更新場景的支持細節有限。

**Research Gap:** 本文主要聚焦於靜態大規模向量資料的高效檢索，對於動態資料更新（如向量插入、刪除）與實時索引維護的效能與策略未充分探討。NTQ量化雖提升精度與效率，但在不同資料分布或非高斯假設下的泛化能力未明確驗證。圖壓縮與重排序方法雖有效減少記憶體，但對於極端稀疏或高度非均勻圖結構的適用性與查詢延遲影響尚未深入分析。實驗中PCA降維與預篩選策略在多任務、多相似度函數下的穩健性與調參敏感度亦未充分呈現。最後，全文未明確說明Ginger在分散式或多機環境下的擴展性與部署風險，這對工業落地尤為重要。

### 5. RM-VLM: From Natural-Language Task Descriptions to Vision-Grounded Reward Machines

- 分數：5
- arXiv: [2611.08308v1](http://arxiv.org/abs/2611.08308v1)
- 發表日期：2026-11-05
- 分類：cs.AI, cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #5 / 7/10: Large-scale benchmark (LeanContext) for theorem proving with detailed analysis of context disentanglement and improvements in proof generation, supported by code.

**Intro:** 本論文聚焦於強化學習中非馬可夫性任務的獎勵設計問題。傳統的Reward Machines（RM）能夠將獎勵函數表示為自動機，揭示任務的時間結構，並將非馬可夫獎勵轉化為馬可夫框架處理。然而，RM依賴於手工設計的標記函數，限制了其在圖像或真實環境中的應用。作者提出RM-VLM方法，利用大型語言模型（LLM）從自然語言任務描述生成RM，並用視覺語言模型（VLM）作為標記函數，將RM的命題基於圖像觀察進行視覺對應，進而指導策略學習。

**Motivation:** 非馬可夫任務中，獎勵依賴於歷史狀態，標準強化學習難以有效處理。RM能結構化地捕捉任務的時間依賴，但手工設計的標記函數限制了RM的普適性。視覺語言模型提供了從圖像中自動標記的可能，但直接用VLM評估整體任務進展存在偏差和噪聲問題。結合RM的結構化記憶與VLM的視覺理解能力，有望實現從自然語言描述到視覺感知的獎勵機制，提升非馬可夫任務的學習效率與泛化能力。

**Method:** RM-VLM首先利用LLM從自然語言任務描述生成一組共享的原子命題，並基於這些命題構建Reward Machine。接著，VLM作為帶噪聲的標記函數，對圖像觀察進行命題判定。為了應對VLM標記的不確定性，方法引入RM狀態信念分布，通過結合RM結構和狀態依賴的標記先驗，利用轉移-發射矩陣進行貝葉斯更新，穩健追蹤RM狀態。獎勵信號由RM狀態信念的期望累積獎勵變化計算，並輔以基於Generative Value Learning的密集獎勵，估計向下一RM轉移的進度，促進策略學習。方法支持離線和在線強化學習，後者通過將VLM標記蒸餾為分類器以降低計算成本。

**Result:** 在三個不同領域（GeoGrid網格導航、OGBench-Scene機器人操作、MiniWorld-Pickup 3D物件收集）上，RM-VLM均顯著優於基於VLM的非RM獎勵基線。離線實驗中，RM-VLM在所有任務中達到更高成功率，尤其在複雜的非馬可夫任務中表現突出。在線實驗中，RM-VLM與假設有完美標記函數的GCR方法表現相當，證明VLM標記與RM狀態信念結合的有效性。消融實驗顯示，RM狀態信念機制在標記噪聲較大環境中顯著提升性能，RM結構化獎勵信號加速收斂，而Generative Value Learning的密集獎勵則在部分任務中提升早期學習速度。LLM生成的命題與RM結構在多數情況下與人工設計相符，支持方法的自動化特性。

**Conclusion:** 本論文提出RM-VLM，成功將自然語言任務描述轉換為視覺對應的Reward Machines，實現了無需手工標記函數的非馬可夫任務強化學習。方法結合LLM的語言理解與VLM的視覺感知，並通過RM狀態信念機制緩解標記噪聲，提升了策略學習的穩健性和效率。實驗覆蓋多種環境與任務，證明RM-VLM在複雜時序任務中的優越性。限制包括VLM標記準確度依賴於命題的視覺明確性，RM表達能力受限於正則語言，且需估計標記函數的真偽陽性率。未來工作將探索層次化RM及跨任務泛化策略。

**Research Gap:** 本研究雖然在多環境驗證了RM-VLM的有效性，但仍存在若干不足。首先，VLM標記的準確度對性能影響顯著，尤其在視覺模糊或複雜場景中，標記錯誤仍會限制策略表現，且估計真偽陽性率依賴少量標註數據，降低了完全無監督的可能性。其次，RM的表達能力限於正則語言，無法捕捉如計數等更複雜的時序屬性，限制了任務範圍。第三，實驗中對於RM生成的錯誤處理及失敗案例分析較少，缺乏對生成RM結構錯誤對策略學習影響的深入探討。此外，方法在更大規模或更高維度視覺環境中的計算成本與實時性未明確評估。最後，雖有離線與在線實驗，但跨任務泛化能力及多任務訓練策略尚未充分驗證，這對實際產品部署與持續學習尤為重要。
