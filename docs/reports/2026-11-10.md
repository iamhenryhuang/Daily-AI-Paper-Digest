### 1. How to "train" a surgeon? Benchmarking generalist agents in surgical scene understanding

- 分數：7
- arXiv: [2611.11437v1](http://arxiv.org/abs/2611.11437v1)
- 發表日期：2026-11-08
- 分類：cs.CV, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #1 / 9/10: Introduces a novel, comprehensive benchmark and agentic environment for surgical scene understanding, addressing a critical real-world domain with clear evidence and open code, showing meaningful gaps and future directio

**Intro:** 本論文聚焦於評估通用多模態大型語言模型（MLLMs）在外科場景理解的能力。外科場景理解涉及視覺辨識、程序推理及專家級評估，對於實現外科超智能至關重要。然而，外科數據稀缺且分散，且現有評估協議不統一，限制了對模型能力的全面認識。作者提出一個兩階段評估框架，首先透過SURGKNOWBENCH統一多個公開外科資料集，診斷MLLMs的零樣本外科能力；接著透過SURGAGENTGYM，讓模型在推理時利用工具進行知識檢索與視覺定位，模擬類似外科訓練的知識獲取過程。

**Motivation:** 外科AI的發展受限於數據不足與模型能力不明，尤其是通用MLLM在外科領域的表現尚未被系統評估。傳統大規模監督訓練難以實施，且現有模型在關鍵的程序理解與工作流程評估上表現薄弱。人類外科訓練強調知識檢索與視覺對應，啟發作者設計一個可讓模型在推理階段主動搜尋並整合外部知識的環境，以期提升模型的外科理解能力，並為工程與產品落地提供可解釋且可追蹤的評估框架。

**Method:** 方法分為兩階段。第一階段，SURGKNOWBENCH整合11個公開外科資料集，涵蓋7種手術程序與7種任務類型，將標註統一為問答格式，評估17款專有及開源MLLM的零樣本能力，指標包括宏F1、準確率、Cohen’s κ等。第二階段，SURGAGENTGYM為一個代理環境，提供兩種工具：視覺定位工具（基於SAM 2自動遮罩生成）與知識檢索工具（檢索SURGWIKI多模態知識庫，包含教科書、臨床指南、教學影片與病例記錄）。代理模型可在有限次數內調用工具，模擬人類外科訓練中主動搜尋與視覺對應的過程，並以軌跡分析評估代理行為與推理過程。

**Result:** 第一階段結果顯示，MLLMs在工具辨識上有部分能力，但定位、關聯判斷及程序理解表現低落，尤其是三元組檢測與階段識別的準確率甚至不及基線。專有醫療模型未必優於通用模型。第二階段中，代理模型透過工具調用在工具辨識與動作識別任務上有顯著提升，但細粒度定位與專家評估任務仍是瓶頸。工具調用分析顯示，視覺工具多用於空間任務，知識檢索多用於程序與評估任務。代理失敗主要因查詢策略不佳、證據整合困難及視覺證據定位不足。整體而言，代理推理能部分彌補零樣本能力不足，但仍未達到實用水平。

**Conclusion:** 本研究系統性揭示了通用MLLM在外科場景理解的能力邊界，並提出一種結合視覺定位與知識檢索的代理推理框架，模擬外科訓練過程中的知識獲取與應用。結果表明，代理推理能提升部分視覺感知任務的表現，證明通用模型具備一定的元認知能力，但在程序理解與專家評估等高階任務仍有明顯不足。該框架為外科AI的工程落地提供了可解釋、可追蹤的評估工具，並指明未來提升代理元認知與證據整合能力的方向。

**Research Gap:** 本論文的不足包括：SURGKNOWBENCH僅涵蓋公開資料集，限制了手術種類、機構與視角的多樣性，可能影響泛化性；SURGWIKI知識庫雖經嚴格篩選，但仍受限於資料來源與授權，知識覆蓋不完整；代理模型在查詢策略與證據整合方面仍表現不佳，缺乏針對性訓練或自我演化機制；視覺定位工具對部分模型無效，顯示缺乏專門針對外科視覺特徵的工具支持；缺少對失敗案例的深入分析與成本、部署風險評估；此外，實驗中多數提升仍未達到實用標準，缺乏與臨床專家評估的直接對比，限制了臨床應用的說服力。全文未明確說明代理模型在多模態融合與長期推理能力上的改進策略。

### 2. MCSA: Multi-Cutoff Spectral Aggregation in SO(3) Equivariant GNNs for Interatomic Potentials

- 分數：5
- arXiv: [2611.11226v1](http://arxiv.org/abs/2611.11226v1)
- 發表日期：2026-11-08
- 分類：cs.LG, cs.AI
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #2 / 8/10: Proposes a principled, physically motivated method to improve SO(3)-equivariant GNNs for interatomic potentials with strong empirical validation and code release, advancing atomistic modeling.

**Intro:** 本論文聚焦於機器學習原子間勢能（MLIPs）中，基於SO(3)等變圖神經網路（EGNNs）在原子尺度建模的應用。現有EGNN架構普遍採用單一截斷半徑來限制消息傳遞範圍，導致無法充分捕捉不同空間尺度的原子交互作用。作者透過分析截斷半徑對徑向頻譜響應的影響，指出單一截斷半徑限制了模型對多尺度幾何特徵的表達能力。為此，提出一種多截斷半徑頻譜聚合（MCSA）模組，以豐富徑向表示並提升模型性能。

**Motivation:** 在工程與產品層面，準確且高效地模擬原子間作用力對材料設計與分子動力學模擬至關重要。單一截斷半徑限制了模型對短程與長程交互的同時捕捉，影響了能量、力及高階物理性質的預測精度。多尺度的幾何表徵能夠更好地反映實際物理系統中不同距離範圍的交互作用，進而提升模型泛化能力與模擬穩定性，對於實際部署及長期模擬具有直接意義。

**Method:** 核心方法為Multi-Cutoff Spectral Aggregation（MCSA），該模組將多個不同截斷半徑的徑向核函數加權疊加，形成多尺度的徑向頻譜響應。為避免多截斷半徑帶來的冗餘角度張量積計算，作者提出一種徑向融合策略，先將不同截斷半徑的徑向權重合併，再進行一次角度張量積操作，保證計算效率且維持SO(3)旋轉等變性。MCSA可作為即插即用模組，兼容多種SO(3)-等變GNN架構，且保留了徑向核的平滑可微性，支持能量與力的導數計算。

**Result:** 作者在多個代表性SO(3)-等變GNN骨幹網路（Nequix、Eqnorm、EquiformerV3）及多個資料集（MPtrj、Alexandria、PhononDB-103）上進行實驗。結果顯示，MCSA在能量、力與應力的預測上均有穩定提升，且在分佈外資料上同樣有效，顯示良好泛化能力。高階物理性質如聲子色散與晶格熱導率的預測精度亦顯著改善，且計算時間僅略增約3%。在層狀材料中，採用物理驅動的雙截斷半徑設計，MCSA在能量與力的預測上均優於單一截斷基線。此外，MCSA保持了勢能曲面平滑性與長期分子動力學模擬的穩定性。

**Conclusion:** 本論文提出的MCSA模組有效解決了單一截斷半徑限制多尺度徑向表示的問題，通過多截斷半徑頻譜疊加豐富了SO(3)-等變GNN的幾何表徵能力。實驗證明其在多種骨幹網路與物理性質預測任務中均有一致提升，且計算效率高，適合實際應用。MCSA的設計兼容性強，易於集成於現有架構，對提升原子尺度模擬的精度與穩定性具有實際價值。

**Research Gap:** 論文中雖展示多截斷半徑帶來的性能提升，但對於不同材料類型及更極端結構異質性的泛化能力尚未充分驗證。實驗主要聚焦於三個截斷半徑的配置，對截斷半徑數量與選擇的系統性優化及其對模型表現的影響仍缺乏深入分析。成本與效能的平衡在更大規模系統或實時模擬場景下的表現未明確說明。此外，對於多截斷半徑可能引入的潛在數值不穩定性或失效案例未有報告。最後，MCSA在注意力機制或非線性聚合層的適用性及限制亦未充分探討。

### 3. Spatial Harness: Grounding Spatial Reasoning in Executable World States with Physics Engines

- 分數：5
- arXiv: [2611.11344v1](http://arxiv.org/abs/2611.11344v1)
- 發表日期：2026-11-08
- 分類：cs.LG
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #3 / 8/10: Presents a novel framework for grounding spatial reasoning in explicit physics-engine states, significantly improving performance on multiple benchmarks with open code and strong empirical results.

**Intro:** 空間推理是理解場景中物體與觀察者的相對位置及其隨視角或移動改變的關係。現有的視覺語言模型（VLMs）多透過模型內部推理，從部分視角形成隱式場景解讀，並想像空間變換的結果，但這種方法容易因誤判場景或不符合空間約束的想像而導致錯誤答案。本文提出Spatial Harness，將場景表示為明確且可執行的世界狀態，並利用物理引擎提供反饋，藉此使空間推理更具可檢驗性與一致性。

**Motivation:** 空間推理任務中，模型需同時完成場景感知與空間變換推理，然而將兩者合併於模型內部使錯誤難以區分與修正。若能將場景表示為可執行的世界狀態，並在物理引擎中執行空間操作，則可確保推理結果符合空間約束，並使推理過程與結果可被檢查。這對工程與產品落地意義重大，因為它提升了空間推理的透明度與可靠性，降低了因誤判場景或錯誤變換導致的錯誤率。

**Method:** Spatial Harness包含兩大模組：Perceiver與Reasoner。Perceiver結合問題中提取的場景約束與專門的視覺估計，將物體與攝影機置於共享座標系中，形成明確的世界狀態（包含物體位置、朝向及攝影機姿態）。Reasoner將此狀態實例化於MuJoCo物理引擎，透過程式化操作控制視角變換、計算幾何量及渲染視圖，並根據引擎反饋逐步推理答案。此流程將感知與推理明確分離，推理結果基於物理引擎計算而非模型內部想像，確保空間關係的一致性。

**Result:** 在MindCube、SAT、MMSI-Bench及SpatialRGPT-Bench四個空間推理基準測試中，Spatial Harness均優於基線方法。以MindCube為例，使用Qwen3.5-27B模型時，Spatial Harness在無地圖標註的端到端設定中，整體準確率達71.14%，較基線提升18.44個百分點，且超越pySpatial 7.52個百分點。使用標註地圖時，Spatial Harness達98.25%準確率，較直接推理提升26.44個百分點。消融實驗顯示，Perceiver的視覺與文本通道均對性能有顯著貢獻，且Reasoner利用物理引擎提供的數值與渲染反饋能有效提升推理準確度。

**Conclusion:** 本文提出的Spatial Harness透過將空間推理基於可執行的世界狀態與物理引擎反饋，成功分離感知與推理兩步驟，提升了空間推理的準確性與可檢驗性。實驗證明此方法在多個空間推理基準上均取得優異表現，並且消融分析支持其設計合理性。此架構為多模態物理世界推理提供了一種可行且有效的基礎，對工程實踐與研究落地具有重要價值。

**Research Gap:** 本文的世界狀態僅描述靜態場景，無法處理時間維度的動態變化，限制了對物體運動或事件順序的推理能力。Perceiver估計的世界狀態仍存在覆蓋率不足（約72%）與部分幾何誤差，影響最終推理效果。Reasoner在部分模型（如Qwen2.5-VL-72B）中未能充分利用物理引擎反饋，顯示推理策略尚需優化。實驗中缺乏對失敗案例、成本與部署風險的深入分析，且對不同場景與更複雜空間關係的泛化能力未充分驗證。未來工作應聚焦於擴展時間維度、提升世界狀態估計精度及強化推理策略的適應性與穩健性。

### 4. When Credit Turns Against Tools: Transition-Aware Credit Assignment in Agentic Reinforcement Learning

- 分數：5
- arXiv: [2611.11330v1](http://arxiv.org/abs/2611.11330v1)
- 發表日期：2026-11-08
- 分類：cs.LG
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #4 / 7/10: Addresses a subtle credit assignment problem in agentic RL with a novel method that improves tool-use reliability and reasoning, supported by quantitative gains and code availability.

**Intro:** 本文探討在多回合工具互動的 agentic reinforcement learning (RL) 中，訓練過程中推理性能與工具呼叫能力下降的問題。作者指出這種性能退化源於三個相互關聯的機制：工具標記不平衡、聚合放大效應以及失敗驅動的重試行為。這些因素導致對工具呼叫的負面信用累積，進而抑制模型的有效學習。為解決此問題，提出一種 Transition-Aware Credit Assignment (TACA) 方法，專注於推理到工具使用的轉換階段，並通過多種策略調整信用分配。研究涵蓋多種模型與任務，並在多個基準測試中展現性能提升。

**Motivation:** 在 agentic RL 中，模型透過多回合工具互動來提升推理能力，但訓練過程中常見性能不穩定甚至退化，尤其是工具呼叫成功率下降。這對工程與產品落地極具挑戰，因為工具互動是提升模型實用性與可靠性的關鍵。現有方法如 MT-GRPO 將終端獎勵平均分配給整個軌跡，忽略了工具呼叫在不同軌跡中所承擔的不同責任，導致錯誤軌跡中工具呼叫反而被負面信用壓制。理解並改善這種信用分配不均，對於穩定訓練流程與提升模型在實際應用中的工具使用能力至關重要。

**Method:** TACA 方法包含三個核心組件：首先，Advantage Projection 透過對工具呼叫標記的優勢值進行均勻偏移，確保其平均優勢非負，避免負面信用抑制工具呼叫。其次，Decision Contrast 利用同一提示下工具使用與直接回答軌跡的獎勵差異，調整決策標記的優勢值，促使模型根據實際獎勵選擇是否使用工具。最後，Supervised Replay 將先前正確軌跡中的工具呼叫作為監督信號，持續強化工具呼叫生成能力。整體訓練目標結合這些調整後的優勢值與輔助監督損失，提升工具呼叫的可靠性與推理性能。

**Result:** 實驗涵蓋 Qwen2.5-1.5B、3B、7B 及 Llama-3.2-1B 等多種模型，任務包括數學推理、程式碼生成與互動決策。TACA 在六個推理基準上相較於 MT-GRPO 平均提升約 3.61 至 4.61 個百分點準確率，並在 TACO 程式碼測試集上將單元測試分數從 41.98 提升至 53.70，WebShop 互動任務成功率提升約 10%。訓練過程中，TACA 維持較高的工具使用率與執行成功率，避免了其他方法中工具使用率下降的問題。消融實驗證明三個組件均對性能提升有顯著貢獻，且效果跨模型大小與架構均具一致性。

**Conclusion:** 本文系統分析了 agentic RL 中工具呼叫信用分配導致的訓練退化問題，並提出 Transition-Aware Credit Assignment (TACA) 以針對推理與工具使用轉換階段進行信用調整。實驗結果顯示 TACA 不僅提升了多種模型的推理準確率，也穩定了工具呼叫的可靠性，促進了工具輔助推理的有效學習。該方法對於實際部署中需要穩定工具互動能力的系統具有重要價值。然而，全文未明確說明在更大規模模型或更複雜環境中的泛化能力與計算成本，且對失敗案例的分析較為有限。

**Research Gap:** 本文雖然針對工具呼叫的信用分配提出有效調整，但仍存在幾個不足。首先，實驗主要集中於特定數學、程式碼與互動任務，缺乏對更廣泛或更複雜場景的驗證，泛化性尚未充分證明。其次，方法依賴終端獎勵，對於中間步驟獎勵較少探討，可能限制對長序列決策的適用性。第三，失敗驅動的重試行為雖被分析，但對於失敗案例的具體處理策略與失敗原因分析不足，未明確揭示模型何時及為何仍會重複失敗。最後，TACA 的計算與存儲成本未詳述，實際部署時的效率與資源需求仍需評估。這些缺口提示未來工作可進一步擴展方法適用範圍、強化失敗案例分析與優化計算效率。

### 5. Decomposing Earth Embeddings with Sparse Autoencoders

- 分數：5
- arXiv: [2611.11398v1](http://arxiv.org/abs/2611.11398v1)
- 發表日期：2026-11-08
- 分類：cs.LG, cs.CV, physics.geo-ph
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #5 / 7/10: Introduces sparse autoencoders to decompose Earth observation embeddings into interpretable features with a tailored evaluation protocol and promising applications, backed by code and NeurIPS acceptance.

**Intro:** 地球觀測基礎模型能生成全球米級解析度的嵌入向量，支撐農業、生態學、水文學等多領域應用。然而，這些嵌入向量維度混合多種物理概念，導致解釋困難且難以評估其魯棒性。本文提出使用稀疏自編碼器（SAE）將地球嵌入分解為稀疏且近似單義的特徵，藉由過完備字典實現。為了克服衛星像素無法用大型語言模型判斷解釋的問題，並考慮空間自相關，作者設計了專門的評估協議。該協議從重建誤差、與參考概念的對齊度及空間尺度三方面評估SAE表現。

**Motivation:** 現有地球嵌入向量維度高度混合多種概念，造成解釋性差，且在分布轉移時下游模型易出錯。對工程與產品而言，缺乏可解釋的特徵會降低模型信任度與應用安全性。稀疏自編碼器能將嵌入向量映射到稀疏且更具語義專一性的特徵空間，有助於提升解釋性與下游模型的魯棒性。本文針對地球嵌入特有的空間結構與評估難題，提出專門的評估方法，對工程實踐有指導意義。

**Method:** 本文採用三種先進的稀疏自編碼器變體（ReLU+ℓ1、BatchTopK、Matryoshka BatchTopK），將AlphaEarth與Tessera兩種地球嵌入向量分解為過完備字典上的稀疏碼。稀疏碼維度遠大於原始嵌入維度，但每個像素僅激活少數特徵。訓練目標為最小化重建誤差，同時保持稀疏性。評估協議包含三個指標：在相同稀疏度下的重建誤差、特徵與地理參考概念的對齊度（使用AUROC衡量）、以及特徵的空間變化尺度。並以一個解碼器權重固定為隨機字典的SAE作為基線，區分稀疏性本身與字典學習的貢獻。

**Result:** 實驗結果顯示，三種SAE變體在AlphaEarth與Tessera嵌入上均優於PCA、ICA、NMF及固定隨機字典基線，在相同稀疏度下重建誤差更低。SAE特徵與原始維度相比，對齊的概念群組數明顯減少，約88%的特徵最多對齊一個概念群組，顯示更高的單義性。SAE特徵在空間尺度上變化更細緻，更多變異集中在640公尺範圍內。固定隨機字典SAE也呈現類似空間尺度特性，說明稀疏性驅動此現象，但只有訓練字典能有效重建嵌入。兩個應用示範中，SAE特徵能發現土地覆蓋的子概念，並在合成分布轉移場景下改善部分目標的異常檢測，但尚未達到實務可靠性。

**Conclusion:** 本文首次將稀疏自編碼器應用於地球像素級嵌入，提出專門評估協議並驗證其在重建、解釋性與空間尺度上的優勢。結果表明SAE能有效分解嵌入為近單義且具區域性的特徵，為地球觀測模型的可解釋性與下游應用魯棒性提供新途徑。雖然應用示範尚未成熟，但為科學發現與可信地理空間應用奠定基礎。未來需針對地理特性設計更適合的SAE架構，並探索自動解釋方法及時間序列與位置編碼的泛化能力。

**Research Gap:** 本文雖驗證SAE在兩種嵌入與三種變體上的效果，但缺乏對更多地球嵌入模型與不同解析度的測試，泛化性尚未充分證明。評估主要依賴靜態參考產品，對動態時序與概念漂移的適應性未明。應用層面，子概念發現與異常檢測尚未達實務可靠，缺乏真實場景下的驗證與失敗案例分析。此外，固定隨機字典基線表明稀疏性本身即帶來部分優勢，如何區分學習字典的實質貢獻仍需更嚴謹消融。成本與部署風險未討論，尤其在大規模全球資料上訓練與推理的效率問題。最後，空間自相關與地理異質性對特徵解釋的影響仍需深入探討。
