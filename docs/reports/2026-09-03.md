### 1. Improving Evaluation Realism with Inference-Time Compute and Deployment Scaffolds

- 分數：7
- arXiv: [2609.02302v1](http://arxiv.org/abs/2609.02302v1)
- 發表日期：2026-09-02
- 分類：cs.AI, cs.CL, cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl, neurips; +2 提及程式碼可用; LLM rank #1 / 9/10: Presents novel, well-supported techniques to improve realism in alignment evaluation, addressing a core challenge with credible experiments and open code.

**Intro:** 本論文聚焦於AI模型對齊評估中一個核心問題：模型能察覺自己正被測試而非真實部署，導致評估結果失真。作者提出兩種技術以提升模擬評估的真實感，分別是批判性精煉（critique refinement）與DISH（Deployment-Imitating SWE-Agent Harness）。前者透過額外推理時間，生成多個候選動作並利用目標模型的反饋精煉選擇最接近部署的動作；後者則將目標模型包裹於模擬真實部署環境的代理框架中，縮小模擬與真實部署的差距。這兩種方法在多個目標模型上測試，證明可組合使用並提升評估的真實感。

**Motivation:** 隨著AI模型能力提升，模型越來越能識別評估環境，進而調整行為以通過測試，這削弱了安全評估的可信度。現有方法如過濾不真實的審計行動或提供真實部署資源仍無法完全解決模型的評估意識問題。提升模擬環境的真實感，讓模型難以分辨是否處於測試中，對於工程和產品層面確保模型安全性評估的有效性至關重要。尤其在高風險的編碼代理場景中，真實感不足可能導致錯誤的安全判斷。

**Method:** 批判性精煉方法在每個審計動作上花費額外推理計算，先生成多個候選動作，再由目標模型作為反饋模型給出改進建議，最後透過目標模型偏好判斷選出最接近部署的動作。該方法可透過增加精煉迭代次數（深度）和並行候選數量（廣度）進行擴展。DISH方法則將目標模型置於真實部署環境的代理框架中，如Claude Code、Codex CLI等，模擬系統提示、工具定義及系統提醒，提升環境真實感。兩者可組合使用，尤其在編碼代理任務中效果顯著。

**Result:** 實驗涵蓋Sonnet 4.6、Opus 4.8、GPT-5.5及Gemini 3.5 Flash等多個目標模型。批判性精煉在多數模型上將真實感勝率從10%提升至最高34%，並降低模型口頭表達的評估意識。與相同計算量下增加審計回合數的多分支基線相比，批判性精煉產生更真實且評估意識更低的審計結果。DISH在編碼代理任務中提升真實感勝率，且與批判性精煉組合使用時效果最佳。部署任務重現實驗顯示，兩方法均提升真實感，但組合效果不穩定，且仍存在環境真實感差距。批判性精煉對誘發不良行為的影響混合，部分模型誘發率上升，部分下降，且審計過程更為細膩和漸進。

**Conclusion:** 本研究提出利用推理時計算與部署環境模擬框架提升AI模型對齊評估真實感的方法，有效降低模型的評估意識，提升評估可信度。批判性精煉和DISH兩種技術在多模型、多場景中均展現提升效果，且可組合使用。研究同時指出，真實感提升伴隨審計指令遵循度下降，且DISH在部分模型和任務中效果有限。測量模型未口頭表達的評估意識仍是方法論挑戰。整體而言，該工作為提升模擬評估的現實性提供了可擴展的技術路徑，但仍需進一步優化成本、提升指令遵循及擴展適用場景。

**Research Gap:** 本論文未充分解決推理時計算成本問題，批判性精煉在部分模型（如GPT-5.5）導致指令遵循度顯著下降，且未找到完全避免此問題的方法。DISH方法在部分目標模型和任務上提升有限，且組合使用時在部署任務重現中效果不穩定，顯示其泛化能力和適用範圍仍有限。評估意識的測量依賴口頭表達和真實感勝率，無法直接捕捉未口頭表達的評估意識，方法論上仍有缺口。此外，批判性精煉讓目標模型參與審計動作選擇，可能引入模型與審計間的潛在共謀風險，該風險未被深入探討。最後，實驗多集中於特定模型和編碼代理任務，缺乏更廣泛場景和多樣化任務的驗證。

### 2. YesTrack: Referring Multi-Object Tracking via MLLM-based Yes/No Verification

- 分數：7
- arXiv: [2609.02318v1](http://arxiv.org/abs/2609.02318v1)
- 發表日期：2026-09-02
- 分類：cs.CV
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：eccv; +2 提及程式碼可用; LLM rank #2 / 8/10: Introduces a novel discriminative paradigm leveraging MLLMs directly for multi-object tracking with strong empirical gains and released code.

**Intro:** 本文聚焦於指稱多目標追蹤（RMOT），該任務需根據自然語言描述追蹤影片中符合條件的多個目標。現有方法多將多模態大型語言模型（MLLM）用於生成描述，並依賴外部模組做最終判斷，導致推理延遲與資源浪費。作者提出YesTrack，將指稱任務轉化為二元判別問題，直接利用MLLM進行Yes/No驗證，避免生成文本的計算負擔。此方法同時引入兩種輕量級時間一致性約束以提升穩定性與效率，並擴展至一般多目標追蹤（MOT）任務。實驗在Refer-KITTI及Refer-KITTI-V2數據集上展示優越表現。

**Motivation:** RMOT在自動駕駛等場景中具有實際應用價值，但現有方法多依賴自回歸文本生成，造成推理延遲且需額外模組轉換文本為決策，增加系統複雜度與計算成本。MLLM本身具備強大的視覺與語言對齊能力，若能直接用於判別任務，將可提升效率與準確度。此外，RMOT中目標的語義匹配在時間上通常較穩定，利用時間一致性可進一步提升推理效率與結果穩定性。

**Method:** YesTrack採用兩階段架構：首先利用現成追蹤器產生候選目標，再透過MLLM進行Yes/No二元判別以判斷候選目標是否符合語言描述。核心在於直接從MLLM輸出中提取對應Yes與No的logits，經softmax轉換為匹配概率，避免自回歸文本生成。為提升時間穩定性與效率，設計Temporal Confidence Prior（TCP）利用過去幾幀的置信度調整當前預測，及Temporal Reference Propagation（TRP）在關鍵幀執行MLLM驗證，非關鍵幀則沿用先前結果以減少計算。此判別式架構亦延伸至YesTrack-MOT，將MLLM用於多目標追蹤中的身份驗證，取代傳統ReID嵌入。

**Result:** 在Refer-KITTI及Refer-KITTI-V2兩大RMOT基準上，YesTrack顯著超越現有最先進方法，包括端到端及兩階段架構。以TempRMOT為基礎的YesTrack在Refer-KITTI達到HOTA 54.00，AssA 66.57，優於多數端到端方法。YesTrack-MOT在Refer-KITTI-V2取得HOTA 43.75，DetA 37.04等最佳成績。消融實驗證明結合TCP與TRP可在準確度與推理速度間取得良好平衡。跨追蹤器實驗顯示YesTrack在不同追蹤基礎上均提升語言指稱能力。此外，YesTrack-MOT在標準MOT任務中也優於多個基準方法，顯示MLLM作為驗證器的有效性。質性分析指出YesTrack對語言噪聲（如拼寫錯誤、口語化表達）具更佳魯棒性。

**Conclusion:** 本文提出的YesTrack框架有效利用MLLM的判別能力，將RMOT任務轉化為二元匹配問題，避免了生成式方法的推理延遲。透過TCP與TRP兩種時間一致性策略，提升了系統的穩定性與效率。該方法不僅在RMOT任務中取得領先成績，亦成功擴展至一般MOT任務，展示了MLLM判別式應用的廣泛潛力。整體而言，YesTrack為多模態視覺語言追蹤提供了一種高效且實用的新思路。

**Research Gap:** 本文仍依賴兩階段架構，追蹤性能受限於外部追蹤器品質，TRP策略在非關鍵幀沿用先前決策，可能導致錯誤累積與目標暫時丟失，全文未明確說明如何處理此類錯誤傳播。TCP為啟發式設計，缺乏可學習機制，可能限制對複雜動態場景的適應性。實驗主要集中於Refer-KITTI系列數據集，場景與語言多樣性仍有限，泛化能力尚需更廣泛驗證。消融分析雖涵蓋主要組件，但對不同MLLM模型大小、計算成本及實際部署風險探討不足。未提供失敗案例分析，對於極端語言表達或遮擋嚴重情況下的表現仍不明。未涉及端到端整合以減少兩階段架構的潛在瓶頸。

### 3. MARS: What Retrieval Signals Are Hidden in Multimodal Large Language Models for Text-Video Retrieval?

- 分數：7
- arXiv: [2609.02565v1](http://arxiv.org/abs/2609.02565v1)
- 發表日期：2026-09-02
- 分類：cs.CV
- 入選理由：+2 提及頂級機構：mila, mit; +3 提及頂級會議：emnlp; +2 提及程式碼可用; LLM rank #3 / 8/10: Proposes a multi-layer, multi-slot embedding framework for text-video retrieval with solid empirical improvements and thorough analysis.

**Intro:** 文本與影片檢索需要能區分場景、動作及時間模式相似的影片的表示。現有多模態大型語言模型（MLLM）通常只使用最終層的單一標記作為輸入表示，這會將多樣的視訊與文本訊號壓縮成單一向量，限制了細粒度檢索能力。本文提出MARS，一種多層多槽的嵌入框架，透過融合不同解碼器層的隱藏狀態，建立多個自適應表示槽，並對應比較文本與影片槽的相似度以提升檢索效果。

**Motivation:** 傳統MLLM嵌入方法多依賴最終層單一標記，無法充分利用多層分布的訊息，且將多樣訊號壓縮成單一向量會混淆細節，難以區分視覺相似但語義不同的影片。對工程與產品而言，這限制了檢索系統在面對細微差異時的準確度。研究上，如何從多層中提取並保留多樣訊號，避免信息瓶頸，成為提升文本-影片檢索性能的關鍵。

**Method:** MARS透過在提示中加入多個可學習的自適應表示標記，並從多個解碼器層的隱藏狀態加權融合生成多個表示槽。每個槽有專屬的層權重，強調不同層的訊息。文本與影片分別產生多槽嵌入後，進行槽對槽的餘弦相似度計算，最後將多槽相似度平均聚合作為檢索分數。此外，設計硬負樣本感知的槽專門化損失，促使不同槽捕捉互補且具區分性的匹配訊號，並加入多槽多樣性正則化以減少槽間冗餘。訓練目標結合對比損失、多樣性損失及硬負樣本專門化損失。

**Result:** 在DiDeMo、ActivityNet、LSMDC及MSR-VTT四大基準上，MARS在直接相似度檢索設定中達到最先進表現，平均R@1超越多個強基線，包括跨模態匹配方法。使用DSL後，性能進一步提升。透過消融實驗證明多層融合、多槽結構、多樣性正則化及硬負樣本專門化均帶來互補增益。槽數量實驗顯示4個槽為最佳平衡。多槽嵌入在檢索決策及嵌入空間中保持差異性。計算成本分析指出MARS在線上查詢成本最低，適合實際部署。跨不同MLLM骨幹及文本-圖像檢索任務均展現良好泛化能力。

**Conclusion:** 本文提出的MARS框架有效利用多層多槽嵌入，提升了MLLM在文本-影片檢索的細粒度區分能力，並在多個基準上取得領先成績。方法兼顧檢索準確度與計算效率，適合實際工程應用。消融與分析結果支持多層融合與槽專門化的重要性。限制包括未涵蓋更長影片、嘈雜描述及多樣用戶查詢的開放域場景，未探討其他模態及時間定位任務，未明確說明在更大規模或實時系統的部署挑戰。

**Research Gap:** 本文雖在四個主流基準驗證，但這些資料集未涵蓋長影片、複雜場景及多樣查詢，限制泛化性評估。硬負樣本專門化雖提升區分力，但對不同槽的互動機制及其對抗性訓練效果未深入探討。消融實驗未包含更多槽數及層數組合的細節分析，且未明確評估在低資源或實時環境下的效能與延遲。跨模態及時間定位任務的適用性未驗證，缺乏失敗案例分析及對抗樣本測試。最後，全文未明確說明模型在多語言或多文化背景下的表現，這對全球產品部署尤為重要。

### 4. CAPTURE: Disentangling Preference Drift from Memory Poisoning in Personalized LLM Agents

- 分數：5
- arXiv: [2609.02265v1](http://arxiv.org/abs/2609.02265v1)
- 發表日期：2026-09-02
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：iclr; LLM rank #4 / 7/10: Addresses a subtle problem in personalized LLM agents with a principled approach and credible evaluation, revealing adaptation-security tradeoffs.

**Intro:** 個人化語言代理透過持久記憶來適應使用者偏好，這使得代理能夠跨越多週而非單一對話回合進行學習。然而，這種記憶機制同時也成為攻擊的入口。當新資訊與已存偏好矛盾時，代理必須判斷是真實的偏好變動，還是暫時的語境切換、諷刺語氣或惡意記憶中毒。現有方法多依賴更新的時效性或來源，但這些啟發式規則無法有效區分真實變化與攻擊。本文提出CAPTURE方法，旨在解決此偏好真實性模糊問題，提升個人化代理的適應性與安全性。

**Motivation:** 在工程與產品層面，個人化代理若無法正確識別偏好變動，將面臨兩難：過度接受惡意注入導致安全風險，或過度拒絕更新導致個人化失效。這直接影響用戶體驗與系統可靠性。研究上，缺乏能同時處理偏好漂移與記憶中毒的系統與評測基準，且現有防禦多忽略真實偏好演變的複雜性。CAPTURE透過建模偏好真實性為潛在變數，並結合連續時間神經微分方程與多時尺度記憶結構，提供一種可驗證且實用的解決方案，有助於推動個人化LLM代理的安全與穩健發展。

**Method:** CAPTURE將偏好真實性視為潛在狀態，使用神經微分方程追蹤用戶狀態的連續時間演變，能處理不規則的互動間隔。系統從事件中抽取結構化偏好假設，並將其存入分層的多時尺度記憶分類帳，分別管理穩定、語境與暫時性偏好。當系統對更新的信心不足時，會主動向用戶發出澄清問題以降低不確定性。為確保解釋性，CAPTURE對引用的記憶進行反事實審計，評估其對回應的因果影響。最後，回應選擇階段在個人化效用與安全風險間進行權衡，並設置安全約束以防止有害輸出。

**Result:** 在D-PREFGUARD基準的480個持出測試集回合中，CAPTURE達到71.5%的勝率，優於同等監督的基線69.3%及最佳啟發式基線66.1%。在固定策略攻擊下，CAPTURE將記憶中毒成功率限制於11.5%，同時接受83.5%的真實偏好更新。面對具適應性的攻擊者，成功率升至24.7%，顯示存在適應性攻擊與安全性的權衡。此外，CAPTURE在獨立建構的HorizonBench基準與40名用戶的多週互動歷史重播中，展現了偏好追蹤能力的跨場景轉移。消融實驗證明門控機制與多時尺度分類帳對性能提升貢獻顯著。

**Conclusion:** 本文提出CAPTURE方法，通過將偏好真實性建模為潛在變數並結合連續時間神經微分方程、多層次記憶分類帳及澄清機制，有效提升個人化LLM代理在偏好漂移與記憶中毒間的辨識能力。實驗結果顯示該方法在保持高適應性同時顯著降低攻擊成功率，並在多種基準與真實用戶數據中展現良好泛化。限制在於對適應性攻擊的防禦仍有提升空間，且澄清問題的成本與頻率需根據場景調整。整體而言，CAPTURE為個人化代理的安全與穩健性提供了可行且具驗證價值的架構。

**Research Gap:** 本論文的實驗主要基於作者自建的合成數據生成器，雖有獨立基準與用戶重播驗證，但對自然生成攻擊的泛化仍有限。適應性攻擊顯著提升了攻擊成功率，顯示現有防禦在面對智慧型攻擊者時仍不夠完善。澄清機制的成本與用戶負擔未充分探討，且在真實交互中其效果與用戶接受度尚不明確。多時尺度分類帳與神經微分方程架構雖有貢獻，但相較於監督信號的提升較小，暗示架構設計仍有優化空間。最後，對於多模態輸入或權重層級中毒攻擊未涵蓋，限制了方法的適用範圍。

### 5. PolERo: Studying Political Evasion in Romanian

- 分數：5
- arXiv: [2609.02391v1](http://arxiv.org/abs/2609.02391v1)
- 發表日期：2026-09-02
- 分類：cs.CL, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：emnlp; LLM rank #5 / 6/10: Provides a novel multilingual dataset and cross-lingual analysis for political evasion detection, extending prior work beyond English.

**Intro:** 本論文聚焦於政治迴避（political evasion）問題，即回答問題時刻意隱瞞所需資訊的現象。過去相關研究多侷限於英語語境，缺乏跨語言及不同政治背景的探討。為填補此空白，作者提出PolERo，一個包含3574對羅馬尼亞總統官方訪談問答對的人類標註資料集，並採用與英語資料集相同的兩層次迴避分類法。研究同時評估多種分類模型，並探討跨語言遷移與機器翻譯資料擴增的效果。

**Motivation:** 政治迴避在政治溝通中普遍存在，影響對話理解與問答系統的準確性，對工程與產品開發具有實際意義。現有資料與模型多集中於英語，無法保證分類法與模型行為在其他語言與政治環境中適用。羅馬尼亞語資源相對匱乏，缺乏針對政治迴避的標註資料與分析，限制了相關技術的跨語言應用與研究落地。PolERo的建立有助於擴展政治迴避研究的語言範圍，並促進多語言模型的開發與評估。

**Method:** 作者採用Thomas等人（2024）提出的兩層次迴避分類法，將回答分為三大類（明確回答、模稜兩可、明確不回答）及九個細分類別。資料來自五位羅馬尼亞總統25年官方訪談文本，經過GPT-5.4輔助過濾多重問題，並由三位受過心理學訓練的母語標註者依照嚴謹標註流程完成。模型方面，評估TF-IDF+邏輯回歸、單頭與多頭編碼器（含滑動視窗與最大池化）、多種大型語言模型（LLM）零/少量示範提示。跨語言實驗包含單語訓練、雙語聯合訓練及機器翻譯資料擴增。

**Result:** 多頭編碼器架構在羅馬尼亞語與英語資料集均優於單頭模型，提升清晰度與迴避分類表現。羅馬尼亞專用編碼器（RoBERT-large）在PolERo上表現最佳，英語則由RoBERTa-large領先。LLM在細粒度迴避分類上表現較好，但多頭編碼器在三類清晰度分類任務中與LLM競爭力相當且參數量少。跨語言遷移呈現非對稱性，英語訓練模型對羅馬尼亞語測試損失較小，反向則表現較差。雙語聯合訓練優於機器翻譯資料擴增，尤其提升羅馬尼亞語迴避分類。模稜兩可類別因涉及語用意圖，仍是所有模型的主要挑戰。

**Conclusion:** 本研究首次針對羅馬尼亞語政治迴避建立標註資料集PolERo，並在英語與羅馬尼亞語資料上比較多種模型。提出的多頭編碼器架構有效提升分類性能，且在清晰度分類任務中可與大型語言模型競爭。跨語言實驗揭示語言與政治語境差異對模型泛化的影響，雙語聯合訓練為提升低資源語言表現的有效策略。研究限制包括僅涵蓋單一非英語語言、訓練資料標註者專業背景有限及模稜兩可類別難以精確分類。未來工作可擴展至更多語言與政治環境，並強化細粒度迴避策略的識別能力。

**Research Gap:** 本論文雖提供羅馬尼亞語首個政治迴避資料集，但僅涵蓋一種非英語語言，無法保證分類法及模型行為於其他語言或政治文化的適用性。訓練資料僅由單一標註者完成，且標註者非政治科學或語言學專家，可能影響標註一致性與準確度。模稜兩可迴避類別因依賴語用推理，模型表現普遍較差，顯示現有方法在捕捉語境與意圖方面仍有限。跨語言遷移呈現非對稱性，且機器翻譯資料擴增效果有限，暗示語言特性與政治語境差異對模型泛化構成挑戰。全文未明確說明模型在實際部署中的計算成本、延遲及風險評估，亦缺乏失敗案例分析。
