### 1. AgentSSL: Can MLE Agents Leverage Unlabeled Data?

- 分數：5
- arXiv: [2611.17323v1](http://arxiv.org/abs/2611.17323v1)
- 發表日期：2026-11-12
- 分類：cs.AI, cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：neurips; LLM rank #1 / 9/10: Introduces AgentSSL, a novel framing of semi-supervised learning as program search with strong empirical gains and a large benchmark, addressing a practical bottleneck in leveraging unlabeled data with credible evidence 

**Intro:** 本論文探討在標註數據稀缺但未標註數據豐富的半監督學習（SSL）場景中，機器學習工程（MLE）代理是否能有效利用未標註數據。現有的MLE代理多聚焦於全監督學習，忽略了現實中標註數據取得困難的問題。作者提出Agentic Semi-Supervised Learning（AgentSSL）框架，將SSL視為程式搜尋問題，讓代理在有限監督下探索SSL策略。此研究對於希望降低標註成本並自動化SSL策略設計的工程與產品開發具有實際意義。

**Motivation:** 標註數據與人工工程設計是機器學習落地的兩大瓶頸。雖然MLE代理已能自動化管線設計，但多數研究仍假設標註數據充足，與現實場景不符。SSL能減少標註需求，但部署時需大量調參與設計，工程成本高。將SSL視為程式搜尋問題，讓代理自動發現並組合多種SSL方法，有助於降低人力成本並提升跨領域適應性，對實際應用尤其重要。

**Method:** AgentSSL將SSL問題定義為代理在程式空間中搜尋最佳SSL策略的問題，包含兩大挑戰：程式發現與程式選擇。代理利用有限的標註數據與未標註數據，透過語言模型生成、調試與改進SSL程式碼。程式評估採用兩種反饋：有標註的噪聲驗證與無標註的指標評估。搜尋策略包括貪婪、蒙地卡羅樹搜尋與演化演算法。程式選擇則透過無監督指標或主動標註選擇最佳程式。作者並建立ProgramSelectBench基準，收錄近1.7萬個程式以評估選擇方法。

**Result:** 在12個不同資料集與標註量設定中，AgentSSL在已知最佳程式的理想選擇下，於8個設定超越最強人類設計的SSL基線，提升幅度最高達21.8%。然而，實際程式選擇時，若依代理反饋指標選擇，性能可能下降高達47%，顯示選擇策略是瓶頸。無監督選擇在假設成立時有效，失效時主動選擇標註能顯著提升準確度。生態檢測實驗顯示AgentSSL在部分任務能接近全標註專家管線，但在其他任務表現不穩定，且未必總能從未標註數據獲益。

**Conclusion:** 本研究首次將MLE代理應用於半監督學習，證明代理能在有限標註下自動發現多樣且具競爭力的SSL策略。研究強調程式選擇是實務應用的關鍵挑戰，並提供ProgramSelectBench作為後續研究基準。實驗結果顯示代理在降低標註與工程成本上具潛力，但未標註數據的效用依任務而異。未來系統應同時探索監督與半監督策略，並提升選擇方法的穩定性與泛化能力。

**Research Gap:** 全文未明確說明代理在更大規模或多樣化任務中的泛化能力與穩定性，尤其在未標註數據效用不明確的場景。程式選擇依賴無監督指標仍存在較大性能波動，缺乏對失敗案例的深入分析。實驗中代理搜尋策略與語言模型的影響雖有探討，但對計算成本與搜尋效率的權衡未充分展開。生態任務案例數量有限，且未說明代理如何處理更複雜的多任務或多模態資料。最後，代理生成程式的可解釋性與維護性未被討論，對實際部署風險與成本評估不足。

### 2. Unbundling Multimodal Vision Encoding

- 分數：3
- arXiv: [2611.17334v1](http://arxiv.org/abs/2611.17334v1)
- 發表日期：2026-11-12
- 分類：cs.CV, cs.LG
- 入選理由：+3 收錄於 Hugging Face Daily Papers; LLM rank #2 / 8/10: Careful controlled study disentangling key design choices in multimodal vision-language models with clear practical implications and strong methodology, backed by a public project page.

**Intro:** 多模態語言模型如何編碼視覺輸入仍存在爭議。大多數模型使用預訓練的視覺編碼器，但近期有些方法從零開始與語言模型共同訓練編碼器，甚至完全移除編碼器。視覺編碼器通常包含三個設計選擇：來自上游預訓練的視覺先驗、專用的視覺容量，以及該容量在多模態骨幹網路融合前的位置。由於現有模型在數據、架構和計算上差異較大，難以分離這些因素的影響。本文提出一個受控框架，從零開始在相同數據上預訓練所有模型，並在視覺問答和語言基準上以匹配的總計算量比較它們。

**Motivation:** 多模態模型的視覺編碼策略直接影響視覺理解能力與訓練效率。現有方法混合多種設計選擇，且多依賴昂貴的預訓練階段，增加工程和部署成本。理解哪些設計選擇真正帶來效益，有助於優化模型架構、降低訓練資源消耗，並提升推理速度，對實際產品和研究落地具有重要意義。

**Method:** 本文將視覺編碼器的設計拆解為三個獨立因素：是否需要預訓練的視覺先驗、是否需要專用的視覺容量、以及該容量是否必須置於多模態融合之前。所有模型均從零開始訓練，使用相同的數據集和優化策略，並以匹配的總計算量（lifetime compute）進行比較。架構基於統一的Transformer骨幹，視覺容量可置於融合前（獨立編碼器）或融合中（在骨幹內部加入視覺專用模組）。評估涵蓋視覺問答和多種語言理解基準，並分析不同設計對性能和推理速度的影響。

**Result:** 實驗結果顯示，預訓練的視覺先驗並非必要，從零開始與骨幹共同訓練的編碼器在匹配計算量下性能相當。專用的視覺容量對視覺理解至關重要，完全移除編碼器的模型即使增加骨幹參數也無法彌補性能差距。視覺容量不必置於融合前，將視覺專用模組置於骨幹早期層內融合，性能可與融合前編碼器匹敵，且可降低推理時的首字生成延遲。這些結論在不同骨幹大小、預訓練視覺編碼器視為免費、以及從預訓練語言模型開始訓練時均成立。

**Conclusion:** 本文透過嚴謹的受控實驗，拆解並驗證了多模態視覺編碼器的三大設計選擇。結果表明，專用的視覺容量是提升視覺理解的關鍵，但不需依賴預訓練的視覺先驗，也不必置於融合前。將視覺容量內嵌於骨幹早期層的融合策略，兼具性能與推理效率優勢。此研究為多模態模型設計提供了明確指引，強調端到端聯合訓練的重要性。

**Research Gap:** 本文的實驗均在固定數據集與分辨率（224×224）下進行，未探討更高解析度或更豐富文本-圖像數據的影響。所用骨幹為密集Transformer，尚未驗證稀疏混合專家架構下的適用性。預訓練階段均使用相同數據，未涵蓋公開大規模預訓練編碼器可能帶來的額外效益。此外，對於不同任務類型、失敗案例及泛化能力的分析不足。消融實驗主要聚焦於視覺容量位置與存在性，對於其他架構變體或融合策略的比較有限。最後，成本與部署風險評估未充分展開，對實際工程落地的挑戰仍需進一步探討。

### 3. Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents

- 分數：5
- arXiv: [2611.17167v1](http://arxiv.org/abs/2611.17167v1)
- 發表日期：2026-11-12
- 分類：cs.AI, cs.CL
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #3 / 8/10: Novel insight that poor actors can still teach well in decision models, supported by experiments on multiple benchmarks and code release, balancing novelty and practical impact.

**Intro:** 本論文探討決策模型在長期任務代理中的三種角色：行動者（Actor）、評判者（Judge）與教師（Teacher）。決策模型能快速且廉價地對給定情境做出多選擇決策，既可用於選擇行動，也可用於評估已執行的行動，甚至用於強化學習中作為教師提供步驟層級的指導。過去研究多聚焦於決策模型作為行動者的表現，但本研究關注即使行動表現不佳的模型，是否仍能有效教導策略。研究在ALFWorld與WebShop兩個環境中，評估六種決策模型及大型語言模型（LLM）在三種角色下的表現差異。

**Motivation:** 長期任務中，子目標間存在依賴關係，行動者往往被較容易的子目標吸引，忽略必須先完成的關鍵步驟，導致任務失敗。傳統強化學習中，結果獎勵對所有步驟給予相同信用，缺乏細緻的行動評價，且標註步驟層級的回饋成本高昂。決策模型若能作為評判者，利用整個軌跡資訊判斷每個行動的貢獻，或許能提供更有效的指導信號，提升策略學習效率與成功率，對工程實務及產品開發具有重要意義。

**Method:** 本研究將決策模型分別以三種方式使用：作為行動者，在每一步選擇下一個行動；作為評判者，對已執行軌跡中的每個行動評分，並比較模型看到的上下文（行動前綴或完整軌跡）及被問及的問題類型（任務是否成功或該行動是否有助於目標達成）對評分效果的影響；作為教師，利用評判者的分數作為強化學習中步驟層級的獎勵，結合GRPO方法訓練策略。實驗中評估三個專用決策模型（JEV、Decider v1.2、GPT Decisions）及三個通用LLM（Qwen prompted、Qwen constrained、GPT Luna），在ALFWorld與WebShop環境中測試其行動、評判與教學能力。

**Result:** 實驗結果顯示，作為行動者時，所有模型在有子目標依賴的任務中表現不佳，常被較容易的子目標吸引而忽略必須先完成的步驟。作為評判者時，模型在看到完整軌跡並被問及每個行動是否有助於目標達成（Progress問題）時，能更準確區分有用與無用行動，優於僅判斷任務是否成功（Value問題）。作為教師，使用JEV在Hindsight+Progress設定下，能顯著提升Qwen2.5-1.5B策略在ALFWorld的成功率從72.8%提升至82.9%，在WebShop從56.8%提升至71.4%，且小型策略在教師指導下表現優於未使用教師的較大模型。教師模型本身行動表現不佳，但仍能提供有效指導。

**Conclusion:** 本論文系統性分析決策模型在長期任務代理中不同角色的表現，發現行動能力不足的模型仍能透過適當的問題設定與完整軌跡資訊，作為評判者提供有效的步驟層級指導，顯著提升策略學習效果。這說明決策模型的價值不應僅以行動表現評估，而應重視其評判能力。實務上，利用決策模型作為教師能降低標註成本，提升強化學習效率，且不需在測試時使用教師模型，具備良好部署潛力。

**Research Gap:** 本研究主要在兩個文本環境中進行，任務長度及多樣性有限，尚未驗證方法在更長、更複雜或多樣化場景下的泛化能力。教師模型均為固定且多為封閉模型，缺乏對訓練決策模型成為優秀評判者的深入分析及公開權重的實驗支持。線上即時評判（無法看到完整軌跡）尚未充分探討，實際應用中可能受限。此外，成本分析僅涵蓋API查詢費用，未考慮整體系統整合與延遲等部署風險。未見對失敗案例的詳細分析，對模型在不同任務類型中失效原因的理解仍不足。

### 4. Auditing AI peer reviewers: a benchmark on real scientific papers

- 分數：5
- arXiv: [2611.17052v1](http://arxiv.org/abs/2611.17052v1)
- 發表日期：2026-11-12
- 分類：cs.CL, astro-ph.IM, cs.AI, cs.DL
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：neurips; LLM rank #4 / 8/10: Introduces a rigorous benchmark for auditing LLM-based peer reviewers with injected errors and multi-agent evaluation, providing valuable tools and insights for a critical real-world application.

**Intro:** 本論文聚焦於AI輔助的學術論文同行評審系統，特別是基於大型語言模型（LLM）的評審工具。隨著AI在研究領域的廣泛應用，對於AI評審系統的可靠性與效能評估需求日益增加。然而，現有評估方法多侷限於與人類評審對齊或僅針對機器學習領域，缺乏對錯誤類型、嚴重程度及誤報率的細緻分析。論文提出一套新的評估基準，並針對真實科學論文注入多類型錯誤，以量化不同AI評審系統的錯誤偵測能力與誤報情況。

**Motivation:** 在AI科學家逐漸擔任研究者角色的背景下，可靠且可擴展的同行評審系統成為必要。現有AI評審系統缺乏全面且細緻的評估，尤其是對於錯誤類型與嚴重度的分級偵測，以及誤報率的控制。此缺口限制了AI評審系統在工程與產品層面的信任與部署。論文旨在填補此評估空白，提供一套可重複使用的基準，並展示多種評審系統在真實論文上的表現差異，促進AI評審技術的實際落地與改進。

**Method:** 論文設計一個評估流程，於兩個領域（天文物理與機器學習）各15篇arXiv論文的LaTeX原始碼中注入四種錯誤類型（一般問題、數學、數值、引用），並分為三個嚴重度等級（微妙、明顯、嚴重）。評估12種評審系統，包括六種單一LLM配置、兩種Claude Code配置、三種公開可用評審器及作者提出的多代理系統SKEPTHICAL。SKEPTHICAL結合多個專家模組，利用檢索引用文獻、計算代數驗證數學、執行程式碼驗證數值，並以跨家族LLM組成的團隊審核一般問題。評估結果經由多模型交叉判決，並輔以機械式驗證以確保判斷準確性。

**Result:** 結果顯示模型選擇對錯誤偵測率影響最大，同一提示下三個頂尖LLM在兩個領域的總體偵測率相差約50個百分點。結構化提示提升較弱模型表現，且在Claude Code中促使工具使用增加，偵測率提升超過30個百分點。SKEPTHICAL在天文物理領域的引用錯誤偵測率顯著優於其他系統，因其強制執行文獻檢索；但在機器學習領域，模型對文獻熟悉度較高，SKEPTHICAL與最佳單一LLM表現無顯著差異。誤報率普遍低於10%，數學相關標記為誤報主因。公開可用的外部評審器偵測率極低，顯示訓練與模型能力差距。

**Conclusion:** 本研究提出一套涵蓋多錯誤類型與嚴重度分級的AI同行評審評估基準，並公開相關工具與數據，促進社群驗證與改進。SKEPTHICAL作為多代理系統，結合機械驗證與跨家族LLM，展現了在特定領域（如天文物理）顯著提升引用錯誤偵測能力。研究證實模型與提示設計對評審效能關鍵，且工具輔助能彌補模型本身不足。此基準有助於工程師與研究者選擇與優化AI評審系統，推動AI在科學評審的實際應用。

**Research Gap:** 本研究的限制包括：評估僅涵蓋客觀且可定位的錯誤，未涉及評審的整體質量、創新性判斷或實驗設計評估，這些仍難以量化且缺乏明確標準。兩個語料庫規模有限，僅涵蓋單日投稿且篇幅上限20頁，未涵蓋長篇或其他學科，限制結果泛化。錯誤注入同時存在多個錯誤，可能互相影響偵測，但未完全排除此效應。判決主要依賴LLM，人工驗證僅限單篇論文，可能存在判決偏差。SKEPTHICAL使用多模型與多次呼叫，未與等成本單一模型進行公平比較，無法明確歸因於架構設計。部署風險如過度自信、對抗攻擊及供應商集中問題仍需進一步研究與緩解。

### 5. Bellman Contraction under MMD: A Unified Framework

- 分數：5
- arXiv: [2611.17116v1](http://arxiv.org/abs/2611.17116v1)
- 發表日期：2026-11-12
