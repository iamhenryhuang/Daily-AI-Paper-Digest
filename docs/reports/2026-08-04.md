### 1. ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction

**Intro:** 企業文件結構化資料擷取過去多由人工完成，隨著大型語言模型與自動化代理興起，企業需求快速轉向由AI系統依據用戶定義的schema進行擷取。現有基準測試多聚焦固定模板或單一維度，缺乏同時評估擷取準確度、完整性、視覺定位與成本的綜合指標。本文提出ExtractBench，涵蓋370份企業文件、4869頁、8個商業領域與67種文件類型，並以挑戰標籤區分不同困難場景，提供全面且可擴展的schema指導擷取評測平台。

**Motivation:** 企業文件多樣且結構複雜，擷取系統需面對長文件截斷、稀疏資訊定位、密集表單誤判及掃描與手寫噪音等挑戰。現有基準缺乏對長列表完整性、視覺證據追蹤與成本效益的整合評估，難以反映真實生產環境需求。ExtractBench旨在填補此缺口，提供多維度標註與評分，幫助從業者理解系統在不同挑戰下的表現與成本權衡，促進更可靠且經濟的企業文件擷取落地。

**Method:** ExtractBench定義schema-guided extraction任務，輸入為文件與用戶定義的JSON Schema，輸出為符合schema的結構化JSON與對應的視覺證據（頁碼與字詞框）。資料集包含真實文件、合成長列表及掃描表單，分別採用多模型一致性判斷、人工作業驗證及程式碼渲染確保高品質標註。評分指標包括無序值F1衡量準確度，字詞與頁面層級F1評估視覺定位，並計算每頁處理成本。實驗涵蓋14種前沿系統，涵蓋商業VLM、開源管線、編碼代理與專用API。

**Result:** 實驗顯示商業VLM在短文件表現良好（約87%準確度），但長文件準確度大幅下降至約28%。編碼代理準確度較高（約88-94%），但成本超過15美分/頁。專用API展現最佳品質與成本平衡，LlamaExtract Agentic Plus達95.6%準確度，成本僅8.1美分/頁，優於編碼代理且成本更低。挑戰標籤分析揭示長文件、長列表完整性、掃描與手寫文件為主要性能瓶頸。視覺定位方面，僅專用API提供字詞框，且字詞層級F1最高未超過50%，頁面層級F1可達85%。

**Conclusion:** ExtractBench提供首個涵蓋企業文件多維挑戰、視覺定位與成本的schema-guided擷取基準，促進系統在真實生產場景的全面評估。結果顯示不同系統在長文件與複雜結構上表現差異明顯，專用API在品質與成本間取得較佳平衡。視覺定位能力仍有顯著提升空間，尤其是字詞層級的證據追蹤。此基準有助從業者選擇適合的擷取方案並推動技術進步。

**Research Gap:** 本文雖涵蓋多種文件類型與挑戰，但仍未明確說明系統在極端長文件（超過百頁）或更複雜表格結構下的泛化能力。視覺定位評估僅限部分專用API，商業VLM與編碼代理缺乏內建證據輸出，限制審核與錯誤診斷。成本計算基於公開價格，未涵蓋部署與維護等隱性成本。實驗未充分探討多語言文件或非拉丁字元文件的適應性。消融實驗與失敗案例分析較少，難以深入理解各挑戰因素對系統性能的具體影響。

### 2. Sign compression for Muon: SignMuon, MuonSign, and the Limits of Error Feedback

- 分數：7
- arXiv: [2607.29674v1](http://arxiv.org/abs/2607.29674v1)
- 發表日期：2026-07-31
- 分類：math.OC, cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; +2 提及程式碼可用; LLM rank #2 / 8/10: SignMuon presents a theoretically grounded and empirically validated compression method for matrix-aware optimizers with surprising insights on error feedback limitations, supported by extensive experiments and code.

**Intro:** 本論文探討在極低通訊頻寬限制下，如何將Muon優化器的更新壓縮至每參數一位元，藉由對更新取符號（sign）來達成。Muon優化器利用矩陣結構資訊，表現優於傳統的SignSGD，但其更新為密集矩陣且需高精度傳輸，限制了實際部署。作者提出三種將符號壓縮結合Muon的策略：SignMuon（符號壓縮於LMO後）、MuonUSign（符號壓縮於LMO前）及MuonSign（雙側符號壓縮），並分析其理論性質與實驗表現。論文同時探討錯誤回饋（error feedback）機制對這些方法的修復效果。研究涵蓋集中式與聯邦學習場景，並在多種模型與資料集上驗證。這是針對矩陣感知優化器在極端壓縮條件下的系統性分析，對工程與產品端的通訊效率優化具參考價值。

**Motivation:** 在分散式與聯邦學習中，模型更新的通訊成本往往是瓶頸，尤其是深度網路的矩陣參數龐大。SignSGD雖然以每參數一位元壓縮更新，但忽略了矩陣結構，導致效能受限。Muon優化器利用矩陣的正交化結構提升優化效果，但其更新需高精度傳輸，與低頻寬需求矛盾。如何在保持Muon結構優勢的同時，實現極端壓縮，是提升實際系統效率的關鍵。錯誤回饋是常用於修正有偏壓縮器的技術，但其在Muon結合符號壓縮時的效果尚不明確。本文旨在填補這一空白，提供理論與實驗證據，指導實務中壓縮策略的選擇與部署。

**Method:** 作者定義三種符號壓縮與Muon LMO結合的策略：SignMuon先執行LMO再取符號，MuonUSign先取符號再執行LMO，MuonSign則在LMO前後皆取符號。這三種方法均將更新壓縮至每參數一位元。理論上，作者證明這三種方法在簡單線性目標函數上均可能導致更新方向上升（非下降），即不保證收斂。針對此問題，引入錯誤回饋機制，分別應用於壓縮後的更新（EF21-SignMuon）與壓縮前的梯度（EF21-MuonUSign與EF21-MuonSign）。錯誤回饋在壓縮梯度時能恢復收斂性，達到平滑非凸問題的標準收斂速率O(T^{-1/2})。實驗中，作者使用多種模型（ResNet-18、CNN2、nanoGPT）與資料集（CIFAR-10、FineWeb），比較六種符號壓縮方法與基線（Muon、SignSGD、SGD、Adam），並採用合理的步長調整策略與多種隨機種子以確保結果穩健。

**Result:** 理論證明三種符號壓縮方法均存在會導致更新方向上升的反例，且錯誤回饋無法修復SignMuon（符號壓縮於LMO後）。然而，錯誤回饋能修復MuonUSign與MuonSign（壓縮於梯度前），使其在平滑非凸問題上達到標準收斂速率。實驗結果顯示，在集中式CIFAR-10訓練中，SignMuon表現最佳，與全精度Muon相當，且優於SignSGD約1.2個百分點。聯邦學習場景下，SignMuon仍優於其他符號壓縮方法，且超越SignSGD約4.3個百分點。nanoGPT語言模型訓練中，所有符號壓縮方法均優於SignSGD，且SignMuon與EF21-SignMuon接近全精度Muon。實驗中最強方法均為符號壓縮於LMO後的SignMuon，儘管理論上該方法無收斂保證。錯誤回饋方法雖有理論保證，但實際表現落後於SignMuon。

**Conclusion:** 本論文揭示了將符號壓縮與Muon LMO結合的三種策略均可能導致理論上的發散，且錯誤回饋機制對符號壓縮於LMO後的更新無法修復。相反，錯誤回饋應用於梯度壓縮則能恢復收斂性並達到標準收斂速率。實驗結果顯示，理論保證與實際性能存在矛盾，符號壓縮於LMO後的SignMuon在多種任務中表現最佳。此研究對理解矩陣感知優化器在極端壓縮條件下的行為提供了重要洞見，並為工程實踐中壓縮策略的選擇提供依據。限制在於理論結果為最壞情況，實際數據分布可能不符合，且錯誤回饋方法增加了記憶體與計算負擔。

**Research Gap:** 本論文的理論分析基於特定小尺寸矩陣的反例，未明確說明這些反例在大型深度學習模型中出現的頻率與影響程度，限制了理論與實務的直接對應。錯誤回饋方法雖有收斂保證，但實驗中表現不如無保證的SignMuon，顯示理論保證未必反映實際效能，缺乏對此矛盾的深入分析與解釋。實驗中步長調整與其他超參數設定對結果影響未充分探討，可能影響方法比較的公平性。錯誤回饋方法增加了客戶端與伺服器端的記憶體需求，論文未詳細評估其在資源受限環境的實際部署成本與風險。此外，對於不同資料分布、非均質聯邦環境及更複雜模型的泛化能力與失敗案例未充分驗證。未來研究應聚焦於縮小理論與實驗間差距，並評估壓縮策略在多樣化實際場景的適用性與穩定性。

### 3. When Does On-Policy Interaction Help? Representational Tradeoffs in Value-Based Imitation Learning

- 分數：5
- arXiv: [2607.29617v1](http://arxiv.org/abs/2607.29617v1)
- 發表日期：2026-07-31
- 分類：cs.LG, cs.AI, stat.ML
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #3 / 7/10: The paper provides a novel theoretical and empirical analysis of on-policy interaction benefits in imitation learning, introducing a new algorithm with clear advantages and negative results clarifying necessity of intera

**Intro:** 本論文探討模仿學習中，為何以及何時互動式(on-policy)查詢專家能提升學習效果。傳統行為克隆(Behavior Cloning, BC)在學習者無法完美表示專家策略時，常面臨誤差累積與性能瓶頸。兩種常見改善手段為沿學習者軌跡互動式查詢專家，以及透過價值函數估計生成策略，而非直接擬合專家行為分布。作者提出一種新演算法OVI，證明互動查詢能降低學習者的表示需求，只需能表示專家的價值函數即可，無需完全表示專家策略。此研究對模仿學習的理論與實務均有重要啟示。

**Motivation:** 模仿學習是許多AI應用的核心，但現有方法在模型容量有限時常受限於誤差累積與性能瓶頸。理解互動查詢如何降低表示需求，能幫助設計更高效且實用的模仿學習系統，尤其對於需要離線資料或模型蒸餾的場景有重要意義。

**Method:** 作者提出OVI演算法，基於一種min-max遊戲框架，將模仿學習問題轉化為策略與價值函數間的對抗優化。OVI逐層學習非平穩策略，利用專家互動數據估計價值函數，並透過線性最大化oracle與softmax策略更新實現高效計算。理論證明OVI在只需表示專家價值函數(QπE-realizability)的假設下，能以多項式樣本複雜度達成近似最優策略。此方法避免了傳統策略擬合的嚴苛假設，並證明無互動時此表示條件不足以保證有效學習。

**Result:** 實驗在多個Gymnasium環境中比較OVI與BC、DAgger及SPOIL等方法，結果顯示OVI在學習者網路容量較小時表現優越，證實價值函數表示需求較策略表示更寬鬆。理論上，作者證明無互動的離線模仿學習在QπE-realizability條件下仍需樣本數隨狀態空間大小線性增長，且使用價值誘導策略的離線方法存在無法辨識的問題。進一步在語言模型鏈式思考任務中，OVI展現出相較於非互動方法的指數級計算效率提升，強調互動與價值函數估計的協同效應。

**Conclusion:** 本論文揭示互動式查詢專家不僅改善時間步長依賴，更重要的是降低學習者的表示需求，使得只需表示專家價值函數即可有效模仿。OVI演算法在理論與實驗上均證明此觀點，並指出離線模仿學習在此表示條件下無法達成相同效果。對語言模型鏈式思考學習的應用展示了互動與價值函數估計帶來的計算優勢。限制在於OVI學習非平穩策略且計算複雜度隨時間步長線性增加，且對非凸函數類的樣本效率仍有提升空間。

**Research Gap:** 全文未明確說明OVI在大規模連續狀態空間或高維感知輸入下的泛化能力與穩定性，且對非凸價值函數類的樣本效率仍較差。實驗主要聚焦於中小規模控制任務，缺乏在真實語言模型蒸餾或複雜機器人任務中的實證驗證。離線模仿學習的理論下界雖被證明，但在實務中如何結合有限互動與離線資料仍未充分探討。此外，OVI學習非平穩策略可能增加部署複雜度，且對失配或模型錯誤的魯棒性分析不足。最後，互動查詢成本與實際部署風險未被深入討論，限制了方法在資源受限環境的應用。

### 4. CodeShrink: Adaptive Visual Compression for Efficient Multimodal Code Understanding

- 分數：4
- arXiv: [2607.29637v1](http://arxiv.org/abs/2607.29637v1)
- 發表日期：2026-07-31
- 分類：cs.CV, cs.SE
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: CodeShrink proposes an adaptive, multi-component visual compression framework for multimodal code understanding with strong empirical gains and code release, addressing practical efficiency challenges.

**Intro:** 本論文探討多模態大型語言模型（MLLM）在程式碼理解任務中，將程式碼渲染為影像所產生的視覺標記冗餘問題。傳統透過調整影像解析度來平衡視覺標記數量與內容清晰度的方法，忽略了由換行與縮排產生的空白區域，以及與當前指令無關的程式碼區域所造成的效率損失。此外，最佳壓縮設定會隨輸入、任務與模型而異，固定比例策略難以達成最佳效果。論文提出一套自適應視覺壓縮框架CodeShrink，旨在提升多模態程式碼理解的效率。

**Motivation:** 程式碼通常包含大量空白與結構性格式，導致渲染成影像後產生大量無意義的視覺標記，增加模型推理成本。固定解析度壓縮策略無法因應不同任務與輸入的需求，造成資源浪費或性能下降。從工程與產品角度看，降低視覺標記數量可減少推理延遲與成本，提升多模態模型在實際軟體開發輔助工具中的可用性與擴展性，因此需要一套能動態調整壓縮策略且能剔除冗餘資訊的方法。

**Method:** CodeShrink包含三個核心組件：首先，Blank-Free Rendering（BFR）透過結構線性化，將原本依賴空白的程式碼版面轉換為緊湊且帶有明確結構標記的格式，消除空白區域造成的冗餘視覺標記。其次，Dominant Token Selection（DTS）在推理階段結合指令與視覺標記的重要性評估，分別對前景程式碼標記與背景空白標記進行剪枝，保留與任務相關的視覺標記。最後，Adaptive Compression Configuration（ACC）利用強化學習訓練一個輕量代理模型，根據每個輸入樣本動態選擇最佳的渲染解析度與剪枝比例，以平衡標記數量與可讀性。

**Result:** 在Python與Java的程式碼問答、程式碼克隆檢測與程式碼補全三項任務上，CodeShrink在大幅減少視覺標記數量（最高達71.2%）的同時，維持甚至超越未壓縮純文字輸入的性能。與多種文本壓縮與視覺壓縮基線方法相比，CodeShrink在準確率、F1分數、編輯相似度等指標上均有顯著優勢。實驗也證明BFR能提升多種MLLM模型的程式碼可讀性，ACC能根據任務特性自適應調整壓縮參數，DTS則有效剔除與任務無關的視覺標記，三者協同提升整體效率與效能。

**Conclusion:** 本論文提出的CodeShrink框架有效解決了多模態程式碼理解中視覺標記冗餘與固定壓縮設定的問題。透過空白消除的緊湊渲染、指令感知的視覺標記剪枝，以及基於強化學習的動態壓縮配置，CodeShrink在多種程式碼理解任務中實現了顯著的視覺標記壓縮與性能提升。此方法對於降低MLLM推理成本、提升軟體工程應用的實用性具有重要意義。然而，全文未明確說明在更大規模程式碼庫或其他程式語言上的泛化能力，且未深入討論在極端壓縮條件下的失敗案例與成本效益分析。

**Research Gap:** 本研究主要在Python與Java兩種語言及三項任務上驗證方法，缺乏對更多程式語言及更複雜軟體系統的實驗，限制了泛化性評估。ACC代理模型雖能動態調整壓縮參數，但全文未明確說明其在實際部署中對推理延遲與計算資源的影響。此外，DTS剪枝策略依賴注意力權重，可能在某些任務或程式碼結構中誤刪重要標記，相關失敗案例與穩定性分析不足。最後，全文未提供對比不同MLLM架構下CodeShrink適用性的深入探討，亦未評估在極端高壓縮率下的性能退化與用戶體驗影響。

### 5. MOT-SR: Multi-Objective Tool-Augmented Scientific Equation Discovery with Large Language Models

- 分數：4
- arXiv: [2607.29561v1](http://arxiv.org/abs/2607.29561v1)
- 發表日期：2026-07-31
- 分類：cs.LG, cs.AI
- 入選理由：+2 提及頂級機構：meta, mit; +2 提及程式碼可用; LLM rank #5 / 6/10: MOT-SR offers a multi-objective, tool-augmented symbolic regression framework with demonstrated improvements on standard and challenging scientific tasks, including a real-world physics application.

**Intro:** 符號回歸（Symbolic Regression, SR）旨在從觀測數據中發現解析方程，對科學建模至關重要。傳統方法多依賴單一目標優化，僅聚焦於擬合誤差，忽略了方程結構複雜度與泛化能力，容易陷入局部最優解。近年大型語言模型（LLM）在SR領域展現潛力，但缺乏系統性變量依賴分析與多目標評估機制，限制了探索效率與模型質量。本文提出MOT-SR，一個結合外部分析工具與多目標優化的統一框架，旨在提升方程發現的準確性、泛化性與效率。

**Motivation:** 現有LLM基礎的符號回歸方法缺乏對變量依賴關係的深入分析，導致搜索空間約束不足，效率低下且方向性差。單目標優化忽視結構複雜度與泛化能力，容易過擬合且早期收斂。對工程和產品而言，這意味著發現的方程可能不具備良好的解釋性和跨場景適用性，限制了科學模型的實際部署與長期可靠性。為此，需引入多目標評估與結構先驗，並利用工具輔助分析提升搜索策略的智能化與適應性。

**Method:** MOT-SR框架包含三大核心組件：首先，工具輔助變量分析模組利用多種統計與信號處理工具（如Pearson相關、Spearman秩相關、傅立葉變換、小波分析、Granger因果檢驗等）自動提取變量間的線性、非線性、周期性及因果關係，形成結構先驗指導方程生成。其次，多目標評估模組同時考量內域（ID）與外域（OOD）數據上的擬合誤差，以及方程的結構複雜度（以抽象語法樹長度衡量），並通過非支配排序維護動態Pareto前沿，促進多維度優化。最後，兩個協同運作的LLM模組：Meta Strategy Generator根據Pareto最優方程分析殘差並調用工具生成搜索策略，Equation Generator根據策略及結構多樣性指標生成新候選方程，形成閉環迭代優化流程。

**Result:** 在40個標準科學符號回歸任務中，MOT-SR相較於傳統基因編程、PySR、uDSR、RAG-SR及現有LLM-SR方法，在準確率、泛化能力及方程緊湊度上均有顯著提升。例如在Oscillator1任務中，MOT-SR的NMSE達1.27×10^-15，遠優於LLM-SR的2.55×10^-5。多目標優化使模型在內外域測試集均表現優異，顯著提升了泛化能力。收斂速度方面，MOT-SR在迭代1000次內即超越LLM-SR 2000次迭代結果。消融實驗證明多目標評估與Meta Strategy Generator均為性能提升關鍵。應用於極端質量比螺旋（EMRI）軌道演化建模，MOT-SR發現的符號修正方程在30個未見配置上達成最低軌跡整合誤差，較神經網絡基線低三個數量級，顯示優異的長期積累誤差控制與泛化能力。

**Conclusion:** 本文提出的MOT-SR框架通過結合工具輔助變量分析、多目標評估及協同LLM模組，有效提升了符號回歸在科學方程發現中的準確性、泛化性與效率。實驗結果涵蓋多領域標準基準及實際天文物理問題，展示了該方法在長期動態系統建模中的應用潛力。MOT-SR不僅能生成結構緊湊且解釋性強的方程，還能在分布外數據上保持穩健表現，對工程和科研落地具有重要意義。

**Research Gap:** 儘管MOT-SR在多項任務中表現優異，全文未明確說明其在高維度數據和更複雜動態系統中的適用性與擴展性。工具集固定且手動指定，缺乏自動化工具發現與優化機制，可能限制對新領域的快速適應。消融實驗集中於部分基準，對不同LLM架構及規模的泛化能力探討不足。成本與計算資源消耗分析有限，對實際部署場景的可行性評估尚不充分。此外，對失敗案例或模型在極端條件下的魯棒性缺乏深入討論，未提供對模型可能陷入局部最優或過擬合的具體防範策略。
