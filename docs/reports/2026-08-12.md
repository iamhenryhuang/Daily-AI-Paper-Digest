### 1. SWE-Bench ProMax: Benchmarking Agents on Large-Scale Multilingual Code Refactoring

- 分數：8
- arXiv: [2608.09802v1](http://arxiv.org/abs/2608.09802v1)
- 發表日期：2026-08-10
- 分類：cs.CL, cs.SE
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; +3 提及頂級會議：colm; LLM rank #1 / 9/10: Introduces a rigorously curated, large-scale multilingual code refactoring benchmark addressing key quality issues in prior work, with strong evidence of challenge for current AI coding agents and practical relevance.

**Intro:** 隨著 AI 編碼代理在軟體工程任務中扮演越來越重要的角色，現有的評測基準逐漸飽和且評價品質受到質疑。尤其是先前的 SWE-bench 評測中，近六成未解決的案例存在測試缺陷，導致無法真實反映模型能力。程式碼重構作為一種需要跨多檔案協調且保持行為不變的複雜任務，能更真實地測試代理能力，但目前相關基準仍不足。本文提出 SWE-Bench ProMax，建立一個多語言且大規模的重構基準，涵蓋七種程式語言，並經過嚴格的專家策劃與測試套件審核，旨在提供更具挑戰性且品質更高的評測環境。

**Motivation:** 現有基準多集中於單檔案或簡單修改，無法反映真實軟體開發中跨多檔案、長期且複雜的重構需求。且許多基準的測試套件存在過於狹隘或過於寬泛的問題，導致評測結果不可靠。此外，資料污染與問題描述不清也影響評測的有效性。SWE-Bench ProMax 透過嚴格篩選與專家重寫問題描述，並手動審核測試套件，解決上述問題，提供一個更貼近實務需求且能有效區分模型能力的評測平台。

**Method:** SWE-Bench ProMax 採用三階段資料蒐集與策劃流程：首先從 GitHub 上符合條件的開源專案中擷取包含「refactor」關鍵字且非錯誤修正的提交，涵蓋七種主流程式語言。接著建立隔離的 Docker 環境，驗證原始碼與測試套件能正常運作。最後由專家結合大型語言模型協助，重寫問題描述以確保明確且無歧義，並手動審核測試套件以剔除不合理的測試。最終篩選出 170 個高品質且具挑戰性的重構任務，每個任務平均涉及 11.4 個檔案與 261.6 行程式碼變更。

**Result:** 在兩種代理架構（mini-swe-agent 與 OpenHands）下，評測六款前沿模型，最佳模型 GPT-5.2 僅達 41.2% 解決率，遠低於現有 SWE-bench Verified 超過 75% 的水準，顯示本基準仍具挑戰性。開源模型如 GLM-5 與 Qwen3.5 在成本遠低於專有模型的情況下，表現接近最佳模型。不同模型在不同語言表現差異明顯，無單一模型全面領先。行為分析發現，失敗主要因未能完成跨檔案的完整重構，且失敗案例多耗費更多互動輪次，顯示跨檔案協調與持續規劃是瓶頸。

**Conclusion:** SWE-Bench ProMax 提供一個多語言、跨檔案且經專家嚴格策劃的程式碼重構評測基準，彌補現有基準在規模、品質與多樣性上的不足。實驗結果證明該基準對現有 AI 編碼代理仍具高度挑戰性，且開源模型在成本效益上具競爭力。分析指出跨檔案協調能力不足是主要失敗原因，為未來模型改進指明方向。此基準有助於推動 AI 編碼代理在真實軟體工程場景中的能力提升。

**Research Gap:** 本文雖然在多語言與大規模重構任務上取得進展，但仍存在限制。首先，任務數量僅有 170 個，覆蓋的專案與場景仍有限，可能影響泛化性。其次，雖有專家審核，但對模型失敗案例的深入分析與消融實驗不足，無法完全揭示失敗原因的細節。第三，成本與效能間的權衡未充分探討，尤其在實際部署環境中的可行性與效率仍待驗證。最後，模型在跨語言特性與複雜記憶管理上的表現差異，全文未明確說明其根本原因，未來可加強對語言特性影響的系統性研究。

### 2. Sci-VBench: Evaluating Knowledge- and Reasoning-Intensive Video Generation in Science Domains

- 分數：8
- arXiv: [2608.09873v1](http://arxiv.org/abs/2608.09873v1)
- 發表日期：2026-08-10
- 分類：cs.CV, cs.AI
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +3 提及頂級會議：colm; +2 提及程式碼可用; LLM rank #3 / 8/10: Presents a large, expert-annotated benchmark for knowledge- and reasoning-intensive scientific video generation with a reproducible evaluation protocol and insightful model analysis.

**Intro:** 本論文提出Sci-VBench，一個針對科學領域中需要知識與推理能力的影片生成任務的綜合性評測基準。該基準包含1,253個由專家註解的範例，涵蓋自然科學、醫療保健、人文社會科學與工程四大核心學科共60個主題。每個範例要求模型生成具有時間豐富性且基於科學推理的影片，超越表面視覺的合理性。作者同時建立了基於評分規範的評估流程，並驗證非專家與多模態大型語言模型作為評審的評分與專家判斷具有較高一致性。

**Motivation:** 隨著影片生成模型在視覺真實感與動態連貫性上的進步，評估焦點從單純的視覺合理性轉向是否忠實呈現提示中指定的事件、限制與時間依賴關係。科學領域影片生成尤其重要，因為視覺合理的影片可能隱藏違反物理定律或因果關係的錯誤。現有評測多聚焦於通用物理常識或視覺品質，缺乏跨科學領域且具專家定義評分標準的多學科推理評測基準，限制了模型在科學推理與因果動態模擬的發展與驗證。

**Method:** Sci-VBench由專家根據教科書核心概念設計提示，要求模型生成符合機制推理的時間演化影片。每個範例配有高階參考指南與詳細評分規範，涵蓋低階視覺品質、提示對應度、科學與因果正確性及時空一致性四個維度。評分規範以1至5分的錨點定義，並由不同專家獨立審核以確保一致性。評估流程結合人類專家評分與基於多模態大型語言模型的自動評分，後者根據每個範例的評分規範進行條件評分，提升評分的可擴展性與重現性。

**Result:** 作者評測16個先進的專有與開源文本生成影片模型，結果顯示視覺品質指標在各模型間差異不大，但提示對應度與科學因果正確性存在顯著差距，且專有模型普遍優於開源模型。時空一致性方面，開源模型表現不落後。非專家在獲得評分規範輔助下，與專家評分的相關性顯著提升，且多模態大型語言模型評分優於先前自動評分方法。錯誤分析指出模型常見誤差包括指令遵循不佳、科學原理模擬不準確及時間連貫性不足。提示重寫實驗顯示更明確提示能提升推理相關維度表現，但無法彌補生成器本身的機制缺陷。

**Conclusion:** Sci-VBench填補了科學領域文本生成影片模型作為專家級世界模擬器評估的空白，提供跨60個主題的專家提示與評分規範，強調機制推理與因果動態的時空連貫性。基準測試揭示視覺真實感與科學有效性間的鴻溝，以及專有與開源模型在推理能力上的明顯差距。這些發現指向提升指令遵循、機制一致性與時空穩定性的具體改進方向。全文未明確說明模型在更複雜科學場景或長時間影片生成的泛化能力與失敗案例。

**Research Gap:** 本研究雖涵蓋多學科與大量專家標註範例，但仍缺乏對模型在更長時間尺度、複雜交互或跨領域科學場景中的泛化性評估。自動評分依賴多模態大型語言模型，對細微視覺與時間錯誤的判斷仍有限，尤其是時空一致性維度。提示重寫實驗顯示生成器本身限制難以透過提示優化完全克服，暗示生成模型架構與訓練策略需進一步改進。缺少對生成成本、部署風險及實際應用中失敗案例的深入分析，限制了對工業落地的指導價值。未來工作可加強消融實驗、跨模型比較及多樣化評估場景，以提升基準的全面性與實用性。
