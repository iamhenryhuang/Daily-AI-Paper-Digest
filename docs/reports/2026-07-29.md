**Intro:** 合成表格數據在隱私保護和少數類別增強中扮演重要角色，尤其在信用卡詐騙和臨床風險等不平衡領域。這類數據不僅需保留每欄的邊際分布，更需維持欄位間的依賴關係，因為少數類別的判別信號多來自欄位間的聯合結構。現有評估合成數據品質的指標多忽略欄位間依賴，導致即使完全破壞依賴的基線模型也被誤判為與真實數據無異。本文提出一種依賴感知的診斷方法，能量化並分解合成數據的邊際與依賴保真度。

**Motivation:** 在實務中，合成表格數據若無法保留欄位間依賴，將導致少數類別的判別能力大幅下降，影響模型訓練與決策效果。現有主流指標如logistic回歸C2ST和Trend分數無法有效揭露依賴缺失，造成對生成模型的誤判。對工程師和產品經理而言，缺乏依賴保真度的評估工具，難以判斷合成數據的實用價值與風險。研究者也需明確依賴缺口的成因，才能設計更有效的生成目標與架構。

**Method:** 本文採用強分類器兩樣本檢驗（XGB-C2ST）作為基礎，利用梯度提升樹捕捉高階欄位交互，將整體判別力分解為邊際成分、依賴成分及數值-類別交叉成分。透過對真實數據的完全獨立重排（破壞依賴但保留邊際）作為下界參考，與真實數據子樣本作為上界，量化生成模型在依賴保真度上的缺口。實驗以先進的流匹配生成器TabbyFlow/EF-VFM為對象，並在多個不平衡數據集上評估依賴缺口及其對少數類別效用的影響。此外，透過模型容量擴增與架構改動實驗，探討缺口成因。

**Result:** 結果顯示，傳統指標如logistic回歸C2ST對完全破壞依賴的基線模型評分接近完美，無法揭露依賴缺失；Trend分數僅部分敏感。XGB-C2ST明確揭示TabbyFlow在多個數據集存在顯著依賴缺口，且該缺口與少數類別F1分數下降相關。容量擴增16倍未能縮小缺口，排除容量不足假設。加入顯式依賴模組、後設copula校正及協方差匹配等方法均未有效改善依賴缺口，顯示缺口源於生成目標缺乏直接依賴監督。實驗嚴謹，採用多次隨機種子與配對檢驗確保結果穩健。

**Conclusion:** 本文提出的依賴感知診斷工具為表格生成模型提供了量化欄位依賴保真度的有效手段，揭示了現有評估指標的盲點與先進生成器的依賴缺口。研究證明該缺口非結構性限制，亦非容量瓶頸，而是生成目標未直接監督依賴所致。多種嘗試修正依賴缺口的策略均告失敗，提醒從業者不應盲目依賴架構改進或擴大模型規模。未來改進需聚焦於設計能直接獎勵依賴結構的生成目標。本文結果對合成數據的品質保證與實務應用具有重要啟示。

**Research Gap:** 本文未明確說明依賴缺口在更廣泛數據類型或更複雜依賴結構下的表現與恢復速率，缺乏對不同依賴結構難易度的系統性分析。容量擴增實驗因優化不穩定排除部分數據集，限制了容量影響的全面評估。依賴模組改進僅限於特定設計，未涵蓋所有可能的依賴建模策略。後設copula校正效果不佳，但未深入探討其調參或複雜度對結果的影響。全文未提供生成模型在實際部署中計算成本與效能權衡的詳細分析。最後，對失敗案例與泛化能力的討論不足，限制了對方法穩健性的全面理解。

**Intro:** 本論文聚焦於記憶增強型大型語言模型（LLM）代理中的關鍵值（KV）快取重用問題。這類代理透過主動策劃檢索內容並附加LLM生成的元資料（如摘要、關鍵詞、標籤）來維持長期上下文。然而，每次檢索都需重新編碼這些結構化記憶單元為KV狀態，導致推理延遲顯著增加。現有的無訓練KV重用方法多針對原始文本檢索設計，對結構化代理記憶效果不佳。論文提出AgentKVShift，一種無訓練、探針引導的KV殘差校正方法，針對每個檢索記憶單元進行校正，顯著提升KV重用的準確度與效率。

**Motivation:** 在長期對話和代理應用中，記憶系統需頻繁檢索並重新編碼大量上下文，KV重用成為降低推理成本的關鍵技術。現有方法透過選擇性重算部分token來減少計算，但在結構化代理記憶中表現不佳，因為元資料豐富且token間誤差呈現結構性。如何有效利用有限的重算預算，修正未重算token的KV狀態，成為提升系統效能與降低延遲的核心挑戰。AgentKVShift正是針對此問題提出解決方案，對工程部署和產品響應速度具有直接影響。

**Method:** AgentKVShift基於對KV重用殘差的光譜分析，發現殘差主要由共享的記憶單元層級偏移和少量token波動組成。方法先從每個記憶單元中選取少量探針token，重新計算其KV狀態，估計該單元的偏移向量。接著，將此偏移加權應用於未重算的token KV，實現全單元的校正。此過程無需訓練，且探針選擇固定於第一層，降低計算負擔。理論分析證明此校正能顯著降低注意力誤差上界，提升重用精度。

**Result:** 在兩大長期記憶基準LoCoMo和AMA-Bench-Recall上，AgentKVShift在僅重算10%-30% KV狀態下，達到接近全重算的性能，F1分數相對差距僅1.5%-6%。與CacheBlend和ProphetKV兩種先進方法相比，AgentKVShift在相同重算比例下表現更佳，且在2-4位元激進量化下保持超過2倍的F1優勢。速度方面，於單張A100 GPU上，AgentKVShift在低重算比下實現2-3.5倍的prefill加速。結果涵蓋3B至32B參數模型，涵蓋多種記憶結構與任務領域，展現良好泛化性。

**Conclusion:** AgentKVShift提出了一種簡潔有效的KV快取重用校正策略，專為結構化代理記憶系統設計。透過探針引導的共享偏移估計與加權校正，顯著提升了KV重用的準確度與效率，降低了推理延遲，並兼容激進量化技術。此方法對長期記憶代理的實際部署具有重要價值，能在保持模型性能的同時節省大量計算資源。全文未明確說明在更複雜跨記憶單元推理場景下的表現，且對於不同探針選擇策略的敏感度尚缺乏深入分析。

**Research Gap:** 本論文雖在多模型、多任務上驗證AgentKVShift，但仍存在幾點不足。首先，探針選擇固定於第一層，未探討多層或動態選擇對性能的影響。其次，校正方法假設殘差主要由共享偏移構成，對於偏移不明顯或token間誤差更複雜的情況未充分驗證。第三，跨記憶單元的推理能力提升有限，KV重用對整體代理推理流程的影響未深入探討。最後，雖有理論分析支持，但實際部署中對硬體資源消耗、延遲波動及失敗案例缺乏詳細報告，限制工程實踐參考價值。

**Intro:** 本文探討 transformer 架構的語言模型在多選題問答任務中，何時以及如何做出最終預測決策。作者發現一個稱為 Hard Decision Layer (HDL) 的層，該層使答案選項的排名在推理過程中突然穩定下來。研究涵蓋四種不同的語言模型與四個多選題資料集，並驗證 HDL 是模型架構的固有特性，且不受微調影響。此現象揭示了 transformer 推理過程中的機制性洞見，對理解模型決策時機及提升推理效率有實務意義。

**Motivation:** 理解 transformer 模型在推理過程中何時做出決策，對於機械可解釋性與計算效率皆具重要性。現有研究多依賴動態路由或後設層剪枝，缺乏對模型內部固有決策層的系統性認識。多選題問答提供一個受控環境，能清楚觀察模型如何在多個選項間做出選擇。揭露 HDL 有助於工程師在模型部署時優化計算資源，並為模型調控與推理策略提供理論基礎。

**Method:** 作者使用 Logit Lens 技術，將 transformer 各層的中間表示映射回詞彙空間，追蹤答案選項的層級排名變化。定義 HDL 為使最終預測答案排名下降幅度最大的層，代表模型做出最終決策的關鍵層。實驗涵蓋四種指令微調模型（Qwen、Llama、Granite、Mistral）與四個多選題資料集，並透過低秩適配（LoRA）微調檢驗 HDL 的穩定性。此外，作者測試不同選項標籤格式及選項數量對 HDL 的影響，並初步探討開放式生成任務中是否存在類似現象。

**Result:** 所有模型與資料集均觀察到固定的 HDL 層，該層後答案排名趨於穩定，且準確率在 HDL 層有顯著提升，提升幅度最高達 0.61（Qwen 在 CommonsenseQA）。HDL 層位置與模型參數量呈反比，較大模型較早完成決策。微調後 HDL 層位置不變，但準確率提升。選項標籤格式影響 HDL 的明顯程度，阿拉伯數字與字母標籤較羅馬數字更明顯。選項數量變化不影響 HDL 層位置。開放式生成任務中，HDL 現象較不明顯但仍可觀察到部分穩定性。

**Conclusion:** 本文首次系統性揭示 transformer 模型在多選題推理中存在一個固有的 Hard Decision Layer，該層標誌著模型做出最終答案選擇的關鍵時刻。此發現對模型推理機制理解、推理效率提升及模型壓縮具有實際應用價值。HDL 的穩定性跨模型、資料集及微調設定均得到驗證，顯示其為架構固有特性。限制在於未涵蓋鏈式思考推理及更廣泛的生成任務，且對答案多樣表達形式未充分考量，未來研究可進一步擴展。

**Research Gap:** 本文未探討 HDL 在鏈式思考等複雜推理任務中的表現，限制了對更自然推理過程的理解。對答案選項的多樣表達形式（如不同標點、同義詞）未進行深入分析，可能影響 HDL 的判定準確性。開放式生成任務的實驗較為初步，尚無法確定 HDL 現象的普適性。此外，對 HDL 層後剪枝的實際部署風險與泛化能力缺乏詳細評估，未說明在不同 prompt 格式下模型性能變化的具體影響。消融實驗主要集中於標籤格式與選項數量，對其他模型架構變異或訓練策略的影響尚未充分探討。

### 4. On the Depth Scalability of Logic Gate Networks

- 發表日期：2026-07-28
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; LLM rank #4 / 7/10: Provides a thorough, reproducible empirical study of token accounting for source code as text vs. images across major providers, revealing nuanced behaviors with practical implications for cost and efficiency in code-rel

**Intro:** 本文探討Logic Gate Networks（LGNs）在深度擴展上的限制。LGNs透過布林運算組合實現計算，但現有LGNs在加深層數時，效能往往無法提升甚至下降。作者指出問題不僅在於優化困難，還有網路拓撲本身限制了深層計算的有效性。為此，提出一種新架構Input-Anchored Logic Gate Networks（IALGNs），讓每層除了接收前一層隱藏特徵外，還直接連結原始輸入，藉此保持資訊流通與計算能力的提升。

**Motivation:** 深度是布林電路理論中擴展表達能力的關鍵資源，但現有LGNs無法從增加深度中獲益，主要因為兩個原因：一是深層LGNs優化時梯度消失，二是拓撲結構限制了深層層間有效資訊流動。工程與產品層面，若LGNs無法有效利用深度，將限制其在複雜任務中表現與應用。解決此問題有助於提升離散神經架構的可擴展性與實用性。

**Method:** 提出IALGN架構，將每個邏輯閘的兩個輸入端之一固定為前一層的隱藏特徵（稱為spine pin），另一端直接連結原始輸入（anchor pin），確保每層均可接觸到原始輸入資訊。此設計保留了深度計算的主幹，同時允許層層基於原始輸入進行細化。為提升靈活性，採用random-k anchor relaxation，從多個候選輸入中學習選擇。訓練時使用skip-biased初始化與straight-through估計器以穩定優化，推論時則將操作與連結離散化。

**Result:** 在MNIST、CIFAR-10與CIFAR-100三個資料集上，IALGN在固定寬度下隨深度增加持續提升準確率，超過100層仍有成效，反觀隨機連結LGN則表現飽和或退化。層級線性探針分析顯示IALGN中間層表徵隨深度逐漸豐富，且在相似激活熵條件下表現更佳。拓撲消融實驗證實輸入錨定是關鍵因素，非單純增加連結彈性。有效計算深度分析指出IALGN保留更長的計算路徑，支持更深層次的計算能力。

**Conclusion:** 本文明確區分LGNs深度擴展的兩大挑戰：優化崩潰與拓撲限制。IALGN透過引入輸入錨定拓撲，成功解決後者，實驗證明其能將深度轉化為實質的計算能力與性能提升。該方法保持了優化穩定性，並促進了逐層更具資訊性的表徵學習。限制在於研究僅針對平坦前饋LGNs，未探討在固定總閘數預算下的深寬權衡，也未涵蓋卷積或硬體優化版本。

**Research Gap:** 全文未明確說明IALGN在固定總閘數預算下與其他架構的比較，無法評估深度擴展是否在資源受限情況下仍具優勢。實驗集中於三個影像分類資料集，缺乏多樣化任務或更複雜場景的驗證，泛化能力尚待檢驗。消融實驗雖探討輸入錨定重要性，但對不同錨定策略或更複雜拓撲的比較不足。成本與部署風險未討論，尤其深層LGNs在硬體實現上的效率與延遲問題。最後，失敗案例與失效模式未被揭露，限制了對方法穩健性的全面理解。

**Intro:** 本論文探討圖神經網路（GNN）在長距離訊息傳遞任務中，因圖結構本身可能形成拓撲瓶頸，導致訊息無法有效傳播的問題。現有方法無法在訓練前快速判斷圖結構是否允許遠距離節點間的訊息流通。作者提出Spectral Flow Certificate（SFC），一種基於圖的正規化拉普拉斯算子計算的單一標量指標，無需訓練或標籤資料，即可預測GNN在特定深度下的長距離傳播能力。此方法能在秒級時間內完成計算，為GNN部署提供前置的拓撲限制診斷。論文中同時驗證SFC在多種合成及真實分子圖上的預測效果，顯示其具備高度解釋力。

**Motivation:** GNN透過局部訊息傳遞來學習節點表示，但當圖結構使遠距離節點間訊息難以傳遞時，無論訓練多長時間都無法克服此限制，尤其在長距離任務中問題更為明顯。現行做法通常需耗費大量計算資源完成訓練後，才發現拓撲瓶頸導致性能不佳，造成資源浪費。若能在訓練前快速判斷圖結構是否適合所選深度的訊息傳遞，將有助於工程師及研究者節省時間並做出更有效的架構或資料處理決策。

**Method:** 核心方法為定義Spectral Flow Certificate（SFC），其計算基於圖的正規化拉普拉斯矩陣的第二小特徵值（spectral gap）γ(G)，並結合訊息傳遞層數k，計算公式為SFC(G,k)=1-(1-γ(G))^k。此指標反映在k層訊息傳遞下，圖中關鍵的頻譜瓶頸能被克服的程度。SFC隨深度及spectral gap單調增加，能動態反映不同層數下的訊息流通能力。論文中證明SFC與訊息傳遞過程中特徵影響力衰減及互信息上限的關聯，並提出計算流程，強調其計算效率與無需訓練的特性。

**Result:** 實驗涵蓋25種合成圖家族及150個真實分子圖，評估SFC在不同深度（k=2,3,4）下對訓練後GNN長距離任務準確率的預測能力。合成圖上SFC的決定係數R^2超過0.86，真實分子圖資料集（ENZYMES、PROTEINS、MUTAG）中R^2介於0.58至0.77。與傳統結構指標如平均有效電阻和圖直徑相比，SFC解釋的變異量多出超過兩倍。當考慮多層數時，SFC比單純spectral gap多出約2.54%的預測力。小規模真實網絡驗證亦呈現正相關，但因樣本數有限，僅作輔助證據。

**Conclusion:** 本文提出的Spectral Flow Certificate為GNN長距離訊息傳遞提供了一個簡潔、可計算且無需訓練的拓撲診斷指標。其理論基礎穩固，能量化訊息在特定層數下穿越圖中頻譜瓶頸的能力，並與實際訓練結果高度相關。SFC可作為GNN部署前的快速篩選工具，幫助研究者及工程師判斷是否需進行圖重接線或架構調整，避免不必要的訓練成本。限制方面，SFC僅針對無向圖及正規化拉普拉斯算子，且只利用第二特徵值，對多重瓶頸或其他圖類型的適用性尚待擴展。

**Research Gap:** 本研究未涵蓋有向圖或其他非正規化拉普拉斯算子的情況，限制了SFC的通用性。僅使用第二小特徵值可能忽略多重瓶頸效應，未探討多特徵值版本的潛力。實驗中雖涵蓋多種合成及分子圖，但對於更大規模或異質性更高的圖結構驗證不足。此外，SFC僅為診斷工具，未提供直接解決方案，對於異質節點特徵、標籤噪聲及過平滑等其他GNN失效模式未涉及。消融實驗及與更多先進基線的比較也較有限，未明確評估計算成本與實際部署風險。全文未明確說明SFC在極端深度或特殊拓撲下的表現穩定性。
