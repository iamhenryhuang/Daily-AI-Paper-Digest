### 1. OpenForgeRL: Train Harness-native Agents in Any Environment

- arXiv: [2607.21557v1](http://arxiv.org/abs/2607.21557v1)
- 發表日期：2026-07-23
- 分類：cs.AI, cs.CL
- 入選理由：+2 提及頂級機構：mila; +3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #1 / 9/10: OpenForgeRL presents a novel, open-source framework enabling end-to-end training of harness-based agents in diverse environments with credible empirical validation and practical scalability, addressing a key limitation i

**Intro:** 現代 AI 代理人依賴複雜的推理 harness，如 Claude Code、Codex 和 OpenClaw，以支援多回合推理、工具使用及外部系統存取。然而，這些複雜的 harness 使得端到端訓練變得困難，因為現有的公開 SFT/RL 訓練架構無法原生支援有狀態、多進程的 harness 推理。本文提出 OpenForgeRL，一個開源框架，能在多樣環境中端到端訓練基於 harness 的代理人，解決了訓練與推理耦合的問題，並支援大規模分散式訓練。作者在多種複雜 harness 與環境中驗證其方法，涵蓋工具/Claw 代理及多模態 GUI 瀏覽器與電腦使用代理，並在多個基準上超越同規模公開模型。此框架同時促進對 harness 選擇與 RL 對代理行為影響的深入分析。

**Motivation:** 隨著 AI 代理人應用於軟體工程、工具使用及 GUI 控制等複雜開放環境，代理人不再是單純的語言或視覺語言模型，而是包裹在複雜的 harness 中以管理多回合互動與工具調用。現有公開訓練架構無法直接支援這類有狀態、多進程的 harness 推理，導致研究社群難以端到端訓練與改進這些代理人。此外，運行這些 harness 需要容器化環境，無法與訓練節點共置，造成訓練擴展性問題。OpenForgeRL 旨在解決這些技術瓶頸，讓研究者能在真實部署的 harness 與環境中訓練代理人，縮小與閉源系統的差距，並促進代理人能力提升與行為研究。

**Method:** OpenForgeRL 採用兩個核心組件：一是輕量級代理伺服器(proxy)，攔截並代理 harness 的模型呼叫，同時記錄 prompt-response 對作為 RL 訓練資料；二是 Kubernetes 編排器，於雲端啟動並管理多個獨立容器執行 rollout，實現大規模分散式訓練。此架構將訓練與推理解耦，允許任意 harness 在任意環境中運行，並將收集的互動軌跡轉換為標準 RL 訓練樣本。為解決 rollout 阻塞與錯誤問題，系統設置了 wall-clock 超時機制及錯誤樣本丟棄策略。此外，作者設計了自動化資料合成管線，生成多樣且可驗證的 SFT 與 RL 任務，涵蓋 CLI、GUI 及瀏覽器使用場景，支援多種 harness 訓練。

**Result:** 作者在多個複雜 harness（ReACT、ZeroClaw、OpenClaw、Codex）及多種環境（Claw、GUI 電腦使用、瀏覽器使用）上進行實驗。OpenForge-Claw（30B-A3B 模型）在 ClawEval、QwenClawBench 與 MCPAtlas 三大基準上，分別達到 31.7 pass3、55.9 pass@3 與 33.7 pass@1，優於同規模公開模型。OpenForge-GUI（8B 模型）在 OSWorld-Verified、Online-Mind2Web 與 WebVoyager 三個 GUI 基準上分別達到 37.7、63.0 與 72.3 pass@1，超越多數同規模模型，並匹敵或超越數倍規模模型。RL 訓練相較純 SFT 顯著提升成功率與行為可靠性，如自我驗證、工具覆蓋與多步計劃完成，但錯誤復原能力仍較弱。多 harness 訓練提升模型泛化能力，且較簡單、可擴展的 harness 容易學習。

**Conclusion:** OpenForgeRL 提供一個可擴展且靈活的訓練基礎設施，能將任意 harness 與環境結合，並與標準 RL 框架無縫整合，實現代理人在真實部署 harness 中的端到端訓練。實驗證明該框架在多種工具使用與 GUI 任務上均優於同規模公開模型，且在 GUI 領域達到與大型模型相當的表現。透過在真實 harness 中訓練，OpenForgeRL 促進了對 harness 選擇與 RL 對代理行為影響的深入理解。限制在於錯誤復原等關鍵能力仍未充分提升，且部分 harness 學習難度較高。作者計畫開源程式碼、資料與模型，期望推動 harness-based 代理人研究與應用。

**Research Gap:** 本文雖成功實現多 harness 與多環境的端到端訓練，但仍存在數項不足。首先，錯誤復原能力在 RL 訓練後仍表現薄弱，顯示現有訓練方法與資料不足以強化此關鍵能力，未來需設計專門資料或訓練策略。其次，部分複雜 harness（如 OpenClaw）學習成效有限，且使用更長提示與上下文，可能導致效率與穩定性問題，全文未明確提出解決方案。第三，雖有多 harness 訓練提升泛化，但對於更大規模、多樣化或實時變化的環境適應性尚未充分驗證。第四，系統依賴 Kubernetes 與雲端容器，部署成本與維護複雜度較高，對資源有限團隊可能造成障礙。最後，錯誤處理策略較為簡單，直接丟棄錯誤軌跡可能浪費有價值的部分資訊，未來可探索更精細的信用分配與錯誤容忍機制。

**Intro:** 深度研究任務面臨多重約束條件的挑戰，答案必須同時滿足這些約束，且發現有效答案的成本高昂。驗證候選答案相對容易，且可分解為多個約束的檢查。現有系統多透過延長搜尋時間來提升結果，但無法保證系統性進展，早期錯誤可能持續存在。本文提出AREX，一種遞迴自我改進的深度研究代理，透過內部研究循環與外部自我改進循環交替運作，利用部分驗證的狀態指導後續研究，提升研究效率與準確性。

**Motivation:** 深度研究中發現與驗證的非對稱性是核心問題：發現答案需在龐大且稀疏的搜尋空間中探索，成本高昂；而驗證則相對簡單且可分解。現有方法多依賴延長搜尋時間，無法有效識別未解決的約束，導致重複探索或接受不完整答案。透過將驗證結果作為控制信號，將部分驗證的答案轉化為更具針對性的研究問題，有助於系統性且有效率地推進研究，這對工程上長時間、多步驟的研究代理設計尤為重要。

**Method:** AREX採用雙層遞迴自我改進架構，包含內部研究循環與外部自我改進循環。內部循環負責執行研究行動、整合證據並產生臨時答案，外部循環則根據答案的約束逐項審核，識別未解決的問題並啟動針對性後續研究。為維持長期研究狀態，AREX學習自主的上下文更新工具，將累積的互動歷史壓縮為包含已驗證證據與未解決約束的精簡狀態。訓練過程包括合成任務、教師軌跡收集、多階段中期訓練及長期強化學習，並針對關鍵決策步驟加強訓練信號以解決稀疏回饋問題。

**Result:** AREX在多個深度研究與推理基準（如BrowseComp、WideSearch、DeepSearchQA、Humanity's Last Exam等）上，展現出超越同規模基線模型的性能，且在部分任務中與使用更多激活參數的模型競爭力相當。實驗中，4B參數的AREX-Turbo與122B參數的AREX-Base均取得穩定提升。消融實驗證實自主上下文更新與外部自我改進循環均顯著提升準確率，且關鍵步驟專注訓練與步驟感知強化學習對性能提升有明顯貢獻。

**Conclusion:** 本文提出的AREX架構有效利用深度研究中發現與驗證的非對稱性，透過遞迴自我改進機制將部分驗證的答案轉化為更精準的研究問題，並結合自主上下文更新與關鍵步驟訓練策略，提升長期研究任務的效率與準確性。實驗結果顯示AREX在多種複雜推理與工具使用任務中具備強大能力，展現了遞迴改進與驗證驅動狀態更新在深度研究代理中的應用潛力。限制在於全文未明確說明在更廣泛場景下的泛化能力及失敗案例分析，未來可進一步探索更自動化的步驟效用估計與細粒度訓練信號分配。

**Research Gap:** 全文未明確說明AREX在不同領域或非合成任務上的泛化表現，缺乏對失敗案例與錯誤類型的深入分析。訓練資料主要基於合成任務與教師軌跡，可能限制模型在真實世界複雜場景的適用性。雖然強調關鍵步驟訓練，但對於如何自動識別與量化步驟重要性仍未充分探討。此外，模型部署成本與實際運行效率未詳細說明，對於工程實踐中的資源限制與延遲要求缺乏評估。最後，外部自我改進循環的最大迭代次數與終止條件設定對性能影響未充分驗證，可能影響系統穩定性與可控性。

### 3. 3D-Aware VLMs with Implicit and Explicit Geometries

- 分數：5
- arXiv: [2607.21595v1](http://arxiv.org/abs/2607.21595v1)
- 發表日期：2026-07-23
- 分類：cs.CV, cs.AI, cs.LG
- 入選理由：+3 提及頂級會議：eccv; +2 提及程式碼可用; LLM rank #3 / 7/10: VLM-IE3D advances vision-language models by integrating implicit and explicit 3D geometries from RGB videos, demonstrating consistent improvements on multiple 3D tasks with open-sourced code, indicating practical usefuln

**Intro:** 現有多數視覺語言模型（VLMs）主要基於2D視覺輸入，難以有效處理需要細緻空間理解與推理的3D任務。這限制了模型在3D場景理解、定位與推理等應用上的表現。本文提出VLM-IE3D框架，通過從RGB影片中學習隱式與顯式3D幾何資訊，提升VLM的3D空間感知能力。該方法不依賴額外3D輸入，僅使用RGB資料，具備實用性與部署便利性。

**Motivation:** 目前多數基於隱式3D表示的VLM只能捕捉場景的粗略全局空間結構，缺乏細節幾何資訊，難以支持精確的3D定位與推理。人類認知中存在抽象的3D認知地圖與具體的3D重建地圖兩種空間表徵，現有模型多只模擬前者。機器人系統則依賴明確的3D重建地圖以獲取精確空間資訊。本文旨在彌補VLM中隱式與顯式3D表示的缺口，融合兩者優勢以提升3D任務表現。

**Method:** VLM-IE3D包含三個主要組件：首先，使用3D幾何編碼器（AnySplat）從RGB影片生成隱式幾何標記（IGTs），捕捉全局高階空間先驗；其次，從重建的3D屬性（如深度圖、點雲）經輕量嵌入模組生成顯式幾何標記（EGTs），提供細粒度結構資訊；最後，設計3D感知適配器，通過隱式-顯式注意力機制融合IGTs與EGTs，並與2D視覺標記結合，輸出統一的3D感知視覺表示，供預訓練VLM進行語言理解與推理。

**Result:** 在多個3D場景理解與空間推理任務中，VLM-IE3D展現出優異性能。於Scan2Cap 3D密集描述任務中，達成80.4%的C@0.5，超越多數僅用2D輸入方法；在ScanRefer 3D視覺定位任務中，未使用3D輸入下準確率達43.2%，顯著優於同類基線；3D視頻檢測任務中，F1分數提升至42.8%，較基線提升11.9。空間推理基準VSI-Bench上，4B參數模型亦超越多數更大規模模型。模型僅增加3.2%參數，推理速度輕微下降，具備實用部署潛力。

**Conclusion:** 本文提出的VLM-IE3D框架成功融合隱式與顯式3D幾何表示，從純RGB影片中注入強3D先驗，提升VLM在3D場景理解與空間推理任務的表現。實驗結果證明該方法在多種任務上均優於僅用2D輸入的先前方法，且與依賴3D輸入的方法競爭力相當。輕量的顯式嵌入設計與有效的融合策略使得模型在保持效率的同時提升精度，具備良好的工程與產品應用價值。

**Research Gap:** 本文雖展示隱式與顯式3D表示融合的優勢，但仍存在若干不足。首先，實驗主要聚焦室內場景與特定數據集，泛化至戶外或更複雜環境的能力未充分驗證。其次，顯式3D表示依賴3D幾何編碼器重建結果，對重建質量敏感，可能影響下游任務穩定性。第三，融合策略雖經多種比較，但對不同任務的最優融合方式仍未深入探討。最後，模型在實際部署中對計算資源與延遲的影響尚未全面評估，缺乏失敗案例分析與魯棒性測試，未來可針對這些方面進行補充。

### 4. DINOde: Continuous Vision-Text Alignment for Open-Vocabulary Semantic Segmentation

- 分數：5
- arXiv: [2607.21371v1](http://arxiv.org/abs/2607.21371v1)
- 發表日期：2026-07-23
- 分類：cs.CV, cs.AI
- 入選理由：+3 提及頂級會議：eccv; +2 提及程式碼可用; LLM rank #4 / 7/10: DINOde introduces a continuous ODE-based alignment method for open-vocabulary semantic segmentation with strong theoretical grounding and state-of-the-art results, accepted at ECCV and with code available.

**Intro:** 本論文聚焦於開放詞彙語義分割（OVSS），該任務旨在利用文本語義來分割超出預定義類別的物體。現有的自監督視覺模型DINOv3雖然具備強大的視覺結構化表示能力，但缺乏與文本語義的原生對齊，限制了其在OVSS中的直接應用。為解決此問題，作者提出DINOde，一種基於常微分方程（ODE）的框架，持續將CLIP文本嵌入映射到DINO視覺流形上。該方法透過連續軌跡避免了傳統離散映射的流形糾纏問題，提升跨模態對齊的穩健性。

**Motivation:** 在OVSS中，CLIP模型雖然提供了強大的視覺-文本對齊能力，但其視覺編碼器主要針對全局對齊優化，導致空間分辨率不足，難以應用於密集預測任務。另一方面，DINO系列自監督模型在視覺定位和空間結構保持上表現優異，但缺乏文本對齊能力。現有方法多採用單步MLP映射來對齊兩種特徵空間，卻忽略了特徵流形的幾何結構，導致語義鄰近關係被破壞。為此，提出一種連續且幾何保留的對齊策略，對工程和產品層面有助於提升模型泛化與細粒度語義分割的準確度。

**Method:** DINOde核心在於利用ODE學習一條連續的特徵轉換軌跡，將CLIP文本嵌入逐步演化至DINOv3視覺流形。方法包含兩大組件：語義文本流（STF）負責文本嵌入的連續對齊，全球上下文流（GCF）則細化DINO的[CLS]全局圖像表示。為保持特徵空間的超球面幾何，設計了速度切向投影（VTP），將速度場限制於切空間，確保流形結構不被破壞。訓練時採用對稱對比損失，利用COCO Caption資料集進行優化，推理時通過計算對齊後文本嵌入與DINO patch tokens的餘弦相似度完成語義分割。

**Result:** 實驗涵蓋八個主流OVSS基準，包括有無背景類別的多種資料集。結果顯示，DINOde在平均mIoU指標上超越多個先進方法，包括dino.txt和Talk2DINO，提升幅度約1.9%至2.3%。消融實驗證明STF、GCF與VTP三者均對性能有正向貢獻，且ODE步數約10步為性能與計算效率的最佳平衡。幾何診斷指標顯示，DINOde較傳統MLP映射更能保留特徵流形的鄰域結構與語義組織。此外，方法在不同視覺與文本骨幹網上均展現良好泛化能力。

**Conclusion:** 本論文提出DINOde，一種基於ODE的連續視覺-文本對齊框架，有效橋接了自監督視覺表示與文本語義空間的差異。透過語義文本流與全球上下文流的協同作用，並結合速度切向投影保留流形幾何，DINOde在多個OVSS基準上取得了領先的分割性能。該方法不僅提升了跨模態對齊的穩定性與細節表現，也為未來多模態大模型中視覺語言對齊提供了新的思路。全文未明確說明在更大規模資料或其他任務上的適用性與計算成本。

**Research Gap:** 本研究雖在多個基準上展現優異性能，但仍存在幾點不足。首先，全文未明確說明在更大規模或多樣化語料上的訓練效果與穩定性，限制了對方法泛化性的全面評估。其次，ODE整合步數與計算開銷的權衡未充分探討，實際部署時可能面臨效率瓶頸。此外，對於失敗案例、異常類別或極端場景的分析缺乏，難以評估方法在真實應用中的魯棒性。最後，雖有幾何診斷，但對比其他流形學習或非歐幾里得映射方法的消融較少，未充分驗證ODE基礎架構的相對優勢。這些均為後續研究可改進之處。

### 5. Streaming Multi-Agent Autoregressive Diffusion Model with World State Registers

- 分數：5

- 發表日期：2026-07-23

**Intro:** 多代理互動世界模型需要生成一致的觀察結果，並維持跨代理且隨視角演變的世界狀態。現有自回歸視訊擴散模型多以過去觀察作為條件，難以在多代理多視角下維持共享狀態。本文提出WorldWeaver，一種串流多代理視訊擴散模型，透過可學習的世界狀態註冊器來存儲共享世界資訊，追蹤個別代理狀態，並在每個生成區塊後動態更新。此設計旨在提升多代理視訊生成的邏輯一致性與品質。

**Motivation:** 多代理系統中，每個代理僅觀察部分視角，如何保持跨代理間的世界狀態一致性是挑戰。傳統方法依賴過去影像作為條件，無法有效捕捉未觀察到的世界變化，導致生成結果在邏輯和幾何上不一致。明確建模並持續更新共享世界狀態，有助於提升多代理視訊生成的穩定性與真實感，對於工程實作和產品落地具有重要意義。

**Method:** WorldWeaver引入世界狀態註冊器（WSR），一組可學習的tokens，持續跨代理和生成步驟更新，攜帶全局場景和代理狀態資訊。模型架構採用Mixture-of-Transformers設計，分別處理視覺影像與世界狀態tokens，減少兩者目標間的衝突。訓練分三階段：第一階段使用雙向注意力訓練教師模型；第二階段轉為因果注意力並加入世界狀態監督，包括代理狀態、鳥瞰圖和場景文字；第三階段採用自我強迫訓練，模擬長時間生成過程中狀態與影像的誤差累積，提升模型穩定性。

**Result:** 在兩代理Minecraft視訊生成任務中，WorldWeaver在多項指標上優於基線模型，包括VLM準確率和FID分數。特別是在狀態敏感類別如Grounding、Building和Consistency上有顯著提升，顯示世界狀態註冊器有效維持跨代理邏輯一致性。監督信號分析顯示，結合代理狀態、鳥瞰圖與場景文字的多重監督能進一步提升性能。架構分析指出，Mixture-of-Transformers在有監督信號時能更好地處理世界狀態表示。半監督實驗表明，少量標註資料結合大量未標註視訊仍能提升生成品質。

**Conclusion:** 本文提出的WorldWeaver模型透過持續更新的世界狀態註冊器，有效提升多代理視訊生成的邏輯一致性與視覺品質。多重監督信號幫助世界狀態表示更具可驗證性，Mixture-of-Transformers架構則穩定了狀態與影像生成的學習過程。此方法在Minecraft多代理場景中展現良好效果，並具備半監督擴展潛力。限制在於真實世界狀態更為複雜且難以標註，模型尚未驗證於更廣泛場景，未來可探索更豐富狀態表示與實際應用。

**Research Gap:** 本文主要依賴模擬環境中可獲得的代理狀態、鳥瞰圖與場景文字監督，真實世界中此類標註難以取得，限制了方法的泛化性與實際部署。實驗僅限於兩代理Minecraft場景，缺乏多代理數量擴展和其他複雜環境的驗證。模型對於狀態註冊器大小、更新頻率及監督信號權重的敏感度分析不足。消融實驗雖有，但對於不同架構設計的比較仍有限，且未明確說明計算成本與推理延遲對實際系統的影響。此外，失敗案例與模型在長時間生成中的穩定性問題未充分揭示。
