### 1. When LLM Agents Fail to Read the Room: ReAdapt for Relational Social Reasoning

- 分數：5
- arXiv: [2609.25284](https://arxiv.org/abs/2609.25284)
- 發表日期：2026-09-23
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #1 / 9/10: Proposes a novel, structured relational social reasoning method (ReAdapt) that significantly improves LLM agent decision-making on a new benchmark with credible quantitative evidence, addressing a clear failure mode in s

**Intro:** 社交代理在決策時，往往不僅依賴內容本身，而是需要理解人與人之間的潛在關係，如關係強度、互惠性及共同連結。現有基於大型語言模型（LLM）的代理循環，缺乏明確機制將新觀察到的關係證據用於修正當前社交假設，導致在關係線索與內容線索不一致時容易做出表面化的錯誤決策。本文提出一個關係推理基準，並針對此問題提出改進方法。

**Motivation:** 在工程與產品層面，社交智能代理需能根據複雜且分散的關係證據做出合理決策，這對於推薦系統、社交媒體互動等應用至關重要。現有方法雖能檢索相關證據，但缺乏將證據轉化為決策修正的明確機制，導致代理在實際應用中無法有效利用關係資訊。解決此問題有助提升代理的決策準確度與社交適應性，促進更自然且有效的用戶互動。

**Method:** 本文提出ReAdapt方法，基於ReAct循環，新增一個結構化的社交狀態表示z=(G,B,R,N,D)，分別捕捉目標、信念、關係、規範與資訊揭露五個維度。每次工具觀察後，ReAdapt執行一個Adapt步驟，明確更新社交狀態並輸出一個策略操作（繼續、切換、放棄或澄清），再根據更新後的狀態與操作決定下一步行動。此設計強制代理將新證據轉化為對當前假設的明確修正，而非僅在語言模型上下文中隱式推理。

**Result:** 在500個合成社交世界中，針對兩項任務（反應選擇與暖場引介）共1000個查詢，使用Gemini-3-Flash模型在300個分層查詢子集上評估。結果顯示，ReAdapt在暖場引介任務的整體準確率從37%提升至51%，反應選擇任務從69%提升至77%。在關係證據與表面線索衝突的覆蓋案例中，暖場引介準確率提升16個百分點，反應選擇提升6個百分點。Oracle regret指標亦顯著下降，顯示錯誤決策的嚴重性降低。

**Conclusion:** 本文提出的ReAdapt方法通過明確的社交狀態更新與策略操作，有效促進了LLM代理將檢索到的社交證據轉化為決策修正，提升了關係推理能力。實驗結果支持在社交代理設計中引入結構化狀態與策略驅動的更新機制，有助於解決證據與決策脫節的問題。然而，本文方法主要驗證於合成社交環境，且未細分各狀態維度與策略操作的獨立貢獻，仍需進一步驗證於真實場景與更複雜社交網絡。

**Research Gap:** 本文雖提出結構化社交狀態更新機制，但全文未明確說明各狀態維度（如規範與資訊揭露）在任務中的具體作用與必要性，缺乏對這些組件的消融實驗。此外，實驗僅限於合成社交世界，未涵蓋真實社交網絡的多樣性與動態性，泛化能力尚不明確。策略操作的選擇與效果未有細緻分析，且ReAdapt在計算成本與工具調用次數上略高於基線，部署風險與效率問題未充分討論。最後，缺乏對失敗案例的系統性分析，無法全面評估方法的穩健性與局限。

### 2. Ovis-Embedding: Pushing the Frontiers of Universal Omni-Modal Embeddings

- 分數：5
- arXiv: [2609.25165](https://arxiv.org/abs/2609.25165)
- 發表日期：2026-09-23
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mila; +3 收錄於 Hugging Face Daily Papers; LLM rank #2 / 8/10: Introduces a unified omni-modal embedding model with native multimodal backbone and novel training strategies, achieving state-of-the-art results across multiple benchmarks, demonstrating clear novelty and practical valu

**Intro:** 本論文提出Ovis-Embedding，一套原生整合文字、影像、影片與音訊的全模態嵌入模型。現有多模態嵌入多以分別訓練各模態後再融合，或是將音訊附加於視覺語言模型，導致跨模態對齊不足。Ovis-Embedding直接採用預訓練的Qwen-Omni模型作為共享骨幹，將多種模態映射至同一語意空間，支援任意模態間的檢索。此模型涵蓋多種下游任務，包含分類、問答、檢索與定位，並在多個大型多模態基準上展現優異表現。

**Motivation:** 隨著資料庫融合多種模態，傳統只針對特定模態對的檢索方法已無法滿足需求。實務中，使用者可能以多模態查詢檢索不同模態的資料，需一套統一且一致的嵌入空間來支援任意模態間的匹配。現有多模態系統多半分模態訓練，缺乏原生融合，導致跨模態細節對齊不足。Ovis-Embedding旨在解決此問題，提升跨模態檢索的準確度與泛化能力，對工程與產品端的多模態檢索系統落地具重要意義。

**Method:** Ovis-Embedding採用三大核心技術：首先，使用預訓練的Qwen-Omni模型作為共享骨幹，直接處理文字、影像、影片與音訊，無需額外模態專屬投影頭。其次，構建涵蓋多模態及多任務的高品質大規模訓練資料集，並引入同源抽樣策略，確保微批次內資料來源一致，提升難負樣本的資訊量與訓練效率。第三，設計嵌入專屬的訓練優化，包括焦點損失強化難例學習，以及透過相似度蒸餾將教師模型的細緻相似度結構轉移給學生模型。推理階段則利用低秩特徵分解實現彈性維度的緊湊嵌入，降低儲存與計算成本。

**Result:** 在MMEB-v3、MMEB-v2、MAEB、MVEB與RTEB等多個多模態檢索基準上，Ovis-Embedding展現領先表現。以3B參數的Ovis-Embedding-Omni-3B為例，整體分數超越多數7B及更大模型，且在影像、影片、視覺文件、文字、音訊與代理任務均取得最高分，顯示其跨模態能力均衡且強大。焦點損失與蒸餾策略有效提升模型對難例的辨識能力。低秩分解與殘差適配器結合，實現多維度嵌入的性能與效率平衡。視覺語言版本在MMEB-v2上亦優於同規模競品，且模型擴大帶來顯著性能提升。

**Conclusion:** Ovis-Embedding提出一種基於原生多模態骨幹的統一嵌入方案，結合資料中心訓練與嵌入專屬優化策略，成功實現任意模態間的高效檢索。實驗證明其在多種多模態基準上均達到或超越現有最佳結果，且具備彈性維度以適應不同部署需求。此工作為多模態檢索系統的工程實踐提供了堅實基礎，並推動了全模態嵌入模型的研究與應用。

**Research Gap:** 論文中雖涵蓋多種模態與任務，但對於多條件文本檢索（MultiConIR）及長期記憶檢索表現仍有不足，顯示模型在複雜語義約束與長距離依賴方面尚待加強。實驗主要聚焦於公開及部分專有資料，泛化至更多真實世界場景與極端模態組合的能力未充分驗證。低秩分解雖提升推理效率，但對於極端壓縮維度下的性能損失與實際部署成本仍需更詳細分析。此外，模型對失敗案例的定性分析與錯誤類型探討較少，限制了對模型弱點的深入理解。最後，全文未明確說明多模態交互中不同模態權重調節的機制，未來可探討更動態的融合策略以提升跨模態對齊精度。

**Motivation:** 核融合裝置的診斷數據來源多樣且採樣頻率差異大，如何有效融合異構數據並同時處理多個診斷任務，是提升診斷準確性與效率的挑戰。現有方法多採用硬參數共享，容易導致任務間衝突與優化不平衡，且對高頻信號的計算成本高。為了實際應用於核融合裝置的運行監控與預警，亟需一套能兼顧多模態、多任務且能處理異構數據特性的統一框架。

**Research Gap:** 本文雖然在EAST數據集上展現優異性能，但缺乏對其他核融合裝置數據的驗證，泛化能力尚未充分評估。多任務間的負遷移風險與任務間權重調整仍依賴三階段優化，缺少更自動化或動態的優化策略。高頻信號壓縮雖降低計算成本，但對快速變化事件的細節捕捉可能受限，全文未提供相關失效案例分析。此外，模型在實際線上部署的計算資源需求與實時性能未明確說明，對工業應用的可行性評估不足。最後，ELM識別中部分時段仍有誤判，顯示模型在某些邊界情況下的魯棒性仍需提升。

### 4. A Behavioral Trait Leaks into Preferences: Diagnosing Trait Interference in LLM User Simulators

- 分數：4
- arXiv: [2609.25572](https://arxiv.org/abs/2609.25572)
- 發表日期：2026-09-23
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: Identifies and mitigates a subtle failure mode (trait interference) in LLM-based user simulators with a novel method (PQA), supported by experiments and code release, improving evaluation reliability.

**Intro:** 本論文探討基於大型語言模型（LLM）的用戶模擬器在推薦系統評估中的應用，特別關注用戶行為特徵與偏好特徵之間的相互影響。現有模擬器透過注入偏好屬性與行為活動特徵來模擬用戶行為，但作者發現行為活動特徵會干擾偏好判斷，導致模擬結果失真。此問題不僅影響模擬器的行為真實性，也使得基於滿意度的評估指標失去效度。論文提出一種新的方法以解決此問題，並在兩個公開資料集上進行實驗驗證。

**Motivation:** 推薦系統的離線評估常因缺乏真實用戶反饋而不準確，LLM用戶模擬器透過注入用戶特徵嘗試彌補此缺口。然而，行為活動特徵在模擬過程中會影響偏好判斷，造成模擬用戶瀏覽大量不符合偏好的項目，這與真實用戶行為不符，且使得評估指標被活動特徵扭曲，無法真實反映推薦系統性能。從工程與產品角度看，這會導致模型調整方向錯誤，浪費資源且影響用戶體驗，因此亟需解決此干擾問題。

**Method:** 作者提出PQA（Page-level Quality Anchoring）方法，核心在於為每位用戶建立個人化的頁面品質錨點，該錨點基於用戶歷史互動中偏好類別的重疊度計算得出。模擬器在瀏覽每頁推薦內容前，先評估該頁是否達到用戶的偏好標準，並根據品質標籤（ABOVE、NORMAL、BELOW）決定是否繼續瀏覽。此機制使得行為活動特徵只能在偏好符合的頁面中調節瀏覽深度，避免因活動強度而無差別瀏覽不相關項目，從而保持偏好與行為特徵的獨立性。

**Result:** 實驗在MovieLens與Amazon CDs兩個資料集上，使用Agent4Rec與SimUSER兩種LLM模擬器進行。結果顯示，PQA有效減少了高活動強度下的過度瀏覽現象，提升了模擬器在不同活動分布下的評估可靠性。利用PQA生成的模擬互動資料進行推薦模型微調，顯著提升了NDCG@5與HR@5指標，證明模擬數據更貼近真實用戶偏好。此外，GPT-4o評估模擬行為的人類相似度也因PQA而提升，顯示模擬行為更自然合理。

**Conclusion:** 本論文揭示了LLM用戶模擬器中行為活動特徵對偏好判斷的干擾問題，並提出PQA方法以個人化頁面品質錨點約束瀏覽決策，有效恢復特徵獨立性並提升評估效度。實驗結果支持PQA在減少過度瀏覽、提升模擬數據質量及人類相似度方面的價值。論文也指出未來可將PQA擴展至更細緻的偏好指標，如項目間關係或協同過濾信號，以進一步捕捉用戶偏好多樣性。

**Research Gap:** 論文雖驗證PQA在兩個資料集與兩種模擬器上的效果，但全文未明確說明其在更多推薦場景或更複雜用戶行為下的泛化能力。此外，PQA依賴用戶歷史類別重疊度作為品質錨點，對於新用戶或資料稀疏情況的適用性未被探討。實驗中對模擬器與推薦模型的計算成本及部署風險亦未評估。最後，缺乏對PQA在極端行為模式或失敗案例的分析，限制了對方法穩健性的全面理解。

### 5. ChatT2: An Adaptive Framework for Developing a Large Language Model-Based Agent for Natural Product Domain Research

**Motivation:** 天然產物研究涉及龐大且多樣的資料庫，使用者需具備跨領域知識與資料庫查詢技能，門檻高且效率低。一般LLM缺乏專業工具整合與自我評估機制，導致結果不可靠。單一代理難以處理複雜多步驟任務且缺乏監控，易產生錯誤。為解決這些問題，ChatT2設計多代理系統，結合檢索增強生成與專業工具，提升查詢的準確性與可追溯性，並降低使用者負擔，促進研究落地與應用。

**Method:** ChatT2架構包含三個LLM驅動代理：導師(mentor)、執行者(executor)與評估者(evaluator)。導師負責解析用戶意圖並透過連鎖思考(chain-of-thought)引導執行者分步檢索與整合多模態資料。執行者採用檢索增強生成(RAG)方法，從關聯式資料庫、向量資料庫、影像庫及工具庫中檢索相關資訊，並結合生物資訊與化學資訊工具生成回應。評估者則在檢索前、中、後階段監控結果，拒絕無法回答的問題，過濾無關資訊，並追蹤引用來源以確保回應的可靠性與科學性。系統支持多輪互動與動態問題細化，並設計了多層次歷史訊息管理以優化代理間溝通。

**Result:** 作者建立了專門針對類型II聚酮類的NPBENCH基準數據集，涵蓋生物合成、結構、功能、應用及分類五大研究場景，共50個開放式問題。ChatT2在單輪與多輪評估中均優於主流LLM，特別在生物合成、功能與應用類別表現顯著提升。評估指標包括科學準確性、一致性、相關性、具體性與可理解性，並利用GPT-4自動評分及專家驗證。多輪互動中，ChatT2展現問題多樣性與答案豐富性，能動態調整查詢策略，提供更全面且具引用支持的回答。實驗顯示，ChatT2即使基於較小模型，也能超越大型模型表現，適合學術與實驗室環境使用。

**Conclusion:** 本文提出的ChatT2多代理框架有效解決了LLM在天然產物專業領域的知識理解與信息檢索挑戰。系統結合多資料庫與專業工具，並透過導師、執行者與評估者協同工作，提升回答的科學性與可靠性。實驗結果證明ChatT2在類型II聚酮類研究中具備優越性能與實用價值，並展現良好的多輪互動能力。該框架為跨領域科學研究提供了一種可擴展且可驗證的智能助手方案，促進知識傳播與研究效率提升。

**Research Gap:** 本文主要聚焦於類型II聚酮類天然產物，對其他天然產物子領域的適用性與效能尚未充分驗證。外部知識庫建構仍需大量人工篩選與擴充，限制了系統的自動化與擴展性。系統高度依賴底層LLM的能力，對模型更新與實時知識整合的支持有限。多代理間的協同策略與錯誤處理機制雖有設計，但對於複雜任務的泛化能力及失敗案例分析不足。成本與部署風險未明確討論，尤其在資源受限環境下的實際應用挑戰。未見對用戶體驗中可能出現的交互瓶頸及多語言支持的深入評估。未來需加強跨領域資料庫自動化擴充、模型自我評估與動態更新能力，以及多代理協同的穩定性與效率分析。
