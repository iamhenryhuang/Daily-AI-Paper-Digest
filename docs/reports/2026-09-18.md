### 1. The Other Half of the Memory Wall: Serving 35B MoEs from SSD with Trained Routing Prediction

- 分數：5
- arXiv: [2609.18063](https://arxiv.org/abs/2609.18063)
- 發表日期：2026-09-17
- 分類：cs.AI
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #1 / 9/10: Presents a novel, practical solution (Edge0) for serving large MoE models efficiently on limited hardware with credible experiments and open-source code, addressing a key bottleneck in MoE deployment.

**Intro:** 本論文聚焦於Mixture-of-Experts (MoE)模型在消費級硬體上的推理瓶頸，特別是權重記憶體限制。35B級別的MoE模型即使量化到4-bit，權重仍高達19.5GB，且稀疏性只減少計算量，無法減少必須儲存的權重大小。傳統將權重全部載入記憶體的方式，在24GB記憶體的桌面機上無法同時容納模型與系統需求，造成效能瓶頸。

**Motivation:** 將權重直接放在SSD上並非解決方案，因為MoE層間的專家選擇依賴前一層輸出，導致無法提前讀取下一層權重以遮蔽磁碟讀取延遲。這使得推理過程中頻繁等待磁碟I/O，嚴重影響速度。如何在有限記憶體下，利用SSD存取大模型權重，同時避免I/O延遲成為關鍵挑戰。

**Method:** 提出Edge0推理引擎，核心是引入一個訓練好的prerouter，該prerouter在每層預測下一層的路由決策，提前一個token進行專家選擇，讓SSD讀取權重能與計算重疊。預測結果直接作為路由使用，避免丟棄任何專家權重。為彌補4-bit量化與路由替換造成的品質損失，設計了unmerged recovery LoRA，作為平行增量適配器，並在學生路由路徑上訓練以恢復性能。整體架構支援多種路由策略與量化格式，並以固定槽位機制管理權重緩存。

**Result:** 在單台24GB記憶體的Mac mini M4 Pro上，Edge0成功以約20 tokens/s速度推理35B MoE模型，峰值活躍記憶體僅約3GB，遠低於傳統需18GB以上的常駐方式。與原始fp16模型相比，平均性能損失約3.9分（滿分100），在五個公開基準測試中表現接近。8B模型版本在相同框架下達到28 tokens/s，峰值記憶體約1.5GB。實驗中使用了同場景A/B測試，確保結果可比較且穩定。prerouter顯著減少因磁碟讀取造成的阻塞時間，提升約80%以上的解碼速度。

**Conclusion:** Edge0提出了一種將MoE權重存放於SSD並利用訓練路由預測消除I/O延遲的創新架構，實現了在消費級硬體上高效推理超大規模MoE模型。結合4-bit量化與unmerged LoRA適配器，成功在有限記憶體環境下維持接近fp16模型的性能。此系統開源，具備實際部署價值，尤其適合記憶體受限且無法使用大型伺服器的場景。

**Research Gap:** 本論文的限制包括：1) 僅支持單請求序列化推理，缺乏多請求併發與批次處理的實驗與分析，對實際服務場景的適應性尚不明確；2) prerouter的效益依賴於存取延遲與記憶體緊張程度，對高速存儲或大記憶體環境下的優勢未充分驗證；3) 長鏈推理任務中品質下降較明顯，顯示4-bit量化與路由預測仍有改進空間；4) 系統目前decode階段CPU負擔較重，圖譜建構耗時未優化，可能限制更低延遲需求；5) 實驗主要在蘋果M系列硬體上進行，泛化至其他硬體架構或更大模型尚未驗證；6) 對於不同路由策略與更廣泛模型結構的適用性與穩定性缺乏深入比較與消融研究。

### 2. CERA-MoA: Co-Evolving Routing Mechanisms with Continually Learning LLM Agents

- 分數：5
- arXiv: [2609.18779](https://arxiv.org/abs/2609.18779)
- 發表日期：2026-09-17
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; LLM rank #2 / 8/10: Introduces a novel co-evolution framework for routing and agent fine-tuning in Mixture-of-Agents, with strong empirical evidence of outperforming state-of-the-art baselines across domains.

**Intro:** 本文針對現有 Mixture-of-Agents (MoA) 系統中查詢路由與代理微調分離的問題，提出一種協同演化的框架 CERA-MoA。傳統方法無法隨著代理能力的演進動態調整路由策略，導致代理無法專精特定領域。CERA-MoA 透過強化學習迭代地共同優化路由器與代理策略，促進代理能力分化與專業化。此方法在多個領域的實驗中展現優於靜態路由與固定工作流程微調的效果。

**Motivation:** 隨著代理能力在後訓練階段持續演進，現有路由策略無法動態適應代理能力變化，且缺乏根據代理專長分配訓練樣本的機制，導致代理無法形成互補專長。這種路由與學習分離的設計限制了系統整體效能提升與專業化發展。工程與產品層面，動態且能力感知的路由能有效提升推理效率與準確度，降低不必要的計算成本，對於多代理系統的實際部署與維護具有重要意義。

**Method:** CERA-MoA 採用一個包含參數化路由器與多個持續學習代理的閉環強化學習框架。核心是設計一個預測熟悉度估計器，利用中層隱藏狀態計算輸入查詢與代理專長的語義相似度，避免昂貴的完整生成評估。基於熟悉度分數，採用累積閾值的自適應路由機制，動態選擇最小子集代理以平衡效能與效率。訓練時，路由器根據代理表現調整熟悉度估計，並將訓練樣本分配給最適合的代理，促進能力分化。代理則使用強化學習方法（如 DAPO）更新策略。

**Result:** 在多個數學推理、程式碼生成、指令跟隨與一般推理資料集上，CERA-MoA 在不同基礎模型（如 Qwen3-4B、Llama-3.2-3B、Phi-4-mini）均超越多種靜態路由與固定工作流程微調基線。實驗涵蓋內部分布與外部分布測試，均展現顯著性能提升。消融實驗證明預測熟悉度估計器優於直接獎勵回歸與多分類方法，累積閾值路由有效平衡效能與計算成本。此外，代理間自發形成互補專長，且路由器能根據查詢難度動態調整啟用代理數量。

**Conclusion:** CERA-MoA 成功整合路由與代理持續學習，通過語義熟悉度評估與累積閾值路由實現高效且精準的查詢分配，促進代理專業化並提升整體系統效能。該框架具備靈活性，支持共享基礎模型或異構模型組合，適用於多種任務與場景。限制方面，全文未明確說明多輪互動或多代理辯論的擴展效果，且對於大規模代理數量下的計算成本與路由穩定性尚缺乏深入分析。

**Research Gap:** 本文雖展示了單輪查詢的語義路由與代理協同演化，但未探討多輪交互或多代理辯論場景下的適用性與效能。實驗中代理數量較少，缺乏對大規模代理池的擴展性與計算負擔評估。熟悉度估計器依賴固定中層隱藏狀態，對於模型架構變化或更複雜語義關係的泛化能力未充分驗證。缺少對失敗案例或路由錯誤對系統整體影響的分析。此外，訓練過程中探索策略與樣本分配的穩定性與收斂性細節未充分揭示，可能影響實際部署的可靠性。

### 3. EvolveTrade: Experience-Driven Policy Refinement for Self-Evolving LLM Trading Agents

- 分數：5
- arXiv: [2609.17632](https://arxiv.org/abs/2609.17632)
- 發表日期：2026-09-17
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; LLM rank #3 / 8/10: Proposes a self-evolving LLM trading agent framework that adapts policies based on feedback, showing practical improvements in financial metrics with detailed behavioral analysis.

**Intro:** 本論文針對大型語言模型（LLM）在金融交易代理中的應用，指出現有系統多依賴固定且手寫的工具使用策略，無法隨市場環境變化自我調整。這限制了代理在資訊蒐集、信號驗證及風險管理上的靈活性與適應性。作者提出EvolveTrade，一種將系統提示視為可文本參數化策略的自我演化框架，透過交易決策軌跡與實際投資組合回饋，定期由一個策略代理更新該策略文本，進而提升代理的決策品質。此方法不需重新訓練LLM本體，僅調整策略文本，具備實務部署的便利性。

**Motivation:** 金融市場環境多變且反饋延遲，固定策略無法因應不同市場階段的特性，導致分析指標與工具使用趨於單一且不具彈性。實驗顯示靜態策略在不同市場階段（如盤整、下跌、上漲）下，分析指標使用高度重複且忽略了階段相關的關鍵指標。這種固定策略限制了LLM代理的表現，且無法從過去交易經驗中學習改進。故需要一種能根據實際交易結果與決策過程，自我調整工具使用與決策流程的機制，以提升代理的適應性與穩健性。

**Method:** EvolveTrade框架將LLM交易代理的系統提示視為可編輯的策略文本，並在每個固定的交易批次結束後，由一個獨立的策略代理（同為LLM）根據該批次的決策軌跡與實際投資組合回饋，生成新的策略文本。該策略文本指導代理如何使用工具（如價格查詢、新聞檢索、程式碼執行）及風險管理。核心流程包括：1) 代理在交易日內依策略文本使用工具並做出配置決策；2) 收集決策與回饋形成精煉記錄；3) 策略代理分析記錄，識別策略缺陷並生成改進後的策略文本；4) 新策略文本用於下一批次交易。此過程不改動LLM模型參數，僅更新策略文本，確保部署簡便且可持續演化。

**Result:** 實驗在多個市場階段（盤整、下跌、上漲等）及兩種LLM骨幹（GPT-5-mini與Gemini-2.5-Flash）上進行，評估指標包括夏普比率、累積報酬、最大回撤、勝率及波動率。結果顯示EvolveTrade在多數市場階段與模型組合中，均優於固定策略的LLM基線，並在部分情況超越傳統規則基準。行為分析揭示EvolveTrade能激活靈活且階段相關的分析指標（如VaR、EMA、RSI等），並增加程式碼工具的使用頻率。案例研究中，EvolveTrade透過調整持股比例成功降低風險暴露，提升實際回報。長期測試亦顯示策略文本不會無限膨脹，且性能持續穩定。

**Conclusion:** 本研究提出的EvolveTrade框架有效解決了LLM交易代理中策略固定不變的問題，透過自我演化策略文本，使代理能根據自身交易經驗調整工具使用與決策流程，提升風險調整後的績效與適應性。此方法不需重新訓練模型，具備實務應用潛力。實驗結果支持持續策略更新是強化LLM交易代理的關鍵方向。限制方面，政策更新頻率固定且未考慮動態調整，交易成本模型較簡化，未涵蓋滑點、市場衝擊與流動性限制，未明確探討泛化至其他資產類別或更長期市場環境的表現。

**Research Gap:** 全文未明確說明策略代理在面對極端市場事件或突發黑天鵝事件時的穩健性與失敗案例，缺乏對策略更新過程中可能過擬合短期噪聲的深入分析。實驗中交易成本考量較為簡化，未納入滑點與市場衝擊，可能影響真實部署效果。策略更新間隔固定，未探討動態調整更新頻率以因應市場波動的可能性。資料集僅涵蓋美國藍籌股，缺乏跨市場、跨資產類別的泛化驗證。消融實驗主要聚焦於工具使用與策略更新，對不同策略代理設計細節及其對性能的影響說明不足。全文未提供程式碼或詳細實現細節，限制了復現與工程落地的便利性。

### 4. Reasoning through Evolution: Automatic Meta-path Discovery for LLM-based Fake News Detection

- 分數：4
- arXiv: [2609.18597](https://arxiv.org/abs/2609.18597)
- 發表日期：2026-09-17
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：meta, mila, mit; +2 提及程式碼可用; LLM rank #4 / 7/10: Addresses fake news detection by bridging LLM reasoning with graph structure via an automatic meta-path discovery framework, supported by extensive experiments and available code.

**Intro:** 假新聞的快速傳播對社會造成嚴重影響，偵測假新聞成為重要課題。傳統方法多依賴小型語言模型或圖神經網絡，這些方法需要大量標註資料且泛化能力有限。大型語言模型（LLM）雖具備強大推理能力，但直接輸入原始傳播圖會導致模態不匹配與資訊過載，影響零樣本與少樣本設定下的效能。本文提出一種基於遺傳演算法的多代理框架MAGER，自動發現適合LLM推理的meta-path，藉由壓縮複雜傳播圖為資訊豐富的子圖，減輕資訊過載與模態不匹配問題。

**Motivation:** 現有假新聞偵測方法依賴大量標註資料且泛化能力弱，難以適應不斷變化的新聞環境。LLM具備跨任務泛化能力，但缺乏結構化傳播訊息的有效整合，導致推理效果不佳。傳播結構提供關鍵的真偽判斷線索，但如何將其有效轉換為LLM可理解的形式仍是挑戰。手工設計的meta-path無法涵蓋多樣且實例特定的傳播模式，限制了結構訊息的利用。故需自動化方法發現與LLM推理相匹配的meta-path，提升結構化推理能力。

**Method:** MAGER框架包含四個LLM代理：增強代理負責細化節點與邊的語義類型，擴展meta-path搜尋空間；生成代理利用語義交叉與突變操作生成候選meta-path；偵測代理基於子圖與結構語義相似示例進行真偽分類並產生推理解釋；評估代理評估偵測代理的推理合理性。整體採用遺傳演算法進行meta-path的選擇、變異與適應度評估，適應度結合分類準確率與推理品質。推理品質透過評估代理對偵測代理解釋的評分實現。推理過程中引入圖結構的上下文學習，根據語義與結構相似度檢索示例，強化少樣本推理能力。演化結束後，利用多個優化meta-path加權融合進行推理。

**Result:** 在PolitiFact、GossipCop及MCFEND三個假新聞資料集的低資源設定下，MAGER顯著優於純文本及全圖輸入的LLM基線，準確率提升約6.8%至8.8%。與傳統監督式SLM及混合LLM+SLM方法相比，MAGER在無需微調的情況下展現更佳的泛化能力。跨領域測試中，MAGER在未微調情況下仍維持較高準確率與F1分數，顯示其結構化推理具備較強的領域不變性。消融實驗證實演化機制、推理適應度、圖結構上下文學習及語義增強均對性能有顯著貢獻。不同LLM骨幹（如Qwen3-8B、Llama3-8B、GPT-4）均能搭配MAGER實現穩定提升，顯示方法具備良好適應性與實用性。

**Conclusion:** 本文提出的MAGER框架成功解決了LLM在假新聞偵測中面對傳播圖模態不匹配與資訊過載的問題，通過自動演化meta-path結構，將複雜傳播圖壓縮為結構化且易於LLM推理的子圖，並結合圖結構上下文學習提升推理效果。實驗結果證明MAGER在低資源及跨領域場景下均優於現有方法，展現出強大的結構化推理能力與數據效率。演化過程離線完成，推理階段無需重新優化，具備實際部署潛力。

**Research Gap:** 本文雖在三個資料集及低資源設定下驗證了方法有效性，但未明確說明在更大規模或更複雜社交網絡中演化meta-path的計算成本與時間效率。演化過程依賴有限標註資料，對極端零樣本場景的適應性尚不清楚。推理合理性評估依賴代理模型，可能存在評估偏差，未提供對失敗案例的深入分析。方法對不同類型假新聞（如政治、健康等）的泛化能力及對抗性魯棒性未充分探討。最後，全文未明確說明在實際線上系統中部署MAGER的延遲與資源消耗，對工程落地的挑戰仍需進一步評估。

**Intro:** 生物實驗中大量重複性手動操作需要自動化以提升效率。現有的視覺-語言-動作（VLA）策略雖然提供通用操作介面，但在環境變化時性能顯著下降。WetRobo提出一套可跨實驗室轉移的機器人套件，包含機械臂、實驗設備、基礎控制程式碼、示範錄影及技能描述文件，讓生物實驗者無需進行遙控操作或神經網絡訓練，即可委派機器人執行任務。該系統透過編碼代理觀察現場環境，自動撰寫並執行控制程式，實現任務適應。此研究聚焦於實驗室機器人自動化的實用性與可重複性。

**Motivation:** 生物實驗室多樣且變動的環境限制了基於深度學習的VLA策略的泛化能力，導致每個實驗室需重新收集示範資料並訓練模型，增加部署成本與門檻。WetRobo旨在解決此問題，通過提供標準化硬體與軟體套件，結合編碼代理的程式碼生成能力，實現跨實驗室的任務轉移與自動適應，降低生物實驗者的技術負擔，促進機器人技術在日常生物實驗中的落地與普及。

**Method:** WetRobo包含一個六自由度Piper機械臂、標準化實驗設備（培養箱、試劑瓶及培養皿）、基礎控制程式碼庫及15段每項任務的遙控示範錄影。核心是AGENTS.md技能文件，定義操作規則與工作流程，並鼓勵代理使用外部Python工具與模型。編碼代理（使用OpenAI Codex）根據自然語言任務描述與現場觀察，自主生成並演化控制程式，結合視覺分割、深度重建、物理模擬、影像處理及機械臂運動控制，完成物體定位、抓取、旋轉及推拉等操作。代理能根據不同實驗室環境調整程式碼，實現跨場景適應。

**Result:** WetRobo在兩個實驗室（Lab X與Lab Y）成功完成三項任務：培養皿蓋提起、試劑瓶蓋旋開及培養箱門開啟。編碼代理在兩實驗室均成功完成試劑瓶蓋任務，展現良好跨場景轉移能力；相比之下，基於VLA的π0.5模型在Lab X微調後僅能成功於該實驗室，無法轉移至Lab Y。任務執行過程中，代理透過多階段策略演化程式碼，結合視覺校正、物理模擬碰撞檢測及力矩監控，提升操作穩定性。實驗也展示代理能重用先前任務程式碼，縮短後續執行時間。

**Conclusion:** WetRobo提供一種實用且可重複部署的生物實驗室機器人解決方案，通過編碼代理的程式碼生成與演化，實現跨實驗室的任務適應與執行，降低了對本地示範數據收集與神經網絡訓練的依賴。該系統在多項典型生物實驗操作中取得成功，並優於傳統VLA策略的跨場景泛化能力。共享與持續優化AGENTS.md技能文件有助於累積與傳播操作知識，促進機器人技術在生物實驗中的廣泛應用。限制包括僅使用單一編碼代理與模型，缺乏多次獨立適應實驗，及設備與任務範圍有限，未涵蓋長期細胞培養等複雜流程。

**Research Gap:** 本研究未測試其他編碼代理或大型語言模型的性能差異，且任務成功率基於連續嘗試而非多次獨立適應，可能影響結果穩定性。實驗設備與任務種類有限，未涵蓋如培養皿運輸等更複雜操作，且未充分評估長期任務的持續性能與失敗案例。代理對環境變化的適應依賴於現有視覺與力矩感測，對更大範圍的實驗室條件變化（如光照、設備擺放）泛化能力尚不明確。成本與部署風險（如LLM運算資源消耗）未深入分析，且缺乏與其他自動化框架的全面比較。未明確說明如何處理突發錯誤或異常情況，限制實際應用的可靠性評估。
