### 1. Ladders of Thought: A Self-Evolving Curriculum of Progressively Simplified Reasoning Traces

- 分數：0
- arXiv: [2609.25643](https://arxiv.org/abs/2609.25643)
- 發表日期：2026-09-24
- 分類：cs.AI
- 入選理由：LLM rank #1 / 9/10: Presents a novel, adaptive curriculum method (Ladders of Thought) that significantly improves reasoning in smaller LLMs with strong empirical gains and faster convergence, addressing a key limitation in current models.

**Intro:** 大型語言模型在規模達數千億參數時展現出優秀的推理能力，但小型與中型模型即使透過知識蒸餾仍然推理能力脆弱。這限制了小型模型在資源有限環境中的應用潛力。本文提出Ladders-of-Thought（LoT）框架，透過逐步簡化推理問題並結合自我演化課程，提升小型模型的推理表現。該方法自動生成語義忠實且難度逐漸降低的問題版本，並以推理步驟數作為難度指標，利用多臂賭徒調度器動態分配訓練資源。實驗涵蓋數學與多跳推理兩大領域，模型規模從1B至8B不等，結果顯示LoT在多項基準上均優於傳統知識蒸餾方法。

**Motivation:** 小型與中型語言模型因容量限制及學生-教師模型間的差距，難以有效學習複雜推理技能，且容易過度擬合表面特徵。現有的推理蒸餾方法在學生模型與教師模型差距大時效果不佳。課程學習理論指出由淺入深的訓練順序能提升樣本效率與泛化能力，但如何為推理問題定義難度並設計動態課程仍具挑戰。LoT透過逐步簡化問題並以推理步驟數作為難度指標，結合自我演化的課程調度，旨在解決小型模型推理訓練的效率與泛化問題，對工程與產品落地有實際意義。

**Method:** LoT方法包含兩大核心：首先，透過逐步重寫問題，將原始推理問題轉換為語義等價但難度逐步降低的版本。具體做法是將每個推理步驟中使用的前提替換為該步驟的結論，形成一系列難度遞減的問題。其次，利用模型估計的最小推理步驟數作為難度標籤，將問題分桶。訓練時，採用多臂賭徒調度器動態選擇不同難度桶的樣本，以最大化學生模型的學習進展。此自我演化課程避免固定或次優的訓練順序，提升訓練效率與泛化能力。

**Result:** 實驗在數學推理（GSM8K及多個外部分布數據集）與多跳推理（EntailmentBank及多個外部分布數據集）上進行，涵蓋OPT與Pythia等多種模型。LoT在數學推理中對AddSub、SVAMP等外部分布數據集提升顯著，最高達32個百分點，且在內部分布GSM8K上也有2-3個百分點的穩定提升。多跳推理中，LoT在QASC與StrategyQA上提升明顯（最高25個百分點），但在MuSiQue與OpenBookQA上表現較為混合，顯示效果依賴任務特性。LoT在較大模型（Qwen 2.5-7B、Llama 3.1-8B）上同樣有效，且自我演化課程較固定課程收斂更快，計算開銷僅略增3-8%。

**Conclusion:** 本文提出的Ladders-of-Thought框架透過語義忠實的逐步簡化問題與基於推理步驟的難度分桶，結合多臂賭徒調度器實現自我演化課程，有效提升小型至中型語言模型的推理能力。實驗結果證明LoT在多個數學與多跳推理基準上均優於強基線，尤其在外部分布泛化上表現突出，且訓練效率提升明顯。該方法計算成本低，具備實際工程應用潛力。限制在於依賴高品質重寫生成器，且目前僅驗證於英文文本推理，對多語言、多模態及更大模型的適用性尚待驗證。

**Research Gap:** 本文未明確探討重寫生成器質量對最終效果的敏感度，若重寫不夠忠實可能引入噪音影響訓練。難度標籤基於模型估計的最小推理步驟，可能存在誤差且未與人工標註難度做充分比較。多跳推理中部分數據集表現不佳，顯示方法對任務類型依賴較大，缺乏對知識檢索或實體連結等能力的支持。實驗主要集中於1-8B模型，對更大規模模型的普適性與成本效益尚未充分驗證。消融實驗雖有，但對不同重寫策略及調度器參數的系統性分析不足，未充分揭示方法各組件的獨立貢獻與風險。

### 2. Spectra: A Rules-Driven LLM Pipeline for Automated KYC Document Processing

- 分數：0
- arXiv: [2609.25474](https://arxiv.org/abs/2609.25474)
- 發表日期：2026-09-24
- 分類：cs.AI
- 入選理由：LLM rank #2 / 8/10: Proposes a practical AI-assisted platform (Spectra) that automates complex KYC document processing with strong accuracy and large human burden reduction, demonstrating clear practical value and credible evaluation.

**Intro:** 本論文聚焦於資本市場中客戶身份認證（KYC）文件處理的自動化挑戰。傳統KYC流程涉及大量文件分類、結構化資料抽取及合規性驗證，耗時且容易出錯。作者提出Spectra系統，結合結構化規則引擎與大型語言模型（LLM）代理，分階段處理文件分類、資料抽取與驗證，並強調流程的可追蹤性與合規審計需求。

**Motivation:** KYC流程繁瑣且涉及多方手續，導致整體審核時間長達數週。文件類型多樣且格式不一，傳統方法難以有效處理。單一大型語言模型無法同時處理龐大政策文件且缺乏錯誤定位能力。為提升效率並降低人力負擔，需設計可分解、可審計且結合規則與AI的自動化系統。

**Method:** Spectra架構包含一個以PostgreSQL實作的規則引擎，將合規政策編碼為可查詢資料庫，動態生成文件清單與抽取規格。文件處理流程分為六階段：檔案清理、注入攻擊偵測、文件分類、規格查詢、資料抽取及驗證。分類與抽取使用LlamaCloud服務，驗證與攻擊偵測則使用OpenAI模型。系統設計雙團隊協作，透過信心分數自動過濾高信心資料，降低人工審核負擔。

**Result:** 在21份真實KYC文件的分類任務中，Spectra達成100%準確率，平均信心值99.3%。抽取任務在15份合成文件中，141個欄位達成89.4%準確率，F1分數90.5%。部分文件類型如企業決議文件表現較差，主要因複雜欄位結構與詞彙歧義。系統成功將人工審核項目從206筆降至8筆，審核負擔減少96%。全文明確報告分類與抽取的評估指標與失敗案例分析。

**Conclusion:** Spectra展示結合規則引擎與多階段LLM代理的KYC文件處理系統，兼顧高準確率與合規審計需求。系統架構支持政策更新無需重新訓練模型，且各階段可獨立優化。雖然在複雜文件與欄位抽取仍有挑戰，且評估資料集規模有限，但此方法為金融合規文件自動化提供實務可行的解決方案。

**Research Gap:** 本研究評估資料集規模偏小且多為清晰PDF，缺乏對掃描件及OCR錯誤的驗證，限制泛化能力。部分複雜欄位抽取準確率低，顯示現有提示與結構約束不足，未明確提出強化方案。系統對跨欄位推理與詞彙歧義處理仍有不足，未充分探討多語言或多司法管轄區的適應性。此外，全文未明確說明系統在大規模實際部署中的效能與成本，缺乏對失敗案例的全面分析與風險評估。未來需擴展資料多樣性、強化結構約束機制及深入探討系統在動態政策環境下的持續維護策略。

**Intro:** 企業環境中的結構化數據代理需在多樣且複雜的數據環境中推理，這些環境中相關證據分散於不同的結構、關係、政策及業務角色。現有系統通常透過可重用的記憶或技能文件來保存先前發現的結構，減少重複發現的負擔，但這種方法未能有效區分語義推理與結構預測的責任分工。本文提出潛在等價學習框架，將持久的任務相關身份與其資料集特定實現分離，並透過高斯原型學習及查詢條件路由，提升數據代理的證據組織與推理效率。

**Motivation:** 在企業中，數據代理面臨的挑戰不僅是模型能力，而是如何有效暴露並組織內部證據以供推理。不同部門使用不同的資料結構表示相同業務角色，導致跨結構推理困難。現有方法要麼依賴多重代理增加探索成本，要麼依賴單一學習模型承擔全部語義理解，兩者均存在計算成本高、泛化能力弱及分布偏移問題。本文主張應將語言模型代理專注於語義推理，將結構預測交由學習系統處理，透過潛在等價學習實現兩者的有效分工。

**Method:** 核心方法為潛在等價學習，將持久任務身份（如客戶識別碼）與資料集特定的實現分離。證據以支持與反對權重表示，利用高斯原型網絡學習每個身份在特定資料集中的表現，並保留軟成員資格以捕捉細微區別。查詢端則學習一組查詢原型，通過兼容性矩陣將查詢需求映射到持久身份空間，實現基於身份的證據路由。此路由機制在查詢時物化相關證據，避免每次查詢重建跨結構關係，提升推理效率與準確度。

**Result:** 在Data Agent Benchmark（DAB）上，涵蓋12個異質資料集與54個查詢，本文方法在五次完整試驗中達成94.67%的資料集宏觀平均Pass@1，成功完成258/270次查詢，顯著優於基準Claude Opus 4.6代理的55.51%。與未使用潛在等價學習的強化代理核心系統相比，提升約10.54個百分點，表明學習身份表示與查詢條件路由有效提升了跨異構資料的查詢準確性與穩定性。

**Conclusion:** 本文證明在異構企業數據環境中，將證據組織提前至語言模型推理前，並透過持久身份與資料集特定實現的分離，能顯著提升數據代理的性能。潛在等價學習框架支持查詢需求與資料集證據的分離重用，減少了每次查詢的結構重建負擔。此方法在多樣化任務與資料結構中均展現優異表現，支持未來結構化數據代理設計中，將學習組織與語義推理明確分工的設計原則。

### 4. SMTB: Fast Structure-Mapping with Tight Bounds

- 分數：0
- arXiv: [2609.25508](https://arxiv.org/abs/2609.25508)
- 發表日期：2026-09-24
- 分類：cs.AI
- 入選理由：LLM rank #4 / 7/10: Presents SMTB, a faster and more robust structure-mapping algorithm with thorough evaluation and clear methodological improvements over SME, relevant for cognitive systems and relational reasoning.

**Intro:** 結構映射是類比推理的核心，透過對關聯元素系統的結構對齊來發現相似性，超越表面特徵。本文提出一種新演算法SMTB（Structure-Mapping with Tight Bounds），相較於經典的SME結構映射引擎，速度提升5至15倍，且在大型巢狀領域中映射品質提升約50%。SMTB整合於Cognitive Rule Engine（CRE）框架中，提供多語言支援與Python介面，方便工程與研究應用。與SME偏好高階對應不同，SMTB強調最大化關聯連通性，適用於任意關聯圖結構，提升了靈活性與泛用性。

**Motivation:** SME作為結構映射的經典實作，已有40年歷史，但其偏好高階結構的設計在某些場景下限制了映射的靈活性與準確性，尤其在無高階結構或存在循環關係的表示中表現不佳。對於需要快速且靈活結構映射的認知系統與教學模擬學習模型，SME的效率與限制成為瓶頸。CRE與SMTB的開發旨在提供一套高效、易用且能處理多種表示形式的結構映射工具，促進認知系統研究與實際應用的快速迭代與擴展。

**Method:** SMTB核心在於逐步分配基底與目標實體的一對一對應，而非像SME以群組（kernel）為單位進行映射。演算法利用一組匹配假設（match hypotheses）與表達對（ExpressionPairs）來評估對應的權重，並設計一種緊密的啟發式函數（tight bound heuristic）來估計未來映射能達成的最大權重，避免SME中因偏好高階結構而導致的失效。SMTB還引入配對遍歷（paired walks）來衡量映射中實體的全局結構連通性，並以指數衰減方式調整該結構偏好，兼顧局部與全局映射品質。整體搜尋採用有界回溯策略，平衡速度與映射品質。

**Result:** 在SME語料庫（5845對基底-目標領域）上，SMTB在不同問題規模均展現優於SME的映射品質與運算效率。小型問題中兩者表現相近，中大型問題（超過128個實體）中SMTB在自身目標函數上提升約80%，在SME目標函數上提升約52%。速度方面，SMTB在典型配置下比SME快5至15倍。加入配對遍歷可微幅提升映射品質，且在部分領域（如ap-physics）顯著增加映射的實體與表達式數量。SMTB允許部分SME禁止的映射（kernel violation），但移除這些映射後仍優於SME，顯示其映射品質提升非僅因放寬限制。

**Conclusion:** SMTB提供一種快速且靈活的結構映射方法，突破SME對高階結構的偏好限制，能處理多種表示形式且在大型複雜領域中表現優異。其整合於CRE框架中，具備良好的工程實用性與擴展性，有助於推動認知系統研究與應用的發展。本文也提出結構映射理論上對高階結構偏好的質疑，並以實驗驗證SMTB在不明顯偏好高階結構下仍能找到高品質映射。整體而言，SMTB為結構映射領域提供了重要的實務工具與理論啟示。

**Research Gap:** 本文雖展示SMTB在SME語料庫上的優異表現，但全文未明確說明在更廣泛或異質性更高的實際應用場景中之泛化能力與穩定性。對於映射中kernel violation的影響與合理性，尚缺乏更深入的理論分析與人類認知實驗支持。SMTB的啟發式函數雖緊密，但仍為近似，對於極大規模問題的計算成本與搜尋策略調整未充分探討。此外，對於不同表示語言（如非謂詞邏輯或非結構化知識）的適用性與效能表現，全文未提供具體實驗或案例。最後，部署於實際認知系統或教學模擬中的整合挑戰與運算資源需求也未詳述。

### 5. LingLan: An Advancing Traditional Chinese Medicine Diagnosis LLM with Multimodal Data

- 入選理由：LLM rank #5 / 7/10: Develops a multimodal deep learning model for breast cancer chemotherapy response prediction with solid performance improvements and use of a public dataset, showing practical clinical relevance.

**Intro:** 本論文聚焦於中醫診斷中多模態數據整合的挑戰，因中醫診斷依賴望聞問切等主觀且整體性的診斷方法，難以與現代醫療的量化標準化系統對接。作者提出一套多模態數據統一框架（UFMD），將舌象與脈象影像自動轉換為結構化的臨床標準描述，並整合多源診斷信息形成完整的數位化病例記錄。基於此，開發了專門針對中醫診斷的語言模型LingLan-14B，透過監督式微調模擬中醫診斷邏輯與流程。實驗結果顯示該方法在診斷準確率與F1分數上均有顯著提升。

**Motivation:** 中醫診斷強調整體觀與經驗判斷，缺乏量化標準，導致AI輔助診斷發展緩慢且準確度不足。隨著老齡化與慢性病負擔增加，社會對中醫預防醫學與個性化健康管理需求提升，迫切需要創新診斷模型。現有AI方法多聚焦於問診文本，忽略多模態數據融合，且公開數據集規模與質量有限，無法支撐高精度個性化診斷。故本研究旨在通過多模態數據統一與專業微調提升中醫診斷的準確性與穩定性，促進AI在中醫臨床的落地應用。

**Method:** 本研究提出UFMD框架，利用DeepSeek-OCR模型自動解析舌象與脈象影像及紙本病歷，轉換為符合中醫臨床術語的結構化文本，並結合人工校對與專家驗證確保數據真實性。為避免生成模型幻覺，設計語義相關性驗證機制，利用Sentence-BERT計算提取文本與原文的語義相似度，過濾不一致數據。基於此結構化數據，採用LoRA參數高效微調Qwen3-14B模型，強化模型對中醫望聞問切診斷邏輯的學習，並使用結構化模板將多模態特徵與問診信息融合，提升模型對症狀與辨證的關聯理解。

**Result:** 實驗使用嚴格分類標準的中醫病歷數據，並與多個基線模型（包括更大參數量的通用模型及專業中醫模型BianCang-14B-Instruct）比較。LingLan-14B在準確率、召回率、F1分數、無約束診斷指標（UDI）及有約束診斷指標（PCDI）均大幅領先，準確率達62.72%，召回率82.03%，F1分數82.02%，相較基線提升超過一倍。混淆矩陣顯示模型在多個診斷類別均有良好識別能力。消融實驗證實結構化數據顯著提升診斷與辨證準確率，強調多模態融合與結構化表示的重要性。

**Conclusion:** 本論文提出的UFMD框架成功實現中醫多模態數據的自動結構化與融合，並基於此開發的LingLan-14B模型通過專業微調顯著提升中醫診斷性能。實驗結果證明結構化多模態數據與專門設計的微調策略對提升中醫AI診斷準確性具有關鍵作用，為中醫AI輔助診斷的臨床應用奠定基礎。論文同時指出數據隱私限制目前無法公開數據集，未來將嘗試匿名化釋出並擴展至更大模型驗證方法的可行性。

**Research Gap:** 本研究雖取得顯著成果，但仍存在多項不足。首先，數據集受限於患者隱私，無法公開，限制了外部驗證與復現。其次，實驗中未明確說明模型在不同臨床場景或罕見病症的泛化能力與失敗案例，缺乏對模型穩定性與魯棒性的深入分析。此外，消融實驗主要聚焦於結構化數據影響，對多模態融合中各模態貢獻的細節探討不足。最後，部署成本與實際臨床應用的計算資源需求未充分評估，對於大規模推廣仍需更多實證支持。全文未明確說明對非開源大型模型的安全合規測試策略，未來研究應補足這些方面以提升模型的實用價值與可信度。
