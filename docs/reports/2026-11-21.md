### 1. Mamba Flow Matching Neural Processes: Linear-Time Inference for Irregularly Observed Spatial Fields

- 分數：7
- arXiv: [2611.26355v1](http://arxiv.org/abs/2611.26355v1)
- 發表日期：2026-11-19
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mit, nvidia; +3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #1 / 9/10: Proposes a novel linear-time neural process method for large-scale spatial field interpolation with strong empirical results and significant speedups, supported by code and NeurIPS acceptance.

**Intro:** 空間場的插值問題在環境與健康科學中非常常見，例如從稀疏且不規則分布的觀測點推估每日最高溫度。傳統的高斯過程克里金法需要對每個新場景重新擬合超參數並解決三次方計算複雜度的系統，計算成本高昂。神經過程（Neural Processes, NP）透過從過去場景學習插值映射，能在單次前向傳播中完成預測，適合多場景觀測的情境。然而，現有的聯合預測神經過程多依賴自注意力機制，計算成本為二次方，限制了可處理的點數規模。本文提出一種線性時間複雜度的聯合預測神經過程架構，針對不規則空間點集進行高效推斷。

**Motivation:** 在實際工程與產品應用中，環境監測網絡常需對大規模且不規則分布的感測點資料進行快速且準確的空間插值。傳統方法計算成本過高，且現有神經過程方法在處理超過數千點時因自注意力的二次方計算限制而難以擴展。線性時間的推斷方法能顯著提升大規模空間場的即時預測能力，對於需要快速反應的環境監控與健康風險評估系統尤為重要。本文旨在解決現有方法在計算效率與預測品質間的權衡，實現大規模空間場的聯合預測。

**Method:** 本文提出的MambaFlowNP結合多方向的Mamba-2狀態空間掃描與條件流匹配訓練，將上下文觀測點與查詢點合併為一序列，並透過Hilbert曲線排序以保持空間鄰近性。模型在掃描過程中為每個點維持獨立的隱藏狀態，避免將上下文壓縮為單一隱藏向量的瓶頸。訓練階段先以條件流匹配目標訓練教師模型，再透過重流蒸餾減少推斷時的ODE求解步數，最終以連續排序概率分數（CRPS）微調學生模型以提升校準度。整體推斷時間複雜度為O(K)，其中K為上下文與查詢點總數。

**Result:** 在合成Matérn高斯過程基準測試中，MambaFlowNP在1D Matérn-3/2任務中達到與最強自注意力基線TNPA相當的均方誤差（MSE），且推斷速度快25至42倍。於NOAA日最高溫度插值任務中，涵蓋猶他州、加州及整個美國三個不同空間尺度，MambaFlowNP在所有層級均取得最低的RMSE與CRPS，且95%預測區間覆蓋率接近理想值。推斷速度較最強的自注意力基線快114至784倍，且單次前向傳播可在NVIDIA L40S GPU上於一秒內處理高達百萬點。消融實驗證實避免上下文壓縮與多方向掃描對性能提升關鍵。

**Conclusion:** 本文提出的MambaFlowNP成功實現了對不規則空間點集的聯合預測，並將推斷時間複雜度降至線性，顯著提升大規模空間場插值的計算效率與預測品質。其在合成與實際NOAA溫度資料上的表現均優於現有聯合預測神經過程基線，且推斷速度大幅提升，具備實際工程部署潛力。限制方面，模型在規則格點資料上的效率不及專門的卷積NP或FFT基礎GP方法，且目前僅評估一維與二維空間輸入，尚未涵蓋時空資料。此外，重流蒸餾增加訓練複雜度，且在百萬點規模下的預測品質尚未充分驗證。未來可考慮擴展至時空資料及多變量場景。

**Research Gap:** 本文雖展示了線性時間推斷的可行性與優越性能，但仍存在多項不足。首先，實驗僅涵蓋NOAA單一變數與固定站點網絡，缺乏跨區域泛化與多變數評估，限制實際應用的廣泛性。其次，對比基準未包含部分先進的可擴展空間統計方法如結構化核插值或圖神經網絡，無法全面評估相對優勢。第三，模型僅針對一維與二維空間輸入設計，對時空序列資料的適用性與效能尚未驗證。第四，重流蒸餾雖提升推斷效率，但增加訓練流程複雜度與成本，實際部署時需考量。最後，雖展示百萬點推斷速度，但未提供該規模下的預測準確度與校準性分析，缺乏對極大規模場景下性能的完整評估。

### 2. EgoCaptioner: Towards Comprehensive and Fine-Grained Egocentric Video Captioning

- 分數：7
- arXiv: [2611.26380v1](http://arxiv.org/abs/2611.26380v1)
- 發表日期：2026-11-19
- 分類：cs.CV
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #2 / 8/10: Introduces a comprehensive egocentric video captioning system with novel coarse-to-fine annotation and multi-reward training, showing strong benchmark performance and code availability.

**Intro:** 本論文聚焦於第一人稱視角的影片描述，該領域要求對細節與時間點的精確掌握。現有多模態大型語言模型在處理此類影片時，常忽略短暫動作、錯亂事件順序或誤判穿戴者的動作。傳統的字幕格式也無法兼顧細節敘述與精確時間標記。作者提出EgoCaptioner，結合影片整體概述與時間標記的細節步驟，並依活動類型調整敘述重點，提升描述的完整性與時間對齊。此方法基於八個第一人稱影片資料集，透過粗到細的標註流程產生五萬筆訓練資料，並利用多重獎勵函數與強化學習優化模型。實驗涵蓋五個基準，顯示EgoCaptioner在公開模型中表現領先，甚至超越部分專有模型。

**Motivation:** 第一人稱影片因視角特殊，動作快速且視野有限，導致現有模型難以捕捉短暫且關鍵的動作細節，且時間標記不精確。這對於個人助理、機器人學習等應用造成挑戰，因為這些系統依賴精確且詳盡的字幕來檢索事件與訓練。現有字幕生成方法多半無法同時兼顧敘述細節與時間準確性，且對穿戴者動作的理解不足。為解決這些問題，需一套能結合全局場景概述與細節時間步驟的字幕生成框架，並針對不同活動類型調整敘述焦點，提升字幕的實用性與精確度。

**Method:** EgoCaptioner將影片描述分為兩層：影片整體概述與時間標記的細節步驟。概述描述場景、參與者與穿戴者的整體活動；步驟則將影片切分為連續不重疊的事件，每事件再細分為有起訖時間的步驟，並標記關鍵時刻。資料標註採用粗到細流程，先由大型語言模型產生事件結構與步驟大綱，再細化步驟描述，最後由另一模型校正。訓練分兩階段：先以五萬筆標註資料進行監督微調，再用Group Relative Policy Optimization強化學習，結合事實正確性、時間對齊與敘述風格三種獎勵函數。當有姿態感測資料時，亦將其轉換為動作事實輔助訓練。

**Result:** EgoCaptioner在五個第一人稱影片基準測試中，於字幕品質、基於字幕的問答準確率及時間對齊指標均取得最佳公開模型成績。於EgoMe-Overview與Steps、EgoTempo、Minerva-Ego及PhysCapBench均超越多數專有及公開模型，並在EgoHome的步驟時間對齊指標PSJ達75.51分，領先其他公開模型。消融實驗顯示粗到細標註流程及多重獎勵設計均顯著提升性能。細節分析指出，模型能根據活動類型調整敘述重點，且在相同字數下，產出更具因果與時間順序資訊的字幕，提升實務應用價值。

**Conclusion:** 本論文提出的EgoCaptioner透過粗到細標註與多重獎勵強化學習，有效提升第一人稱影片字幕的細節豐富度與時間準確性。模型在多項基準中展現優異表現，尤其在捕捉活動因果關係與時間順序方面具明顯優勢。此方法對於需要精確事件定位與詳盡敘述的應用場景，如個人助理記憶檢索與機器人學習，具實際工程與產品價值。然而全文未明確說明模型在極端場景或多樣化活動類型下的泛化能力與失敗案例，部署成本與實時性能亦未詳述。

**Research Gap:** 本研究雖在多個基準展現優異成績，但仍存在數個不足。首先，資料集涵蓋的活動類型與場景有限，缺乏對極端或罕見事件的驗證，可能影響泛化性。其次，強化學習獎勵設計雖包含事實與時間對齊，但對生成文本的語義一致性與多樣性控制未充分探討。第三，全文未明確說明模型在長時間影片或高頻動作場景下的效能與計算成本，對實際部署風險評估不足。此外，缺乏對失敗案例的分析，無法全面理解模型弱點。最後，消融實驗雖揭示部分設計貢獻，但對比其他先進多模態架構的全面性不足，未充分驗證方法的相對優勢。

### 3. A CPU Inside an LLM: Zero-Gradient Compilation of Exact Circuits into Pretrained Weights

- 分數：5
- arXiv: [2611.26450v1](http://arxiv.org/abs/2611.26450v1)
- 發表日期：2026-11-19
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：alibaba, ibm, mit; +3 收錄於 Hugging Face Daily Papers; LLM rank #3 / 7/10: Presents a novel zero-gradient compilation method to embed exact arithmetic circuits into pretrained LLM weights, achieving near-perfect arithmetic accuracy without training, with detailed evidence.

**Intro:** 預訓練語言模型在執行精確多位數算術時表現不佳，通常需要梯度微調或外部工具介入。此論文提出一種零梯度的電路編譯方法，能將確定性計算直接編譯進預訓練模型權重中，無需訓練樣本或運行時掛鉤，且能控制層間正規化漂移，同時保留自然語言能力。該方法結合多種分析機制，實現多位數加減乘法及布林電路的精確執行。論文在多個大型模型上驗證，展示高準確率與良好語言生成連續性。此工作旨在提升預訓練模型的確定性計算能力，減少對外部工具的依賴。

**Motivation:** 現有語言模型在多位數精確算術上不穩定，且多依賴外部工具或梯度微調，增加系統複雜度與部署成本。直接將確定性電路編譯進模型權重，可實現內建的精確計算能力，提升推理效率與安全性，避免運行時中斷。此方法對工程與產品落地具實際意義，尤其在對安全性與推理一致性要求高的場景。論文同時解決了正規化變動、跨token路由與詞彙分割等技術挑戰，為實際應用提供可行方案。

**Method:** 核心方法包括三大分析機制：一是利用兩層Mellin-GLU積分，將未知的RMSNorm縮放轉換為對數尺度的門控平移，實現尺度不變性並控制誤差；二是透過簽名Chebyshev Indefinite-RoPE自吸收注意力與無記憶SiLU反對稱GatedDeltaNet位移，實現跨token尺度抵消與精確路由；三是軸向寬度擴展搭配正規化補償及基數1000的BPE編碼，並採用差分綁定解碼器。基於這些原語，設計了一個五階段自動化編譯器，能合成4至8位數的加減乘電路及布林電路，並在多個大型Transformer架構中實現。

**Result:** 在IBM Granite 4.2 3B與Alibaba Qwen 3.5 4B兩大模型上，編譯後的電路達到99.17%至100% ALU前綴準確率，且在中斷續寫測試中達98%至100%成功率，明顯優於使用12.8K樣本LoRA微調的42.2%與61.7%。此外，提出的因式分解稀疏sidecar結構有效降低了GPU記憶體使用量42%至44%，並在多種硬體與量化設定下保持性能穩定。實驗涵蓋多種解碼策略、長上下文測試與安全評估，均未引入異常觸發，證明方法的穩健性與泛化能力。

**Conclusion:** 本論文提出的零梯度電路編譯原語與自動化編譯器，成功將精確算術與布林電路內嵌於大型預訓練語言模型中，無需額外訓練或外部工具，且保持自然語言能力與長上下文一致性。該方法在多模型、多硬體環境下均展現優異性能與資源效率，為提升語言模型確定性計算能力提供了實用路徑。限制方面，尚未涵蓋除加減乘外的除法與更複雜迴圈結構，且對部分架構如42層Gemma 4的完整支持仍在進行中。

**Research Gap:** 論文未充分驗證除法及無界迴圈等更複雜算術運算的零梯度編譯能力，限制了方法的通用性。實驗主要集中於兩款大型模型，泛化至其他架構或更大規模模型的效果尚不明確。雖有稀疏sidecar設計降低記憶體需求，但整體計算成本與部署風險仍需評估，尤其在資源受限環境。缺乏對失敗案例或異常觸發的深入分析，對安全性影響的討論雖有提及，但實際防範措施與檢測方法仍需完善。消融實驗雖涵蓋多原語，但對不同tokenization策略與語言任務的適應性驗證有限。

### 4. Coda-DaVinci: Reimagining Video Generation with Code2Video

- 分數：5
- arXiv: [2611.26595v1](http://arxiv.org/abs/2611.26595v1)
- 發表日期：2026-11-19
- 分類：cs.CV
- 入選理由：+2 提及頂級機構：mit; +3 收錄於 Hugging Face Daily Papers; LLM rank #4 / 7/10: Develops a task-adaptive multi-agent framework for Code2Video generation with detailed ablations and human evaluations, improving physical plausibility and visual realism.

**Intro:** 本論文探討了Code2Video方法在視頻生成中的應用，該方法利用代理生成的3D代理物件來引導視頻生成，從而實現對結構和動態的明確控制。現有視頻生成模型在遵循複雜指令、保持場景一致性及物理合理性方面仍存在挑戰。Code2Video通過可執行的場景程序提供精確的場景表示，有助於維持跨鏡頭的場景狀態。作者針對代理物件的細節層級、物理模擬和提示語設計進行系統性分析，並基於此提出Coda-DaVinci框架，旨在提升視頻生成的質量和一致性。

**Motivation:** 視頻生成在工程和產品層面面臨指令遵循困難、場景狀態持續性差及物理互動不合理等問題。Code2Video通過3D代理物件提供結構和動態的顯式控制，理論上可解決這些問題，但如何設計代理物件的細節層級和提示語以達到最佳效果尚未明確。此外，代理物件的物理模擬能力及其對最終視頻質量的影響也未充分研究。這些問題直接關係到視頻生成技術在實際應用中的可用性和穩定性，因此有必要深入探討並提出有效的解決方案。

**Method:** Coda-DaVinci是一個任務自適應的代理框架，根據任務需求選擇代理引導生成或直接生成路徑。對於需要精確場景或動作控制的任務，採用中等粒度的3D代理建模環境和物體，粗粒度代理建模人體，並利用Blender進行物理模擬。代理生成後，代理會檢查渲染結果並修正場景代碼，然後生成與代理對齊的提示語，將外觀參考與代理實體綁定，並描述細節動作。框架包含多代理協作機制，支持場景資產持久化、視覺反饋和獨立審核，確保生成視頻符合任務要求。

**Result:** 實驗在多個基準數據集（包括VTR、R2M、World Models’ Last Exam in Physics及T2AV-Compass）上進行，結果顯示Coda-DaVinci在指令遵循和場景一致性方面優於多個直接生成及Code2Video基線方法。具體指標如VTR的詞錯率從59.21%降至11.08%，R2M的場景一致性指標提升，物理合理性在物理模擬任務中明顯改善。消融實驗證明任務自適應路由、多粒度建模和獨立審核均對性能有正面影響。長視頻評估顯示該方法在事件結構和多輪交互一致性上有提升，但在過渡穩定性和場景設定遵守方面仍有不足。

**Conclusion:** 本論文系統分析了Code2Video中代理粒度、物理模擬和提示語設計對視頻生成質量的影響，並提出Coda-DaVinci框架以任務自適應方式協調代理建模與視頻合成。實驗結果證明該方法在指令遵循、場景一致性及物理合理性方面取得領先表現，並在長視頻生成中展示了場景狀態持續性的優勢。限制方面包括動作自然度不足、鏡頭過渡穩定性和場景設定遵守仍需改進，提示未來需加強代理與視頻生成模型間的控制協調以應對更複雜長序列場景。

**Research Gap:** 本研究雖在多個基準上驗證了方法有效性，但仍存在幾個不足。首先，動作自然度在動作密集任務中仍不理想，代理動畫的僵硬問題未完全解決。其次，長視頻生成中過渡穩定性和場景設定遵守表現較弱，說明代理與視頻生成模型間的連續性控制尚不完善。第三，實驗主要集中於特定數據集和場景，泛化能力及在更複雜或多樣化場景下的表現未充分驗證。此外，代理建模和物理模擬的計算成本及部署風險未詳細討論，對實際工程應用的影響仍不明確。最後，消融實驗雖涵蓋多個組件，但對不同視頻生成模型的適配性和失敗案例分析較少，限制了對方法穩健性的全面評估。

### 5. Active Feature Acquisition by Distilling an Oracle Teacher

- 分數：5
- arXiv: [2611.26598v1](http://arxiv.org/abs/2611.26598v1)
- 發表日期：2026-11-19
- 分類：cs.LG, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #5 / 7/10: Proposes an explicit oracle teacher distillation approach for active feature acquisition, outperforming prior methods with clear theoretical grounding and empirical validation.

**Intro:** 在許多應用中，取得完整特徵資料往往伴隨高昂成本，例如金錢、時間延遲或隱私風險。主動特徵獲取（Active Feature Acquisition, AFA）旨在於有限預算下，為每個樣本選擇最具資訊性的特徵子集以提升預測效能。現有方法多透過自建效用目標來訓練策略，缺乏明確的教師訊號。本文提出一種明確構造的教師策略，利用訓練階段可取得的標籤與未觀察特徵值，計算出一個閉式的oracle，依據其對下游預測誤差的影響對候選特徵排序，並透過軟目標模仿學習蒸餾成可部署的策略。

**Motivation:** 現有AFA方法的監督信號多為自我構建的效用函數，缺乏明確且可解釋的教師指導，導致策略學習不穩定且難以分析。訓練階段可取得的完整標籤與特徵資訊，理應能提供更精確的教師訊號。若能明確定義教師策略並將其蒸餾給部署策略，不僅能提升策略效能，也能讓教師行為可被量化與分析，對工程實務及研究落地均具重要意義。

**Method:** 本文提出OracleImitator方法，核心在於將教師策略定義為一個myopic Brier oracle，該oracle利用標籤與未獲取特徵計算每個候選特徵加入後對預測誤差的減少，並以此對候選特徵排序。學生策略為一個mask-conditioned多層感知機，僅依賴已觀察特徵與其遮罩資訊，透過軟目標交叉熵損失模仿教師的排序分布。訓練時以隨機遮罩生成多樣化狀態，減少行為克隆的偏差。部署時，學生策略在預算限制下逐步選擇最高分特徵，無需教師或標籤資訊。

**Result:** 在多模態醫療診斷與AFABench基準的六個資料集上，OracleImitator在整體預算範圍內均匹配或超越現有AFA方法。以TCGA-Glioma資料集為例，該方法在不到四分之一的特徵獲取成本下，恢復了90%的可達準確度提升。實驗亦證明方法對不同預測器與成本設定具魯棒性，且透過教師品質消融實驗顯示更精確的教師信號能帶來更佳策略。最後，透過鄰近點一致性估計，量化了部署策略可恢復教師行為的上限，發現資訊限制是主要瓶頸。

**Conclusion:** 本文提出一種基於明確教師策略蒸餾的主動特徵獲取方法，成功將訓練階段的豐富資訊轉化為可部署的決策策略，提升了預測效能並降低獲取成本。明確教師策略的設計不僅提升了策略品質，也提供了分析與診斷AFA問題的新視角。方法在多種資料集與預測器上展現穩定優勢，且教師品質與策略恢復度的研究揭示了資訊限制對策略表現的影響。

**Research Gap:** 本文主要依賴myopic Brier oracle作為教師，未探討非myopic或成本敏感等更複雜教師策略的潛力與影響。學生策略為固定架構的MLP，對於更複雜或大規模特徵空間的泛化能力及計算成本尚未充分驗證。實驗中教師行為的可恢復度約為30%至53%，顯示部署策略因資訊限制無法完全模仿教師，未來需深入探討如何縮小此差距。此外，方法未考慮動態預算調整或停止決策，且缺乏對失敗案例與實際部署風險的分析。全文未明確說明在極端稀缺預算或高維度場景下的表現與穩定性。
