### 1. CalibForge: Adversarial Solver Calibration for Scaling Learnable Terminal Tasks

- 入選理由：+3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #1 / 9/10: Presents a novel adversarial solver calibration framework for generating challenging, verifiable terminal tasks with strong empirical improvements and practical training data utility, supported by ablations and multiple 

**Intro:** 本論文探討如何建構適合訓練終端代理的任務，強調任務不僅要可執行且可驗證，更需具備適當的學習挑戰性。現有方法多著重於任務的可執行性驗證，卻無法反映任務在特定求解器設定下的行為表現。為此，作者提出CalibForge系統，透過對求解器行為的對抗性校準，動態調整任務以達到學習上的適切難度。該系統能自動合成並校準終端任務，並以多求解器及對比求解器校準策略，確保任務既可解又不過於簡單。

**Motivation:** 在工程與產品層面，訓練終端代理需大量高品質且具挑戰性的任務資料，但單純的可執行驗證無法保證任務難度適中，導致訓練效果有限。透過求解器行為反饋，能更精確地定位任務難度區間，提升訓練資料的有效性與泛化能力。此方法對於提升代理在複雜軟體工程及終端操作任務的實際表現具有直接影響，尤其在多模型求解環境中能更全面捕捉任務特性，促進模型能力的穩健提升。

**Method:** CalibForge從一個線索開始，由作者代理進行網路調研、任務規格撰寫、環境建置及驗證測試，確保任務結構完整且可自我解決。接著進入對抗性求解器校準階段，依據校準規範γ，使用多求解器或對比求解器策略反覆嘗試任務。多求解器校準要求至少一個求解器成功且至少一個失敗，對比求解器校準則要求強求解器成功且弱求解器失敗。若未達標準，作者代理根據求解器反饋修訂任務並重新驗證，最多迭代50輪。此流程確保任務位於求解器相對可學習區間，提升訓練資料品質。

**Result:** 作者合成了5,431個經校準的終端任務，涵蓋16個領域，並在Terminal-Bench 2.0、SWE-bench Pro及Doc2Repo三個基準上評估。與多個公開終端任務資料集相比，CalibForge訓練的模型在Terminal-Bench 2.0上分別達到32.58%及47.57%準確率，較最佳基線提升約6.3至6.7個百分點；在SWE-bench Pro與Doc2Repo上亦有顯著提升，最高達27.68及30.04個百分點。消融實驗顯示，多求解器及對比求解器校準策略帶來的提升超過單一求解器反饋或無求解器反饋，證明校準策略的有效性。

**Conclusion:** 本研究提出CalibForge系統，透過對抗性求解器校準將求解器行為轉化為任務建構的反饋，成功合成大量具挑戰性且多樣化的終端任務。實驗結果證明該方法能提升終端代理的訓練效果及跨領域泛化能力，尤其在軟體工程相關任務中表現突出。此系統為終端任務資料集構建提供了一種可驗證且可調整難度的實用框架，對工程實踐與研究落地均具參考價值。

**Research Gap:** 全文未明確說明CalibForge在不同求解器組合或更大規模任務集上的泛化能力及成本效益，且校準迭代上限設定為50輪，對於更複雜任務的適用性及效率尚缺乏深入分析。任務修訂過程中對作者代理的具體改動策略描述有限，缺乏對失敗案例或校準失效情況的討論。此外，系統對於求解器能力差異的依賴可能限制在求解器多樣性不足時的表現，且未探討在真實產品部署中可能面臨的資源與時間成本挑戰。未來可進一步驗證校準策略在更多終端任務類型及動態環境下的穩健性。

### 2. RRC: Unlocking Generative Reward Models in LLM Reinforcement Learning via Ranking-Based Reward Construction

- 分數：4
- arXiv: [2608.06310v1](http://arxiv.org/abs/2608.06310v1)
- 發表日期：2026-08-06
- 分類：cs.LG, cs.CL
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #2 / 8/10: Introduces a principled ranking-based reward construction method that bridges a key gap in generative reward models for RL, with strong empirical gains on open-ended benchmarks and publicly available code.

**Intro:** 本論文探討大型語言模型（LLM）強化學習中獎勵模型的設計問題。傳統上，獎勵模型多為判別式，輸出標量分數作為強化學習的回饋信號，但此類模型未能充分利用LLM的生成能力。近年生成式獎勵模型因能以文本形式表達偏好，展現出較強的排序能力，然而在強化學習中未能有效發揮其潛力。作者指出這是因為生成式獎勵模型的比較性質與現有強化學習算法要求的標量分數存在本質不匹配。論文提出一種基於排序的獎勵構造方法（RRC），以更好地利用生成式獎勵模型的比較優勢。

**Motivation:** 生成式獎勵模型在回應排序任務中表現優異，但直接將其生成的偏好概率作為強化學習的標量獎勵，常因概率崩潰或信心偏差導致獎勵信號不穩定，影響策略優化效果。現有方法未能解決生成式模型與標量獎勵的本質差異，限制了生成式模型在強化學習中的應用。從工程與產品角度看，如何穩定且有效地將生成式獎勵模型用於強化學習，對提升LLM的指令遵循和推理能力具有重要意義。

**Method:** 作者提出Ranking-based Reward Construction（RRC）方法，核心在於不直接使用生成式獎勵模型輸出的偏好概率，而是透過對同一輸入下多個回應的相對排序來構造標量獎勵。RRC包含兩種策略：自競爭排序（SCR）透過生成式模型對樣本回應兩兩比較，計算每個回應贏得的次數作為獎勵分數；錨點引導排序（AGR）則引入少量固定錨點回應作為參考，降低比較次數，提升計算效率。為提升排序穩定性，方法中還加入多次投票機制與循環衝突調整。該方法可無縫整合至現有強化學習算法如GRPO和DAPO。

**Result:** 實驗涵蓋六個開放式聊天與推理基準，包括AlpacaEval2、ArenaHardV2和MMLU-Redux。結果顯示，RRC在使用生成式獎勵模型時，較傳統概率基礎獎勵構造方法顯著提升強化學習性能，例如AlpacaEval2從35.8%提升至41.3%，ArenaHardV2從8.0%提升至11.2%。此外，增加投票次數和錨點數量均能進一步提升性能，展現良好的擴展性。與判別式獎勵模型及其他偏好優化方法相比，RRC均取得更穩定且明顯的優勢。

**Conclusion:** 本論文提出的RRC方法有效解決了生成式獎勵模型在強化學習中標量獎勵構造的瓶頸，充分發揮了生成式模型的比較排序能力。實驗結果證明RRC能提供更準確且穩定的獎勵信號，促進策略優化，對提升LLM的強化學習性能具有實際價值。該方法兼具理論支持與工程可行性，為生成式獎勵模型在強化學習領域的應用提供了新思路。

**Research Gap:** 論文未明確說明RRC在極大規模樣本或更複雜任務中的計算成本與延遲問題，尤其生成式模型多次比較的實際部署風險尚未充分探討。實驗主要集中於特定基準，泛化能力及在多樣化真實場景下的表現仍需驗證。對於生成式獎勵模型在面對不一致或矛盾偏好時的魯棒性分析不足，且缺少對失敗案例的詳細討論。此外，錨點選擇策略雖有理論支持，但實際對策略演化的影響及動態調整機制未深入研究。最後，消融實驗主要聚焦於投票與錨點數量，對其他超參數敏感度及不同生成模型架構的適用性尚未充分展開。

### 3. Scalable estimation of VARMA models

- 分數：3
- arXiv: [2608.06340v1](http://arxiv.org/abs/2608.06340v1)
- 發表日期：2026-08-06
- 分類：stat.ML, cs.LG, math.ST
- 入選理由：+3 提及頂級會議：acl; LLM rank #3 / 7/10: Addresses a longstanding computational bottleneck in VARMA model estimation with a novel scalable framework, theoretical guarantees, and strong empirical results on real datasets, advancing time series modeling.

**Intro:** VARMA模型因其能以較少參數捕捉時間序列的動態特性，理論上優於純VAR模型，但其估計困難且計算成本高昂，限制了在高維度和長序列上的應用。傳統方法如MLE因非凸性、參數不可辨識性及需遍歷整個序列，導致計算成本隨序列長度線性增加，且在維度超過十時常出現收斂失敗。本文提出一種新框架，利用部分自相關重參數化確保穩定性與可逆性，並透過固定大小的充分統計量及傅立葉變換降低每次優化迭代的計算成本，使其不依賴序列長度，實現VARMA模型的可擴展估計。

**Motivation:** 在工程與產品實務中，多變量時間序列分析常需處理高維且長時間序列資料，傳統VARMA估計方法因計算瓶頸難以應用，導致從業者多選擇較簡單的VAR模型，犧牲了模型的表達力與預測準確度。本文的動機在於突破此計算限制，提供一套理論嚴謹且實務可行的估計方法，使VARMA模型能在大規模資料上有效運行，提升預測性能並支援季節性與外生變數等複雜結構，對於需要精確預測與結構解釋的應用場景尤為重要。

**Method:** 核心方法為將VARMA模型的參數透過部分自相關（PAR）重參數化映射至無約束空間，確保穩定性與可逆性無需額外約束。利用截斷的無限VAR表示，將原本依賴序列長度T的損失函數轉換為只依賴固定大小充分統計量的形式，並以傅立葉（Parseval）定理加速計算，使每次梯度評估的成本與T無關。提出兩種點估計器：正則化最小二乘（RLS）與邊際化協方差的最大後驗（JMAP）估計，後者透過逆Wishart先驗對噪聲協方差進行邊際化，提升對異方差與相關性的適應能力。方法同時擴展至季節性VARMA、VARMAX及滾動視窗重估，均維持相同計算複雜度。

**Result:** 在合成資料中，JMAP估計器在不同維度（10至40）與樣本長度下均優於RLS及現有稀疏VARMA套件bigtime，且在MLE套件MTS中常見的非可逆解問題得到有效避免。實際應用於Dominick’s零售需求（含價格外生變數）、新加坡氣象資料及北京空氣品質資料，結果顯示本文方法在預測準確度上普遍優於或匹配VAR、Bayesian VAR、逐變量ARMA及bigtime稀疏VARMA。季節性VARMA模型在氣象與空氣品質資料中展現顯著優勢，能以較少參數捕捉日週期性結構。稀疏方法在高維且結構密集的空氣品質資料中表現不佳，顯示密集正則化更適合此類資料。

**Conclusion:** 本文提出的VARMA估計框架成功解決了傳統方法在高維長序列上的計算瓶頸，透過PAR重參數化與充分統計量及傅立葉加速，實現每次優化迭代成本與序列長度無關。兩種估計器均具備理論收斂保證，並在多種實際資料集上展現競爭力。季節性與外生變數擴展進一步提升模型適用性。限制在於優化過程為非凸，無法保證全局最優，且理論結果僅涵蓋固定維度與階數，尚未探討高維度隨樣本增長的情況。未來工作可朝向完整貝葉斯推論與高維理論拓展。

**Research Gap:** 本文雖提供了理論保證，但優化過程為非凸，無法確保L-BFGS達到全局最優，實際優化誤差未被嚴格控制。理論分析限制於固定維度與模型階數，未涵蓋維度與階數隨樣本增長的高維情境，對於大規模高維資料的泛化能力尚不明確。實驗中超參數透過交叉驗證選擇，缺乏自動化或理論指導的調參方法。稀疏方法的比較僅限於bigtime套件，且其估計策略與本文不同，無法完全區分稀疏誘導與估計方法差異。全文未明確說明在極大維度（如數百維以上）或極長序列下的計算與記憶體限制，以及失敗案例分析。未探討模型在非高斯或非線性動態下的適用性。

### 4. HarnessOpt-Bench: Evaluating LLMs at Harness Optimization

- 分數：3
- arXiv: [2608.06301v1](http://arxiv.org/abs/2608.06301v1)
- 發表日期：2026-08-06
- 分類：cs.AI, cs.CL, cs.LG
- 入選理由：+3 收錄於 Hugging Face Daily Papers; LLM rank #4 / 7/10: Proposes a new benchmark for harness optimization in LLM-based agentic systems with rigorous evaluation protocols and extensive experiments, establishing a measurable capability with practical relevance.

**Intro:** 隨著大型語言模型（LLMs）越來越多被部署在具行動能力的系統中，其效能不僅取決於模型本身的權重，也高度依賴於周邊的harness，即提示詞、工具、控制流程、記憶體及協調程式碼。自動化harness優化成為提升AI系統效能的重要途徑，但目前社群缺乏統一的評估協議來衡量前沿LLM在此任務上的表現。本文提出HarnessOpt-Bench，一個針對昂貴且隨機評估環境下的端到端harness優化基準，並提供可信執行環境以確保評估的嚴謹性與可重現性。

**Motivation:** harness優化的挑戰在於評估成本高且結果具有隨機性，優化器必須在有限的評估預算下，從不完整的證據中判斷失敗原因並做出系統層級的改動，這對模型的推理與決策能力提出嚴苛要求。現有方法多使用各自不同的種子、預算與評分協議，導致結果難以比較。建立一個標準化且嚴格的評估框架，對工程師與研究者在開發更可靠的自我優化AI系統具有實際價值，能促進技術落地與性能提升。

**Method:** HarnessOpt-Bench定義了一個優化問題，其中優化器為一個LLM搭配編碼harness，接收目標代理的初始harness、分級的評估反饋及固定的評估預算，通過編輯harness並提名最終候選版本。評估在開發、驗證及測試三個不重疊資料集上進行，測試集在優化過程中完全不可見，確保泛化能力的驗證。系統在可信執行環境中運行，限制優化器對測試資料與模型的存取，並記錄所有候選版本以便審計。實驗中比較了五款前沿LLM優化器在共享及原生harness上的表現，涵蓋四個下游任務，總計111次評分運行。

**Result:** 實驗結果顯示，優化器模型的選擇對性能影響大於編碼harness本身，模型間性能差異約為harness差異的1.8倍。原生harness並不總是優於共享harness，且不同任務及種子條件下的提升幅度差異顯著。多數優化器傾向廣泛探索多個harness調整槓桿，且探索範圍與提升成效呈正相關。詳細的失敗追蹤閱讀頻率低且與提升無正相關。測試集得分普遍低於驗證集的最高得分，顯示驗證結果存在樂觀偏差。模型版本更新帶來的性能提升在部分任務上超過評估噪聲範圍，證明基準能分辨模型進步。

**Conclusion:** HarnessOpt-Bench成功將harness優化能力轉化為可量化且可重複的評估任務，證明當前前沿LLM具備一定的自我優化能力，但提升仍不穩定且受任務影響大。該基準為研究者和工程師提供了一個標準化平台，以比較不同優化器與harness設計，推動自我改進AI系統的發展。未來挑戰在於提升模型在多樣任務與環境下的穩定性與泛化能力，並探索更有效的診斷與改進策略。

**Research Gap:** 本文未系統性探討種子harness複雜度對優化器性能的影響，缺乏對不同起點成熟度的控制實驗。評估僅限於Python語言與單一目標模型，尚未驗證跨語言、跨架構或多模型環境的泛化性。雖有可信執行環境限制作弊，但仍可能因固定評估環境導致優化器過度擬合，未引入隨機化以防止評估策略被利用。優化過程中詳細失敗追蹤利用率低，可能反映診斷工具不足或使用成本過高，未深入分析其原因。成本與部署風險方面，全文未明確說明優化器推理資源消耗對實際應用的影響。最後，對失敗案例與泛化失效的分析不足，限制了對優化器穩健性的全面理解。

- 分類：cs.DB, cs.AI
- 入選理由：+2 提及頂級機構：mit; LLM rank #5 / 7/10: Presents TYTAN, a hybrid neurosymbolic system for automatic semantic schema construction from relational data, achieving near-perfect coverage and correctness with human-in-the-loop disambiguation and thorough evaluation

**Intro:** 本論文針對資料分析系統中，語意層（semantic layer）建置的瓶頸問題提出解決方案。語意層負責描述資料庫中的實體、屬性及表間關係，對自然語言查詢及自動報告生成至關重要，但目前多由專家手動撰寫，限制了系統的擴展性並增加錯誤風險。作者提出TYTAN系統，結合符號方法與大型語言模型（LLM）推理，並輔以使用者互動，旨在自動構建分析用的語意結構化模式（analytic semantic schema）。

**Motivation:** 手動建立語意層需同時具備資料庫結構與領域知識，難以大規模推廣且易過時，導致非技術用戶依賴專家，降低資料分析效率。現有符號方法無法充分理解語意，LLM雖能推理但易產生幻覺與不一致，兩者各有侷限。TYTAN透過結合兩者優勢並以資料驗證與使用者澄清機制，提升語意模式建構的準確性與可靠性，促進分析系統的自動化與可用性。

**Method:** TYTAN流程包含三階段：符號分析、LLM語意推理與使用者互動澄清。首先從資料庫抽取結構性資訊（表、欄位、鍵、樣本值等），再由LLM基於結構與可選描述提出實體、屬性及關聯建議。系統以確定性規則驗證LLM輸出，如鍵唯一性、欄位值重疊檢查及類型一致性。對無法確定的決策，系統以自然語言向使用者提問，根據回覆調整模式。最終產出符合分析需求的JSON格式語意結構（ring），包含實體、屬性、分析角色、連接路徑及人類可讀標籤。

**Result:** 在八個資料庫（七個有專家標註參考模式，一個為盲測FIFA資料集）上評估，TYTAN在實體與屬性覆蓋率達100%，所有自動生成的檢索指令（共3,758項）均成功執行，語意角色與參考模式一致率介於92%至100%。盲測中，系統在無任何鍵或外鍵宣告的情況下，成功恢復完整實體結構並通過五位獨立評審的期望測試。去除資料庫元資料後，核心結構保持穩定，但關聯發現較依賴元資料。多次獨立執行結果高度一致，顯示系統穩定性良好。

**Conclusion:** 本研究提出的TYTAN系統有效結合符號與神經方法，並透過資料驗證與使用者互動，實現自動化且可靠的分析語意模式建構。評估結果顯示系統在多樣資料庫中均能完整捕捉實體與屬性，並正確執行檢索指令，支持下游分析工具使用。此方法降低了手動建置語意層的負擔，提升資料分析系統的可擴展性與易用性。系統目前侷限於關聯式資料，且對於結構複雜或資料不完整的情況仍有挑戰，使用者互動部分尚未獨立評估。

**Research Gap:** 本論文未充分探討使用者互動澄清機制的使用者體驗與效益，缺乏對澄清問題品質及回覆影響的系統性評估。系統對於多重平行外鍵的聚合屬性處理尚不完整，未涵蓋所有可能的連接路徑。對於資料樣本有限或無法完全存取的場景，基於值重疊的關聯發現方法可靠性降低，尚未提出替代策略。此外，系統主要針對關聯式資料，對於階層式或圖形資料的適用性及擴展性未明確說明。最後，評估依賴特定下游系統（SATYRN），尚缺乏對其他分析平台兼容性與實際應用成效的驗證。
