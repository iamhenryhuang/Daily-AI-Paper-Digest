### 1. Contextual Information Policy Optimization for Search Agents

- 分數：0
- arXiv: [2608.06128v1](http://arxiv.org/abs/2608.06128v1)
- 發表日期：2026-08-06
- 分類：cs.AI
- 入選理由：LLM rank #1 / 9/10: Proposes a novel reinforcement learning framework (CIPO) that explicitly aligns reasoning with retrieved evidence, addressing confirmation bias in search agents with strong empirical validation across multiple benchmarks

**Intro:** 本論文探討大型語言模型結合外部檢索工具，形成可進行多步推理的搜尋代理，特別針對知識密集且資訊複雜或不斷變化的任務。現有方法多以最終答案正確性或中間推理進展作為獎勵，卻未直接評估推理行為是否真正依據檢索到的證據，導致模型傾向於先形成內部假設，再用檢索結果做確認，產生確認偏誤並浪費證據資源。論文提出一種新穎的強化學習框架，旨在促進模型在推理過程中有效利用檢索證據。

**Motivation:** 在工程與產品層面，搜尋代理若無法合理利用檢索證據，將導致推理結果不穩定且難以解釋，影響系統可靠性與用戶信任。現有強化學習獎勵設計未能解決此問題，因為獎勵只關注最終答案，忽略推理過程中證據的實際影響。這種獎勵錯配使得模型容易陷入先驗驅動的推理模式，無法充分發揮外部知識的價值。解決此問題對於提升知識密集型任務的推理質量與效率具有重要意義。

**Method:** 作者提出Contextual Information Policy Optimization (CIPO)框架，核心在於設計Evidence-Access Log-Likelihood Ratio (EALR)作為密集的步驟級獎勵。EALR透過比較模型在有無檢索證據可見兩種條件下，對下一步推理行動的生成機率差異，量化該行動對檢索證據的依賴程度。此獎勵不需額外的人工標註或獎勵模型，結合全局最終答案獎勵，形成兼顧證據利用與答案正確性的強化學習目標。訓練過程中，模型在每個推理回合均獲得基於EALR的局部獎勵，並通過折扣累積形成回合級優勢函數，進行策略優化。

**Result:** 實驗涵蓋七個包含內域與外域的問答基準，使用Qwen2.5-3B與7B兩種模型規模。CIPO在所有基準上均優於多種強化學習與非強化學習基線，包括IGPO、GiGPO、ReasonRAG等，平均F1提升約4.7分。證據利用率分析顯示，CIPO顯著降低先驗驅動推理比例，提升基於檢索證據的推理比例。訓練效率分析指出，EALR帶來約4.6%至9.2%的額外訓練時間，但F1提升達12%至17%，性價比良好。此外，CIPO在訓練過程中表現出穩定的性能提升趨勢，且在外域數據上展現良好泛化能力。

**Conclusion:** 本研究提出的CIPO框架有效解決了搜尋代理中獎勵錯配導致的先驗驅動推理問題，通過EALR獎勵促進模型在推理過程中真實利用檢索證據，提升了多項問答任務的性能與證據依賴性。該方法不依賴人工標註或額外獎勵模型，具備較好的實用性與擴展潛力。整體結果強調了在強化學習中明確獎勵證據利用的重要性，對於構建更可靠且可解釋的知識型搜尋代理具有指導意義。

**Research Gap:** 論文未明確說明EALR在更長推理序列或多工具、多模態環境下的適用性與效率，且缺乏對失敗案例或泛化失效情況的深入分析。實驗主要集中於問答任務，對其他類型知識密集任務的適用性尚未驗證。雖然EALR不需額外標註，但增加的計算成本與訓練複雜度可能限制實際部署，尤其在資源受限環境下。未提供對比不同證據遮蔽策略或獎勵權重調整的消融實驗，對獎勵設計的敏感性和穩定性評估不足。未探討模型在面對錯誤或誤導性檢索結果時的魯棒性與風險控制。

### 2. PRISM: Distribution-Gated Flow Matching for Controllable Unpaired Image Translation

- 分數：0
- arXiv: [2608.06240v1](http://arxiv.org/abs/2608.06240v1)
- 發表日期：2026-08-06
- 分類：cs.CV, cs.AI
- 入選理由：LLM rank #2 / 8/10: Introduces PRISM, a novel GAN-free flow-matching method for controllable unpaired image translation with per-feature gating, showing state-of-the-art results on diverse natural and biomedical benchmarks, demonstrating cl

**Intro:** 本論文針對無配對影像轉換中如何決定哪些區域應保留、哪些應改變的問題提出解決方案。現有擴散模型多以單一全域參數控制保留程度，無法區分不同區域的內容與外觀變化需求。作者提出PRISM，一種基於流匹配的無GAN框架，透過學習每個特徵位置的保留門控，根據該特徵與目標分布的距離決定保留程度。此方法可同時控制初始化與運輸時序，並支援推理時局部覆寫，提升控制靈活性與結構保留能力。

**Motivation:** 無配對影像轉換因缺乏像素對應，難以精確判斷哪些內容應保留。現有方法如CycleGAN等對保留控制隱含於判別器中，易導致模式崩潰與訓練不穩定。擴散模型雖穩定，但全域噪聲控制無法區分不同區域需求，造成過度或不足翻譯。工程上，精細控制可提升產品生成品質與用戶體驗，醫療影像中更需保留關鍵結構以維持診斷準確性。故需一種可解釋且可控的機制，實現區域性保留與改變。

**Method:** PRISM採用兩階段架構，第一階段訓練凍結的域條件流匹配模型，第二階段學習一個U-Net門控預測器，輸出每個特徵位置的保留門控τ。該門控以特徵與目標分布距離的標準化值作為空間先驗，並用於混合真實來源潛碼與任務匹配的腐蝕（結構保留用AdaIN，結構改變用部分錨定噪聲）以初始化ODE起點，同時控制ODE積分中各特徵的啟動時刻。此設計使高τ特徵保持來源狀態，低τ特徵則較早開始轉換。另有一個受限的修正網路用以調整流場，並結合多層MMD與k-NN DINO特徵匹配作為無GAN真實感驅動。醫療影像中加入診斷一致性損失以保證語義不變。

**Result:** PRISM在五個自然與醫療影像基準（AFHQ貓轉狗、CelebA男轉女、日夜光照轉換、虛擬染色、乳腺冷凍切片轉永久切片）下進行評估。與CycleGAN、CUT、SDEdit、UNSB、EGSDE等方法比較，PRISM在四個基準取得最低FID與KID，並在第五個基準表現競爭。醫療影像中，PRISM在核細胞數量比率接近理想值，顯示結構保留優於其他方法。實驗亦展示門控與特徵位移相關，推理時可用文字或檢測器局部覆寫門控，實現靈活控制。消融實驗證實門控粒度、分布先驗與內容錨定腐蝕對性能均有正面影響。

**Conclusion:** 本研究將無配對影像轉換視為選擇性特徵運輸問題，提出基於分布距離的每特徵保留門控，結合任務匹配的初始化與受限修正，實現無GAN且具可控性的轉換。PRISM在多種任務中達成優異的真實感與結構保留平衡，並支援推理時局部調整，對工程與產品落地具實用價值。限制包括缺乏真實空間變化標註驗證、門控動態無理論保證、計算加速潛力未實現，以及醫療評估依賴自動指標未經臨床驗證。未來可探索學習式計算分配與更廣泛的應用場景。

**Research Gap:** 本論文雖提出創新門控機制，但未提供對門控空間分布的真實變化標註驗證，無法確定門控語義正確性。門控動態設計為經驗性，缺乏理論分布保證，可能影響泛化。計算節省分析僅為理想化估計，實際加速需結構稀疏執行支持，尚未實現。醫療影像評估依賴自動核細胞檢測與指標，缺乏病理專家盲測與臨床驗證，限制臨床應用信心。實驗多在256×256解析度，尚未驗證高解析度或更複雜場景。推理時局部覆寫雖示範有效，但對不同文本或檢測器的穩定性與泛化未充分探討。最後，模型需針對每對域分別訓練，缺乏多域或通用轉換能力。

### 3. Handling Missing Data in Probabilistic Regression Trees

- 分數：0
- arXiv: [2608.06195v1](http://arxiv.org/abs/2608.06195v1)
- 發表日期：2026-08-06
- 分類：stat.ML, cs.LG
- 入選理由：LLM rank #3 / 8/10: Extends probabilistic regression trees to handle missing data directly with theoretically grounded methods and empirical evidence of improved performance over classical trees, addressing a common practical challenge in M

**Intro:** 本論文聚焦於決策樹在迴歸任務中處理缺失資料的問題。傳統的回歸樹如CART雖然易於解釋，但預測結果為分段常數，難以捕捉平滑的函數關係。Probabilistic Regression Trees（PRTrees）透過概率分配取代硬分割，能產生連續且一致的預測，但原始方法未提供原生的缺失值處理機制。缺失資料在實務中普遍存在，若無法直接處理，需額外進行插補或刪除，增加流程複雜度與潛在偏誤。論文旨在擴展PRTree框架，使其能在建樹過程中直接處理缺失預測變數，避免事前插補。

**Motivation:** 缺失資料會降低有效樣本數並增加預測不確定性，對模型解釋與性能造成挑戰。現有方法多依賴外部插補，可能引入不連續性，與PRTree追求平滑預測的目標相悖。CART的替代分割策略無法直接套用於概率式樹模型，因為後者以平滑概率分配觀察值至節點。缺乏內建缺失值處理限制了PRTree在實務場景的應用。故本研究提出三種策略，分別利用不同程度的可用資訊，保留PRTree的概率結構與理論性質，提升模型在含缺失資料環境下的適用性與穩健性。

**Method:** 本研究提出三種缺失值處理策略，分別由參數fill type控制：0為均勻概率法，當缺失時不考慮觀察值，平均分配至子節點；1為部分觀察法，僅根據已觀察的維度進行硬分配；2為降維平滑法，將觀察值與區域投影至已觀察維度空間，並應用原始平滑函數。這些策略皆保證概率守恆與邊際相容性，且在無缺失時退化為標準PRTree。模型參數透過最小平方誤差交替估計區域權重與分割，並以交叉驗證選擇平滑參數。實作已整合於R語言的PRTree套件中，方便工程與研究使用。

**Result:** 實驗採用五個含自然缺失值的公開迴歸資料集，與CART進行15折交叉驗證比較。結果顯示缺失值處理策略是影響預測表現的主要因素，fill type 1與2通常優於fill type 0，且在缺失比例高的資料集（如Crime、Ozone）中，PRTree明顯優於CART。fill type的影響遠大於平滑分布或代理選擇標準。平滑分布中，Student-t分布表現較佳但非絕對。計算成本方面，PRTree遠高於CART，主要因平滑參數調整與多候選分割評估，且fill type 2計算負擔最大。整體而言，PRTree在缺失值多的場景下提供了有效且可解釋的替代方案。

**Conclusion:** 本論文成功將缺失值處理整合入PRTree框架，提出三種策略以保留概率結構並直接處理不完整預測變數。實驗證明缺失值處理策略對預測性能影響顯著，且在缺失比例高的資料中，PRTree優於傳統CART。雖然計算成本較高，但提供了避免插補的非參數解決方案，提升模型在實務中面對缺失資料的適用性。未來研究可探索其他概率規格、集成方法及更高效的分割評估策略，以進一步提升性能與效率。

**Research Gap:** 全文未明確說明缺失值處理策略在不同缺失機制（MCAR、MAR、MNAR）下的理論保證與實務表現，缺乏對缺失機制假設的敏感度分析。實驗僅涵蓋五個資料集，資料多樣性與缺失模式覆蓋有限，泛化性尚待驗證。消融實驗主要聚焦於fill type，對平滑分布與代理標準的深入比較不足。計算成本高昂，未探討實際部署中對資源限制的影響與優化空間。缺少失敗案例或模型在極端缺失情況下的魯棒性分析。理論一致性證明未延伸至含缺失值的擴展版本，理論基礎仍待加強。

### 4. Gryphon-v2: One Model in Place of a Cascade - Generate-and-Rank Recommender with Rollout Distillation

- 分數：0
- arXiv: [2608.06213v1](http://arxiv.org/abs/2608.06213v1)
- 發表日期：2026-08-06
- 分類：cs.IR
- 入選理由：LLM rank #4 / 8/10: Presents Gryphon-v2, a unified generate-and-rank recommender that replaces complex cascades with a single model using rollout distillation, validated by a large-scale online A/B test showing improved user engagement and 

**Intro:** 工業推薦系統通常採用多階段級聯架構，包括候選生成器、預排序器和最終排序器，雖然效果良好，但維護成本高且服務延遲較長。Semantic-ID基礎的生成式檢索提供了簡化端到端系統的可能，但僅靠下一項預測無法捕捉生產排序目標中的細粒度偏好。本文提出Gryphon-v2，一種統一的生成與排序架構，通過共享編碼器一次編碼用戶歷史，生成Semantic-ID候選並用項目級排序模組重新排序，旨在替代傳統多階段級聯系統。

**Motivation:** 多階段推薦系統存在用戶歷史重複處理、複雜特徵管線及多次服務階段的問題，導致系統維護和延遲成本高。生成式推薦雖可簡化流程，但缺乏對生產環境中多目標排序偏好的精細捕捉。現有方法要麼通過強化學習後訓練調整生成器，要麼嘗試將生成與排序統一，但多數仍需額外模型或重複編碼。Gryphon-v2結合這兩條路徑，通過知識蒸餾將高容量教師排序器的細粒度偏好傳遞給輕量排序模組，實現單模型端到端推薦，降低服務複雜度並保持性能。

**Method:** Gryphon-v2採用共享編碼器架構，對用戶歷史進行一次編碼，接著自回歸解碼器生成Semantic-ID候選，並將其映射到具體目錄項目。候選項目由項目級排序模組根據共享編碼器狀態進行排序。為傳遞生產排序器的細粒度偏好，設計了Rollout Distillation訓練流程，利用一個高容量、僅訓練用的教師排序器對兩類候選（解碼器生成的rollout候選和生產日誌中的曝光候選）進行評分，並以均方誤差或平均絕對誤差損失蒸餾給排序模組。整體訓練結合下一項預測損失和蒸餾損失，實現生成與排序的聯合優化。

**Result:** 離線實驗中，Gryphon-v2在候選生成召回率（Recall@1000）與基線相當，且在教師排序器一致性指標（TeacherRecall@k）上大幅超越無蒸餾模型，顯著提升排序模組的精確度。加權對比準確率（WPA）也優於其他生成模型，接近教師排序器和生產排序器的水平。線上A/B測試中，Gryphon-v2以單一模型替代超過15個候選生成器及後續排序階段，活躍用戶數提升1.41%，總聆聽時長增加1.62%，且服務延遲與生產級聯相當。消融實驗顯示，結合rollout與曝光候選的蒸餾效果最佳，且不同蒸餾損失對性能有細微影響。

**Conclusion:** 本文提出的Gryphon-v2成功整合生成與排序功能，通過Rollout Distillation將高容量教師排序器的偏好知識有效蒸餾至輕量排序模組，實現單模型替代傳統多階段推薦級聯。實驗結果證明該方法在保持候選質量的同時，顯著提升排序準確度並改善用戶參與度，且服務延遲可控，具備實際部署價值。此架構簡化了推薦系統的服務流程，降低了維護和計算成本，為工業推薦系統提供了一種可行的端到端替代方案。

**Research Gap:** 本文的線上實驗僅在單一音樂推薦場景和有限用戶樣本中進行，未評估長期效果、全量用戶部署後的表現及對長尾項目、多樣性和新穎性的影響。離線指標如TeacherRecall@k和WPA均依賴教師排序器或生產曝光數據，無法獨立衡量端到端推薦質量。蒸餾方法未與基於強化學習的後訓練方法進行直接比較，缺乏對穩定性和計算效率的分析。此外，Rollout Distillation的計算成本隨beam大小增加顯著，實際部署中需權衡性能與成本。未明確說明在極端用戶行為或冷啟動場景下的泛化能力和失敗案例。
