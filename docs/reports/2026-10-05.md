**Intro:** 本論文聚焦於金屬有機框架（MOF）假設驗證中，現有大型語言模型（LLM）在結構識別、合成條件驗證、證據充分性判斷及計算驗證等環節的可靠性問題。MOF領域因結構標識多樣、實驗條件影響大、證據來源異質且部分假設需計算支持，使得驗證流程複雜且易出錯。作者提出一套診斷性基準測試，細分驗證流程中的失敗點，並基於此設計一個失敗感知的代理式驗證框架MOF-VERIFY，旨在提升整體驗證準確度與可靠性。

**Motivation:** MOF材料的發現與驗證涉及多源異構資料及計算工具，單純依賴LLM生成答案易導致錯誤判斷，尤其在結構識別錯誤、合成條件誤讀、證據不足判斷失誤及計算失敗等方面。現有系統多聚焦最終任務表現，缺乏對錯誤來源的細緻定位，難以針對性改進。為了在工程與產品層面提升MOF驗證的可靠性，必須明確區分失敗環節並設計專門模組加以補救，這對於實際部署AI輔助材料科學家系統具有重要意義。

**Conclusion:** 本研究提出一套細分MOF假設驗證失敗原因的診斷基準，並基於此設計MOF-VERIFY代理式驗證框架，透過專門模組針對結構識別、文獻抽取、證據充分性及計算驗證等瓶頸進行補救。實驗結果顯示該框架在多種LLM骨幹上均能顯著提升驗證準確度，特別是在結構與計算驗證任務中效果明顯。此方法為AI輔助材料科學家系統的可靠性提升提供了可行路徑，並強調了多模組協同與證據追蹤的重要性。

### 2. RIPPLE in Still Water: Zero-Shot Clustering in Federated Learning with Wavelet Scattering Transform

- 分數：5
- arXiv: [2610.03054v1](http://arxiv.org/abs/2610.03054v1)
- 發表日期：2026-10-02
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mila, mit; +3 提及頂級會議：acl, neurips; LLM rank #2 / 8/10: Proposes RIPPLE, a novel offline spectral clustering method for federated learning with strong theoretical guarantees and consistent empirical gains on realistic benchmarks, addressing key practical and security issues.

**Intro:** 聯邦學習在面對非獨立同分布（non-IID）資料時，單一全局模型常因客戶端資料差異大而導致性能下降。分群聯邦學習透過將客戶端分組並為每組訓練專屬模型，有效緩解此問題。然而，現有方法多在訓練過程中動態發現分群結構，增加通訊負擔並暴露隱私風險。本文提出RIPPLE，一種基於客戶端本地資料頻譜特徵的離線分群方法，利用Wavelet Scattering Transform（WST）與高斯混合變分自編碼器（GMM-VAE）實現零次分群分配，無需額外通訊或梯度交換。

**Motivation:** 現有分群聯邦學習方法依賴訓練中動態計算分群，導致通訊成本增加且易受梯度反演攻擊，且無法為未參與訓練的新客戶端分配模型。這在實際工程部署中增加了系統複雜度與安全風險。RIPPLE透過離線預先計算分群權重，降低通訊負擔並提升安全性，且支持新客戶端零次分群分配，對於需要高效且安全的聯邦學習系統具有重要意義。

**Method:** RIPPLE首先從每個客戶端本地資料計算變異數加權主成分原型，並透過Wavelet Scattering Transform獲得穩定的頻譜嵌入。伺服器端事先在合成客戶端資料上訓練一個GMM-VAE，將嵌入映射到軟分群權重向量。分群權重在聯邦訓練開始前固定，客戶端模型更新時根據權重加權聚合梯度。此方法避免了訓練中分群計算，通訊成本與FedAvg相同，且新客戶端可透過單次前向推理獲得分群權重，實現零次分群分配。此外，RIPPLE-HDB版本利用HDBSCAN自動調整群數。

**Result:** 在五個涵蓋標籤不均衡、實際異質性及長尾分布的資料集（MNIST、CIFAR-10/100、Office-Home、GLDv2）上，RIPPLE三種變體均優於11個基線方法，包括全局、個人化及其他分群聯邦學習方法。特別是在真實異質性較強的GLDv2資料集上，RIPPLE-STRAT較最佳基線IFCA提升約7.4%。在新客戶端零次分群分配實驗中，RIPPLE-UNIF在CIFAR-10與CIFAR-100均超越基線的最佳模型選擇策略。RIPPLE-HDB在部分資料集表現不佳，顯示自動群數調整需謹慎使用。

**Conclusion:** 本文提出的RIPPLE框架成功將分群分配從訓練過程中分離，實現離線、零次分群分配，降低通訊成本並提升安全性。理論上證明分群目標與理想目標的差距可控且不依賴訓練輪數，且分群模型收斂速率達到最優。實驗結果顯示RIPPLE在多種異質性場景下均優於現有方法，特別是在真實世界資料分布中表現突出。此方法對於需要高效、安全且支持新客戶端快速個人化的聯邦學習系統具有實際應用價值。

**Research Gap:** 全文未明確說明RIPPLE在極端非IID或極少樣本客戶端的穩定性與泛化能力，尤其是頻譜嵌入對於高度動態或非平穩資料分布的適應性。此外，GMM-VAE訓練依賴合成資料，對真實資料分布的代表性及其對分群準確度的影響未充分探討。RIPPLE-HDB在部分資料集表現不佳，顯示自動群數選擇機制尚需改進。成本方面，雖然通訊成本與FedAvg相當，但頻譜嵌入與GMM-VAE推理的計算負擔及其在資源受限設備上的實際部署挑戰未詳述。最後，缺乏對失敗案例或極端異質性場景下模型表現的深入分析。

### 3. EVOL: Simulator-Guided Evolutionary Expert Synthesis for Deployment-Free Learning Path Recommendation

- 分數：5
- arXiv: [2610.03273v1](http://arxiv.org/abs/2610.03273v1)
- 發表日期：2026-10-02
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #3 / 7/10: Presents EVOL, a simulator-guided evolutionary approach to learning path recommendation overcoming sparse rewards and lack of expert data, with strong empirical results across multiple datasets and imitation strategies.

**Intro:** 學習路徑推薦（LPR）旨在為個別學習者推薦一系列知識概念，以最大化其目標概念的掌握度。此任務面臨兩大挑戰：一是策略必須在無中間反饋的情況下，從初始狀態一次性規劃完整路徑，導致組合空間超指數增長且獎勵稀疏；二是缺乏專家示範路徑，因為學生日誌只記錄實際行為而非理想行為。本文提出的EVOL框架借鑒機器人模擬器中示範學習的做法，利用知識追蹤模擬器合成個別學習者的專家示範，並訓練一個無需部署時模擬器的策略。該策略基於非對稱演員-評論家架構，演員在部署時僅依賴初始掌握狀態進行盲規劃，評論家則在訓練時利用模擬器的特權狀態。實驗涵蓋三個資料集與不同路徑長度，結果顯示EVOL優於多種基線方法。

**Motivation:** LPR的核心困難在於必須在無中間反饋的情況下規劃長序列，導致探索空間極大且獎勵稀疏，傳統強化學習難以有效學習。此外，教育領域缺乏可用的專家示範路徑，限制了示範學習方法的應用。現有方法若在推理時依賴模擬器反饋，則與實際部署場景不符，因為真實系統無法獲得未來學習者的中間掌握狀態。EVOL透過離線模擬器內的進化搜尋合成高質量專家路徑，並將其蒸餾為部署時無需模擬器的策略，解決了探索效率與部署現實性的矛盾，對工程和產品落地具有重要意義。

**Method:** EVOL包含三個主要階段：第一階段利用知識演化模擬器（KES）和進化算法，針對每位訓練學習者在候選概念集合中搜尋高效學習路徑，該集合結合目標概念、先修與相似概念及近端發展區域概念。第二階段以行為克隆（BC）方式，從合成的專家路徑中學習策略，策略輸入僅包含初始掌握狀態、目標掩碼及步驟索引，確保部署時無需模擬器。第三階段先對評論家進行warm-start，再用PPO進行策略微調，評論家在訓練時可利用模擬器提供的演化掌握狀態以提升價值估計準確度。此非對稱演員-評論家架構確保部署策略完全獨立於模擬器。論文亦比較了三種示範利用策略（BC、AWR、DAPG），證明性能主要受專家品質影響。

**Result:** 在三個資料集（ASSIST15、Junyi、EdNet）及路徑長度5、10、20的設定下，EVOL的三個變體均在效果百分比（EP）指標上超越八個涵蓋啟發式、序列模型、強化學習、圖增強強化學習及LLM增強方法的基線。消融實驗顯示，進化搜尋生成的專家路徑質量是性能提升的關鍵，隨機路徑示範無法帶來相似效果。非對稱評論家warm-start有助於穩定早期訓練。EVOL策略在目標覆蓋率和序列排序敏感性方面均優於基線，且在模擬器實例變異和隨機響應模型下保持較好魯棒性。不同示範利用方法間性能差異微小，強調專家合成的重要性。

**Conclusion:** 本文提出的EVOL框架成功將機器人領域的模擬器引導示範學習方法移植至教育領域的學習路徑推薦，解決了稀疏獎勵與無中間反饋的挑戰。通過進化搜尋合成高質量專家路徑並蒸餾為無需模擬器的部署策略，實現了高效且部署現實的推薦系統。實驗結果證明該方法在多資料集、多路徑長度下均優於多種先進基線，且對模擬器變異及隨機性具備良好魯棒性。限制在於依賴DKT模擬器的準確性，且未在真實線上學習者中驗證，未來需進一步評估實際教學效果及擴展至更複雜的教育場景。

**Research Gap:** 本文未在真實線上學習環境中驗證策略的實際教學效果，僅依賴DKT模擬器作為知識演化模型，該模擬器對不同學習者能力差異的表達有限，可能影響專家路徑的真實有效性。實驗中所有基線均在嚴格的無模擬器推理條件下比較，這限制了與原始方法在其假設下的性能對比。進化搜尋的計算成本雖可並行化，但對於大規模即時部署仍有挑戰。缺乏對失敗案例或策略泛化能力的深入分析，尤其是在模擬器外部環境變化或非典型學習者上的表現。此外，對於多目標或動態調整的學習路徑推薦場景，本文未提供相關探討或擴展方案。

### 4. Sample complexity of variance-reduced policy gradient: weaker assumptions and lower bounds

- 分數：5
- arXiv: [2610.03165v1](http://arxiv.org/abs/2610.03165v1)
- 發表日期：2026-10-02
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #4 / 7/10: Provides a theoretically grounded variance-reduced policy gradient algorithm with weaker assumptions and matching lower bounds, offering credible advances in RL sample complexity analysis.

**Intro:** 政策梯度方法是強化學習中重要的演算法，適用於大規模決策與控制問題。這類方法的樣本複雜度通常很高，導致訓練時間長與資源消耗大，限制了其在實際系統中的應用。過去基於重要性採樣的變異數降低版本能將樣本複雜度從O(ϵ^{-4})改善到O(ϵ^{-3})，但依賴於不切實際的假設，即重要性權重的變異數有界。本文提出一種新的演算法DEF-PG，利用防禦性重要性採樣技術，在不需該假設下達成相同的O(ϵ^{-3})樣本複雜度，並且建立了相應的理論下界，提供了該速率的最佳性證據。

**Motivation:** 政策梯度方法在多種應用中展現潛力，但其高昂的樣本需求限制了工程與產品的落地。現有的變異數降低方法雖提升效率，卻依賴於不合理的變異數有界假設，實務中常見無法滿足。如何在不依賴此假設的前提下，設計有效且理論有保障的演算法，是推動政策梯度方法實際應用的關鍵。本文透過防禦性重要性採樣，解決了重要性權重變異數無界的問題，對工程實現與理論分析均具重要意義。

**Method:** 本文提出DEF-PG演算法，基於防禦性重要性採樣的混合分布，將目標策略與行為策略的軌跡分布以加權混合方式抽樣，確保重要性權重的變異數有界。演算法結合了PAGE的隨機變異數降低框架，交替使用大批量的全梯度估計與小批量的防禦性重要性採樣修正梯度，實現樣本效率提升。理論上，演算法在標準的政策正則性條件下，滿足平滑性能函數、有限變異數單策略反饋及均方連續雙策略耦合反饋的假設，證明可達到O(ϵ^{-3})的樣本複雜度。

**Result:** 在標準假設（如有界獎勵、政策分數的有界性與均方連續性）下，DEF-PG在理論上達成O(ϵ^{-3})的樣本複雜度，優於傳統REINFORCE的O(ϵ^{-4})。此外，本文在一個廣義的黑盒政策優化模型中，分別對單策略與雙策略反饋建立了匹配的下界，證明了該複雜度的最佳性。這些結果在理論層面支持了DEF-PG相較於傳統政策梯度方法的優勢，且不依賴於重要性權重變異數有界的假設。

**Conclusion:** 本文提出的DEF-PG演算法利用防禦性重要性採樣，成功消除了過去變異數降低政策梯度方法中不切實際的變異數有界假設，並在理論上達成了最佳的O(ϵ^{-3})樣本複雜度。透過黑盒模型的下界分析，提供了該速率的最佳性證據，凸顯了雙策略耦合反饋在樣本效率上的本質優勢。限制在於下界分析未直接涵蓋傳統MDP互動模型，且演算法對政策分數的均方連續性假設仍有一定限制，未來仍需驗證在更廣泛政策類別及實務場景的泛化能力。

**Research Gap:** 本文的理論下界是在一個較為抽象的黑盒模型中建立，尚未直接證明在標準MDP互動模型下的最小樣本複雜度，缺乏對實際環境中狀態與行動可觀測情況的考量。此外，DEF-PG依賴政策分數的均方連續性與有界性假設，對於常見的高斯策略等連續動作空間政策可能不完全適用。實驗部分全文未明確說明，缺乏對演算法在多樣化任務、不同策略類型及實際部署成本的評估。未來研究可聚焦於放寬政策假設、擴展至第二階資訊利用、以及在真實強化學習環境中的實證驗證。

### 5. MintEval: Do LLMs Implement the Trading Strategy You Asked For? A Behavioural-Equivalence Benchmark for Natural-Language-to-Strategy Code

- 分數：4
- arXiv: [2610.03080v1](http://arxiv.org/abs/2610.03080v1)
- 發表日期：2026-10-02
- 分類：cs.SE, cs.CL, cs.LG, q-fin.TR
- 入選理由：+2 提及頂級機構：mila; +2 提及程式碼可用; LLM rank #5 / 6/10: Introduces MintEval, a novel behavioral-equivalence benchmark for natural-language-to-strategy code in trading, revealing silent failures in LLM-generated code with strong empirical analysis and public code.

**Intro:** 本文探討大型語言模型（LLMs）在將自然語言交易策略轉換為可執行程式碼時，存在的隱性失效問題。現有的程式碼評測多著重功能正確性或財務預測能力，卻無法衡量生成程式碼是否真正執行了使用者所描述的策略邏輯。作者提出MintEval基準，透過行為等價性評估，檢驗模型生成的策略程式碼在相同市場資料與摩擦條件下，是否與參考策略在每個時間點的行為一致。

**Motivation:** 在金融交易中，策略實作錯誤可能導致嚴重損失，但這類錯誤往往不易被察覺，因為程式碼能正常執行且回測結果看似合理。現有評測無法捕捉此類隱性失效，導致模型生成的策略程式碼雖通過測試卻未忠實反映交易意圖。對於工程與產品落地而言，確保策略實作的行為一致性是降低運營風險的關鍵，因此需要一套能精確評估行為等價性的基準。

**Method:** MintEval基準由程式化生成的參考策略組成，這些策略由可組合的建構模組組成，並經由LLM反向翻譯成口語化的交易員指令，模型需根據指令重新實作策略程式碼。兩段程式碼在相同市場資料與摩擦條件下逐根K線執行，並以行為等價性指標ActionMatch評估兩者在持倉行為上的吻合度。基準同時考量策略狀態跨度（state-span complexity）與描述長度，並提供開放與封閉兩種設定，封閉設定中模型可使用建構模組菜單以輔助理解。

**Result:** 在800個BTCUSDT 15分鐘資料的任務中，低成本模型最高ActionMatch約0.544，完全重現任務比例僅0.087。前沿模型Claude Opus 5.5在200個分層任務上ActionMatch達0.889，完全重現比例0.575，但仍有27.5%任務存在隱性失效。模型在理解指令（SpecMatch）方面表現良好，但多數隱性失效源於持續狀態邏輯實作錯誤。狀態跨度越大，模型行為吻合度下降。現有以程式碼閱讀為基礎的評判方法無法識別這些隱性失效。

**Conclusion:** MintEval提供了一種針對自然語言到策略程式碼轉換的行為等價性評估框架，揭示了LLM在策略實作中存在的隱性失效風險。該基準強調持續狀態管理的重要性，並指出現有評測方法不足以捕捉策略行為偏差。對金融工程與產品部署而言，MintEval有助於提升策略生成的可靠性與安全性，但目前基準規模有限，且策略多為程式化生成，尚未涵蓋真實交易策略分布。

**Research Gap:** 本文基準以程式化生成策略為主，尚未充分涵蓋真實交易策略的多樣性與複雜度，可能影響結果泛化。策略指令由LLM生成，可能較友善於模型理解，缺少真實交易員語言的多樣性與模糊性。實驗僅使用單一交易品種與時間框架，缺乏跨市場、跨時間尺度的驗證。隱性失效的系統性分類與根因分析尚未完成，對模型失敗模式的理解仍有限。基準未考慮執行延遲與實際部署成本，對生產環境適用性評估不足。最後，前沿模型結果可能受限於與基準設計者相同家族模型，跨模型家族的可重現性尚待驗證。
