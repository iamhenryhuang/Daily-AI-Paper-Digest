### 1. Frontis-MA1: Training an AI4AI Model towards Recursive Self-Improvement in Machine Learning Engineering

- 發表日期：2026-07-30
- 分類：cs.CL
- 入選理由：+2 提及頂級機構：meta; +3 收錄於 Hugging Face Daily Papers; +2 提及程式碼可用; LLM rank #1 / 9/10: Introduces a novel open full-stack system (OpenMLE) for recursive self-improvement in machine learning engineering with strong empirical results surpassing state-of-the-art models; provides reproducible code and model we

**Intro:** 本論文聚焦於遞迴自我改進（RSI）中的AI4AI系統，特別以機器學習工程（MLE）作為具體且可執行的測試平台。提出OpenMLE全棧系統，涵蓋可驗證的任務環境（OpenMLE-Gym）、可訓練的演化操作子學習（OpenMLE-ERL）及長期搜尋策略（OpenMLE-Evo）。基於此系統，訓練Frontis-MA1-35B模型作為元演化代理，並在MLE-Bench Lite與NatureBench Lite等基準上展示其性能與轉移能力。論文同時釋出模型權重與完整系統，促進可重現研究。

**Motivation:** AI系統自我改進的終極目標是遞迴自我改進，這需要AI不僅能生成解決方案，還能持續優化自身改進流程。MLE作為AI4AI的具體實例，要求代理能在實際任務中反覆透過執行反饋改進機器學習解決方案。現有研究多聚焦於單一環節，缺乏涵蓋環境建構、模型後訓練與長期演化搜尋的整合方案。OpenMLE旨在填補此缺口，提供一個完整且可擴展的技術棧，支持從任務構建到模型訓練再到推理搜尋的閉環，推動RSI研究向前。

**Method:** OpenMLE系統包含三大核心組件：OpenMLE-Gym提供5,758個經過質量篩選的可執行任務環境，支援隔離執行與結構化反饋；OpenMLE-ERL訓練四種原子演化操作子（Draft、Improve、Debug、Crossover），透過執行結果導向的監督微調與強化學習提升操作子品質；OpenMLE-Evo則利用結構化經驗卡與多因子父節點選擇策略，結合操作子條件化記憶合成，實現長期且經驗驅動的演化搜尋。Frontis-MA1模型在此架構下進行後訓練，並作為演化搜尋的變異引擎。

**Result:** 在MLE-Bench Lite 22任務子集上，Frontis-MA1-35B結合OpenMLE-Evo後，Medal Average由39.39%提升至60.61%，Human Rank亦顯著提升。進一步使用OpenMLE-Evo-Max配置，Medal Average達71.21%，超越GPT-5.5與Codex組合，接近GPT-5.6 Sol與2.8T Kimi K3。30B版本模型亦重現類似提升。OpenMLE-Evo在多個模型家族中均優於通用編碼代理架構。長期搜尋分析顯示，後期Improve與Crossover操作貢獻大部分性能提升。跨模態分析與NatureBench Lite轉移實驗證明模型與搜尋框架具一定泛化能力。

**Conclusion:** 本研究提出OpenMLE作為一個開放且完整的技術棧，實現了從可執行任務環境、執行反饋導向的操作子訓練，到長期經驗驅動的演化搜尋的閉環。Frontis-MA1模型在此架構下展現出顯著的性能提升與跨任務轉移能力，並在多項基準中超越多個先進系統。此系統為可重現的AI4AI與RSI研究提供了堅實基礎，促進未來在自我改進代理設計與長期搜尋策略上的探索。

**Research Gap:** 論文雖展示了整合後訓練與演化搜尋的成效，但仍存在多項限制。首先，改進目標主要依賴執行結果分數，缺乏對研究方向潛力、泛化性或策略價值的評估，限制了改進者的判斷能力。其次，演化搜尋與通用編碼代理仍分離，限制了模型自主發起多樣化操作的能力。第三，現有環境僅涵蓋MLE範疇，代理參與AI開發流程的範圍有限，尚未涵蓋語言模型自身的改進。第四，演化系統本身未被演化，缺乏更高層次的自我優化。最後，經驗卡雖記錄豐富元數據，但父節點選擇策略僅利用三個固定因子，未充分挖掘全部經驗訊號，且缺乏任務依賴的動態權重學習，限制搜尋策略的適應性與效率。

### 2. ShadowDancer: Teaching Video World Models Any Action by Learning Unified Dynamics Representations from a Video and Its Shadow

- 分數：6
- arXiv: [2607.28362v1](http://arxiv.org/abs/2607.28362v1)
- 發表日期：2026-07-30
- 分類：cs.CV, cs.AI, cs.LG
- 入選理由：+3 收錄於 Hugging Face Daily Papers; +3 提及頂級會議：acl; LLM rank #2 / 8/10: Presents a novel method (ShadowDancer) for precise action control in video world models using innovative shadow pairs and cross-shadow prediction; shows strong empirical improvements and provides a website for results, i

**Intro:** 本論文提出ShadowDancer，一種針對互動式視頻世界模型的任意動作逐幀控制方法。現有方法在動作表示上存在限制，要麼動作編碼過於寬鬆，導致模型自行即興生成動作過程，要麼動作編碼過於嚴格，依賴難以取得的結構化信號，難以跨多樣動態精確控制。示範視頻雖然能逐幀指定動態，但因為視頻只呈現特定外觀下的動態陰影，導致學習的動作難以轉移到新場景。ShadowDancer透過學習視頻及其陰影的統一動態表示，解決了這一問題。

**Motivation:** 互動式世界模型在視頻生成和模擬中具備重要應用，但缺乏一套既精確又通用的動作控制接口。現有符號或文本命令無法精確指定動作細節，而結構化運動輸入雖精確但侷限於特定動態家族且難以獲取。示範視頻作為自然的動作規範方式，卻因動態與外觀糾纏，導致動作表示不具備跨場景轉移能力。從工程和產品角度看，若能從示範視頻中提取可重用且跨場景通用的動作表示，將大幅提升互動世界模型的可控性和擴展性。

**Method:** 核心方法包括兩大創新：(1)陰影對（Shadow pairs）：通過Shadow Library大規模構建同一動態在不同外觀下的視頻對，確保動態家族可控；(2)跨陰影預測（cross-shadow prediction）：編碼器從一個視頻中提取動作潛變量，解碼器則在目標陰影的外觀上下文中預測另一陰影的下一幀，強制潛變量只保留動態信息，丟棄外觀差異。該潛變量作為統一動態表示，驅動基於視頻擴散模型的區塊因果世界模型，可實現任意動作的逐幀控制。示範片段經編碼後成為可重用的動作資產，無需動作標籤、運動估計器或微調即可在新環境中重放。

**Result:** 實驗涵蓋多種動態家族（人類動作、第一人稱戰鬥、第三人稱動作、機器人操作、攝像機控制），在動作轉移任務中，ShadowDancer在PSNR、LPIPS、ATE和RPE等指標上均顯著優於Olaf-World基線，平均勝率達86%。長期動作滾動實驗中，通過盲測2AFC評估，ShadowDancer在動作控制、動作忠實度及長期一致性方面均優於LingBot-World 2.0、Yume-1.5及Olaf-World。消融實驗證明陰影配對是提升性能的關鍵，源資產輔助提升細節表現。額外測試表明，模型能成功轉移訓練外的動作資產，展示良好泛化能力。

**Conclusion:** ShadowDancer通過陰影對和跨陰影預測，學習到一種統一且可重用的動態表示，實現了任意動作的逐幀精確控制，且無需動作標籤或微調。該方法在多種動態家族和場景中均展現出優越的動作轉移和長期滾動能力，為互動視頻世界模型提供了更靈活且通用的控制接口。此技術對娛樂、模擬訓練等領域的應用具有潛在價值，推動了從示範學習驅動互動世界模型的研究。

**Research Gap:** 全文未明確說明該方法在真實世界視頻中陰影對構建的可行性及其對性能的影響，因真實視頻缺乏精確陰影對，可能限制實際應用。實驗主要基於合成數據和模擬環境，對於更複雜或多變的現實動態場景泛化能力尚未充分驗證。消融分析集中於陰影配對和源資產，缺少對不同潛變量維度、模型架構或訓練超參數的系統性研究。部署成本、計算資源需求及實時性能未詳述，對工程實踐指導有限。此外，對失敗案例或動作轉移失效情況缺乏分析，限制了對方法穩健性的全面評估。

### 3. Oracle-Budgeted Molecular Optimization with Short-Term Graph Memory

- 分數：5
- arXiv: [2607.28437v1](http://arxiv.org/abs/2607.28437v1)
- 發表日期：2026-07-30
- 分類：cs.LG
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：acl; LLM rank #3 / 7/10: Proposes a practical plug-in module for molecular optimization under limited oracle budget, improving performance consistently across multiple generators with clear analysis; balances novelty and practical impact well.

**Intro:** 分子優化常受限於昂貴的評估成本，評估分子所需的oracle呼叫數量有限，成為瓶頸。現有生成模型能快速產生大量候選分子，但無法全部評估，因此如何有效分配有限的oracle預算成為關鍵。本文提出一種短期圖記憶模組，作為生成器與oracle間的插入層，利用已評估分子資料在線微調圖神經網路代理模型，預先篩選候選分子以優先評估預測效用較高者。此方法不改變生成器架構與更新規則，能在相同oracle預算下提升優化效率。

**Motivation:** 在分子優化中，oracle評估成本遠高於生成成本，且實際實驗或高階模擬的評估次數極為有限。如何在有限oracle呼叫下，從生成的候選分子中挑選最有價值的進行評估，是提升優化效率的關鍵。現有方法多聚焦於改進生成策略或代理模型，卻較少針對oracle預算分配問題。本文提出的短期圖記憶模組，能在不增加oracle呼叫的前提下，透過在線學習代理模型，智能篩選候選分子，提升oracle預算的使用效率，對工程與產品落地有實際價值。

**Method:** 短期圖記憶模組插入於生成器與oracle之間，維持生成器原有架構與更新規則。每輪生成大量候選分子後，代理模型（基於GraphGPS圖神經網路）對候選分子進行快速評分，僅將預測分數最高的子集送入oracle評估。代理模型從已評估分子及其oracle分數中在線微調，實現短期記憶與適應。候選分子選擇可採用確定性（取最高分）或隨機性（根據softmax分布抽樣）策略，後者用於避免生成器訓練過度收斂。此方法不增加oracle呼叫數，僅重新分配oracle預算。

**Result:** 在PMO基準測試中，短期圖記憶模組在1,000及10,000 oracle呼叫預算下，對四種不同類型生成器（GenMol、InVirtuoGen、REINVENT、Graph-GA）均有提升，尤其在緊湊預算下效果顯著。GenMol提升最大，top-10平均分數從0.648提升至0.784，且在22個oracle中幾乎全勝。分析顯示，提升效果與生成器原生利用oracle反饋的程度及搜索廣度相關，搜索較廣的生成器受益較多。確定性選擇提高分數但降低多樣性，隨機選擇則在保持多樣性與分數間取得平衡。與Augmented Memory方法比較，本文方法在分數與多樣性上均有優勢。

**Conclusion:** 本文提出的短期圖記憶模組是一種oracle預算中立的插入式選擇器，能有效利用已評估分子資訊在線微調代理模型，優化oracle預算分配，提升分子優化效率。該方法跨多種生成器架構均有效，尤其在緊湊oracle預算下表現突出。分析指出其效果依賴生成器的搜索策略與反饋利用方式，且可透過選擇策略調節探索與利用的平衡。此方法為分子優化中oracle預算分配問題提供了簡潔且實用的解決方案，對工程與產品開發具參考價值。

**Research Gap:** 本文實驗基於模擬基準與預測oracle，尚未驗證於實驗室真實評估場景，真實預算可能更嚴苛，短期圖記憶在更低預算下的效用尚不明確。代理模型僅使用GraphGPS架構，未比較其他代理或不確定性估計方法，可能限制泛化性。對代理模型排名質量的直接評估不足，對生成器-記憶模組間互動機制的理解仍不完整。實驗中多樣性與探索-利用權衡分析基於少數oracle與指標，缺乏更廣泛的多樣性度量與失敗案例分析。最後，僅測試四種生成器，尚需擴展至更多生成策略與更複雜任務以驗證普適性。

**Intro:** 大型稀疏線性系統的求解是科學計算中的核心任務，而高效的迭代求解器依賴於有效且穩健的預條件器。傳統的代數多重網格（AMG）方法在對稱正定系統中表現良好，但在非對稱或不定系統中其穩健性會下降。近年來，圖神經網絡（GNN）被提出作為數據驅動的預條件器，但如何將AMG風格的多層次結構引入一般稀疏矩陣的GNN預條件器尚未充分探討。本文提出一種結合AMG結構先驗與學習的多層次圖神經預條件器（GMP），並將其作為標準Krylov求解器的可替換預條件器。

**Motivation:** 傳統AMG方法在非對稱或不定系統中依賴於針對特定問題設計的啟發式規則，這些規則在這些系統中可能失效，導致預條件器效果不佳甚至不穩定。單層GNN預條件器雖然具有一定的魯棒性，但其本質上是局部的，難以有效處理全局低頻誤差成分。多層次方法能夠分離誤差頻率，通過粗網格校正消除全局誤差，但如何將多層次結構與GNN學習結合，並在非對稱系統中保持穩定性，是工程和研究落地中的重要挑戰。

**Method:** 本文提出的GMP方法利用AMG生成的多層次層級結構作為拓撲先驗，並在此基礎上學習平滑、限制和插值算子。核心技術包括：在每層利用MPNN進行基於節點特徵的消息傳遞來實現平滑；利用雙分圖交叉注意力機制分別學習限制和插值算子，支持非對稱系統中的Petrov–Galerkin粗網格算子；在粗層使用專門的MPNN進行粗網格求解，並將結果插值回細層。整體架構可作為非線性預條件器嵌入靈活的Krylov求解器中。

**Result:** 在SuiteSparse資料集中選取867個非對稱非SPD稀疏矩陣進行評估，與單層GNN預條件器（GNP）、經典AMG、ILUT和Jacobi方法比較。結果顯示，兩層GMP在收斂軌跡（Iter-AUC）和嚴格容差下均優於GNP，且多層次結構在高精度求解中優勢更明顯。GMP與AMG在失敗率相當，但GMP的失敗主要因記憶體限制，AMG則多因數值不穩定。GMP在部分挑戰性矩陣（如電路模擬、優化、流體力學）中顯著優於AMG和AIR，能有效處理非對稱系統中AMG失效的情況。計算成本方面，GMP訓練和應用時間高於單層GNP和經典方法，但在收斂效率上有明顯提升。

**Conclusion:** 本文提出的GMP方法成功將AMG多層次結構與圖神經網絡學習結合，實現了針對一般稀疏矩陣的端到端多層次預條件器。該方法在非對稱和不定系統中展現出較傳統AMG更強的適應性和收斂性能，特別是在高精度求解需求下。GMP利用雙分圖交叉注意力靈活學習限制和插值算子，突破了傳統AMG對稱性假設的限制。限制在於目前訓練成本較高，且多層次層數和層級結構的選擇依賴於AMG生成的層級質量，且泛化能力尚未充分驗證。

**Research Gap:** 本文主要針對每個矩陣單獨訓練模型，缺乏跨矩陣或跨應用場景的泛化能力驗證，這限制了實際工程部署的效率和適用範圍。多層次層級結構的選擇和調整依賴於AMG生成的層級質量，當層級質量不佳時，GMP性能可能下降，且缺乏自適應層級選擇機制。訓練和推理成本較高，尤其是大規模矩陣，對硬體資源要求較大。實驗中未明確說明在更深層多層次結構下的穩定性和收斂性，且缺少對失敗案例的系統分析。最後，全文未明確說明GMP在實際科學計算應用中的整體部署流程和與現有軟體生態的整合難度。

**Intro:** 本論文聚焦於提升推理型語言模型的訓練穩定性與效能，特別是針對現有的on-policy self-distillation (OPSD)方法在實務中表現不穩定且需大量工程調整的問題。作者指出，傳統OPSD實際上是政策優化家族中β=1的特例，且β可視為調節學生模型與參考策略間KL懲罰強度的參數。透過將β視為可控參數，提出一種更廣義的β-OPSD框架，能在參考策略與教師指導間取得平衡。此方法在數學推理基準上展現優於傳統OPSD的效果。

**Motivation:** OPSD雖然理論上能利用教師的特權資訊提升學生模型，但實務中常因直接模仿教師導致學習不穩定，且缺乏調節學生策略與教師策略間距離的機制。將β引入政策優化目標中，能明確控制學生策略向教師策略靠攏的程度，避免過度偏離參考策略造成的訓練不穩。此舉對工程與產品層面意義重大，因為它提供了更穩健且可調的訓練流程，降低了調參與部署風險。

**Method:** β-OPSD方法將原本固定β=1的OPSD擴展為一個可調節的KL正則化政策優化問題，β控制學生策略與參考策略的KL距離。理論上，β-OPSD的最優策略是參考策略與教師策略的幾何插值。由於直接強化學習優化成本高且梯度方差大，作者提出以token層級logits插值作為蒸餾目標，透過線性調度β值實現從參考策略平滑過渡到教師策略。此外，採用return-to-go回報分配機制，將序列層級目標的影響反饋至早期token，提升訓練的序列一致性與穩定性。

**Result:** 在多個數學推理競賽基準（AIME 2024、AIME 2025、HMMT 2025）上，β-OPSD在不同規模的Qwen3模型（1.7B、4B、8B）均優於傳統OPSD，尤其在1.7B模型上平均提升約5.74個百分點。與監督式微調(SFT)及GRPO強化學習基線相比，β-OPSD亦展現更佳或相當的表現。消融實驗證實logit插值目標與return-to-go信用分配均對性能提升有顯著貢獻，且動態學生與固定教師的插值端點設計效果最佳。

**Conclusion:** 本論文提出β-OPSD框架，將on-policy自蒸餾視為一種帶有參考正則化的政策優化問題，並以token層級logits插值與return-to-go信用分配實現高效且穩定的訓練。實驗結果證明該方法在數學推理任務中優於傳統OPSD及其他基線，提供了一條從政策優化理論到實務蒸餾訓練的有效橋樑。限制在於目前僅驗證於數學推理領域，且插值調度策略仍為線性，未探索更複雜或自適應方案。

**Research Gap:** 論文未明確說明β-OPSD在其他類型任務（如自然語言理解、生成等）上的泛化能力，限制了方法的廣泛適用性。實驗中插值調度僅採用線性策略，缺乏對非線性或自適應調度的深入探討，可能影響在不同模型規模或訓練階段的最佳化效果。此外，return-to-go信用分配的折扣因子γ設定與其對訓練穩定性與效率的權衡未充分分析。全文未提供對失敗案例或極端情況下方法表現的討論，對部署風險評估不足。最後，雖然提出了理論上的政策優化視角，但未實際比較直接強化學習優化與蒸餾近似的成本與效益差異。
