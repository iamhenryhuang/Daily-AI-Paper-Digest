### 1. Semantic Behavioral Watermarking: Paraphrase-Robust and Forgery-Resistant Provenance for LLM Agents

- 分數：5
- arXiv: [2610.08668v1](http://arxiv.org/abs/2610.08668v1)
- 發表日期：2026-10-06
- 分類：cs.CR, cs.AI
- 入選理由：+3 提及頂級會議：acl; +2 提及程式碼可用; LLM rank #1 / 9/10: Presents a novel, theoretically grounded watermarking method for LLM agents that is robust to paraphrasing and forgery, with strong empirical validation across multiple models and benchmarks, and publicly available code.

**Intro:** 本論文針對大型語言模型（LLM）代理的行為水印技術，提出一種能抵抗語義改寫與偽造攻擊的新方法。現有的代理水印方法多綁定於精確的動作符號，導致在工具重命名或語義改寫時水印失效。此外，過去研究多只關注水印移除攻擊，忽略了偽造攻擊的可能性。作者提出的語義行為水印（SBW）利用語義動作群集與帶密鑰的碰撞抗性分箱，提升水印的穩健性與安全性。研究在多個代理模型與編碼器上進行實驗，涵蓋不同任務與動作空間，展現了方法的普適性。

**Motivation:** 隨著LLM代理在商業應用中普及，確保代理行為的來源可追溯性與防止未授權重用成為重要需求。傳統文字水印無法直接應用於代理的行為序列，且現有行為水印對語義改寫極為脆弱，容易被攻擊者移除或偽造。尤其偽造攻擊尚未被充分研究，存在被冒用身份的風險。此研究旨在解決語義改寫導致的水印失效問題，並首次提出針對偽造攻擊的防禦機制，對工程部署與產品安全具有實際意義。

**Method:** SBW方法核心包括三部分：(1) 將代理動作映射至語義群集符號，並基於最近的動作歷史條件化水印標記，確保語義改寫後仍能保持水印同步；(2) 採用帶密鑰的碰撞抗性分箱函數，將動作嵌入映射到密鑰控制的桶中，防止攻擊者根據公開語義編碼推測水印分佈，降低偽造成功率；(3) 透過隨機鍵排列檢驗實現水印檢測，並引入邊界動作的放棄策略以減少錯誤率。整體方法無需訓練，僅依賴固定的語義編碼器與密鑰，方便部署與維護。

**Result:** 在ToolBench與ALFWorld兩個基準上，SBW在五種不同規模與供應商的代理模型中均展現出顯著優於精確符號水印的語義改寫魯棒性。具體而言，ToolBench中改寫攻擊下的檢測真陽率由0.05-0.17提升至0.49-0.66，ALFWorld中更達0.92-0.97。針對偽造攻擊，帶密鑰分箱將偽造成功率從100%降至接近假陽性率下限（約1%），顯著提升安全性。對於複製受害者步驟的攻擊，部分方法（如步驟重排）被完全抵消，但鏈式重放仍存在高偵測率，為未解決問題。與現有AgentMark及AGENTWM方法的比較中，SBW在語義改寫與偽造防禦上均有明顯優勢。

**Conclusion:** 本論文提出的SBW是首個同時具備語義改寫魯棒性與偽造防禦能力的LLM代理行為水印方法，並提供了理論分析與實證驗證。方法無需訓練，易於集成於現有代理系統，對保護代理知識產權與行為來源追蹤具有實際價值。然而，對於複製受害者行為的偽造攻擊仍無法完全防禦，且語義改寫魯棒性帶來約一半的水印容量損失。未來可進一步探索多段行為歸屬與更高容量的水印設計。

**Research Gap:** 本研究的限制包括：首先，實驗僅涵蓋五款中小規模開源代理模型，未驗證於更大規模或封閉模型；其次，實驗中缺乏環境執行反饋，僅基於代理行為分布，可能影響真實部署效果；第三，語義改寫魯棒性以犧牲水印容量為代價，容量損失約達50%，限制短序列水印能力；第四，對於複製受害者行為的偽造攻擊（如鏈式重放）仍無有效防禦，且提升檢測窗口長度無法根本解決此問題；第五，跨動作模板的泛化能力在ALFWorld上表現較弱，開放集泛化證據有限；最後，部分比較基於重現實現，缺乏原作者代碼支持，可能影響公平性。這些缺口提示未來需加強大規模模型驗證、環境交互測試、容量提升策略及複製行為偵測方法。

### 2. Feature Information Dynamics in Diffusion

- 分數：5
- arXiv: [2610.08626v1](http://arxiv.org/abs/2610.08626v1)
- 發表日期：2026-10-06
- 分類：stat.ML, cs.AI, cs.LG
- 入選理由：+3 提及頂級會議：neurips; +2 提及程式碼可用; LLM rank #2 / 8/10: Introduces a new information-theoretic framework to quantitatively analyze feature generation in diffusion models, providing novel insights beyond empirical observations, validated on multiple representations with code r

**Intro:** 本論文探討擴散模型中不同特徵資訊隨去噪過程的動態變化，旨在量化並定位特徵資訊在不同噪聲水平下的生成時序。擴散模型透過一連串去噪任務逐步生成數據，先呈現粗略結構再細化細節，然而此現象多為經驗性質且缺乏定量分析。作者提出一套基於資訊理論的框架，利用I-MMSE恆等式連結特徵互資訊變化率與最佳無條件及條件去噪損失之差距，進而估計特徵資訊密度。此方法可應用於不同特徵層級，並揭示特徵資訊的共享與增量貢獻。論文同時比較多種表示空間下的資訊動態，提供對擴散模型訓練與表示選擇的洞見。

**Motivation:** 擴散模型在視覺生成領域取得顯著成果，但對於特徵資訊何時、如何在去噪過程中被生成尚缺乏量化理解。現有研究多為定性描述，且多聚焦於像素空間，未能涵蓋潛在表示空間。由於潛在表示已成為提升生成效率與品質的主流，理解不同表示如何影響特徵資訊動態對工程與產品設計至關重要。此外，特徵資訊動態與模型訓練效率、生成順序密切相關，若能量化此關係，將有助於優化訓練流程與架構選擇。

**Method:** 核心方法基於I-MMSE恆等式，定義特徵資訊密度為無條件與條件去噪最小均方誤差（MMSE）之差的函數，該差距反映特徵對去噪的貢獻。進一步提出鏈式分解方法，將特徵層級組合成遞增條件集合，分離共享與增量資訊，避免重複計算。方法可在擴散模型的Gaussian Flow Matching參數化下實現，並透過訓練的無條件與條件去噪器估計MMSE差距。為解決高信噪比下估計偏差，作者引入雙極Lorentzian曲線擬合以平滑並外推MMSE差距曲線，提升估計穩定性與準確度。

**Result:** 實驗首先在MNIST與CIFAR-10像素空間驗證頻譜自回歸現象，鏈式分解清晰呈現低頻先於高頻的資訊生成順序。進一步在ImageNet-256上，對比四種表示（pixel, SDV AE, VAVAE, RAE）在相同class→mask→Canny條件鏈下的特徵資訊動態，發現不同表示呈現顯著差異：像素空間中mask資訊先於class，違反語義優先假設；VAVAE部分恢復語義優先；RAE則嚴格遵循class→mask→Canny順序。此資訊動態排序與模型訓練速度呈現一致性，RAE收斂最快且資訊順序最清晰。實驗中使用固定優化配方與模型架構，確保差異主要源於表示本身。

**Conclusion:** 本論文提出一套基於I-MMSE的特徵資訊動態量化框架，能精確定位特徵資訊在擴散過程中的生成時序，並透過鏈式分解揭示多層級特徵間的資訊結構。實驗證實像素空間擴散近似頻譜自回歸，且不同表示空間對特徵資訊動態有顯著影響，進而影響模型訓練效率。此框架為理解與優化擴散模型的生成順序與表示選擇提供了新工具，具有工程與研究上的實用價值。限制包括估計依賴訓練去噪器品質、鏈式分解對特徵順序敏感、計算成本較高等，未能涵蓋非獨立耦合通道等情況。

**Research Gap:** 本研究依賴訓練完成的去噪器近似最優MMSE，故估計結果受限於模型訓練品質與容量，可能導致資訊密度偏差。鏈式分解結果強烈依賴特徵條件順序，缺乏對順序不變性的分析，限制了結果的普適性。跨表示比較僅涵蓋四種代表性模型與單一條件鏈，未涵蓋更多表示類型與多樣條件組合，限制泛化能力。實驗多為平均分布層級分析，未探討單張圖像或極端案例的資訊動態。方法假設獨立耦合的高斯通道，對非獨立耦合或其他擴散變體尚未驗證。最後，鏈式分解需訓練多個條件模型，計算成本與實際部署風險未充分討論。

### 3. A Case Study in Assuring AI-Written Software

- 分數：5
- arXiv: [2610.08651v1](http://arxiv.org/abs/2610.08651v1)
- 發表日期：2026-10-06
- 分類：cs.SE, cs.AI, cs.MA
- 入選理由：+2 提及頂級機構：meta; +3 提及頂級會議：neurips; LLM rank #3 / 8/10: A credible case study on assuring AI-written software in a real-world healthcare platform, highlighting practical challenges and human-agent interaction dynamics with evidence from production use.

**Intro:** 本文探討在軟體工程中，當AI編碼代理（coding agents）負責生成大量程式碼且超出人類專家可全面審查範圍時，如何維持人類對系統的控制。研究以一個由無正式軟體工程背景的操作員管理的生產級醫療平台為案例，分析該平台如何透過多代理系統進行開發與監督。此案例反映出在AI生成軟體的實務應用中，傳統的逐行程式碼審查已不足以作為唯一的監督手段。文章透過訪談與專案紀錄，重建並分析該系統的開發與保證流程。

**Motivation:** 隨著AI編碼代理能快速產生大量程式碼，傳統的人工程式碼審查面臨瓶頸，無法有效掌控系統品質與安全。尤其在醫療等受規範嚴格的領域，確保系統符合規範且運作正確更為重要。本文動機在於理解在實務中，當實作與審查工作委由代理完成時，人類如何保持對系統的控制權，以及現有的測試與監督機制在實際運作中存在哪些缺陷與風險。這對於工程師設計可部署且可控的AI軟體開發流程具有指導意義。

**Method:** 研究採用回顧性案例研究方法，基於兩次結構化訪談及六個月的專案紀錄（包含決策日誌、稽核報告、事件紀錄等）重建系統的開發與保證工作流程。系統由多個代理組成：主代理負責編碼，其他代理負責審查與監督，並將經驗與規則持續累積於專案規則庫。操作員負責審核代理提出的方案與代碼，並決定是否部署。系統中還設計了多模型委員會以提供獨立建議。研究聚焦兩個問題：人類控制權如何分布，以及測試與審查代理的貢獻與失效情況。

**Result:** 結果顯示人類控制主要集中在代理輸出成為持久專案內容與生產環境變更的關鍵節點，操作員不需逐行審查程式碼，但需理解審查機制的觀察範圍與權限。測試與監督代理雖能捕捉多數安全與功能問題，且涵蓋約82%的OWASP及HIPAA相關安全項目，但仍存在多種失效情況，如監控指標偏向代理指標而非真實結果、稽核靜默失敗、缺失檢查未被報告，以及自動修復導致營運中斷等。這些問題凸顯測試與監督本身也是軟體層級的脆弱環節，不能視其輸出為絕對真實。

**Conclusion:** 本文案例說明在AI代理主導軟體開發時，人類控制權可透過集中於預期結果、證據、代理權限及最終決策來維持。代理間的監督與測試機制雖有助於提升系統可靠性，但其本身的失效風險也需被嚴肅對待。此案例強調，當監督工作也委由代理執行時，人類必須能評估監督機制的觀察範圍與權威，避免過度信任代理輸出。研究同時指出，AI軟體工程工作並未消失，而是重組為更多需求定義、結果檢查與安全決策的工作。

**Research Gap:** 本研究為單一案例，僅涵蓋一位操作員與一個醫療平台，結果的普適性與可重現性有限。案例中操作員同時參與系統與治理流程設計，可能導致偏向正面解讀。全文未明確說明該流程是否實際降低缺陷率或提升安全合規性，也缺乏與其他監督策略的比較。代理生成測試的準確性與覆蓋率仍有待更嚴謹的驗證，且對於更複雜或不同領域系統的適用性未知。此外，代理監督失效的成本與風險評估不足，缺少對失敗案例的深入分析與緩解策略。未來研究應擴展多案例、多操作員與多場景驗證，並探討如何設計更健壯的多層次監督架構。

### 4. FlowCF: Sparse Counterfactual Explanations for Mixed-Type Tabular Data using Flow Matching

- 分數：5
- arXiv: [2610.08537v1](http://arxiv.org/abs/2610.08537v1)
- 發表日期：2026-10-06
- 分類：cs.LG, cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：neurips; LLM rank #4 / 8/10: Proposes a novel, model-agnostic generative method for sparse counterfactual explanations on mixed-type tabular data, demonstrating significant improvements in sparsity and proximity with extensive benchmarks.

**Intro:** 本論文聚焦於解釋性人工智慧（XAI）中的反事實解釋，該解釋透過建議輸入變更以達成更有利的模型預測結果。反事實解釋在實務中需兼顧稀疏性與接近性，即改動特徵數量少且幅度小，這對於理解與執行解釋至關重要。現有方法在數值特徵的稀疏性表現上仍有限，無論是模型無關的生成式方法或是需模型梯度的優化方法。論文提出FlowCF，一種基於流匹配的生成式模型，專門針對混合型表格數據，實現精確的數值稀疏性與接近性。

**Motivation:** 反事實解釋的核心問題是如何在不損失有效性的前提下，盡可能少且小幅度地改變輸入特徵。現有方法多透過L1近似或後處理剪枝來達成稀疏性，但無法保證特徵完全不變，尤其是數值特徵。這在工程與產品層面影響解釋的可用性與可操作性。FlowCF透過將反事實生成視為從原始類別到目標類別的稀疏運輸問題，利用流匹配學習特徵變化的速度場，並引入門控網路精確控制改動特徵，解決了現有方法在數值稀疏性上的不足。

**Method:** FlowCF包含兩個主要模型：混合流操作子Fθ與門控操作子Gψ。首先，Fθ學習從原始類別分布到目標類別分布的流匹配運輸，對數值特徵學習位移向量，對類別特徵預測終點分布。其次，Gψ學習門控機制，對每個特徵產生二元門控，決定是否應用流變化以實現稀疏性。訓練分三階段：第一階段訓練Fθ以學習有效的運輸；第二階段凍結Fθ，訓練Gψ以最大化稀疏性同時保持有效性；第三階段凍結Gψ，微調Fθ以提升接近性。推論時，僅需一次前向傳播且不需查詢黑盒模型。

**Result:** 在六個二元分類的基準表格數據集上，FlowCF在數值特徵的稀疏性與接近性指標上均優於六個先進基線方法。平均而言，FlowCF只改動29%的數值特徵，遠低於最佳基線89%，且改動幅度減少70%。在有效性與類別特徵稀疏性方面，FlowCF表現與其他方法相當。實驗亦涵蓋連續特徵專用數據集，顯示FlowCF在純數值場景下的優勢。視覺質性實驗使用CelebA-HQ數據集的潛在空間，FlowCF能以最少特徵改動生成有效反事實，且改動更符合語義。

**Conclusion:** FlowCF提出了一種基於流匹配的稀疏反事實生成方法，成功解決了數值特徵精確稀疏性難以優化的問題。其模型無關且生成過程可攤銷，適合實際部署且推論快速。實驗結果證明其在多個表格數據集上達成最佳數值稀疏性與接近性，且保持有效性。限制在於對類別特徵稀疏性的提升有限，且部分數據集有效性略低。未來可探討群組反事實與全局解釋，以及提升模型可解釋性。

### 5. Prediction-powered inference for time series across space

**Intro:** 本文探討在多空間位置的時間序列資料中，如何利用有限的標記資料與較長時間的未標記共變量資料，估計未來的期望標籤值並提供有效的信賴區間。此問題常見於農作物產量預測、空氣品質監測及保險風險評估等場景。傳統方法因標記資料時間短且存在時間依賴性，導致估計不準確且信賴區間失真。作者提出一種結合偏誤校正與時間相關性調整的新方法，以提升估計準確度與信賴區間的有效性。

**Motivation:** 在實務中，標記資料往往有限且時間跨度短，而未標記的共變量資料時間較長且跨多空間位置。若直接使用有限標記資料估計，會因樣本不足而偏誤嚴重；若用機器學習模型填補缺失標籤，則可能引入系統性偏誤。現有的Prediction-powered inference (PPI)方法雖能校正偏誤，但假設資料獨立同分布，無法處理時間序列中的自相關問題。異方差與自相關一致性(HAC)方法能處理時間相關性，但未結合標籤填補的情境。故需設計新方法兼顧偏誤校正與時間依賴性調整，提升工程與產品中風險評估與預測的可靠性。

**Method:** 作者提出PPITSAS方法，核心在於將標記資料分割為訓練預測模型與校正偏誤的兩部分，並跨空間位置共享資料以提升預測器效能。針對時間依賴性，採用區塊切分(chunking)策略保留時間序列結構，並利用HAC方法估計自相關調整後的變異數。此方法在保留PPI偏誤校正優勢的同時，透過Newey-West框架調整時間序列的自相關，進而構建有效的信賴區間。全文中提供了方法流程與理論依據的概要說明，並以模擬資料驗證效能。

**Result:** 實驗使用模擬資料，模擬多空間位置的時間序列，包含較長的未標記共變量與較短的標記資料。比較方法包括傳統經驗平均、機器學習填補(IWI)、標準PPI、HAC調整及PPITSAS。結果顯示PPITSAS在點估計上達到最低的標準化均方根誤差(RMSE)，且信賴區間覆蓋率接近名義95%，優於其他方法。尤其在極端天氣條件下，PPITSAS仍維持良好表現，且信賴區間寬度較HAC更窄，顯示其在工程應用中能提供更準確且可靠的預測與不確定性評估。

**Conclusion:** 本文針對跨空間位置的時間序列資料，提出結合偏誤校正與時間相關性調整的PPITSAS方法，有效解決標記資料稀少且時間依賴性強的挑戰。實驗結果證明該方法在點估計與信賴區間覆蓋率上均優於現有方法，具備實務應用價值。方法適用於風險評估、環境監測等多領域，能提升決策的信心與準確度。全文未提供完整理論證明，且實驗僅限模擬資料，仍需進一步驗證於真實資料與多樣場景中。

**Research Gap:** 本文提出的方法雖在模擬資料中表現優異，但全文未明確提供完整的理論證明，僅有概要與推測，理論嚴謹性尚待加強。此外，實驗僅限於模擬資料，缺乏真實世界資料的驗證，尤其在多樣化空間結構與非平穩時間序列的適用性未充分探討。方法中對於分割標記資料的策略選擇與緩衝區處理仍較簡單，未考慮更複雜的時間依賴結構與空間交互影響。最後，計算成本與實際部署風險未明確評估，對於大規模資料與即時應用的可行性仍需深入研究。
