### 3. Active-Trace Complexity Bounds for Moreau--Yosida Unadjusted Langevin Sampling

- 分數：0
- arXiv: [2608.13467v1](http://arxiv.org/abs/2608.13467v1)
- 發表日期：2026-08-13
- 分類：cs.LG
- 入選理由：LLM rank #3 / 8/10: Provides new theoretical complexity bounds for Moreau-Yosida unadjusted Langevin sampling with refined error control, offering a significant methodological contribution with potential impact in sampling algorithms.

**Intro:** 本文研究了 Moreau–Yosida unadjusted Langevin algorithm (MYULA) 用於非光滑複合目標分布的取樣問題。目標分布形式為 π(dx) ∝ exp{−f(x)−g(x)}，其中 f 是強凸且具有 Lipschitz 梯度的光滑函數，g 是凸且 Lipschitz 的非光滑函數。MYULA 通過 Moreau envelope g_λ 平滑非光滑項，並對平滑後的目標分布 π_λ 進行顯式 Euler–Maruyama 離散化。本文聚焦於離散化誤差的精細分析，特別是如何利用 Moreau envelope 的局部曲率結構來改進複雜度界。研究背景涵蓋 Bayesian 逆問題、高維統計與機器學習中常見的結構化正則化問題。

**Motivation:** 傳統 MYULA 分析中，離散化誤差受限於全局曲率上界 d/λ，導致精度 ε 的複雜度呈現 ε^{-3} 的依賴，且隨 λ 變小而惡化。然而，對於許多結構化的非光滑正則化，如稀疏性、群組稀疏性及全變差，曲率集中在低維活躍子空間附近，且該區域的概率質量隨 λ 收縮。忽略這種結構會導致過於保守的複雜度估計。本文旨在提出一種分布依賴的活躍曲率跡（active trace）分析，精確捕捉曲率與路徑分布的耦合，從而改善 MYULA 的理論複雜度界，對工程與產品中高效非光滑取樣具有實際意義。

**Method:** 本文核心方法是引入 Moreau active trace a_λ(x) = tr H_λ(x)，其中 H_λ 是 Moreau envelope g_λ 的 a.e./弱 Hessian，並定義參考活躍曲率跡 B_ref 為沿 MYULA 一步熱路徑（heat path）對 a_λ 的期望時間平均。分析證明離散化誤差主要由 B_ref 控制，而非全局曲率 d/λ。利用 KL–EVI 遞迴結構，將當前步的活躍曲率跡 B_k 用 B_ref 與 KL 散度差異界定，實現遞迴閉合。進一步通過幾何管道（curvature–tube）原理和切片密度估計，將 B_ref 轉化為活躍子空間附近的概率質量與局部曲率的乘積，從而在多種結構化正則化（如有限折點分段線性、加權 Lasso、群組 Lasso、廣義 Lasso 及全變差）中給出 λ 無關的 B_ref 上界，實現 ε^{-2} 的複雜度依賴。

**Result:** 在強凸且光滑部分 f 與 Lipschitz 非光滑部分 g 的假設下，本文證明 MYULA 在固定 λ 下的迭代複雜度為 N ≲ (L_f + τ_f + G^2 + B_ref)/ε_alg^2 + M_λ/ε_alg，其中 B_ref 是參考活躍曲率跡，M_λ 是 a.e. 曲率的上界。結合 Moreau 偏差界 √m W_2(π_λ, π) ≤ G^2 λ/4，選擇 λ ≍ ε/G^2 可獲得對原始目標 π 的端到端誤差保證。對結構化正則化，通過管道概率估計證明 B_ref 與 λ 無關，從而將 ε 依賴從 ε^{-3} 降至 ε^{-2}。具體實驗設定涵蓋一維有限折點分段線性、可分離加權 Lasso、群組 Lasso、廣義 Lasso 及一維全變差，均給出明確的活躍曲率跡常數與複雜度界。

**Conclusion:** 本文提出的活躍曲率跡分析為 MYULA 的非光滑複合目標取樣提供了更精細的理論複雜度界，顯著改善了傳統基於全局曲率的保守估計。該方法保留了 MYULA 的經典迭代結構，無需改變算法本身，對於工程實踐中利用 Moreau envelope 平滑非光滑正則化的取樣任務具有直接指導意義。活躍曲率跡的分布依賴性及其幾何管道估計方法，為未來其他平滑基礎 Langevin 方法的分析提供了有益思路。限制在於分析依賴於強凸性與 Lipschitz 梯度假設，且對非強凸或非 Lipschitz 梯度情況未涵蓋。

**Research Gap:** 本文分析基於固定 Moreau 參數 λ，未考慮動態調整 λ 的策略對複雜度的影響，且假設精確計算 proximal map，未探討近似計算對理論界限的影響。活躍曲率跡的估計依賴於對參考熱路徑的概率密度估計，對高維或複雜結構的泛化能力尚未充分驗證。實驗部分主要為理論驗證，缺乏數值實驗支持。對非強凸目標、非 Lipschitz 梯度或非凸目標的適用性與理論保障未明確說明。此外，算法在實際部署中計算活躍曲率跡的成本及其對步長選擇的影響未被討論，限制了工程落地的直接指導價值。

**Method:** 本文提出Equi-cDFT框架，將三維密度場分割為局部環境，利用立方晶格點群Oh的不變特徵（基於Cartesian atomic cluster expansion）表示局部密度環境，確保自由能泛函為標量且對旋轉反射等變換保持不變。泛函以局部自由能密度的形式表達，通過自動微分獲得一體密度直接關聯函數c(1)。訓練時利用局部化學勢平衡條件作為損失函數，無需自由能或化學勢標籤，並解析消除未知的化學勢常數。模型在固定粒子數和化學勢條件下均可求解，實現變分一致的密度與相關物理量預測。

**Result:** 在Lennard-Jones截斷位移流體上，模型成功跨溫度、系統尺寸及統計系綜合轉移。未使用結構因子、壓力或相平衡標籤的情況下，準確重建了靜態結構因子、狀態方程、液-氣共存曲線及界面展寬。應用於三維複雜幾何中，模型預測了膠體間溶劑耗盡橋的形成與破裂過程及非單調溶劑介導力，並成功模擬了互連Gyroid孔中的吸附行為。這些結果證明學習的泛函能作為一個可轉移的熱力學生成器，連結微觀結構與宏觀相行為及力學響應。

**Conclusion:** 本文提出的Equi-cDFT方法結合了三維對稱性保護、變分一致性及無需自由能標籤的局部化學勢平衡學習，實現了可轉移且物理一致的三維經典密度泛函。該泛函不僅能準確預測多種熱力學與結構性質，還能應用於複雜三維幾何，展現良好泛化能力。此方法為機器學習經典密度泛函提供了實用且理論嚴謹的基礎，對工程與研究中液體模擬的效率與準確度提升具有重要意義。

**Research Gap:** 本文模型基於固定空間離散度與有限鄰域截斷，對於更大尺度或多重空間解析度的泛化能力尚未充分驗證。對臨界區域的描述仍為平均場近似，缺乏對臨界波動的捕捉。模型目前僅針對特定Lennard-Jones截斷位移流體，對其他流體種類（如離子液體、多組分系統）及長程相互作用的處理仍需擴展。消融實驗與與其他先進方法的系統比較有限，且部署成本與計算效率在更大系統或動態模擬中的表現未明確說明。此外，失效案例與模型在極端條件下的魯棒性未被充分探討。

### 5. RippleMem: From Isolated Retrieval to Associative Recollection for Long-Term Agent Memory

- 分數：0
- arXiv: [2608.13334v1](http://arxiv.org/abs/2608.13334v1)
- 發表日期：2026-08-13
- 分類：cs.CL
- 入選理由：LLM rank #5 / 7/10: Introduces RippleMem, a novel associative recollection memory system for LLM agents that significantly improves long-term memory retrieval and efficiency, supported by strong empirical gains and clear motivation.

**Intro:** 本論文探討大型語言模型（LLM）代理在長期記憶管理上的挑戰，特別是如何從分散於多次互動中的資訊中恢復完整且可用的證據集合。現有方法多依賴一次性檢索，容易因為資訊分散而導致檢索結果不完整或噪聲過多。RippleMem提出一種基於認知科學中提示依賴性和聯想補全的長期記憶系統，將互動歷史轉化為具備豐富提示的事件記憶單元，並以事件為中心構建記憶圖譜，透過初步檢索的記憶錨點進行聯想擴展，補全缺失的支持證據。此系統旨在提升長期記憶的檢索完整性與效率。

**Motivation:** 在長期互動中，回答查詢往往需要跨多次會話整合分散的資訊，單純一次性檢索或平面檢索難以組合完整證據，且圖結構記憶系統雖能捕捉關聯，但建構成本高且缺乏針對缺失證據的導向擴展策略。RippleMem的動機在於將記憶檢索視為一種循序漸進的證據補全過程，利用已檢索的記憶作為提示，主動尋找缺失的支持資訊，從而提升記憶存取的準確性與完整度，這對於工程上需要穩定且高效的長期記憶系統尤為重要。

**Method:** RippleMem採用寫入-讀取架構。寫入階段將對話歷史切分為具備語義表示及多維提示（參與者、地點、時間）的事件記憶單元，並以語義與結構提示為基礎建立稀疏加權的事件記憶圖。讀取階段則從查詢中提取語義、詞彙及結構提示，初步檢索相關記憶錨點，接著由記憶錨點出發在圖中進行局部擴展，根據缺失支持目標選擇相關記憶補全證據。最後將檢索到的記憶依據多重指標排序合併，形成回答生成的證據上下文。此方法強調記憶檢索的適應性與聯想性，避免一次性檢索的局限。

**Result:** RippleMem在LoCoMo和LongMemEval-S兩個長期對話記憶基準上均取得最佳整體表現。在LoCoMo上，RippleMem相較於最強基線SimpleMem，F1提升約3.98%，BLEU-1提升3.62%，LLM-as-a-Judge準確率提升3.95%。在LongMemEval-S上，RippleMem在兩種評測設定中分別達到84.80%與86.60%的最高準確率。特別是在需要跨多會話整合證據的問題類型上，提升更為明顯。此外，RippleMem在記憶圖構建階段的時間與資源消耗比基線減少約30倍，展現出較佳的效率。消融實驗顯示結構提示、錨點擴展及計劃性回憶均對性能有顯著貢獻。

**Conclusion:** 本論文提出RippleMem，一種基於事件中心且結合提示豐富的記憶單元與適應性聯想回憶的長期記憶系統，有效解決了分散證據的檢索與補全問題。實驗結果證明其在多項長期記憶基準上均優於現有方法，尤其在跨會話證據整合上表現突出。RippleMem不僅提升了記憶檢索的準確性，也大幅降低了圖構建成本，對於實際部署長期記憶系統具有重要參考價值。限制方面，系統目前僅針對純文本對話，未涵蓋多模態或具體行動環境，且LLM介入的多階段操作增加了延遲與成本，未來需進一步優化效率與擴展場景。

**Research Gap:** RippleMem雖在文本長期對話記憶上展現優異性能，但全文未明確說明其在多模態、具體行動或工具使用場景的適用性，限制了其通用性評估。系統依賴多次LLM調用進行記憶抽取與回憶規劃，增加了運行延遲與成本，對大規模部署存在挑戰。實驗中對於記憶隨時間增長的持續管理、記憶老化及隱私刪除策略缺乏探討，這些是長期記憶系統實際應用的重要課題。此外，消融實驗雖揭示部分組件貢獻，但對比其他先進記憶結構或更複雜回憶策略的廣泛比較不足，且缺少失敗案例分析與泛化能力評估。未來工作應補充這些方面以提升系統完整性與實用性。
