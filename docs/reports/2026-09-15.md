### 1. Harness or Model? Isolating the Harness Effect in Agentic Coding with a Contamination-Controlled Private Suite

- 分數：7
- arXiv: [2609.11987](https://arxiv.org/abs/2609.11987)
- 發表日期：2026-09-14
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：anthropic, openai; +3 提及頂級會議：acl; +2 提及程式碼可用; LLM rank #1 / 9/10: Strong empirical study isolating the harness effect in agentic coding with a contamination-controlled private benchmark, releasing code and oracles; clear novelty and credible evidence with nuanced cost-performance analy

**Intro:** 本論文探討在 agentic coding 系統中，語言模型搭配不同 harness（工具、提示、控制流程）對解題能力與成本的影響。現有實務中，廠商通常會提供與其模型配套的專屬 harness，業界普遍假設此搭配能提升任務解決率。作者設計一套私有且防止資料汙染的測試套件，利用同一模型搭配不同 harness 進行對比，旨在量化 vendor-native harness 與中立 harness 之間的效能差異。研究涵蓋兩種主流模型及其對應 harness，並包含多種任務類型與成本分析。

**Motivation:** 在實際工程與產品部署中，選擇合適的 harness 影響系統的可攜性、成本與效能。若 vendor-native harness 確實優於中立 harness，則可能綁定特定供應商，限制靈活性。反之，中立 harness 若能維持相近效能，則有利於跨供應商部署與成本控制。過往研究多聚焦模型本身，缺乏對 harness 本身效應的嚴謹量化，且多數公開基準存在資料汙染問題，無法確保結果的真實性與泛化性。本研究透過嚴謹的私有測試套件與控制設計，填補此研究空白，對從業者在 harness 選擇與成本評估上具實務參考價值。

**Method:** 作者建立一套包含256個任務的私有測試套件，分為179個私有代碼庫任務與77個公開競賽後切割任務，確保無訓練資料汙染。實驗設計採用配對同模型對比，分別在claude-opus-4-8與gpt-5.5兩種模型上，比較其 vendor-native harness 與中立 harness（deepagents）表現。每次執行在獨立的微虛擬機中，並記錄完整事件日誌，結果由獨立 Docker 隔離的 oracle 離線評分。成本計算基於原始每輪 token 使用量，並修正了先前發現的多重計費錯誤。實驗包含多重重複與嚴格的統計檢定，並針對任務類型進行後設分析。

**Result:** 實驗結果顯示，vendor-native harness 與中立 harness 在整體解題率上無顯著差異，claude-opus-4-8 差異為−1.25百分點（95%信賴區間[-10.0, +7.5]），gpt-5.5 差異為+1.25百分點（[-4.4, +6.9]）。不過，claude-opus-4-8 在任務類型上呈現顯著交互作用：在私有代碼庫任務中中立 harness 表現較佳，競賽任務中 vendor-native harness 優勢明顯。中立 harness 執行時間較長，更多次達到 1200 秒的執行上限，且在觀察到的 token 使用成本上約為 vendor-native harness 的1.2至1.6倍，但因部分使用紀錄缺失，實際帳單成本排序尚未確定。截斷設定的探針實驗未能明確驗證其效果。

**Conclusion:** 本研究首次在私有且嚴格控管資料汙染的環境下，針對同一模型比較 vendor-native 與中立 harness 的效能與成本，結果未發現明顯的平均解題率優勢，但揭示了任務類型對 harness 效果的調節作用。中立 harness 雖具跨供應商可攜性，但在成本與執行效率上存在劣勢。研究強調解題率、完成時間與成本三者需共同考量，並提出了多項方法論改進，包括成本計量的嚴謹校正與執行環境的嚴密隔離。此結果對實務部署 harness 選擇提供了重要參考。

**Research Gap:** 本研究的限制包括任務來源集中於單一組織私有代碼庫，且測試池因篩選策略而非隨機抽樣，可能影響結果泛化。約30個任務存在白盒耦合，可能偏向某一 harness，但未保留標籤無法分析。實驗中部分配置（如 VM 記憶體大小）與工具集存在差異，可能影響比較公平性。成本分析受限於部分執行缺失使用紀錄，導致帳單成本排序不確定。截斷探針實驗因缺乏原始工具輸出長度紀錄，無法驗證假設。後設分析的任務類型分割為事後選擇，需設計性重複驗證。未探討更細粒度的執行軌跡與早期停止策略，亦未涵蓋更廣泛模型與 harness 組合。未明確說明 harness 對失敗案例或泛化能力的影響。

### 2. Can We Trust LLM Judges: A Study of Capability-Dependent Biases and Multi-Judge Ensemble for Bias Calibration

- 分數：5
- arXiv: [2609.12002](https://arxiv.org/abs/2609.12002)
- 發表日期：2026-09-14
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：meta; +3 提及頂級會議：acl; LLM rank #2 / 8/10: Addresses systematic biases in LLM judges with a novel multi-judge ensemble calibration method that requires no ground truth, showing strong empirical gains and practical value for reliable automated evaluation.

**Intro:** 本論文探討大型語言模型（LLM）作為自動評判者在絕對評分任務中的偏誤問題。過去多數研究聚焦於成對比較設定，而本研究關注更貼近實務的絕對評分情境，評估單一回應是否正確。研究涵蓋四個基準測試與六種模型，分析評判者的準確度與偏誤，並提出多評判者加權投票方法以校正偏誤。此議題對於自動化評估系統的可靠性與公平性具有重要意義。

**Motivation:** 隨著LLM被廣泛用於模型訓練與評估，評判者本身的系統性偏誤可能導致錯誤接受不正確答案或錯誤拒絕正確答案，進而影響模型排名與部署決策。尤其在絕對評分任務中，偏誤不易被察覺且可能隨模型能力提升而加劇。如何在無需標註資料的情況下，準確估計並校正這些偏誤，對工程與產品落地的自動評估系統至關重要。

**Method:** 作者首先分析六種模型作為評判者在四個客觀基準上的表現，發現評判準確度與模型自身能力高度相關，且更強的被評估模型會獲得更寬鬆的評價。為解決此偏誤，提出校正加權多數投票（WMV）方法，根據評判者的假陽性率與假陰性率進行加權。這些錯誤率透過一種基於評判者間意見不一致的估計器在線估計，無需任何標註或任務元資料。實驗模擬任務分布隨時間變化，證明該方法能接近理想狀態，優於單一評判者與無權重投票。

**Result:** 實驗涵蓋閱讀理解、數學推理與程式碼生成四個基準，使用六種不同模型作為評判者與被評估者。結果顯示評判者準確度與其評判準確性高度正相關（Pearson r≥0.90），但更強的被評估模型普遍獲得較高的假陽性率，顯示能力依賴的寬鬆偏誤。多數投票能提升整體準確度並降低寬鬆率，校正加權多數投票在無標註條件下能有效估計錯誤率，並在模擬的任務分布漂移中表現接近理想上限，顯著優於基線方法。

**Conclusion:** 本研究揭示LLM評判者在絕對評分任務中存在能力依賴的系統性寬鬆偏誤，且此偏誤超越自我偏好現象。提出的校正加權多數投票方法能在無需標註資料的情況下，透過評判者間不一致性估計錯誤率，實現有效偏誤校正與準確度提升。此方法為自動化評估系統提供可擴展且可靠的解決方案，尤其在模型能力持續提升的背景下更具實用價值。

**Research Gap:** 本研究雖涵蓋多種模型與基準，但模型族群仍有限，缺乏如Anthropic、Google等其他重要模型的驗證，限制泛化性。模擬的時間漂移實驗未使用自然時間序列資料，真實場景下的適用性尚待驗證。僅使用單一提示模板，未探討提示設計對偏誤大小的影響。校正方法假設多數評判者大致正確，對小規模或同質評判者群體的魯棒性未明。全文未明確說明在更複雜或主觀任務中的適用性與限制。

### 3. Who Pays for Open Review? Visible Author Reputation and Its Effect on Ratings

- 分數：5
- arXiv: [2609.11983](https://arxiv.org/abs/2609.11983)
- 發表日期：2026-09-14
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +3 提及頂級會議：iclr; LLM rank #3 / 7/10: Large-scale empirical analysis of open vs blind review effects on author reputation bias with real conference data and AI simulation, providing credible evidence on a socially important topic.

**Intro:** 本論文探討在學術會議審稿中，作者身份是否公開對評分的影響。2025年OpenReview系統的匿名漏洞事件引發了對開放審稿的討論，促使作者研究從盲審轉向開放審稿對作者評分的影響。研究以ICLR 2026超過1.8萬篇投稿為資料，根據arXiv預印本發布時間將投稿分為實質開放與盲審兩組，分析作者聲譽與評分的關係。論文同時透過AI模型模擬審稿，控制論文內容不變，僅改變作者聲譽以驗證觀察結果。研究聚焦於作者聲譽如何影響評分，尤其是在決定接受與否的邊界評分區域。

**Motivation:** 在學術評審中，作者身份公開可能導致評審偏見，影響評分公正性與學術公平。理解作者聲譽在開放審稿下對評分的影響，有助於設計更合理的審稿機制，避免高聲譽作者獲得不公平優勢。對AI從業者而言，這關係到如何利用AI輔助審稿、評估模型偏差，以及在產品或系統中實施開放或盲審策略的風險管理。透過大規模實際審稿資料與AI模擬，能提供更具工程與實務參考價值的證據。

**Method:** 作者首先從OpenReview API收集ICLR 2026所有投稿資料，包括PDF、作者名單、評審意見與決定，並將作者與OpenAlex資料庫連結以取得五種聲譽代理指標（機構排名、h-index、引用數、發表數、i10-index）。根據arXiv預印本發布時間將投稿分為實質開放（預印本於審稿前發布）與盲審組。利用線性迴歸分析評分與作者聲譽的關係，並比較兩組斜率差異。為控制論文品質，採用五款先進AI模型對同一篇論文在不同聲譽條件下進行評分模擬，評估聲譽對評分的因果影響。實驗中變化輸入內容範圍與提示詞，檢驗結果穩健性。

**Result:** 分析顯示作者聲譽與評分正相關，且開放審稿組的評分對聲譽的敏感度顯著高於盲審組，尤其在決定接受與否的邊界評分區域差異最大。此趨勢在五種聲譽代理指標、三種作者聚合規則及多種開放窗口定義下均成立。AI模擬實驗中，五款模型中四款均呈現隨聲譽提升評分增加的現象，幅度介於0.2至0.6分，與觀察到的人類評審結果一致。模擬結果對輸入內容長短及提示詞變化均具穩健性。資料匹配規則與開放定義變化亦未改變主要結論。

**Conclusion:** 本研究證實在開放審稿機制下，作者聲譽對評分的影響較盲審更為顯著，且此影響主要集中於決策邊界的評分區間。透過大規模實際審稿資料與AI模擬雙重驗證，分離了內容品質與聲譽效應，強調匿名審稿能減少聲譽偏見。此結果對學術會議審稿制度設計及AI輔助審稿系統開發具有重要啟示。論文同時指出使用arXiv預印本作為開放標記的限制，並對聲譽代理指標的時效性與AI模型可能的預訓練資料污染進行討論。

**Research Gap:** 本研究以arXiv預印本時間作為開放審稿的代理，然而預印本發布非隨機，開放組作者整體聲譽較高，可能導致估計偏高，無法完全因果識別。聲譽代理指標多為事後收集，未能反映審稿當時的真實聲譽狀態。AI模擬雖控制內容不變，但模型評分範圍壓縮且與人類評分相關度有限，可能無法完全模擬人類審稿行為。論文未充分探討不同領域、不同會議或非頂級會議的泛化性，也缺乏對失敗案例或聲譽偏見負面影響的深入分析。此外，成本、部署風險及如何在實務中平衡透明度與公平性等工程層面議題未被詳細討論。

### 4. Autonomous Research for Open-Ended Problems: A Case Study on Telecom Ticket Retrieval

- 分數：4
- arXiv: [2609.13073](https://arxiv.org/abs/2609.13073)
- 發表日期：2026-09-14
- 分類：cs.AI
- 入選理由：+2 提及頂級機構：mit; +2 提及程式碼可用; LLM rank #4 / 7/10: Explores autonomous research on open-ended industrial ML problems with a real-world telecom case study, showing practical usefulness and balanced human-machine collaboration insights.

**Intro:** 本論文探討如何將自主研究系統應用於開放式、工業級的機器學習問題，具體以電信故障單檢索任務作為案例。過去自主研究多侷限於搜尋空間狹窄的任務，如語言模型或生物醫學基準，缺乏對更複雜任務的驗證。電信故障單檢索涉及多維度的設計自由度，包括資料表示、模型架構及訓練資料生成，具有高度開放性與挑戰性。論文旨在評估自主研究在此類問題上的效能、成本及限制。研究同時比較不同自主研究架構、語言模型代理及是否提供人類設計知識的影響。

**Motivation:** 隨著大型語言模型及其推理與編碼能力的突破，自主研究成為可能，能部分或完全取代人類在機器學習研究中的角色。然而，現有成功案例多限於固定資料及小搜尋空間的任務，缺乏對開放式工業問題的實證。電信故障單檢索是實際工業中重要且複雜的任務，涉及多種資料結構及系統設計選項，適合作為檢驗自主研究系統泛化能力的典範。理解自主研究在此類任務的表現與限制，有助於推動其在實務及研究落地的應用。

**Method:** 本研究採用兩種自主研究架構：單代理循環（基於Karpathy 2026）及多代理團隊（基於Gao et al. 2026），並比較三種LLM代理（Claude Sonnet 5、Cursor Composer 2.5及開源GPT-OSS 120B）。實驗中定義明確的任務與環境文件，並設計操作穩定性控制機制，包括明確的搜尋空間定義與外部腳本控制實驗迴圈。搜尋空間涵蓋資料表示、訓練資料生成及模型架構與超參數。代理在有限人類監督下，透過迭代提出實驗方案、執行並評估結果，目標最大化Recall@1指標。比較是否提供人類設計的先進技術資訊（如資料增強、重排名、模型集成）對結果的影響。

**Result:** 最佳自主研究模型為單一微調的MPNet檢索器，Recall@1達0.343，顯著優於BM25基線（0.072）、人類設計的單模型（0.200）及集成模型（0.251），但未超越內部複雜的SoTA系統（0.380）。不同架構（單代理或多代理）、代理類型及是否提供人類知識對最終性能影響有限。自主研究在狹窄的超參數優化表現良好，但缺乏人類直覺與創造力，未能嘗試重排名或資料增強等高階策略。成本方面，使用Cursor代理的10-20次實驗約需150-200美元API費用，運行時間約10週，遠低於人類約10個月的開發時間。多數代理需人類介入以解決運行中斷、資源利用不足等操作問題。

**Conclusion:** 本研究證實自主研究系統能在開放式工業任務中達到接近人類設計的先進模型性能，且大幅節省時間與成本。自主研究擅長系統化探索超參數與資料表示，但缺乏創新能力，無法自發實現複雜系統設計。建議未來機器學習研究可結合自主研究的系統化搜尋與人類研究者的直覺與創造力，以達最佳效益。操作層面仍需人類監督以維持系統穩定性。整體而言，自主研究對於加速工業級機器學習問題的解決具實用價值，但尚未達到完全自動化。

**Research Gap:** 本研究僅以單一工業任務及三種代理進行案例分析，泛化性尚待驗證。自主研究與人類研究的比較非嚴格對照，因代理依賴人類設計的基礎文件與監督，無法證明代理能獨立完成整個研究流程。實驗數量有限，難以明確分離架構、代理及知識提供的影響。代理未能嘗試高階系統設計改變，顯示其探索能力受限，且操作穩定性仍需人類介入。未評估研究過程的創新性、重現性及科學價值，僅以檢索性能與成本衡量。未明確說明代理在不同資料分布、任務目標或模型架構下的表現，未涵蓋失敗案例或長期部署風險。未探討如何提升代理的創造力與直覺能力，或降低操作監督需求。

### 5. Pelican-Sim 1.0: A General World Model Simulator for Embodied Intelligence

**Intro:** 本文提出Pelican-Sim 1.0，一款針對具身智能的通用世界模型模擬器，能根據視覺上下文與機器人動作預測未來觀察，支援後續學習與決策。該模擬器整合了統一的28維動作表示、基於URDF和相機渲染的動作視頻、稀疏專家混合模型（MoE）架構，以及高效的自回歸推理方法。訓練資料涵蓋約一百萬條真實與模擬軌跡，涵蓋多種機器人形態與任務場景。實驗在多個資料集上展示了優異的視覺質量與動作可控性，並驗證了其在資料生成、策略評估、動作選擇與策略改進等下游應用的有效性。

**Motivation:** 具身智能系統需在異構機器人與多變場景中準確預測動作結果，支援策略學習與決策。現有方法多依賴單一數值或視覺動作表示，難以兼顧精確配置與影像空間的動作幾何信息，且缺乏跨機器人形態的通用性。此外，模擬器計算成本高，限制了大規模推理與應用。Pelican-Sim 1.0旨在解決這些問題，通過結合數值與視覺動作條件、引入稀疏MoE提升動態建模能力，以及設計高效的推理流程，實現跨形態、跨場景的高質量模擬，促進工程與產品層面的落地。

**Method:** 核心方法包括：(1) 統一28維動作表示，涵蓋單臂與雙臂機器人，包含關節角度、夾爪開合與靈巧手狀態，確保跨異構機器人兼容；(2) 基於URDF與相機參數渲染動作視頻，將數值動作映射為影像空間的骨架運動，提供明確的幾何動作引導；(3) 使用Video Diffusion Transformer架構，交替注入數值動作調制與動作視頻殘差，並在Transformer層中引入稀疏MoE以提升對異質動態的建模能力；(4) 採用多階段因果蒸餾，將原始35步擴散過程壓縮至4步，實現約5.67倍推理加速，適合大量軌跡生成與決策應用。訓練資料涵蓋真實與模擬多源數據，並通過嚴格的質量篩選與視覺語言模型評估確保數據一致性。

**Result:** 在AgiBotWorld Beta、RoboMIND與RoboTwin三個資料集的測試集上，Pelican-Sim 1.0在PSNR、SSIM、LPIPS、FID與FVD等視覺質量指標均優於IRASim、Ctrl-World與EnerVerse-AC等基線，PSNR提升最高達10.343dB，FVD顯著降低。利用生成軌跡進行策略訓練，成功率從70%提升至93%。結合微調的視覺語言模型評估器，策略評估與排序達到Pearson相關係數0.994，動作選擇與策略改進分別帶來47.7%與20.3%的相對成功率提升。多維度的分布外泛化實驗展示了對軌跡反轉、場景變換、機器人形態替換、物體替換及視角變化的良好適應性。

**Conclusion:** Pelican-Sim 1.0通過結合統一數值動作與視覺動作視頻條件、稀疏MoE架構及高效推理策略，實現了跨異構機器人與多場景的高質量動作條件視頻生成。其生成的視覺結果不僅提升了模擬真實感，也有效支援了策略的數據增強、評估、選擇與改進，展現出作為通用世界模型模擬器的潛力。限制方面，全文未明確說明模型在更長時間尺度、極端動態或更複雜交互場景下的穩定性與泛化能力，且對計算資源需求與部署成本的詳細分析不足。未來工作將擴展訓練數據多樣性，深入研究因果蒸餾的質效權衡，並建立更嚴謹的泛化評估標準。

**Research Gap:** 本文雖展示了多維度泛化能力，但缺乏對極端動態場景、長時間尺度預測及複雜物理交互的系統性驗證。實驗主要基於固定視角與有限物理屬性變化，對於真實世界中感知噪聲、動作誤差及非理想條件下的魯棒性未充分探討。稀疏MoE與雙分支條件結構的計算成本與推理延遲未有詳細量化，可能影響實際部署。下游應用中，策略改進依賴視覺語言模型評估，該評估器的泛化能力與誤判風險未明確說明。此外，消融實驗雖涵蓋多個設計要素，但對於不同動作維度與視頻解析度的敏感性分析不足，限制了對模型設計選擇的深入理解。未來需針對這些方面進行更全面的實驗與分析。
